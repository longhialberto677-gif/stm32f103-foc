## 第一部分：先搞清楚"开关放在哪里"这件事

### 1.1 电路是一个圈，不是一根线

初学者最容易犯的错：以为电流从电源出发、经过负载、就"用完了"。

**其实电流必须走一个完整的圈（回路），回到电源：**

```
   电源 + ────→ 电流流出去 ────→ 负载 ────→ 电流流回来 ────→ 电源 −
     +12V                                                      GND
```

**中间任何一处断开，整个圈就断了，没有电流。**

> **这就是"开关"的作用：它不消耗电流，它只是"圈上的一个断点"。**

### 1.2 用水管类比

把电路想成水管：

```
   水泵出口 ────[阀门]──── 水轮机 ────→ 回到水池
   (12V)                                 (0V/GND)
```

- **水轮机** = 负载（电机、灯泡、加热丝）
- **阀门** = 开关（MOS 管/三极管）
- **水压** = 电压
- **水流** = 电流

**现在关键问题来了：这个阀门，装在"水轮机前面"还是"水轮机后面"？**

```
方案 A（高边）：  水泵 ──[阀门]── 水轮机 ── 水池
                        ↑ 阀门在负载"上游"

方案 B（低边）：  水泵 ── 水轮机 ──[阀门]── 水池
                                    ↑ 阀门在负载"下游"
```

**这两种都能控制水轮机转不转！** 但它们的**后果不一样**。这就是"高边/低边"要讨论的全部内容。

## 第二部分：高边 / 低边的定义

### 2.1 一句话定义

> **高边开关（High-Side）：开关接在"电源正极"和"负载"之间。**
> **低边开关（Low-Side）：开关接在"负载"和"地"之间。**

```
【高边】  +12V ──[开关]── 负载 ── GND
                    ↑
                这里叫"高边"（靠近电源正极的那一侧，电位高）

【低边】  +12V ── 负载 ──[开关]── GND
                            ↑
                        这里叫"低边"（靠近地的那一侧，电位低）
```

**"高"和"低"指的是这个位置在电路里的电位高低**：靠近 +12V 的叫"高边"，靠近 0V 的叫"低边"。

### 2.2 一个非常重要的区别：关断之后，负载上还有没有电？

这是高边/低边**最实质的区别**，很多人学完都没注意到：

```
【高边关断】  +12V ──╳── 负载 ── GND
                          ↑
                   负载两端都是 0V（通过负载自己连到地）
                   → 负载"完全没电" ✅ 安全

【低边关断】  +12V ──── 负载 ──╳── GND
                          ↑
                   负载上端仍然是 +12V！
                   → 负载"一端还带着 12V" ⚠️ 有隐患
```

**低边开关关断时，负载的一端仍然带电！**

**这在实际中意味着什么？**

| 场景 | 低边关断后的后果 |
|---|---|
| 你想去摸一下电机接线 | **电机端子上还有 12V**，碰到地就短路/触电 ⚠️ |
| 电路要"完全断电"检修 | **做不到**，还得拔总开关 |
| 电机被外力拖动（比如用手转） | **危险！** 电机会变成发电机，从相线往外送电 |

> 💡 **这就是为什么"整机总开关"（你家电器上的电源开关）几乎都是高边开关**——因为关掉之后，后面的东西要真正没电。
>
> **这也解释了你的板子**：「电源电路」里那个 Q6/Q7 的背靠背 P-MOS 就是**高边开关**（它接在 +12V 和后面的所有电路之间）。关掉它，整个板子真正断电。

### 2.3 那为什么还要用低边？

因为**低边好驱动**（下面第三部分讲），而且很多场合不需要"完全断电"。**两个方案是权衡，不是谁绝对更好。**

## 第三部分：⭐ 为什么"低边用 N 型，高边用 P 型"？

这是本节最核心的推理，我慢慢来。

### 3.1 先纠正一个误解

新手常以为：**"我给栅极 10V，MOS 就导通。"**

**错！** MOS 管的导通条件看的是：

> **Vgs = 栅极电压 − 源极电压**

**是"栅极相对源极"的电压差，不是"栅极对地"的电压。**

**这是整个问题的钥匙。** 记住这句话，下面全都通了。

### 3.2 水龙头类比（升级版）

把 MOS 管想成一个**特殊的水龙头**：

- 它的手柄不是"转到某个绝对位置就开水"
- 而是 **"手柄要比起出水口高出一大截，水才流"**

**出水口在哪里，决定了手柄要举多高。**

### 3.3 现在推理：低边为什么用 N 型？

**低边接法**：MOS 的**源极接 GND（0V）**，负载在它上面。

```
   +12V
     │
   负载 (电机)
     │
     ├──── D (漏极)  ← 电流从这里进
   [N-MOS]
     ├──── S (源极)  ← 电流从这里出，接到 GND = 0V
     │
    GND
     ↑
   源极永远在 0V
```

**源极固定在 0V**，所以：

```
栅极给 10V  →  Vgs = 10V − 0V = +10V  →  导通 ✅
栅极给 0V   →  Vgs = 0V − 0V  = 0V    →  断开 ✅
```

**太简单了！栅极给 10V 就开，给 0V 就关。** 而且 **10V 这个电压很容易得到**（板子上就有 +12V，随便分一下就行）。

### 3.4 现在推理：高边如果也用 N 型，会怎样？

**高边接法**：MOS 在负载**上面**，源极接**负载**（不是接地）。

```
   +12V
     │
     ├──── D (漏极)
   [N-MOS]
     ├──── S (源极)  ← 这个点接负载，而负载另一端接地
     │
   负载 (电机)
     │
    GND
```

**MOS 导通后，源极的电位会是多少？** 因为源极通过负载连着地，导通后源极 ≈ **12V**（几乎等于电源电压，因为 MOS 导通电阻很小）。

**那么现在要让 MOS 导通，栅极要给多少？**

```
要满足 Vgs > 0（N 型），即 Vg − Vs > 0
   Vs ≈ 12V
   所以 Vg 必须 > 12V
   实际要 Vgs = 10V 才能完全导通（Vgs(th) 只是"开始导通"）
   → 栅极需要 12V + 10V = 22V ！
```

**问题来了：你手上只有 12V。栅极给不出 22V。**

**栅极给 12V 会怎样？** `Vgs = 12V − 12V = 0V` → **完全不导通** ❌

**栅极给 5V？** `Vgs = 5 − 12 = −7V` → **反而更截止了** ❌

> 💡 **结论：N-MOS 放在高边，需要"比电源还高的电压"来驱动。这就是根本困难。**

### 3.5 那高边怎么办？两个办法

**办法一：改用 P 型**

P 型的导通条件是 **Vgs < 0**（栅极低于源极）。高边时源极接电源（12V），所以：

```
栅极给 0V   →  Vgs = 0 − 12 = −12V < 0  →  导通 ✅
栅极给 12V  →  Vgs = 12 − 12 = 0V       →  断开 ✅
```

**漂亮！栅极拉到地就开，拉到电源就关。** 完全不需要额外的电源。

> **你的板子：「电源电路」里的 Q6/Q7（NCE30P12S）就是 P-MOS，用来做高边总开关。**

**办法二：还用 N 型，但想办法造出"比电源高的电压"**

这就是**自举电路**（第 4 课讲）。思路是：用一个电容"存"10V，让它的"地板"跟着源极一起浮动，这样电容上端就自动比源极高出 10V。

```
   +12V ──|>|──┬── VB (电容上端 = 会自动浮高的那一端)
               │
              [C]  ← 电容里存着 10.5V
               │
   负载/相线 ──┴── VS (电容下端 = 跟着源极一起跳的"地板")
```

**为什么电机桥的上管非要用 N 型（而不是直接用 P 型图省事）？**

因为**上管每秒要开关上万次**，导通损耗极其关键：
- N-MOS 的 RDS(on) ≈ P-MOS 的 **1/3** → 发热只有 1/3
- 十几安培的电流下，这个差别就是"能用"和"烧管"的区别

**所以只能忍受复杂度，用自举。这笔交易划算。**

### 3.6 小结这张推理表

| 位置 | 源极电位 | 用 N 型 | 用 P 型 |
|---|---|---|---|
| **低边** | 固定在 0V | **栅极给 10V** ✅ 简单 | 栅极要给 −10V ❌ 麻烦 |
| **高边** | 跟着电源浮动 | 栅极要给 **22V** ❌ 困难（要自举） | **栅极拉低就通** ✅ 简单 |

> **一句话记住：**
> **N 型的源极喜欢接地 → 做低边。
> P 型的源极喜欢接电源 → 做高边。
> 如果高边非要用 N 型，就得加自举。**

## 第四部分：四种经典接法，逐个拆解

我统一用**五步分析法**来讲每种接法（这个框架你可以套用到任何电路）：

1. **开关在哪边**（高边/低边）
2. **器件是什么型**（N/P）
3. **导通条件是什么**（栅极要给多少）
4. **关断时负载还带电吗**
5. **优缺点 / 用在哪**

---

### 接法一：低边 N-MOS（最简单、最常见）

#### 电路图

```
        +12V
          │
       ┌──┴──┐
       │负载 │  (电机/灯/加热丝)
       └──┬──┘
          │
          ├───────── D (漏极)
          │
       [N-MOS]
          │
          ├───────── S (源极) ────── GND
          │
          └── G (栅极) ←── 控制信号
                │
             [10kΩ]  ← 下拉电阻，保证默认关断
                │
              GND
```

#### 五步分析

| 步骤 | 分析 |
|---|---|
| ① 开关在哪 | **低边**（在负载下方） |
| ② 器件 | **N-MOS** |
| ③ 导通条件 | 栅极给 **10V**（因为源极 = 0V，Vgs = 10V）✅ 容易 |
| ④ 关断后 | **负载上端仍然是 +12V** ⚠️ |
| ⑤ 优缺点 | ✅ 驱动极简单（MCU 加个驱动芯片就行）<br>✅ 源极接地，散热好（可以直接把散热片接机壳地）<br>❌ 负载一端带电<br>❌ 负载不能接成"共地"结构 |

#### 工作过程（数字说话）

```
栅极 = 10V  →  Vgs = 10 − 0 = +10V  →  MOS 导通
              →  漏极到源极像一根几毫欧的导线
              →  电流：+12V → 负载 → 漏极 → 源极 → GND
              →  负载得电 ✅

栅极 = 0V   →  Vgs = 0 − 0 = 0V  →  MOS 截止
              →  漏极和源极之间断开（相当于开关断开）
              →  回路断了，没有电流
              →  负载失电，但它的上端仍然接着 +12V ⚠️
```

#### 你板子上的位置

> **三相桥的 3 个下管（Q2 / Q4 / Q6），每相下管源极经采样电阻接 PGND，就是标准的低边 N-MOS。**

### 接法二：高边 P-MOS（控制简单，但损耗大）

#### 电路图

```
        +12V
          │
          ├───────── S (源极)   ← 注意：源极接电源！
          │
       [P-MOS]
          │
          ├───────── D (漏极)
          │
       ┌──┴──┐
       │负载 │
       └──┬──┘
          │
         GND
          ↑
     G (栅极) ←── 控制信号
          │
       [10kΩ] ── 接在栅极和源极之间（不是接地！）
```

#### 五步分析

| 步骤 | 分析 |
|---|---|
| ① 开关在哪 | **高边** |
| ② 器件 | **P-MOS**（源极接电源） |
| ③ 导通条件 | 栅极**拉到 0V** → Vgs = −12V ✅ 容易（比 N 型高边容易得多） |
| ④ 关断后 | **负载两端都是 0V，真正没电** ✅ 安全 |
| ⑤ 优缺点 | ✅ 控制简单，不需要额外电源<br>✅ 关断后负载完全断电<br>❌ **P-MOS 的 RDS(on) 大（同规格约 N 型的 3 倍）→ 大电流发热严重**<br>❌ 贵 |

#### ⚠️ 特别提醒：栅源下拉电阻要接对地方

注意看图上 P-MOS 的下拉电阻是**接在栅极和源极之间**，**不是接到地**！

为什么？回顾：**MOS 的导通条件看的是 Vgs（相对源极）**。

- **接在栅极—源极之间**（R39 = 2.2kΩ）→ 关断时 Vgs = 0V → 可靠截止 ✅
- **如果错接成栅极—地**（10kΩ 到 GND）→ 关断时 Vgs = 0 − 12 = **−12V** → **MOS 一直导通！永远关不掉** ❌❌

> **这是一个真实的高频错误。记法：下拉电阻永远接在"栅极和源极之间"，因为 MOS 看的就是这两点之间的电压。**

#### 你板子上的位置

> **「电源电路」的 Q6 + Q7（NCE30P12S），两个 P-MOS 背靠背做总开关（第 1 课讲过为什么要两个）。**

### 接法三：高边 N-MOS + 自举（难，但电机桥必须用）

#### 电路图

```
        +12V ──┬──────────────┐
               │              │
               │         ┌────┴────┐
               │         │  D1 自举 │
               │         │  二极管  │
               │         └────┬────┘
               │              │ VB
               │            ┌─┴─┐
               │            │ C │ 自举电容 (100nF)
               │            └─┬─┘
               │              │
               ├──────────────┴── D (漏极)
               │
            [N-MOS]  ← 上管
               │
               ├── S (源极) ──┬────→ 电机相线 (M_U)
               │              │
               │              └────→ VS (接回自举电容下端)
               │
   （下方是下管和采样电阻，构成完整半桥）
```

#### 五步分析

| 步骤 | 分析 |
|---|---|
| ① 开关在哪 | **高边** |
| ② 器件 | **N-MOS** + 自举电路 |
| ③ 导通条件 | 栅极要给 **源极 + 10V**（即约 22V），靠自举电容提供 |
| ④ 关断后 | 负载两端都 0V ✅ 安全 |
| ⑤ 优缺点 | ✅ **RDS(on) 小，损耗低，大电流不发热** ← 电机桥必须的理由<br>✅ 高边开关的共同优点：关断后负载真断电<br>❌ 需要自举电路（多了二极管+电容）<br>❌ **占空比不能到 100%**（否则自举电容没机会充电）<br>❌ 调试更复杂 |

#### 自举是怎么"凭空造出"22V 的？

**核心思路：电容两端的电压差不会突变。**

```
【第一步：下管导通时，给电容充电】
   相线被下管拉到 ~0V  →  自举电容的"下端(VS)" ≈ 0V
   +12V 经 D1 给电容充电  →  电容上端(VB) ≈ 10.5V (12V 减二极管压降)
   
   此时：电容两端电压差 = 10.5V ✅ 充好了

【第二步：下管关断、上管导通】
   相线电压升到 ~12V  →  电容"下端(VS)"被抬到 12V
   电容两端电压差仍然是 10.5V（电容特性：电荷不变）
   →  电容"上端(VB)"自动变 = 12V + 10.5V = 22.5V ✅
   
   此时：栅极拿到 22.5V，源极 12V  →  Vgs = 10.5V  →  完美导通 ✅
```

**用"水桶垫高"理解**：你要给二楼送水，就在二楼放个水桶（电容），趁没人时从一楼打水上去。用的时候，桶里的水自然比一楼高。

> 💡 **所以占空比不能到 100%**：如果上管一直开着，下管永远不导通 → 水桶再也没机会打水 → 电容慢慢漏电 → 上管掉电 → 炸管。

#### 你板子上的位置

> **三相桥上管 Q1/Q3/Q5 + 自举二极管 D1/D2/D3（FR107）+ 自举电容 C3/C4/C5（100nF）。**

### 接法四：低边 NPN 三极管（小信号开关）

#### 电路图

```
        +3.3V
          │
       ┌──┴──┐
       │ LED │  (负载，也可以是继电器、蜂鸣器)
       └──┬──┘
          │
          ├───────── C (集电极)
          │
       [NPN]
          │
          ├───────── E (发射极) ────── GND
          │
          └── B (基极) ←──[1kΩ 限流电阻]←── MCU 引脚
```

#### 五步分析

| 步骤 | 分析 |
|---|---|
| ① 开关在哪 | **低边** |
| ② 器件 | **NPN 三极管** |
| ③ 导通条件 | 基极有**电流流入**（约 1~3mA），不是电压！ |
| ④ 关断后 | 负载上端仍带电 ⚠️ |
| ⑤ 优缺点 | ✅ 便宜、小电流够用<br>✅ MCU 引脚能直接驱动（加个限流电阻就行）<br>❌ 只适合小电流（几百 mA 以内）<br>❌ 大电流时饱和压降 0.3V 也会发热 |

#### 为什么需要那颗 1kΩ 电阻？（重点）

**三极管的 B-E 之间相当于一个 PN 结（就是一个二极管），正向压降约 0.7V。**

```
不加电阻：
   MCU 输出 3.3V → B-E 结直接承受 3.3V
   而 B-E 结只需要 0.7V 就导通 → 剩下 2.6V 加在"极小的内阻"上
   → 电流 = 2.6V / 极小内阻 = 可能几百 mA 到几安培
   → 烧掉三极管 或 烧掉 MCU 引脚 ❌❌

加 1kΩ 电阻：
   电流 = (3.3V − 0.7V) / 1kΩ ≈ 2.6mA  →  安全 ✅
   而 2.6mA 的基极电流足以让三极管完全导通，驱动几十 mA 的负载 ✅
```

> **为什么 2.6mA 能控制几十 mA？** 因为三极管有"电流放大"作用：`集电极电流 ≈ 基极电流 × β`（β 通常 100 以上）。2.6mA × 100 = 260mA。**这就是"以小控大"。**

#### 你板子上的位置

> **「外设电路」里驱动 LCD 背光的 Q3，R14 = 1kΩ 就是这颗基极限流电阻。**
>
> **为什么要用三极管而不是直接让 MCU 驱动？** 背光 LED 要几十 mA，**超过 STM32 单引脚 20mA 的上限**。用三极管"以小控大"。

## 第六部分：常问的 5 个问题

**Q1：为什么不能全用低边？反正能控制通断就行。**

三个原因：
1. **低边关断后负载还带电**——整机总开关必须高边，否则"关了还带电"很危险
2. **低边要求负载一端接地**——但很多负载必须直接接电源（比如三相桥的电机，它的三相必须接到桥臂中点，上管必须是高边）
3. **三相桥是"半桥"结构**：上管高边 + 下管低边，缺一不可。这是电机驱动的基本拓扑

**Q2：那为什么不全用高边 P-MOS？控制多简单。**

因为 **P-MOS 的 RDS(on) 是同规格 N-MOS 的约 3 倍**：
- 电机相电流 10A 时，N-MOS（5mΩ）损耗 0.5W，P-MOS（15mΩ）损耗 1.5W
- 三相桥有 6 个管子，每秒开关上万次，**多出来的发热会累计成"烧管"**
- 所以：**只在"开关频率低、电流不大"的场合（如总开关）才用 P-MOS**

**Q3：自举电容那么小（100nF），怎么能驱动那么大的 MOS？**

因为**栅极只需要"电压"，不需要持续电流**（第 0 课讲的：MOS 是电压控制器件）。100nF 存的是电荷，而上管导通期间栅极几乎不耗电（只有极小的漏电），所以一小桶水足够喝。

**Q4："栅极给 10V"——这个 10V 是相对谁说的？**

**永远相对源极。** 这就是为什么：
- 低边（源极接地）：栅极给 10V 就行
- 高边（源极浮动）：栅极要跟着源极一起抬到 22V

**永远用 Vgs（栅极−源极）来判断，不要用"栅极对地"。**

**Q5：为什么低边 N-MOS 的散热好？**

因为低边的**源极直接接 GND**，而 MOS 的散热焊盘（PowerPAD）通常和漏极相连。在低边接法里，你可以把散热铜箔大面积接到地平面上——**地平面就是最好的散热器**（整块板都是铜）。

而高边接法时源极/漏极在浮动电位上，散热铜箔不能随便接大面积地，散热设计要更小心。

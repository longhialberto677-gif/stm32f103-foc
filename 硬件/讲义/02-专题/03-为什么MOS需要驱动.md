# 专题：为什么 MOS 需要驱动

> 难度 🟡。这个专题回答一个问题：**为什么三极管 IO 直推就行，MOS 却要专门加一颗驱动芯片？**

---

## 先纠正一个绝对化的说法

**不是"MOS 一律必须加驱动"，而是分情况：**

| 场景 | 能不能 IO 直驱 |
|---|---|
| 小电流（<1A）、低频、用**逻辑电平 MOS** | ✅ **能，不加驱动也行** |
| 大电流、每秒开关上万次、**标准功率 MOS** | ❌ **必须加驱动** |

**本板是后一种。**

---

## 一、根本差别：MOS 看的是 Vgs

```
三极管 = 电流控制 → IO 给 0.7V + 一点电流 就能开 → 门槛低 ✅
MOS 管 = 电压控制 → 栅极要够高的 Vgs 才能开      → 门槛高 ❌
```

**但"够高"是多高？很多人以为 `Vgs(th) = 2V` 就是答案 —— 这是个陷阱。**

### 陷阱：Vgs(th) 只是"刚开始漏一点电"

```
Vgs(th) 的官方定义：漏极电流达到 250µA 时的 Vgs
                                    ↑
                        250 微安！不是 250 安培
```

**换句话说：`Vgs(th) = 2V` 的意思是"给它 2V，它能漏 0.25mA"。**
**而你要的是 20A。差 8 万倍。这根本不是一个工作点。**

### 真正的判据：RDS(on) 标在哪个 Vgs 下

```
RDS(on) = 5mΩ  @ Vgs = 10V     ← 厂家承诺的"完全导通"
RDS(on) = 8mΩ  @ Vgs = 4.5V    ← 降额了（只有逻辑电平 MOS 才有这一行）
RDS(on) = ???  @ Vgs = 3.3V    ← 通常根本没有这一行
```

> **"完全导通"的定义是"RDS(on) 足够小"，而它只在 Vgs = 10V（或 4.5V）时才成立。**
> **3.3V 不在这个范围内 → MOS 处于半开 → 它就是个电炉丝。**

---

## 二、算一笔账：3.3V 直驱有多惨

```
电机电流 I = 10A

【理想：Vgs = 10V，RDS(on) = 5mΩ】
   导通损耗 = I² × R = 100 × 0.005 = 0.5W   ✅ 可以接受

【3.3V 直驱：RDS(on) 可能只有 50mΩ】
   导通损耗 = 100 × 0.05 = 5W               ❌ 一颗几毫米的管子散 5W

【更糟：RDS(on) 到 200mΩ（3.3V 下很常见）】
   导通损耗 = 100 × 0.2 = 20W               ❌❌ 几秒钟冒烟
```

> **这不是"效率低一点"，而是"根本不能用"。**

---

## 三、第二个理由：栅极是"电容"，IO 充不动

```
必须充入的电荷量 = Qg（栅极总电荷）
一颗 30V 功率 MOS：Qg 约 10~30nC

想在 100ns 内充完 20nC：
   I = 20nC / 100ns = 【200mA 峰值】
而 STM32 单脚最多约 20mA → 差 10 倍

用 20mA 慢慢充：
   IO 内阻约 50Ω，栅极电容约 5nF
   充电时间常数 τ = 50Ω × 5nF = 250ns
   充到 10V 约需 5τ ≈ 【1.25µs】
```

### 慢会怎样？开关损耗立刻爆炸

```
开关一次的损耗 ≈ ½ × Vds × Id × t_开关

Vds = 12V，Id = 20A（峰值）
【开关过程 1µs（IO 慢充）】
   单次损耗 = ½ × 12 × 20 × 1µs = 120µJ
   PWM 20kHz → 平均损耗 = 120µJ × 20000 = 2.4W 每颗管子 ❌

【开关过程 100ns（驱动芯片快充）】
   单次损耗 = 12µJ → 平均损耗 = 0.24W  ✅
```

> **开关速度提升 10 倍 → 开关损耗降低 10 倍。**

### 更危险的后果：直通

死区时间是固定的。**如果 MOS 关断太慢，上管还没关断、下管就导通了** → 上下管同时导通 → **+12V 直接短路到地** → 瞬间几十安培 → **炸管**。

> **所以关断必须快，这不是"效率优化"，是"安全必需"。**

---

## 四、第三个理由：高边 MOS 的"浮动栅极"

**三相桥的上管**，源极接在电机相线上（电压在 0V~12V 之间跳）：

```
当源极 = 0V  → 栅极要 10V
当源极 = 12V → 栅极要 22V   ← 你根本没有 22V 这个电源
```

**IO 只能输出 3.3V，连 10V 都给不出，更别说是"跟着源极浮动的 22V"。**

解决靠**自举电容**。而**自举电路本身就是驱动芯片内部的一部分**。

---

## 五、驱动芯片在干什么（三件事）

以本板的 FD6288T 为例：

| 驱动芯片干的事 | 不用驱动会怎样 |
|---|---|
| **① 电流放大**：3.3V 逻辑输入 → 1.8A 峰值输出 | IO 只有 20mA，充电慢 10 倍 → 开关损耗爆炸 |
| **② 电平转换**：3.3V 逻辑 → 12V 栅极电压 | 栅极只有 3.3V → MOS 半开 → 5~20W 发热烧管 |
| **③ 硬件死区 + 自举** | 直通炸管；上管根本打不开 |
| **④ 替 MCU 挡子弹** | 驱动芯片坏了换一颗；MCU 坏了整块板报废 |

---

## 六、怎么判断"要不要加驱动"？决策清单

**问自己 5 个问题，任何一个答"是" → 加驱动：**

| # | 问题 | 如果是 |
|---|---|---|
| 1 | **电流 > 1A？** | 加驱动（RDS(on) 要求 Vgs=10V） |
| 2 | **PWM 频率 > 1kHz？** | 加驱动（开关损耗会累积） |
| 3 | **母线电压 > 5V？** | 加驱动（要给 10V 栅压） |
| 4 | **是高边开关？** | 必须加（需要自举/电平转换） |
| 5 | **是标准功率 MOS（RDS(on) 标 @10V）？** | 必须加 |

**5 个问题全是"否" → 有可能直驱，但必须满足：**

| 条件 | 说明 |
|---|---|
| **用"逻辑电平 MOS"** | 型号里带 **L** 的，如 `IRLZ44N`、`AO3400`、`SI2302`（RDS(on) 明确标 @4.5V 或 @2.5V） |
| **电流 ≤ 1A 左右** | 因为 3.3V 下 RDS(on) 还是比 10V 时大好几倍 |

**三档方案：**

| 方案 | 器件 | 适用 | 成本 |
|---|---|---|---|
| **① IO 直驱** | 逻辑电平 MOS（带 L） | 电流 <1A、低频、低边 | 0 元 |
| **② 单路驱动芯片** | UCC27517 / TC4427 | 单颗 MOS、需要快点开关 | 几毛~几块 |
| **③ 三相驱动芯片** | **FD6288T**（本板） | 三相桥、需要自举+死区 | 集成 6 路 |

## 七、三极管 vs 标准功率 MOS

| | 三极管 | 标准功率 MOS |
|---|---|---|
| 控制方式 | 电流（几 mA） | **电压（Vgs ≥ 10V）** |
| IO 的 3.3V 够不够 | ✅ **够**（B-E 只要 0.7V） | ❌ **不够**（要 10V） |
| IO 的 20mA 够不够 | ✅ **够** | ❌ **不够**（栅极要 200mA 峰值） |
| 需要额外芯片吗 | ❌ 不需要 | ✅ **需要驱动芯片** |
| 本板上的例子 | 背光 Q3 | 电机 Q1~Q6 + FD6288T |

> **一句话：**
> **三极管是"低门槛"器件 —— IO 拍一下肩膀它就干活。**
> **功率 MOS 是"高门槛"器件 —— IO 喊不动它，得雇个"翻译 + 大力士"（驱动芯片）：翻译电平（3.3V→12V），大力士出力（1.8A 踹开栅极）。**

## 八、补充：一颗三极管能替代驱动芯片吗？

**不能。** 分两种情况：

### 低边：一颗三极管 + 电阻 —— 能导通，但太慢

```
        +12V
          │
        [R 上拉]
          │
          ├────── MOS 栅极
        [NPN]（栅极被拉低时关断）
          B ←──[R_b]── IO
          E ──── GND
```

**开通靠上拉电阻给栅极充电：**

```
τ = 1kΩ × 5nF = 5µs → 充到 10V 约 10~15µs
PWM 周期才 50µs（20kHz）→ 开通过程占了 20~30%！

单次开通损耗 ≈ ½ × 12V × 20A × 10µs = 1200µJ
每秒损耗 = 1200µJ × 20000 × 2 = 【48W】 ❌❌
```

**改小上拉电阻呢？** 100Ω →

```
开通快了（约 1.5µs，损耗降到约 7W），但新问题：
MOS 关断时 NPN 导通，+12V 经 100Ω 直接接地
→ 静态电流 = 12V / 100Ω = 120mA
→ 电阻上白烧 1.44W（一直烧着）
```

> **这就是"上拉电阻驱动"的死结：想要快 → 电阻必须小 → 关断时白烧大电流。**

### 所以必须用"推挽"结构（两颗管子）

```
                +12V
                  │ E
               [PNP]  ← 负责"拉高"（开通）
                  C
                  ├──────── MOS 栅极
                  C
               [NPN]  ← 负责"拉低"（关断）
                  E
                 GND
```

**一颗三极管只能"单方向"动作；而 MOS 栅极需要"被拉高"和"被拉低"两个动作，而且都要快 → 至少两颗。**

### 高边：一颗三极管连导通都做不到

```
上管栅极需要"源极 + 10V"
当源极 = 12V 时 → 栅极需要 22V
三极管不是变压器、不是电荷泵 → 【它产生不了 22V】
→ 必须配自举电路
```

### 三相桥总共要多少元件？

| 部分 | 三相合计 |
|---|---|
| 上管推挽驱动 | 12 个 |
| 下管推挽驱动 | 12 个 |
| 自举（二极管 + 电容） | 6 个 |
| 栅极网络 | 18 个 |
| 死区相关 | 6~12 个 |
| **合计** | **约 50~60 个元件** |

**而一颗 FD6288T（TSSOP-20）就全包了。**

> **结论：不是"做不到"，而是"不值得"。**
> **50 多个元件焊错一个就炸管，而 FD6288T 把这些都封装好了，还自带死区保护。**
>
> **有意思的是：FD6288T 内部就是用一堆 MOS/三极管搭的推挽驱动级。**
> **你花的钱买的不是"新原理"，而是"别人已经调好的、参数一致的、带保护的实现"。**

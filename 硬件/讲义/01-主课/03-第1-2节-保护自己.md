# 第 1-2 节：怎么保护自己（保险丝 + TVS）

> 难度 🟢 轻松。这一节解决两个很实际的问题。

---

## 第 1 步：先看第一个问题 —— 短路

### 场景：一秒钟的失误

设想这样的场景：

```
你不小心，让一根镊子（或者一根散落的电线）同时碰到了 +12V 和地。
   ↓
+12V 和 GND 之间只剩下一根镊子的电阻 —— 大概 0.01Ω
   ↓
电流 = 12V / 0.01Ω = 【1200 安培】
```

**1200 安培。** 一块动力电池能吐出几百安培，它会毫不犹豫地吐出来。

```
结果：
• 镊子瞬间烧红、熔化，金属飞溅
• 电池温度飙升 → 可能鼓包、起火
• 板子上的走线被烧断
• 整个过程不到 1 秒
```

**所以第一个问题：我需要一个东西，在电流异常大时自动把电路断开。**

---

## 第 2 步：所以需要什么？

**需要"过流保护"。** 最直白的办法就是**在电流的必经之路上装一个"闸门"**：

```
电池 → [闸门] → 板子
```

- 电流正常 → 闸门开着，电正常过
- 电流太大 → 闸门自己关上，电过不去

**但这里有个新的选择：关上之后，要不要能"自己打开"？**

| 方案 | 关上之后 |
|---|---|
| **不可恢复**（普通保险丝） | 熔断了，报废了，要换新的 |
| **可恢复**（自恢复保险丝） | 故障排除了，它自己恢复 |

**对你这种"学习和调试用"的板子，显然应该选"可恢复"。**

---

## 第 3 步：于是有了 F2 —— 自恢复保险丝

### 3.1 它是什么

**F2 = BSMD1812-xxx-12V**（具体保持电流见下面分析）

| 型号中的部分 | 含义 |
|---|---|
| `1812` | **封装尺寸**：4.5 × 3.2 mm 的贴片 |
| `xxx` | **保持电流**（比如 300 = 3.0A，800 = 8.0A） |
| `12V` | **额定电压 12V** |

学名叫做 **PPTC**（高分子正温度系数热敏电阻）。

### 3.2 它怎么工作

想象它内部是**很多微小的导电颗粒，被"粘"在一起形成一条导电链**：

```
【正常状态】
   导电颗粒紧紧挨着 → 形成畅通的通道 → 电阻很小（几毫欧）
   → 电流顺利通过 ✅

【电流过大时】
   电流大 → 发热多 → 温度升高
   → 内部高分子材料【受热膨胀】
   → 颗粒被"撑开"，导电链断开
   → 电阻从几毫欧【暴涨到几百千欧】
   → 电流被限制到几毫安 → 后面的电路安全了 ✅

【故障排除、温度降下来】
   → 材料收缩 → 颗粒重新挨上 → 导电链恢复
   → 电路自动恢复正常 ✅
```

> **核心原理一句话：靠"热"工作。电流大 → 热 → 材料膨胀 → 断开；冷却 → 收缩 → 恢复。**

### 3.3 它和普通保险丝的区别

| | 普通玻璃管保险丝 | **PPTC 自恢复保险丝** |
|---|---|---|
| 内部是什么 | 一根细金属丝 | 高分子材料 + 导电颗粒 |
| 触发原理 | **电流烧断金属丝** | **受热膨胀，撑开导电链** |
| 触发后 | **永久熔断** | **只是"断开"，没有损坏** |
| 要不要换 | **必须焊新的** | **不用，自己恢复** |
| 响应速度 | 很快（毫秒级） | 稍慢（几十 ms ~ 几秒） |

### 3.4 选型要看"三个数字"

| 参数 | 含义 | 怎么定 |
|---|---|---|
| **I_hold 保持电流** | 低于它永远不断开 | 要 **> 最大正常工作电流**（留 2~4 倍余量） |
| **I_trip 触发电流** | 高于它一定断开 | 通常 ≈ **2 × I_hold** |
| **环境温度** | 会降低保持电流 | 25°C 标称 100%，**60°C 只剩约 70%** |

### 3.5 两个必须知道的局限

**局限 1：响应比较慢**

```
PPTC 从"检测到过流"到"完全断开"，可能需要几十毫秒到几秒。
在这段时间里，电流仍然在流。
```

**局限 2：它不能替代"真正的过流保护"**

```
PPTC 保护的是：防止【起火、烧板子】这类灾难
PPTC 不保护的是：它不能保护 MOS 管！

因为 MOS 管的耐受能力是【微秒级】的。
电机堵转时电流可能瞬间冲到几十安培，
在 PPTC 反应过来之前，MOS 管已经烧了。
```

> **真正保护 MOS 管的是"另一套机制"：检测到过流 → 立刻关掉 PWM（微秒级）。**
> **PPTC 的角色是"最后一道防火灾底线"，不是"MOS 的保镖"。**

---

## 第 4 步：第二个问题 —— 电压尖峰

### 场景：电机这个"电感"

**问题出在电机身上 —— 因为电机是"电感"。**

电感有一个脾气：

> **电感"不允许电流突变"。电流想突然变小，它就会拼命反抗，反抗的方式是把电压抬得极高。**

```
电机正在高速运转，电流是 5A
   ↓
突然，MOS 管关断了（PWM 的一个周期结束）
   ↓
电流想从 5A 立刻变成 0 —— 但电感不答应！
   ↓
电感产生一个【反向高压】来"维持电流"
   ↓
这个电压可能达到几十伏、甚至上百伏
   ↓
它顺着电线【回灌到 12V 母线上】
   ↓
所有接在 12V 上的芯片都在承受这个高压 → 【击穿】
```

**另外还有两个会产生尖峰的场景：**

| 场景 | 尖峰怎么来的 |
|---|---|
| **插拔电池时打火** | 插头接触的瞬间会跳火花，产生几十伏的高频尖峰 |
| **长导线耦合干扰** | 电源线像天线，会接收环境里的电磁干扰 |

---

## 第 5 步：于是有了 D9 —— 双向 TVS 二极管

### 5.1 它是什么

**D9 = SMF15CA**

| 型号中的部分 | 含义 |
|---|---|
| `SMF` | **封装**：SOD-123FL，很小的贴片 |
| `15` | **击穿电压**约 15V |
| `CA` | **双向**（Bidirectional） |

学名 **TVS**（Transient Voltage Suppressor，瞬态电压抑制器）。

### 5.2 它怎么工作（用"安全阀"理解）

```
【正常工作，比如 12V】
   → TVS 几乎不导通（漏电流只有微安级）
   → 相当于"它不存在" ✅

【电压突然冲到 15V 以上】
   → TVS 在【纳秒级】时间内击穿导通
   → 变成一根"导线"，把电压死死钳在 15V 左右
   → 多余的能量全被它自己吸收（变成热量散掉）
   → 后面的芯片只看到被钳住的电压 ✅

【尖峰过去，电压降回正常】
   → TVS 自动恢复高阻态 → 再次"消失" ✅
```

> **比喻：TVS = 水管上的安全阀。平时关着不碍事；压力太大自动泄压；压力降下来又自己关上。**

**注意它和保险丝的分工：**
- **保险丝**管的是"电流太大" → **断开电路**
- **TVS** 管的是"电压太高" → **钳住电压，但不切断**

### 5.3 为什么必须是"双向"的？

因为电感负载（电机）在关断时产生的不是单纯的"正的高压"，而是**一上一下的振荡**：

```
   ↑ 30V ─┐
   │      └─┐
 12V ──────┴──┐  ┌────
   │          └──┘
   0V ───────────────
```

单向 TVS 只能按住上面那部分；**双向 TVS 上下都能按**。

### 5.4 为什么选 15V？

```
【选太低，比如 13V】
   正常 12V 稍微波动就到 13V
   → TVS 经常导通 → 一直发热、甚至烧毁

【选太高，比如 30V】
   尖峰冲到 25V 它都不动
   → 而你的 MOS 管耐压只有 30V，芯片早就击穿了

【选 15V】
   正常 12V 时不动（留了 3V 余量）✅
   尖峰一起来就钳住 ✅
```

> **选型原则：TVS 的击穿电压要"比正常工作电压高一点，比被保护器件的耐压上限低很多"。夹在中间，两头都照顾到。**

**TVS 的额定参数里还有一个"峰值脉冲功率"：**

| 封装 | 典型峰值脉冲功率 |
|---|---|
| **SMF**（本板） | 约 200~400W |
| SMB（SMBJ 系列） | 约 600W |
| SMC（SMCJ 系列） | 约 1500W |

**如果尖峰能量超过额定值，TVS 会过热烧毁，而且失效模式常常是短路**（会把母线直接拉死）。
**改进方向**：换更大封装（SMBJ15CA），或在它前面串小电阻限制流入电流。

## 本节总结

### 两个问题、两个答案

| 问题 | 危险的后果 | 用了什么 | 怎么工作 |
|---|---|---|---|
| **电流太大（短路）** | 电池和板子一起报废、起火 | **F2 自恢复保险丝** | 受热膨胀 → 导电链断开 → 限流；冷却后自动恢复 |
| **电压太高（尖峰）** | 芯片被击穿 | **D9 双向 TVS** | 超过 15V 纳秒级导通 → 钳住电压 → 吸掉尖峰能量 |

### 一张对比表

| | 保险丝（F2） | TVS（D9） |
|---|---|---|
| 管什么 | **电流** | **电压** |
| 触发后 | **断开电路** | **钳住电压（不断开）** |
| 能否恢复 | **能** | **能** |
| 保护谁 | 防火灾、防烧板子 | 保护芯片不被高压击穿 |
| 响应速度 | 慢（几十 ms~几秒） | **快（纳秒级）** |

### 两条通用认知

**① 保护是"分层"的**

```
快层（微秒级）  → 保护 MOS 管：硬件刹车（运放比较器 + TIM1 BKIN）
中层（毫秒级）  → 软件逻辑：FOC 限幅
慢层（几十 ms~秒）→ 防火：PPTC
瞬时层（纳秒级）→ 防击穿：TVS + 母线电容
```

**② 选型的通用思路是"夹在中间"**

电压要高于正常工作电压、低于器件耐压 —— **两头都留余量**。

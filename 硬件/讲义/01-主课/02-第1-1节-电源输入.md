## 第 1 步：要解决什么问题？

**我要让电机转起来。电机要用电。所以电得从外面进来。**

这是整门课的第一句话，也是最朴素的一句话。但"把电接进来"这一件小事，往深里想会冒出一串问题：

| # | 问题 | 如果不解决会怎样 |
|---|---|---|
| 1 | 电用什么接口接进来？ | 接触不良 → 一跑大电流就发烫、掉电 |
| 2 | 我不小心把电池接反了怎么办？ | **整块板瞬间烧毁** |
| 3 | 我不小心把输出短路了怎么办？ | **电池和板子一起报废，甚至起火** |
| 4 | 电机启停时电压会猛跳，怎么办？ | 超过芯片耐压 → **击穿** |
| 5 | 我想把这台设备关掉怎么办？ | 只能拔插头，又麻烦又伤接口 |

**所以第 1 课要干的事：设计一条"既能把电顺利吃进来、又能保护自己不受伤、还能一键开关"的入口通道。**

---

## 第 2 步：所以需要什么？

按照电流流进来的顺序，需要 5 个东西：

```
① 一个能过几十安培的插头        → 解决"接口"问题
② 一个"电流太大就自己断开"的元件  → 解决"短路"问题
③ 一个"电压太高就自己吸掉"的元件  → 解决"电压尖峰"问题
④ 一组"能双向断电"的开关        → 解决"反接"和"关机"问题
⑤ 一堆电容                     → 解决"电流突变"问题
```

## 逐个讲：每个元件在回答哪个问题

### 问题 1：电用什么接口接进来？ → **CN3 = XT30PW-M**

**为什么不能用那种常见的 DC 圆头（5.5×2.1mm）插头？**

| 对比 | DC 圆头 | **XT30** |
|---|---|---|
| 额定电流 | 1~3A | **十几安培以上** |
| 接触方式 | 靠弹片轻压 | **大接触面积 + 弹性夹紧** |
| 会不会松 | 容易松（一碰就掉） | **有锁扣感，插上很紧** |
| 用途 | 小功率适配器 | **航模/无人机动力电池** |

**关键原因：接触电阻。** 电流流过接触点时会发热：

```
发热功率 = 电流² × 接触电阻

假设接触电阻 0.1Ω，电流 10A：
P = 100 × 0.1 = 10W  ← 一个小小插头散 10W，几分钟就烫手甚至熔化
```

XT30 的接触电阻只有几毫欧，同样 10A 下发热只有零点几瓦，**几乎不烫**。

> 💡 **设计第一原则：接口和线材的规格，由"电流"决定，不是由"电压"决定。**
> 12V 电压不高，但电流十几安培，所以必须用动力插头。

### 问题 2：我不小心短路了怎么办？ → **F2 = 自恢复保险丝（PPTC）**

**F2 = BSMD1812-800-12V**，参数含义：
- `1812` = 封装尺寸（4.5×3.2mm）
- `800` = **保持电流 0.8A**（低于这个电流正常通过）
- `12V` = 额定电压

**它怎么工作？**

```
电流正常（< 0.8A）
   → 内部聚合物处于低阻态（几毫欧到几百毫欧）→ 电流顺利通过 ✅
   → 几乎不影响电路

电流过大（比如短路，几安培）
   → 内部发热 → 聚合物膨胀 → 内部导电链断开 → 电阻暴涨到几百 kΩ
   → 电流被限制到很小（几毫安）→ 保护了后面的电路 ✅
   → 元件本身有点温度，但不会烧毁

故障排除、温度降下来
   → 聚合物收缩 → 导电链恢复 → 电阻回到很低
   → 电路自动恢复正常 ✅  ← 这就是"自恢复"的含义
```

**为什么用它，而不是普通玻璃管保险丝？**

| | 普通保险丝 | **自恢复保险丝（PPTC）** |
|---|---|---|
| 触发后 | **熔断，永久损坏** | **自动恢复** |
| 要不要更换 | 要拆下来焊新的 | 不用 |
| 响应速度 | 很快 | 稍慢（几十毫秒到几秒） |
| 适合场合 | 需要"绝对断开" | **实验/开发板最合适** ✅ |

> 💡 **对你这块学习用的板子，PPTC 是完美选择**：调试时不小心短路，它自己保护一下，你把短路排除，它又活了。**不用每次焊保险丝。**

> ⚠️ **但要知道它的局限**：PPTC 的响应**比较慢**，而且**不能替代过流保护电路**。真正的防护是"软件/硬件快速检测过流 → 立刻关掉 PWM"，PPTC 只是最后一道"防火灾"的底线。

### 问题 3：电压尖峰太高怎么办？ → **D9 = 双向 TVS 二极管**

**D9 = SMF15CA**：
- `SMF` = 封装（SOD-123FL，很小的贴片）
- `15` = 击穿电压约 15V
- `CA` = **双向**（Bidirectional）

**什么是 TVS？**

TVS（Transient Voltage Suppressor，瞬态电压抑制器）本质上是一个**"电压超过阈值就瞬间变成导体"的器件**。

```
正常工作（比如 12V）
   → TVS 几乎不导通（漏电流只有微安级）→ 相当于"不存在" ✅

电压突然冲到 15V 以上（尖峰）
   → TVS 在纳秒级时间内击穿导通 → 变成一根"导线"把电压钳住
   → 多余的能量被它吸收掉（变成热量散掉）
   → 后面的电路只看到被钳住的电压 ✅

尖峰过去，电压降回正常
   → TVS 自动恢复高阻态 → 再次"消失" ✅
```

**为什么需要它？** 三个真实场景：

| 场景 | 产生的尖峰 |
|---|---|
| **插拔电池时打火** | 插头接触瞬间会跳火花，产生几十伏的高频尖峰 |
| **电机急停/换向** | 电机是电感，电流突变会产生反电动势，回灌到电源母线上 |
| **长导线耦合干扰** | 电源线像天线，会接收到环境中的电磁干扰 |

**为什么是"双向"的？**

- **单向 TVS**：只钳位一个方向的过压（比如只保护正电压尖峰）
- **双向 TVS**：正负两个方向都钳位

**电源线为什么要双向？** 因为电感性的负载（电机）在关断时可能产生**反向的电压尖峰**（不是负电压，而是"低于 0V 的振荡"）。双向 TVS 能同时应付两个方向。

> 💡 **记忆：TVS 是"电压的安全阀"**，平时关着不碍事，压力太大就自动泄压。

### ⭐ 问题 4：接反了怎么办？想关机怎么办？ → **背靠背 P-MOS（Q6 + Q7）**

**这是本课最核心、也最难懂的一段。** 先看它长什么样：

```
   [D9 之后]                                     [+12V 输出]
       │                                              │
       ├──── D ┌──────┐ S ──┬── S ┌──────┐ D ─────────┤
       │      │ Q6   │     │     │ Q7   │              │
       │      └──────┘     │     └──────┘              │
       │         G         │        G                  │
       │         └────┬────┘                            │
       │              │  ← 两管的栅极连在一起            │
       │              ├──[R39 2.2kΩ]── 公共源极（中间那个点）
       │              │
       │              └──[R40 1kΩ]── U9 拨动开关 ── PGND
       │
      PGND
```

#### 4.1 先问：为什么一个 P-MOS 不够？（答案：体二极管）

回顾第 0 课：**MOS 管内部天然有一个体二极管，方向是"源极 → 漏极"（对 P-MOS 是从漏极？我们按 N/P 具体看）。**

**关键在于：这个二极管永远存在，关不掉。**

- **电池正接**时，体二极管反向截止，没问题 ✅
- **电池反接**时，体二极管**正向导通** → 电流从反方向"偷偷"通过 → **防反接失败** ❌

所以单个 MOS **只能单向阻断电流**，做不了"双向断电"。

#### 4.2 两个 MOS 背靠背（共源）→ 双向阻断

把两个 P-MOS 的**源极连在一起**（叫"共源"），两个漏极分别朝外：

```
   输入侧 ←── Q6 的体二极管方向 ──→ 公共源极
   公共源极 ←── Q7 的体二极管方向 ──→ 输出侧
```

**两个体二极管方向相反！** 所以：

| 情况 | 结果 |
|---|---|
| 有反向电压 | 总有一个二极管是反向截止的 → **挡住了** ✅ |
| 有正向电压（正常情况） | 两个二极管都"想"导通，但…… |

等等，等等 —— **如果两个体二极管方向相反，那正向电压下不也是"总有一个截止"吗？**

**是的！** 所以在**关断状态**下，**无论哪个方向的电压，都被挡住** → **这就是双向阻断** ✅

**那"导通"怎么实现？** 靠**同时打开两个 MOS 的沟道**（不是靠体二极管）：

- 两个 MOS 都导通 → 沟道电阻只有几毫欧 → 电流畅通无阻 ✅

> 💡 **一句话总结：两个 MOS 关着时，两个体二极管互相"顶住"，任何方向都不通；两个 MOS 开着时，沟道导通，比二极管路径电阻小得多，电流正常走。**
>
> **这就同时实现了两个功能：既能防反接（反接时不开 MOS，二极管互相顶住），又能当开关（打开 MOS 就通）。**

#### 4.3 栅极怎么控制？"默认关断"的设计

```
公共源极 ──[R39 2.2kΩ]── 公共栅极
```

**R39 的作用：把栅极拉到源极电位。**

对 P-MOS 来说，`Vgs = Vg − Vs`。当栅极被 R39 拉到和源极一样时：
`Vgs = 0V` → **不导通 → 默认关断** ✅

**这就是第 0 课讲的"安全底线"**：上电瞬间、MCU 还没初始化、开关没拨的时候，**功率开关必须是关的**。

**那怎么打开？** `U9` 是一个拨动开关，一端接栅极（经 R40 = 1kΩ），另一端接 PGND：

```
U9 拨到闭合 → 栅极被拉到 PGND（0V）
            → 而源极在 12V 左右（正接时）
            → Vgs = 0V − 12V = −12V < 0
            → P-MOS 导通 ✅  +12V 上线
```

**R40 = 1kΩ 的作用**：栅极是个电容，拨动开关闭合瞬间要给栅极电容充电。没有 R40 的话，开关触点要承受很大的瞬时电流（可能烧蚀触点）。R40 起到**限流**作用，保护开关。

> 💡 **回顾第 0 课：**
> - **栅源电阻（R39）** = 保证默认关断
> - **栅极串联电阻（R40）** = 限制驱动电流
>
> **你在这块板上已经见到两次这个组合了**（这里，以及第 4 课的 R9/R8、R13/R10），**它是功率开关的标准配置。**

#### 4.4 为什么这里用 P-MOS，而电机桥上管用 N-MOS？

| | 电源总开关 | 三相桥 |
|---|---|---|
| 电流 | 一路总电流，**开关频率极低**（只在开机/关机时动作） | 三相，**每秒开关上万次** |
| 对损耗的要求 | 不那么敏感 | **极其敏感**（发热直接烧管） |
| 器件选择 | **P-MOS**（控制简单，栅极拉低就通） | **N-MOS + 自举**（RDS(on) 小 3 倍，损耗低） |

> 💡 **这是"用复杂度换效率"和"用效率换复杂度"的经典取舍。** 哪里该省事、哪里必须较真，是设计者要判断的。

### 问题 5：电流突变时电压会掉，怎么办？ → **C28 / C29 / C30**

```
+12V ──┬──[C28 470µF 电解]
       ├──[C29 10µF 陶瓷]
       └──[C30 10µF 陶瓷]
       │
      PGND
```

**为什么需要三种不同容量？** 因为**不同容量的电容擅长对付不同频率的干扰**：

| 电容 | 等效串联电感(ESL) | 擅长频率 | 对付什么 |
|---|---|---|---|
| **470µF 电解** | 大 | 低频（几百 Hz ~ 几 kHz） | 电机启动/变速时电流猛变，母线电压想塌下去 → 它当"蓄水池"补上 |
| **10µF 陶瓷** | 小 | 中频（几十 kHz） | 开关纹波 |
| **100nF**（板子各处都有） | 极小 | 高频（MHz 以上） | 开关瞬间的高频噪声，必须**贴着芯片引脚**放 |

**为什么大电容单独用不行？**

想象一个大水桶（大电容）和一个水杯（小电容）：
- **水桶**能存很多水，但**口小、出水慢**（ESL 大，高频响应差）→ 应付"慢慢用水"很好
- **水杯**水少，但**能瞬间倒出来**（ESL 小）→ 应付"突然要一大口水"很好

**电机启动时要的是"瞬间一大口电流"**，所以两种都要有。

> 💡 **贯穿全板的规律：**
> **大电容放在"入口"（应付大能量突变），小电容放在"芯片脚边"（应付高频噪声）。**

### 问题 6（隐藏问题）：大电流会不会干扰测量电路？ → **PGND，以及 R43 = 0Ω**

**这个问题在第 4、5 课才会完全展开，但种子在这里就埋下了。**

**问题是什么？** 功率地上有巨大的脉冲电流（十几安培）。因为走线有电阻和电感，**地线上不同点的电位其实不一样**：

```
   PGND ═══[走线电阻 5mΩ]═══════ PGND'
   0V                               +50mV（地弹）
   ↑ 同一个"地"，两点电位竟然差了 50mV
```

**这对测量是致命的**：第 5 课要用运放测量采样电阻上**只有 10mV** 的信号。如果"地"本身就在抖 50mV，**信号完全被淹没**。

**解决方案（本课先用，第 5 课展开）：**

> **让大电流走"功率地 PGND"，让小信号走"信号地 GND"，两条地各走各的，最后只在一个点上汇合。**

在本图的体现：**R43 = 0Ω**（0 欧姆电阻）把 PGND 和 GND 单点连接。

**为什么用 0Ω 电阻而不是直接连？** 三个原因：

1. **强制单点**：图上必须画一个明确的位置，让所有电流"只能从这一个门进出"，不允许有第二条偷偷的地回路
2. **可改造**：如果发现噪声问题，可以把 0Ω 拆掉换成**磁珠**（滤高频）或**小电感**
3. **约束 Layout**：PCB 布线时，"0Ω 焊盘的位置"就是地的汇合点，画板时不会乱连

## 本课总结：一张"问题 → 方案"对照表

| 要解决什么问题 | 用了什么 | 位号 | 核心原理 |
|---|---|---|---|
| 电流大、接口不能发热 | **XT30 动力插头** | CN3 | 大接触面积 → 接触电阻几毫欧 |
| 短路保护（可恢复） | **自恢复保险丝** | F2 | 过流发热 → 电阻暴涨 → 限流；冷却后自动恢复 |
| 电压尖峰保护 | **双向 TVS** | D9 | 超过 15V 瞬间击穿钳位，吸掉尖峰能量 |
| 防反接 + 一键开关 | **背靠背 P-MOS** | Q6/Q7/U9 | 两个体二极管方向相反 → 关断时双向阻断；开沟道 → 导通 |
| 保证"默认关断" | **栅源电阻** | R39 | 栅极拉到源极 → Vgs=0 → 截止 |
| 保护开关触点 | **栅极限流电阻** | R40 | 限制栅极充电峰值电流 |
| 应付电流突变 | **470µF + 10µF 电容** | C28/C29/C30 | 不同容量对付不同频率 |
| 隔离功率噪声 | **PGND + 单点接地** | R43 = 0Ω | 大电流与信号地各走各的，一点汇合 |

## 下一课预告

**第 2 课：电源变换 —— 12V 怎么变成芯片能吃的电压**

**问题链：**

1. 从第 1 课出来，我们有了一个 **+12V 主轨**（能过十几安培）。
2. **但**：STM32 要 **3.3V**，MOS 驱动芯片要 **12V**（刚好），运放要 **干净得多的 3.3V**，LCD/按键要 3.3V……
3. **而且**：如果直接用电阻分压把 12V 降到 3.3V，会怎样？（答案：`(12−3.3) × 电流` 全变成热，效率极低）
4. **所以**：需要**开关电源**（高效率）和**线性稳压器**（低噪声）这两类器件，各管一段。
5. **于是有了**：TPS5430（12V→5V，开关型）+ AMS1117（5V→3.3V 数字）+ RT9013（5V→3.3V 模拟）三级变换。
6. **还有**：为什么"数字 3.3V"和"模拟 3.3V"必须是**两颗不同的芯片**？（这是本课最精彩的部分）

# 第 8-1 节：从焊完板到电机转起来（8 关）

> **每一关都必须"看到预期现象"才能进下一关。跳步 = 炸管。**

---

## 第 0 关：焊接与静态检查（不接电！）

| 检查项 | 怎么测 | 通过标准 |
|---|---|---|
| **电源短路** | 万用表测 `+12V↔PGND`、`+5V↔GND`、`VCC↔GND`、`VCCA↔AGND` | 电阻**不能接近 0Ω**（应为几百 Ω 以上，或看到电容充电曲线） |
| **元件方向** | 目视 | 电解电容极性、IC 一脚方向、二极管方向 |
| **虚焊/连锡** | 目视 + 放大镜 | 特别是 TSSOP-20（FD6288T）和 SOT-23 的引脚 |
| **MOS 桥直通** | 万用表二极管档测 `M_U↔+12V`、`M_U↔PGND` | 应能看到体二极管的单向压降，**不能双向都通** |

> ⚠️ **这一步花 10 分钟，能省掉一次炸板。**

---

## 第 1 关：上电，只看电源（不接电机、不下载程序）

| 测什么 | 在哪测 | 预期 |
|---|---|---|
| +12V | C28 两端 | 输入电压（开关拨到 ON） |
| +5V | C39 两端 | **4.95 ~ 5.05V** |
| VCC | C31 两端 | **3.3V ± 2%** |
| VCCA | C47 两端 | **3.3V ± 2%** |
| **VREF** | U13 输出 | **1.65V ± 1%** ⭐ |

> ⚠️ **如果 VREF 不是 1.65V（比如 0V 或 3.3V），先别往下走！**
> **说明基准跟随器有问题，后面所有电流读数都会错。**

**用带限流的可调电源**：先设 0.5A 限流，万一有短路不会炸。

---

## 第 2 关：下载与 SWD 连接

| 步骤 | 预期 |
|---|---|
| 接 SWD（SWCLK/SWDIO/GND/VCC 四线） | 调试器能识别芯片 |
| 下载最简程序（点灯） | LED 按预期闪烁 |
| **连续两次连接成功** | 确认 PA13/PA14 没被占用 ⚠️ |

> ⚠️ **如果第一次就把自己锁死了**（PA13/PA14 配成了普通 IO）
> → 只能靠 BOOT0 拉高进 Bootloader 擦除芯片救回来。

## 第 3 关：只跑 PWM，不接电机（示波器必备）

| 测什么 | 在哪测 | 预期 |
|---|---|---|
| **6 路 PWM** | FD6288T 的 6 个输入脚 | 干净方波，频率 = 设定值，占空比可控 |
| **死区** ⭐ | HO1 与 LO1 同时测 | 两路之间有 **几百 ns ~ 1µs 的空白**（都不为高） |
| **栅极波形** | Q1/Q2 栅极对各自源极 | **10 ~ 10.5V 方波**（不是 3.3V！） |
| **自举电压** | VB1 对 VS1 | **稳定 10 ~ 11V** |
| **占空比上限验证** | 让程序输出 100% | **自举电压会掉** → 证明必须限幅 |

### 顺便做一件事：确认相序 ⭐

```
只让 TIM1_CH1 输出 50% 占空比
→ 用示波器看 M_U / M_V / M_W 哪个端子在动
→ 【记录下来！写代码时按这个对应】
```

> 💡 **这是为了解决第 3 课发现的疑点：图上 TIM1 通道与电机相序可能是交叉的。**

## 第 4 关：电流采样标定（不接电机）

| 步骤 | 预期 |
|---|---|
| 电机不接、PWM 关掉 | 运放输出应停在 **1.65V** |
| 读 ADC，换算成电流 | **≈ 0A ± 50mA** |
| 长时间观察 | 读数不应缓慢漂移（漂移大 → 运放失调或基准不稳） |

### 标定做法（重要）

```c
// 【零点标定】电机不转、PWM 关掉
uint32_t sum = 0;
for (int i = 0; i < 1000; i++) sum += read_adc();
uint16_t zero = sum / 1000;      // 这就是实际零点
// → 把 zero 写进代码的 ADC_MID，不要用理论值 2048

// 【增益标定】用可调电源给采样电阻两端加已知电流（比如 1A）
// → 看 to_amps() 读数是不是 1.0A
// → 不是就微调 GAIN 常量
```

> ⚠️ **如果零点不是 0A：**
> **① 先查 VREF 是否 1.65V → ② 再查 ADC_MID 是否为实测值 → ③ 最后查运放**

## 第 5 关：开环强拖（第一次让电机转）

**先不要闭环！用开环 V/F 让电机转起来。**

```c
// 开环：自己生成旋转的电压矢量，不管电流
float theta_open = 0;

void open_loop_task(void) {
    theta_open += 2 * PI * elec_freq * dt;   // 电频率慢慢加
    if (theta_open > 2*PI) theta_open -= 2*PI;
    
    float Ud = 0;
    float Uq = voltage_amplitude;             // 从小开始
    set_voltage_vector(theta_open, Ud, Uq);   // 反 Park + SVPWM
}
```

**用低压母线（5V 或更低）限制故障电流。**

| 看什么 | 应该看到 |
|---|---|
| 电机是否转 | **平稳旋转**，不抖不响 |
| **三相电流波形** | **三相对称、相位差 120°、接近正弦** ⭐ |
| 缓慢升频 | 转速跟随，电流不过大 |

> ### 🎯 这一步同时验证了四件事
> **PWM、驱动、相序、电流采样 —— 一起验证。**
>
> **如果电流波形不对称 → 相序错了（回第 3 关的记录）。**
> **如果电流读数不合理 → 回第 4 关重新标定。**

## 第 6 关：电流环闭环

| 步骤 | 预期 |
|---|---|
| 目标 `Id = 0`、`Iq = 小值` | 电机出力，`Iq` 实际值跟随目标 |
| **观察 `Id`** | **应接近 0** ⭐ **这是"磁场定向是否正确"的唯一判据** |
| 增大 `Iq` 目标 | 转矩增大 |
| 相电流波形 | 仍是正弦，无尖刺 |

> ⚠️ **`Id` 明显不为 0 → 电角度没对齐**（回第 5 关做电角度标定）
>
> **电角度标定的做法：**
> ```
> ① 只给 d 轴电压（θ=0 的电压矢量），等转子稳定停住
> ② 这时读编码器角度 θ_mech_0
> ③ θ_offset = 0 − θ_mech_0 × 极对数
> ④ 之后：θ_elec = θ_mech × 极对数 + θ_offset
> ```

## 第 7 关：速度环 / 位置环

**串级结构：**

```
位置环（1kHz）→ 速度环（5kHz）→ 电流环（10~20kHz）
   ↑ 外环慢，内环快
```

**整定顺序：先 P（从小到大）→ 再加 I → 观察阶跃响应。**

| 步骤 | 预期 |
|---|---|
| 加速度环 | 转速跟随目标，无持续振荡 |
| 突加负载 | 转速能恢复，电流自动增大 |
| 加位置环 | 能定位到目标角度 |

---

## 第 8 关：保护与故障处理

| 保护 | 实现 |
|---|---|
| **过流** | 比较器 → **TIM1 刹车输入（BKIN）** → 硬件封锁 6 路 PWM |
| **过温** | NTC → ADC → 降额或停机 |
| **欠压/过压** | 母线电压采样 → 停机 |
| **编码器故障** | 角度跳变检测 → 停机 |
| **故障锁存** | **红灯常亮 + 故障码显示在 LCD** ← 排查全靠这个 |

# 第 8-2 节：调试工具清单

**按必需程度排：**

| 工具 | 必需性 | 为什么 |
|---|---|---|
| **示波器（≥2 通道）** | 🔴 **必需** | 看 PWM、死区、栅极波形、自举电压、电流波形。**没有它调试 FOC 就是盲人摸象** |
| **STM32 调试器（ST-Link）** | 🔴 **必需** | 下载 + **Live Watch 实时看变量** |
| **万用表** | 🔴 **必需** | 电源、短路检查 |
| **带限流的可调电源** | 🟠 **强烈建议** | **限流是你的安全网**：先设 0.5A，故障时不会炸板 |
| **USB-CAN 分析仪** | 🟠 建议 | 调 CAN 通讯（CANable 等便宜的都可以） |
| **电流钳 / 电流探头** | 🟡 加分 | 直接看真实相电流，验证采样链路 |
| **测温枪 / 热成像仪** | 🟡 加分 | 长时间跑，找异常发热 |

> 💡 **最省钱且最有效的组合：**
> **一块 ST-Link + 一个二手 2 通道示波器 + 一个带限流的可调电源。**
> **有这三样，FOC 就能调出来。**

### Live Watch 具体怎么用

```
在 IDE 里打开 Live Watch（实时变量监视），加入这些变量：
   Ia / Ib / Ic        三相电流
   Id / Iq             旋转坐标系电流
   theta_elec          电角度
   speed               转速
   adc_raw[3]          ADC 原始值
   
→ 一边转电机一边看波形 → 【比串口打印快得多，也不占用控制周期】
```

# 第 8-3 节：新手必踩的 10 个坑

| # | 坑 | 现象 | 原因 / 解法 |
|---|---|---|---|
| **1** | **上下管直通** | 上电就炸管 | 死区太小或没配；**用 TIM1 硬件死区设 500ns~1µs，先不接电机验证** |
| **2** | **自举掉电** | 电机转一下就停、上管发热 | 占空比到 100% → 下管永不导通 → 自举电容补不上电。**限制占空比 ≤90%** |
| **3** | **采样饱和削顶** | 电流读数卡在极值不动 | 超过 ±11A 量程。**限流、改小采样电阻或降低增益** |
| **4** | **偏置搞错** | 电流读数恒定偏移、Id 不为 0 | VREF 不是 1.65V，或 ADC_MID 不是实测值。**先测 VREF 再写代码** |
| **5** | **相序反了** | 电机抖动、堵转、反转 | TIM1 通道与相序不对应。**做"只开 CH1 看哪个端子动"的实验** |
| **6** | **电角度没对齐** | Id 明显不为 0、效率低、异响 | d 轴与转子位置没对应。**做电角度标定** |
| **7** | **JTAG 脚没关** | 按键读不出来（一直是 1） | PA15/PB3/PB4 默认被 JTAG 占用。**加 `__HAL_AFIO_REMAP_SWJ_NOJTAG()`** |
| **8** | **PI 参数振荡** | 电流/转速啸叫、来回振 | 先只上 P（从小到大），再加 I；**带宽不能超过采样率/10** |
| **9** | **地环路噪声** | 采样噪声大、读数乱跳 | 地没按 PGND/GND/AGND 分开走；或 0Ω 单点被画成多点 |
| **10** | **ADC 采样时刻错** | 电流波形有尖刺、读数周期性跳变 | 没用 TIM1 TRGO 硬件触发，而是软件随便采 |

### 补充：中断里的"三不三要"

```
❌ 不要：printf、延时函数、复杂数学库、malloc、while 死等标志位
✅ 要  ：读寄存器、四则运算、查表、写寄存器
```

# 第 8-4 节：这块板的"改进清单"

| 优先级 | 改进项 | 收益 |
|---|---|---|
| 🔴 **高** | **I2C 补上 4.7kΩ 上拉**（或确认 AS5600 模块自带） | **让编码器真正可用** |
| 🔴 **高** | **核对 PA0 / PA1 / VREF / VREF1 的网络名** | 避免 ADC 通道和偏置代码全错 |
| 🔴 **高** | **确认 TIM1 通道与电机相序的对应** | 避免抖动/反转/堵转 |
| 🟠 中 | **确认 PPTC 型号**（3A 还是 8A） | 3A 带 C2208 会误跳 |
| 🟠 中 | **CAN 终端电阻改跳线** | 支持 3 个以上节点组网 |
| 🟠 中 | **自举二极管换肖特基（SS14）** | 自举电压多 0.4V |
| 🟠 中 | **USB D+/D− 加 22Ω 串联电阻** | USB 通讯更稳 |
| 🟡 低 | **VCCA 输入加磁珠/π 型滤波** | 进一步降低模拟电源噪声 |
| 🟡 低 | **增加测试点**：VB1 对 VS1、VREF、三相电流 | 调试时不用到处找测点 |
| 🟡 低 | **加母线电压采样分压**（若现在只有 NTC） | 支持电压前馈和欠压保护 |

# 第 8-5 节：第一版代码参数建议

**保守起见，第一版先"求稳"，跑通再提速。**

| 参数 | 建议值 | 理由 |
|---|---|---|
| **PWM 频率** | **10 kHz** | 周期 100µs，时序宽松 |
| **死区时间** | **1 µs** | 偏大更安全（先用示波器确认） |
| **占空比限幅** | **10% ~ 90%** | 保证采样窗口 ≥ 5µs |
| **ADC 采样时间** | **7.5 或 13.5 周期** | 折中精度和速度 |
| **ADC 模式** | **注入组 + T1_TRGO 触发** | 硬件自动 |
| **重复计数器 RCR** | **1** | 中心对齐下只触发一次 |
| **电流环频率** | **= PWM 频率（10kHz）** | 一次中断算一遍 |
| **速度环频率** | **1 kHz** | 在电流环里分频执行 |
| **电流环 PI 初值** | **Kp 小、Ki 更小** | 从很保守开始 |
| **极对数** | **7**（C2208） | 这个不能错 |
| **最大电流限制** | **3A**（相电流峰值） | 先保守，再放开 |

### 调试顺序（照着走）

```
① 先只跑 PWM，示波器看死区和 6 路波形
② 打开 ADC，看三个电流值是否稳定在 0A 附近（电机不转）
③ 开环转起来，看三相电流是否正弦对称
④ 进闭环，盯住 Id 是否接近 0
⑤ 加负载，看 Iq 跟随
⑥ 最后才提频率、放宽限幅
```

# 第 8-6 节：整块板的完整信号链（总结）

```
【能量流】
   XT30 电池 → 保护 → 总开关 → +12V
      ↓
   TPS5430 → +5V → AMS1117 → VCC（数字）
                 → RT9013  → VCCA（模拟）
      ↓
   +12V → 三相桥 → 电机 U/V/W

【信号流（FOC 闭环）】
   ① SVPWM 算出三相占空比（软件）
   ② TIM1 输出 6 路带死区互补 PWM
   ③ FD6288T 电平转换 + 1.8A 放大 + 自举
   ④ 三相全桥开关，电机线圈过流
   ⑤ 电流穿过 10mΩ → 产生 10mV 级压降
   ⑥ 差分放大 ×15 + 1.65V 偏置
   ⑦ TIM1 在谷底硬件触发 ADC
   ⑧ Ia/Ib/Ic 数字量（PA1/PA2/PA3）
   ⑨ Clarke：Ia/Ib/Ic → Iα/Iβ
   ⑩ Park（需电角度 θ）：Iα/Iβ → Id/Iq
   ⑪ PI 调节：Id/Iq vs 目标 → Vd/Vq
   ⑫ 反 Park + SVPWM → 回到 ①

【地】
   PGND ──[R43 0Ω]── GND ──[R44 0Ω]── AGND
```

## 最后：一句话总结全板设计哲学

```
1. 能量从粗到细：12V → 5V → 3.3V（数字/模拟分开）
2. 地按噪声分级：PGND / GND / AGND，0Ω 单点汇合
3. 功率开关默认关断：所有栅极都有上拉/下拉
4. 大电容在入口，小电容贴引脚
5. 上管必须自举：所以占空比永远不能到 100%
6. 电流必须差分放大 + 偏置到量程中点：10mΩ、15 倍、1.65V
7. 采样时机由硬件定时器决定：不在干净的瞬间采，再高的精度也没用
8. FOC 只用 6 路 PWM + 3 路 ADC，剩下全是保障可靠性和可调试性
```

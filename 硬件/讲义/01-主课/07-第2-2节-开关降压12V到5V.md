# 第 2-2 节：开关降压 —— 12V 怎么变成 5V（TPS5430）

> 难度 🔴 硬骨头。上一节我们知道"大压差要用开关方式"，这一节讲**开关到底怎么变成稳定电压**。
> **核心角色只有一个：电感。**

---

## 第 1 步：先看"光开关"会得到什么

```
把 12V 通过一个开关，快速地开、关、开、关……
占空比 = 42%  →  平均电压 = 12V × 42% = 【5V】
```

**但如果你用示波器去看这个输出：**

```
电压
 ↑
12V ┤  ┌─┐   ┌─┐   ┌─┐   ┌─┐
    │  │ │   │ │   │ │   │ │
  0V┤──┘ └───┘ └───┘ └───┘ └──
    └────────────────────────→ 时间
    这是一个【方波】，不是稳定的 5V！
```

> **平均电压是 5V，但瞬时电压在 0V 和 12V 之间疯狂跳。**
> **MCU 需要的是"平稳的 5V"，不是"平均 5V 的方波"。**

---

## 第 2 步：只用电容"抹平"还不够

```
   方波 ──┬── 电容 ── 输出
          │
         GND
```

**两个问题：**

| 问题 | 说明 |
|---|---|
| **① 需要超大容量** | 要把 0~12V 方波抹到 5V 附近，需要极大电容 |
| **② 致命问题：开关断开时没有能量来源** | 输出全靠电容放电 → 电压持续下降 → **输出会"塌"下去** |

```
【开关闭合时】12V 直接给电容充电 → 电压冲高（接近 12V）
【开关断开时】电容只能放电，而且【没有任何东西在给它供电】
   → 负载越大，掉得越快
   → 结果：输出是个"锯齿波"，不是平稳的 5V ❌
```

> **光有"储能"（电容）不够，还需要一个"能量中转站"：**
> **开关闭合时把多余能量存起来，开关断开时把能量放出来继续供电。**
> **这个"中转站"就是电感。**

---

## 第 3 步：电感的脾气（本节核心）

> **电感不允许电流突变。**

### 3.1 电流想变大时，电感"反抗"

```
你给电感加电压，想让它电流变大
   → 电感产生【反向电压】对抗
   → 电流只能【慢慢】升上去
```

### 3.2 电流想变小时，电感也"反抗"（关键）

```
电流正在流动，你突然把电源断掉
   ↓
电流想立刻变成 0 —— 电感不答应：「我要维持这个电流！」
   ↓
它靠【把电压抬得极高】来硬撑
   ↓
如果不给它一条"出路"，这个电压会高到把开关管打穿
```

> **电感这个脾气：一面是敌人（切断电流 → 超高压 → 打穿器件），一面是朋友（电流想变小时它主动推动电流继续流）。**
> **怎么把敌人变成朋友？给它一条出路。**

---

## 第 4 步：完整工作原理（两个阶段）

**三个角色：**

| 角色 | 作用 |
|---|---|
| **开关** | 快速开合，决定"什么时候给电感充电" |
| **电感** | 能量中转站（存能量 / 放能量） |
| **续流二极管** | 开关断开时，给电感电流一条"出路" |

### 4.1 阶段一：开关闭合（电感"吃饭"）

```
   +12V ──[开关 闭合]──┬──[L 电感]──┬── 输出 (+5V)
                       │            │
                     [D 二极管]   [C 输出电容]
                       │  ↑         │
                      GND 反偏截止  GND

   电流路径：+12V → 开关 → 电感 → 输出电容/负载 → GND
   电感电流【上升】（在充电，能量存进磁场）
   二极管【反偏，不干活】
```

### 4.2 阶段二：开关断开（电感"吐出来"）

```
   +12V ──[开关 断开]──┬──[L 电感]──┬── 输出 (+5V)
        ✗ 断开了       │            │
                     [D 二极管]   [C 输出电容]
                       │  ↑         │
                      GND 现在导通了！

   电感要维持电流 → 但 +12V 那边的路断了
   → 它在电感两端产生电压，把"二极管"那一端抬成【正电压】
   → 二极管【正向导通】！
   → 电流找到新的出路：GND → 二极管 → 电感 → 输出 → 负载
   → 电感把存的能量"吐出来"，继续给负载供电 ✅
```

> **"续流二极管"这个名字的含义：让电流继续流动的二极管。**
> **它平时不干活，只在开关断开的瞬间导通。没有它，电感产生的高压会直接打穿开关管。**

### 4.3 两个阶段合起来

```
   电感电流随时间的变化：

   ↑ 电流
   │     ╱╲    ╱╲    ╱╲
   │   ╱    ╲╱    ╲╱    ╲
   └──────────────────────→ 时间
     ↑      ↑      ↑
   开关闭合  断开  闭合

   无论哪个阶段，负载都在持续获得电流 ✅
```

> **开关负责"节奏"，电感负责"平滑"，二极管负责"续命"。**

## 第 5 步：逐个讲外围元件

### 5.1 L1 = 15µH —— 储能电感

```
电感越大 → 电流波动越小（输出更平滑）✅ 但体积大、贵、响应慢 ❌
电感越小 → 体积小、便宜、响应快 ✅ 但纹波大 ❌
15µH 是折中值
```

**两个关键参数：**

| 参数 | 含义 |
|---|---|
| **电感量** | 15µH，决定电流纹波大小 |
| **饱和电流** | 超过它，电感会"饱和"（失去电感特性，变成一根导线） |

> **饱和电流是个容易忽略的坑：**
> ```
> 如果电感选小了：饱和 → 不再"反抗电流变化"
>   → 电流突然暴涨 → 开关管过流烧毁
> ```
> **选电感时，"饱和电流"必须大于电路的最大工作电流（还留余量）。**

### 5.2 D12 = SS34 肖特基 —— 续流二极管

**为什么必须用肖特基？两个原因：**

**原因一：压降小**

| 二极管类型 | 正向压降 |
|---|---|
| 普通硅二极管（如 1N4007） | **0.7~1V** |
| **肖特基（如 SS34）** | **0.3~0.5V** ✅ |

```
阶段二（续流）时，5A 电流下：
   普通二极管损耗 = 0.7V × 5A = 【3.5W】❌
   肖特基损耗    = 0.4V × 5A = 【2W】  ✅
```

**原因二（更关键）：反向恢复时间极短**

```
普通二极管从"导通变截止"时不是立刻截止的
   → 它会先"反向导通"一小段时间（反向恢复时间 trr）

【问题来了】
   开关频率 500kHz → 每 2µs 就要切换一次
   普通二极管 trr：几百 ns ~ 几 µs
   → 【它还没恢复过来，就又要导通了】
   → 这段时间里 +12V 和 GND 之间有电流直通！
   → 【发热、效率暴跌、甚至烧毁】❌

肖特基：trr ≈ 0 → 完全跟得上 500kHz ✅
```

> **选续流二极管的两条铁律：① 压降小 ② 反向恢复快。**

### 5.3 C40 = 10nF —— 自举电容

```
   +12V ──┬── BOOT（芯片的自举脚）
           │
         [C40 10nF]
           │
          PH（开关节点）
```

```
TPS5430 内部的高边开关是【N 沟道 MOS】
   → 栅极需要"比源极（PH 节点）高 10V"的电压
   → 当 PH = 12V 时栅极需要 22V，而芯片只有 12V ❌
   → 【自举电容】：开关断开时充到约 10.5V，
      开关闭合时它的"地板"（PH）抬到 12V → 上端自动 22.5V ✅
```

> **这个套路和三相桥上管的 D1/C3 一模一样，只是功率小得多。**
> **记住：看到芯片上有"BOOT"引脚，就知道它内部有高边 N-MOS，需要自举。**

### 5.4 C44 / C45 —— 输入去耦

```
   +12V ──┬── C44 100nF
           ├── C45 10µF
           └── VIN（芯片的电源脚）
```

开关每秒开合 50 万次，每次闭合瞬间要抽一大口电流。靠远处的大电容供电会因为**走线电感**而响应不及，所以必须就近放小电容"当场供货"。

## 第 6 步：输出 5V 是怎么"定"出来的？

**靠反馈。**

```
        +5V（输出）
          │
       [R48  10kΩ]
          │
          ├──────── VSENSE（芯片的反馈脚，4 脚）
          │
       [R53  3.24kΩ]
          │
         GND
```

**芯片内部基准 1.221V，它的逻辑是：**

```
· VSENSE < 1.221V → 输出太低 → 【延长开关闭合时间】（占空比↑）
· VSENSE > 1.221V → 输出太高 → 【缩短开关闭合时间】（占空比↓）
→ 直到 VSENSE 稳定在 1.221V
```

**算一下：**

```
VSENSE = Vout × R53 / (R48 + R53)
1.221 = Vout × 3.24 / 13.24
Vout = 1.221 / 0.2447 = 【4.99V】≈ 5V ✅
```

**换个写法（教科书公式）：**

```
Vout = 1.221V × (1 + R48 / R53) = 1.221 × (1 + 10/3.24) = 4.99V
```

### "用电阻比例定电压"这个套路，你在板子上见了三次

| 位置 | 用什么定什么 | 公式 |
|---|---|---|
| **TPS5430 的 R48/R53** | 定输出电压 5V | `Vout = 1.221 × (1 + R48/R53)` |
| **电流采样的 R1/R4** | 定偏置 1.65V | `V = VCCA × R4/(R1+R4) = 3.3/2` |
| **运放的 R32/R34** | 定增益 15 倍 | `增益 = R32/R34` |

> **规律：芯片/电路内部都有一个"基准"，你用电阻网络把输出"按比例映射"到这个基准上。**
> **想改变输出？改变那个"比例"（换电阻）就行。**

## 第 7 步：用一个故事串起来（水塔供水）

```
【角色】
   +12V 水源   = 高压水源
   开关管      = 一个快速开合的大阀门（每秒 50 万次）
   L1 电感     = 一个【惯性很大的飞轮】
   续流二极管  = 一个【只允许水往一个方向流的单向阀】
   输出电容    = 一个小水塔

【工作过程】
   阀门开 → 水冲进飞轮 → 飞轮被推着转起来（转速上升）
          → 水继续流到小水塔和用户 ✅
   阀门关 → 但飞轮还在转！（惯性）
          → 它继续推水，水从"单向阀"那条路被吸过来（从水池）
          → 继续供应用户 ✅

【关键】飞轮的"惯性"就是电感的"不允许电流突变"
        → 阀门关了，水照流 → 输出保持平稳

【反馈】水位传感器（R48/R53）不断检测
        → 水位低 → 阀门开久一点
        → 水位高 → 阀门开短一点 → 始终稳定在 5V ✅
```

## 本节总结

### 元件的分工

| 元件 | 角色 | 一句话 |
|---|---|---|
| **开关管**（芯片内部） | **节奏** | 快速开合，决定占空比 |
| **L1 电感** | **平滑 + 中转** | 开关开时存能量，关时放能量 |
| **D12 续流二极管** | **续命** | 开关关时给电感电流一条出路 |
| **C39 输出电容** | **滤细纹波** | 把残余波动抹平 |
| **R48/R53** | **定值** | 用电阻比例把输出"钉"在 5V |

### 三条关键认知

**① 电感的"不允许电流突变"是双刃剑**

```
敌人：电流被切断 → 产生超高压 → 打穿器件
朋友：电流想变小时 → 它主动推动电流继续流
关键：给它一条"出路"（续流二极管），敌人就变成朋友。
```

**② 为什么必须用肖特基**

```
① 压降小（0.3V vs 0.7V）→ 少发热
② 反向恢复极快 → 跟得上 500kHz
   （普通二极管恢复不过来会造成直通 → 发热甚至烧毁）
```

**③ "用电阻比例定电压"是通用套路**

```
芯片内部有基准（TPS5430 是 1.221V）
→ 你用电阻网络把输出按比例映射到基准
→ 想改输出？改比例（换电阻）
```

## 补充：如果不用二极管 —— "同步整流"

**二极管有 0.4V 压降，就说明它有损耗。有没有更好的办法？**

```
把续流二极管换成一个 MOS 管
→ 在需要续流的时刻让它导通
→ 电流走【沟道】，压降 = I × RDS(on) = 5A × 5mΩ = 【25mV】
→ 比肖特基的 450mV 小了 18 倍
```

| | 二极管续流 | **同步整流（MOS）** |
|---|---|---|
| 阶段②压降 | 450mV | **25mV** ✅ |
| 5A 时损耗 | **2.25W** | **0.125W** ✅ |
| 控制复杂度 | 简单（自动工作） | **复杂**（要精确控制下管时序） |
| 风险 | 无 | **上下管同时导通 = 直通炸管** |

> **本板 TPS5430 用的是 D12（SS34 肖特基）→ 属于"非同步"方案。**
> **很多"高效率"芯片内部集成了下管 MOS —— 那才是同步整流。**

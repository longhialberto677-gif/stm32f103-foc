# 第 2-1 节：为什么不能用电阻分压

> 难度 🟢 轻松。这一节不教新电路，只做一件事：**排除错误方案。**

---

## 第 1 步：问题来了

第 1 课结束，我们有了一个**稳定的 +12V 主轨**。但板子上需要的电是：

| 谁 | 需要多少伏 |
|---|---|
| STM32 数字部分 | **3.3V** |
| STM32 的 VDDA | **3.3V**（而且要很干净） |
| 3 颗电流采样运放 | **3.3V**（而且要很干净） |
| LCD / 按键 / LED | **3.3V** |
| CH340N / TJA1050T | **3.3V** |
| FD6288T 驱动芯片 | **12V**（刚好，不用变） |

> **手上只有 12V，但大部分芯片要 3.3V。怎么变？**

---

## 第 2 步：最容易想到的办法 —— 两个电阻分压

```
   +12V ──[R1]──┬── 输出
                [R2]
                GND

   输出电压 = 12V × R2 / (R1 + R2)
```

**要得到 3.3V，就配比例：**

```
   3.3 / 12 = R2 / (R1 + R2)
   → 取 R1 = 87Ω，R2 = 33Ω
   验证：12 × 33/(87+33) = 12 × 0.275 = 【3.3V】✅
```

**空载测一下，真的是 3.3V。看起来完美。但一接上负载就崩了。**

---

## 第 3 步：崩在哪 —— 三个致命问题

### 问题 1：负载一接，电压就塌

```
【空载时】
   电流从 R1 流到 R2 再到地，只有一条路
   → 分压比就是 87:33 → 输出 3.3V ✅

【接上 MCU 后】
   MCU 相当于一个电阻，【并联在 R2 上】
        +12V ──[R1]──┬── 输出 ──→ MCU
                      │
                    [R2]  [R_MCU]   ← 并联！
                      │      │
                     GND ────┘
   → 等效的"下臂电阻"变小 → 分压比变了 → 输出电压【下降】
```

**算一下掉多少（MCU 要 100mA 时）：**

```
MCU 等效电阻 = 3.3V / 0.1A = 33Ω
下臂 = R2 ∥ R_MCU = 33Ω ∥ 33Ω = 【16.5Ω】

Vout = 12 × 16.5 / (87 + 16.5) = 12 × 0.159 = 【1.9V】❌
→ 从 3.3V 掉到 1.9V，MCU 直接复位
```

> **分压器的输出电压"依赖负载"。负载一变，电压就变。这不是"不够好"，是"根本不成立"。**

### 问题 2：静态功耗巨大（就算不接负载）

```
空载电流 = 12V / (R1 + R2) = 12V / 120Ω = 【100mA】
白烧功率 = 12V × 100mA = 【1.2W】
→ 什么都不干，就烧 1.2W
```

**意思是：分压器白烧的电，和它实际供给的电一样多。**

### 问题 3：多余的电压全变成热 —— 电阻烧毁

```
R1 上电压 = 12 − 3.3 = 8.7V
R1 发热 = 8.7V × 0.1A = 【0.87W】

而一颗 0402 贴片电阻额定只有 1/16 W = 0.0625W
→ 超了 14 倍 → 【瞬间烧毁，冒烟】
```

| 封装 | 额定功率 | 能不能扛 0.87W |
|---|---|---|
| 0402 | 0.0625W | ❌ 超 14 倍 |
| 0603 | 0.1W | ❌ 超 8.7 倍 |
| 0805 | 0.125W | ❌ 超 7 倍 |
| 1206 | 0.25W | ❌ 超 3.5 倍 |
| **2512** | **1W** | ✅ 勉强（但已经是个大块头） |

---

## 第 4 步：更深一层 —— 分压器根本不是"电源"

### 4.1 电压是"被电流撑起来"的

```
水压是怎么产生的？
   不是"水管里存着水压"，而是"水泵在推水，推得动才有水压"

电压也一样：
   电压 = "电路能维持的电位差"
   维持它的能力叫：【源阻抗】
       源阻抗 = 0Ω  →  "硬"电压源，接任何负载电压都不变 ✅
       源阻抗 大    →  "软"电压源，一接负载电压就塌 ❌
```

### 4.2 分压器的"源阻抗"是多少？

```
从输出端往左看，R1 和 R2 是"并联"关系（都通向低阻抗的电源或地）：

源阻抗 = R1 ∥ R2 = 87Ω ∥ 33Ω = 【24Ω】
```

**24Ω 是什么概念？**

```
负载电流 100mA 时，源阻抗上的压降 = 0.1A × 24Ω = 【2.4V】
输出本来是 3.3V → 现在只有 3.3 − 2.4 = 【0.9V】
```

> **分压器的源阻抗是"几十欧姆"级别；一个合格的电源应该是"几毫欧"级别。差 10000 倍。**
> **这就是为什么"分压器不是电源" —— 它能"指示"电压，但撑不住电压。**

### 4.3 分压器的正确用途

| 用途 | 为什么可以 |
|---|---|
| **ADC 采样分压**（测量母线电压） | ADC 输入阻抗极高（几 MΩ），几乎不取电流 ✅ |
| **基准电压分压**（比如 1.65V） | **后面必须加运放跟随器缓冲** ✅ |
| **偏置电路** | 同样需要缓冲 ✅ |

**你板子上两个地方用了分压器，都用对了：**

| 位置 | 分压 | 为什么不直接用 |
|---|---|---|
| TPS5430 反馈（R48/R53） | 10kΩ / 3.24kΩ | 是给芯片内部的高阻比较器用的，不取电流 ✅ |
| 电流采样基准（R1/R4） | 10kΩ / 10kΩ | 后面接了运放跟随器缓冲 ✅ |

> **规律：分压器要"接给高阻抗的负载"，不能"直接接给负载供电"。**

---

## 第 5 步：第二个"容易想到"的办法 —— 线性稳压器直降

```
   12V ──[AMS1117-3.3]── 3.3V
```

**能工作，但会烧。**

### 5.1 线性稳压器不是"变魔术"，而是"把多余的电压主动烧掉"

```
线性稳压器内部 = 一个【会自动调节的可变电阻】

   12V ──[可变电阻]──┬── 3.3V
                     │
                  负载
   → 多余的 8.7V 全部变成热，散在芯片上
```

**比喻：线性稳压器像一个"泄洪闸" —— 上游压力太大，它就在中间"放掉"多余的压力。**

### 5.2 算一下热多少

```
VCC 需要 200mA 时：
压差 = 12V − 3.3V = 8.7V
发热 = 8.7V × 0.2A = 【1.74W】

SOT-223 热阻约 60°C/W：
温升 = 1.74W × 60 = 【104°C】
环境 25°C → 芯片温度 【129°C】
→ 超过结温上限（125~150°C）→ 热保护/烧毁 ❌
```

### 5.3 效率有多低？

```
线性稳压器效率 = 输出电压 / 输入电压 = 3.3 / 12 = 【27.5%】
→ 72.5% 的电全部变成热
```

> **线性稳压器的效率"由压差决定"。压差越大，效率越低，发热越多。**
> **所以：小压差可以用线性，大压差绝对不行。**

---

## 第 6 步：两个错误方案的共同点

| | **电阻分压** | **线性稳压直降** |
|---|---|---|
| 电压稳得住吗 | ❌ 负载一变就塌 | ✅ 稳得住 |
| 发热 | 0.87W（烧电阻） | 1.74W（烧芯片） |
| 根本问题 | **源阻抗太大（几十欧）** | **效率太低（27%）** |

```
   分压器：多余的 8.7V 烧在 R1 上
   线性稳压：多余的 8.7V 烧在芯片里
   区别只是"烧在哪"，不是"烧不烧"。
```

---

## 第 7 步：所以需要"不烧掉多余电压"的办法

### 7.1 关键洞察：不用"烧掉"，用"截断"

```
【线性的思路】12V 全部进来，多余的 8.7V 烧掉
【开关的思路】让 12V 【只接通一部分时间】
   比如只在 42% 的时间里接通
   → 输出电压的平均值 = 12V × 42% = 【5V】
   → 开关管要么"全通"（压降≈0），要么"全断"（电流=0）
   → 【没有"半开"，就没有烧掉的功率】✅
```

**比喻：**

```
【线性 = 用闸门卡住水流】
   水流太大就用闸门半开着卡住 → 水在闸门处剧烈摩擦、发热
【开关 = 快速地全开全关】
   全开 0.42 秒，全关 0.58 秒，反复循环
   → 全开时没有阻力（不发热），全关时没有水流（不发热）
   → 平均流量刚好合适，而且【几乎不发热】✅
```

### 7.2 这就是"三级"的由来

```
   +12V ──[TPS5430 开关降压]──→ +5V ──┬──[AMS1117 线性]──→ VCC（数字3.3V）
                                      │
                                      └──[RT9013 线性]──→ VCCA（模拟3.3V）
              ↑                                    ↑
      大压差(7V)用开关                    小压差(1.7V)用线性
      效率 90%、几乎不发热                损耗小、而且干净
```

**为什么最后还要用线性？**

```
开关电源虽然效率高，但它每秒开关 50 万次
→ 输出上叠加着开关频率的纹波

而 3.3V 是给 MCU 和运放用的，需要【干净】
→ 在开关电源后面再串一级"线性稳压"
→ 线性的 PSRR（纹波抑制）能把纹波压下去
→ 最终输出：既高效、又干净 ✅
```

## 本节总结

### 两个错误方案、两个根本原因

| 方案 | 致命问题 | 根本原因 |
|---|---|---|
| **电阻分压** | 负载一变电压就塌 + 电阻烧毁 | **源阻抗几十欧姆（太大）** |
| **线性稳压直降** | 发热 1.74W，芯片过热 | **效率只有 27%** |

### 三条通用规律

**① 分压器不是电源**

```
   它能"指示"电压，但不能"撑住"电压
   正确用途：接给"高阻抗的负载"
   错误用途：直接给负载供电
```

**② 线性稳压的效率 = 输出电压 / 输入电压**

```
   12V → 3.3V：效率 27.5%
   5V  → 3.3V：效率 66%
   → 压差越小，效率越高
```

**③ 开关电源不"烧"多余电压，而是"截断"**

```
   代价：输出有高频纹波 → 后面要串一级线性来"精修"
```

# 第 4-3 节：三相桥 + 采样电阻

> 难度 🟡。第 4 课的最后一节。讲清"三相全桥"这个拓扑，以及采样电阻为什么插在下管下面。

---

## 第 1 步：现在缺什么？

```
✅ 6 路带死区的 PWM（TIM1）
✅ 一颗"翻译官"（FD6288T）
✅ 6 颗 MOS 的栅极网络（R8/R9/D4…）
✅ 三路自举（D1/C3…）

缺的是：这 6 颗 MOS 怎么摆？
```

---

## 第 2 步：三相全桥长什么样

**答案：三个"半桥"并排。**

```
        +12V 母线
          │
     ┌────┼────┬────┐
     │    │    │    │
    [Q1] [Q3] [Q5]  │   ← 三个上管
     │    │    │    │
     ├────┼────┼────┤
     │    │    │    │
    M_U  M_V  M_W   │   ← 三个输出，接电机三根线
     │    │    │    │
    [Q2] [Q4] [Q6]  │   ← 三个下管
     │    │    │    │
     └────┼────┼────┘
        PGND PGND
```

**每"一路"就是一个半桥：上管 + 下管 + 输出中点。三个输出 → 接电机 U/V/W。**

> **这就是"三相全桥逆变器"，所有 BLDC / PMSM 驱动的标准拓扑。**

---

## 第 3 步：为什么必须用"半桥"，不能用低边开关？

```
【半桥的能力】
   上管开 → 电流从母线【流出】到电机
   下管开 → 电流从电机【流回】母线
   → 同一个输出点，电流方向可以正可以反 ✅

【低边开关只能】
   +12V ── 电机 ──[开关]── GND
   → 只能"开/关"，电流只能单向 ❌
```

**而电机相电流是【交流】的（一会儿流出、一会儿流回）→ 只有半桥能做到。**

> **"半桥"是电机驱动的原子单元。三个半桥 = 三相电机。**

---

## 第 4 步：⭐ 采样电阻插在哪？（三种方案）

### 方案 A：插在母线上（单电阻）

```
   +12V ──[采样电阻]──┬── 三个上管
                       │  （桥）
                     PGND
```

| | |
|---|---|
| ✅ | **只要一个电阻、一个运放**，最便宜 |
| ❌ | **采样时刻极难控制** —— 不同开关状态下，母线电流和相电流的关系不一样 |
| ❌ | 占空比特殊区域根本测不到 |

### 方案 B：插在三个下管下面（三电阻）⭐ 本板选的

```
        +12V
          │
     ┌────┼────┬────┐
    [Q1] [Q3] [Q5]
     │    │    │
    M_U  M_V  M_W
     │    │    │
    [Q2] [Q4] [Q6]
     │    │    │
   [R19] [R35] [R49]   ← 三颗 10mΩ
     │    │    │
     └────┼────┘
        PGND
```

| | |
|---|---|
| ✅ | **每相电流随时可测**，波形最干净 |
| ✅ | **三相同一时刻采样**，满足 Ia+Ib+Ic=0 |
| ✅ | 可做完整 FOC + 独立过流保护 |
| ❌ | 成本高（3 个电阻 + 3 个运放 + 3 路 ADC） |

### 方案 C：插在两个下管下面（双电阻）

| | |
|---|---|
| ✅ | 省一个运放 |
| ❌ | 第三相要"算"出来（`Ic = −Ia − Ib`），低速误差大 |

### 三方案对比

| 方案 | 电阻 | 运放 | 优点 | 缺点 |
|---|---|---|---|---|
| **单电阻** | 1 | 1 | 最便宜 | **采样时刻极难控制**，低速差 |
| **双电阻** | 2 | 2 | 折中 | 第三相要推算 |
| **三电阻（本板）** | **3** | **3** | **最干净、可做完整 FOC** | 成本高 |

> **本板选"三电阻"，说明设计者是想认真做 FOC 的。在采样上省钱 = 在 FOC 性能上省钱。**

## 第 5 步：⚠️ 下管采样的"时机问题"（关键，最容易理解错）

**三电阻方案有个前提：电流只有走【下管那条路】时，才能被采样电阻测到。**

### 5.1 电流在两条路之间切换

**一个半桥，相电流只有两条路可走：**

```
        上管导通          下管导通
        ────────          ────────

   +12V                    +12V
     │                       │
   [Q1 通]                 [Q1 关]
     │                       │
     ├── M_U                ├── M_U
     │   ↓                  │   ↑
   电机                    电机
     │                       │
   [Q2 关]                 [Q2 通]
     │                       │
    PGND                   [R19]  ← 电流走这里！
                            │
                          PGND
```

**⚠️ 关键：不管走哪条路，都是【同一个相电流】。**

### 5.2 两种状态对比

| 状态 | 相电流 | 采样电阻 R19 | 能不能测 |
|---|---|---|---|
| **上管导通** | **照常流动** | **没有电流通过** | ❌ **测不到** |
| **下管导通** | **照常流动** | **有电流通过** | ✅ **能测** |

> **容易误解的地方：**
> **"测不到"不等于"相电流是 0"。**
> **相电流一直都在流动，只是它走上了管那条路，没经过采样电阻。**
>
> **比喻：相电流是一条河，采样电阻是河上装的流量计。**
> **上管导通时水从另一条支流走了 → 流量计读数为 0，但整条河的水还在流。**

### 5.3 所以要在"三个下管同时导通"的时刻采

```
① PWM 用【中心对齐模式】
② 这个时刻就是【计数器到谷底】的那一瞬间
③ 用 TIM1 硬件触发 ADC，触发点设在谷底
④ 三相同一瞬间采完 → 保证 Ia+Ib+Ic=0 成立
```

### 5.4 ⭐ 为什么"谷底时刻三个下管都导通"？（不是巧合，是设计保证的）

**先看中心对齐 PWM 的原理：**

```
中心对齐模式：计数值从 0 涨到 Period，再降回 0

   计数 3600 ┤    ╱╲
             │   ╱  ╲
        3000 ┤──╱────╲──   ← 比较值
             │ ╱      ╲
           0 ┤╱        ╲
             └──────────────→ 时间

   计数 < 比较值 → 主输出有效 → 【上管导通】（周期的中间）
   计数 > 比较值 → 互补输出有效 → 【下管导通】（周期的两头）
```

**用具体数字看三相（假设占空比 20% / 50% / 80%）：**

```
时间轴：  0%        50%       100%
          ├──────────┼──────────┤

U 下管:  ██░░░░░░░░░░░░░░░░░░██     ← 两头各 10%
V 下管:  █████░░░░░░░░░░░░░░█████   ← 两头各 25%
W 下管:  ████████░░░░░░░░████████   ← 两头各 40%

三个都导通的地方：
         ██                ██
         ↑                  ↑
      开头 10%          末尾 10%
      ← 共同窗口 →       ← 共同窗口 →
```

**关键结论：**

```
共同窗口宽度 = 三相中【最短的那个下管导通时间】
→ 因为它最短，它导通时另外两个一定也在导通
```

### 5.5 ⚠️ 所以"一定有"吗？—— 要加一个约束

```
【假设某一相占空比 = 100%】
U 下管:  ░░░░░░░░░░░░░░░░░░░░░░    ← 完全没导通！
V 下管:  █████░░░░░░░░░░░░░░█████
W 下管:  ████████░░░░░░░░████████

三个都导通的地方：【没有！】
→ U 相的下管从来不导通 → U 相电流永远测不到 ❌
```

**所以：**

> **"三个下管同时导通"不是天然存在，而是靠约束【保证】出来的：**
> **⭐ 最大占空比限制在 95~97% 以内**（保证最短的下管导通时间 ≥ 3~5%）

### 5.6 这个约束和第 4-2 节的"占空比不能 100%"是同一件事吗？

**是两个独立的理由，得出同一个结论：**

| 理由 | 出自 | 说明 |
|---|---|---|
| **① 自举电容要充电** | 第 4-2 节 | 下管不导通 → 自举电容没机会打水 |
| **② 采样要有窗口** | 本节 | 下管不导通 → 那一相测不到电流 |

> **所以 SVPWM 输出必须限幅 —— 两条独立的物理约束都指向它。**

### 5.7 窗口够不够用？（算一下）

```
最坏情况：最短的下管导通时间 = 5%（限幅在 95%）
共同窗口 = 5% 的周期

但不能在窗口边缘采（那里正在切换，有噪声和振铃）
→ 只能在窗口【中间】采 → 实际可用 = 2.5% 的周期

【20kHz，周期 50µs】
   可用时间 = 50µs × 2.5% = 【1.25µs】
   
【STM32F103 的 ADC 采 3 个通道】
   每个约 1µs → 3 个 = 3µs  ❌ 不够！
```

**三个解法：**

| 解法 | 说明 |
|---|---|
| **降低 PWM 频率** | 10kHz 时窗口变 2.5µs，勉强够 |
| **提高限幅门槛** | 比如限制占空比在 10%~90%（窗口变大） |
| **用双 ADC 模式** | ADC1 + ADC2 同时采，时间减半 |

> **这就是为什么"什么时候采样"是个专门的工程问题 —— 要算清楚窗口多宽、ADC 要多久、够不够。**

## 第 6 步：采样电阻的参数怎么定？

**本板的实际值（已确认）：**

| 参数 | 值 | 说明 |
|---|---|---|
| **阻值** | **10mΩ** | 权衡：太小信号弱，太大损耗大 |
| **封装** | **2512** | 大封装为了散热 |
| **功率** | **3W** | 型号 `LR2512D-3W` |
| **品牌** | Milliohm（毫欧） | 低温度系数的专用采样电阻 |

### 为什么是 10mΩ？

```
【太小，比如 1mΩ】
   1A 时压降只有 1mV，而 ADC 1 个刻度 = 0.8mV
   → 信号只有 1 个多刻度，被噪声淹没 ❌

【太大，比如 100mΩ】
   10A 时压降 = 1V，损耗 = 1V × 10A = 【10W】❌
   而且会挤占电压余量

【10mΩ 的权衡】
   1A  → 10mV（放大 15 倍后 150mV，够 ADC 分辨 ✅）
   10A → 100mV，损耗 = 【1W】（可接受）
```

### 功率余量（针对 C2208）

```
C2208 最大电流 4.5A：
   压降 = 4.5A × 10mΩ = 45mV
   损耗 = 45mV × 4.5A = 【0.2W】

电阻额定 3W → 余量 15 倍 ✅ 非常充足
```

## 第 7 步：⭐ 隐藏角色 —— MOS 的体二极管

```
【死区期间（上下管都关）】
   电机电流还得流（电感）→ 走哪？→ 走体二极管！（4-2 节讲的）

【相线上的尖峰】
   负向尖峰 → 通过上管体二极管泄回母线
   正向尖峰 → 上下管体二极管都反偏 → 被"憋"住慢慢衰减
   → 【天然钳位，把相电压限制在母线附近】
```

**但体二极管有代价：**

```
体二极管压降约 0.7V（比沟道导通大 100 倍）
→ 死区期间电流走体二极管 → 【发热】
→ 死区越长，这段发热越多
```

> **所以死区时间的两难：太短防不住直通（危险），太长体二极管损耗大。**
> **取 500ns~1µs 是常见折中。**

## 第 8 步：完整功率级（一张图）

```
                    +12V 母线
                        │
        ┌───────────────┼───────────────┐
        │               │               │
      [Q1]            [Q3]            [Q5]      三上管
        │               │               │
        ├── M_U ────────┼── M_V ────────┼── M_W ──→ 电机端子
        │               │               │
      [Q2]            [Q4]            [Q6]      三下管
        │               │               │
     [R19 10mΩ]     [R35 10mΩ]     [R49 10mΩ]   三采样电阻
        │               │               │
        └───────────────┼───────────────┘
                        │
                      PGND
                        │
                    [R43 = 0Ω]
                        │
                       GND
```

**从这里，电流流向两个方向：**

```
【往上】电机相电流 → 需要测 → 进运放 → 进 ADC（第 5 课）
【往下】大电流回地 → 会产生地弹 → 所以要 PGND/GND 分开（第 1-4 节）
```

## 本节小结

### 一个拓扑

```
三相全桥 = 三个半桥并排
每个半桥 = 上管 + 下管 + 输出中点
三个输出 → M_U / M_V / M_W → 电机三相
```

### 三种采样方案

| 方案 | 优缺点 | 本板 |
|---|---|---|
| 单电阻（母线） | 便宜但采样时机难控 | ❌ |
| 双电阻 | 折中，第三相要算 | ❌ |
| **三电阻（下管）** | **最干净，可做完整 FOC** | ✅ **选它** |

### 采样时机的三个要点 ⭐

| 要点 | 内容 |
|---|---|
| **① 什么时候能测** | 只有**下管导通**时，电流才流过采样电阻 |
| **② "测不到"≠"电流为 0"** | 相电流照常流动，只是走了上管那条路 |
| **③ 共同窗口** | 中心对齐 PWM 的**谷底时刻**，三个下管都导通 → 可同时采三相 |
| **④ 窗口宽度** | = 三相中**最短的那个下管导通时间** |
| **⑤ 保证窗口存在** | **占空比限幅 95~97%** |

### 采样电阻的参数

```
10mΩ / 2512 封装 / 3W
→ 1A 时压降 10mV；10A 时损耗 1W
→ C2208 的 4.5A 只用 0.2W（余量 15 倍）
```

### 两个"隐藏角色"

| 角色 | 作用 | 代价 |
|---|---|---|
| **体二极管** | 死区期间续流；相线尖峰天然钳位 | **压降 0.7V → 死区损耗** |
| **死区时间** | 防直通 | 太短危险，太长费电 |

# 第 4-2 节：自举 —— 上管的电从哪来

> 难度 🔴。**这是第 4 课最难的一节，但也是最有意思的一节。**

---

## 第 1 步：问题的由来

**三相桥的一个半桥：**

```
        +12V
          │
        ┌─┴─┐
        │Q1 │  ← 上管
        └─┬─┘
          ├──── M_U（电机相线）
        ┌─┴─┐
        │Q2 │  ← 下管
        └─┬─┘
          │
        PGND
```

**下管 Q2 很好办：**

```
Q2 的源极接 PGND = 0V（固定不变）
→ 栅极给 10V，Vgs = 10V ✅
```

**上管 Q1 很难办：**

```
Q1 的源极接 M_U（电机相线），这个点在 0V 和 12V 之间跳

要让 Q1 导通，需要 Vgs = 10V
   → V栅极 = V源极 + 10V
   当 M_U = 0V  → 栅极要 10V
   当 M_U = 12V → 栅极要 【22V】❗
```

> **上管的栅极需要一个"跟着源极一起浮起来的 10V 电源"。但你手上只有 12V，凑不出 22V。**

---

## 第 2 步：为什么不用 P-MOS 图省事？

```
高边位置用 P-MOS：源极接 +12V，栅极拉到 0V → Vgs = −12V → 导通 ✅
→ 完全不需要 22V！
```

**但一个字：热。**

```
同规格下 P-MOS 的 RDS(on) ≈ N-MOS 的 3 倍

电机电流 10A 时：
   N-MOS（5mΩ）：损耗 = 100 × 0.005 = 【0.5W】 ✅
   P-MOS（15mΩ）：损耗 = 100 × 0.015 = 【1.5W】 ❌

而且上管每秒开关上万次，这个损耗是【一直累计】的
```

**所以：为了效率，上管必须用 N-MOS，就得忍受自举的复杂度。这就是"用电路复杂度换效率"。**

---

## 第 3 步：核心思路 —— 用一个"会浮起来的电池"

**想象你要给二楼送水，但只有一楼的水龙头。解法：在二楼放一个水桶，趁没人时从一楼打水上去。**

```
        +12V ────|>|──── VB1   ← "水面"
                  D1      │
                          ├── C3（100nF）← "水桶"
                          │
   电机相线 M_U ───────── VS1   ← "地板"
```

| 元件 | 角色 | 说明 |
|---|---|---|
| **C3（100nF）** | **水桶** | 存着"浮在 VS1 之上的 10.5V" |
| **D1（FR107）** | **单向进水阀** | 只允许 +12V 往 C3 里充电 |
| **VS1** | **水桶的地板** | 接电机相线，会跟着浮动 |
| **VB1** | **水桶的水面** | 自动等于 VS1 + 10.5V |

---

## 第 4 步：完整工作过程（三个阶段）

### 阶段一：下管导通（给水桶打水）

```
   下管 Q2 导通 → M_U 被拉到 0V → VS1 ≈ 0V
        ↓
   +12V 经过 D1 给 C3 充电
        ↓
   C3 两端充到约 【10.5V】（12V 减去二极管压降 0.7V）
        ↓
   ✅ 水桶装满了
```

> **注意：只有下管导通时才有机会充电。这个细节后面会变成一个重要限制。**

### 阶段二：下管关断，上管导通（用水）

```
   下管关断 → M_U 开始升高 → VS1 跟着升高
        ↓
   上管导通后，M_U ≈ 12V → VS1 ≈ 12V
        ↓
   【关键】C3 里的电荷没变，两端电压差还是 10.5V
        ↓
   所以"水面" VB1 自动变成 = 12V + 10.5V = 【22.5V】
        ↓
   上管栅极拿到 22.5V，源极 12V → Vgs = 10.5V ✅ 完美导通
```

### 阶段三：上管关断 → 回到阶段一

```
   上管关断 → M_U 被下管拉回 0V → VS1 回到 0V
        ↓
   C3 又被充电 → 循环
```

---

## ⭐ 第 4 步补充：为什么"下管关断"能让 M_U 升高？（最容易卡住的地方）

**书上常常一句话跳过这一步，但它其实是自举能工作的关键。用三阶段拆开讲。**

### 一句话答案

> **M_U 会升高，不是因为"下管关断"这个动作，**
> **而是因为【电机是电感，它不允许电流断掉】。**
> **下管一关，电流没路走了，它就自己找了一条新路 —— 上管的体二极管。**
> **"找新路"这个动作，就把 M_U 的电压"顶"上去了。**

### 拆解 ①：下管导通时

```
   +12V
     │
   [Q1 关]
     │
     ├──── M_U ────→ 电机 U 相
     │
   [Q2 通]  ← 电流从这里流回地
     │
   PGND
```

**电流路径：** 电机 → M_U → Q2 → PGND
**M_U 电压：** Q2 导通时电阻只有几毫欧，所以 **M_U ≈ 0V**

### 拆解 ②：下管关断的那一瞬间 ⭐

```
   [Q2 关掉]  → 电流的路断了
        ↓
   但电机是【电感】！电感里还流着电流（比如 1A），
   它【不肯让电流变成 0】
        ↓
   电感会怎么办？
   → 它会【拼命抬高电压】，硬把电流"推"出去
   → 但前面 Q2 关了，走不通
        ↓
   它抬头一看，发现上面有条路：
   Q1 虽然关着，但【它内部有个体二极管】
   （第 0 课学的：体二极管永远存在，关不掉）
   方向是：源极 → 漏极（对 N-MOS）
        ↓
   只要 M_U 的电压【高于 +12V】，体二极管就【正向导通】！
        ↓
   电流这样找到了新路：
   电机 → M_U → Q1 的体二极管 → +12V 母线
```

### 拆解 ③：M_U 会升到多少？

```
要让体二极管导通，需要正向压降 0.7V
→ M_U 必须升到 【12V + 0.7V = 12.7V】
→ 一到 12.7V，体二极管就导通了，电流有了出路
→ M_U 就"卡"在这个电压不动了
```

```
电压
 ↑
12.7V ┤        ┌──────────  ← 被体二极管钳住（电流从这里回母线）
      │       ╱
 12V  ┤      ╱
      │     ╱
  0V  ┤────┘
      └────────────────────→ 时间
          ↑
      Q2 关断
```

> **不是"下管关断"把 M_U 抬高的，是"电感的续流电流"把 M_U 抬高的。**
> **而且它不会无限升高 —— 一到 12.7V，上管的体二极管就把它"接住"了。**
> **这个"接住"的动作，专业上叫「续流」—— 和第 2-2 节开关电源里 D12 干的事一模一样。**

### 三阶段完整对照表

| 阶段 | 管子状态 | 电流走哪 | M_U 电压 | 谁在"决定"M_U |
|---|---|---|---|---|
| **① 下管导通** | Q2 通 | 电机 → Q2 → 地 | **≈ 0V** | **Q2 主动拉低** |
| **② 两个都关**（死区） | 都关 | 电机 → **Q1 体二极管** → 母线 | **≈ 12.7V** | **电感续流，被体二极管钳住** |
| **③ 上管导通** | Q1 通 | 电机 → **Q1 沟道** → 母线 | **≈ 12V** | **Q1 沟道导通，压降比体二极管小** |

**对应到上面的讲解：阶段一 = ①，阶段二 = ② → ③。**

### 补充：为什么上管导通后 M_U 反而从 12.7V 降回 12V？

```
【Q1 关着，走体二极管】
   压降 = 0.7V（二极管的固定压降）
   → M_U = 12 + 0.7 = 12.7V
   → 而且【损耗大】（0.7V × 电流）

【Q1 导通，走沟道】
   压降 = I × RDS(on) = 1A × 5mΩ = 0.005V（几乎为零）
   → M_U = 12 + 0.005 ≈ 【12V】
   → 而且【损耗小】
```

> **上管导通做的事：把电流从"体二极管那条路"（压降 0.7V）切换到"沟道这条路"（压降 5mV）。**
> **M_U 从 12.7V 降到 12V —— 这一丁点降低，就是省下来的损耗。**
>
> **这也解释了为什么上管必须导通：不导通的话电流一直走体二极管，0.7V 压降在 10A 下产生 7W 发热，管子很快烧掉。**

### 补充：自举电容怎么跟着动？

```
   VB1（水面）= M_U（地板）+ 10.5V（电容存的压差）

阶段 ①：M_U ≈ 0V    → VB1 = 0 + 10.5    = 【10.5V】
阶段 ②：M_U ≈ 12.7V → VB1 = 12.7 + 10.5 = 【23.2V】
阶段 ③：M_U ≈ 12V   → VB1 = 12 + 10.5   = 【22.5V】

★ 无论 M_U 怎么变，VB1 永远比它高 10.5V
★ 所以上管栅极的 Vgs 永远是 10.5V ✅
```

> **电容像一个"电压差搬运工"：它不管绝对电压是多少，只管"始终保持 10.5V 的差"。**
> **地板（M_U）升到哪，水面（VB1）就跟到哪。**

### 补充：这个理解在写代码时有用

```
【相电压和占空比的关系】
   下管占空比 = 100%  → 相电压 ≈ 0V
   下管占空比 = 0%    → 相电压 ≈ 12.7V（一直靠体二极管续流）
   下管占空比 = 50%   → 相电压 ≈ 6V 左右（平均值）

→ FOC 就是通过调整三相占空比，合成出想要的电压矢量
→ 而"相电压"就是 SVPWM 计算要得到的东西
→ 【所以 SVPWM 输出的"电压"，本质上是"占空比"】
```

## 第 5 步：由此推出四条铁律

### 铁律 1：自举电容要够大

```
上管导通期间，栅极驱动电流全靠 C3 供电
→ 容量太小，电压会往下掉 → 掉到 8V 以下 MOS 就半开了
100nF 是典型值 ✅
```

### 铁律 2：自举二极管要快

```
每个 PWM 周期，D1 都要"导通一次、截止一次"→ 频率很高

普通整流管（1N4007）：反向恢复慢 → 发热
FR107（快恢复）：够用 ✅
SS14（肖特基）：更好 —— 压降只有 0.3V，自举电压能多 0.4V ⭐
```

### 铁律 3：⭐ 占空比绝对不能到 100%

```
如果占空比 = 100%：
   → 上管【一直导通】→ 下管【永远不导通】
   → C3 再也没机会充电 → 电容慢慢漏电
   → 上管掉电 → MOS 半开 → 【发热烧毁】
```

```
所以 SVPWM 的占空比必须【限制在 95~97% 以内】
→ 强制留出 3~5% 的时间让下管导通 → 给电容"打水"的机会
```

> ⚠️ **这是新手最容易踩的坑：**
> **"为了全力输出把占空比设到 100%" → 电机转一下就停（自举电压掉光）。**
> **你会以为是程序问题，其实是【硬件限制】。**

### 铁律 4：启动时要先"打水"

```
上电瞬间 C3 是空的
→ 必须先用下管导通几个周期把电容充满
→ 靠 FD6288T 内部的上电时序，或程序里先跑几周期
```

## 第 6 步：自举电容上的电压会掉多少？

```
电容表达式：Q = C × ΔV → ΔV = Q / C

【Q 是多少？】上管导通期间栅极消耗的电荷（含 Qg + 静态电流 + 漏电）
   假设总共 Q ≈ 10nC（每次开通）

【ΔV 是多少？】
   C3 = 100nF 时：ΔV = 10nC / 100nF = 【0.1V】 ✅ 几乎不掉
   C3 = 10nF 时： ΔV = 10nC / 10nF  = 【1V】   ⚠️ 有点多
   C3 = 1nF 时：  ΔV = 10nC / 1nF   = 【10V】  ❌ 直接掉光
```

**100nF 给出 100 倍的余量，非常安全。**

> **为什么这么小的电容能驱动那么大的 MOS？**
> **因为 MOS 是【电压控制】器件 —— 栅极只需要"电压"，稳态时几乎不耗电（只有极小漏电）。一小桶水就够喝。**

---

## 第 7 步：自举的三个局限

| 局限 | 说明 |
|---|---|
| **① 占空比不能到 100%** | 下管必须有机会导通 → SVPWM 输出要限幅 |
| **② 低频时电容会漏电** | PWM 频率太低（比如 <100Hz）时，一个周期太长，漏掉的电来不及补 |
| **③ 启动瞬间电容是空的** | 需要先跑几周期下管 |

> **这三个局限全部来源于同一件事：电容必须靠"下管导通"来充电。**

---

## 第 8 步：其它"造浮动电压"的办法

| 方案 | 原理 | 优缺点 |
|---|---|---|
| **自举电容**（本板） | 用下管导通时充电 | ✅ 便宜、简单<br>❌ 占空比受限 |
| **独立隔离电源** | 每路高边配一个小型隔离 DC-DC | ✅ 不受占空比限制<br>❌ 贵、体积大 |
| **电荷泵** | 用开关电容把电压"泵"高（TB6612 用的就是这个） | ✅ 集成度高<br>❌ 电流能力有限 |

> **三种方案的本质都是"造一个比电源更高的电压"。选哪种取决于：占空比要求、成本、体积。**

## 本节总结

### 一个问题、一个答案

| 问题 | 答案 |
|---|---|
| 上管栅极要 22V，只有 12V 怎么办？ | **用自举电容"存"10.5V，让它的地板跟着源极浮起来** |

### 三个元件

| 元件 | 作用 |
|---|---|
| **C3 = 100nF** | **水桶** —— 存"浮在相线之上的 10.5V" |
| **D1 = FR107** | **单向阀** —— 只让 +12V 往里充电 |
| **VS1（接相线）** | **地板** —— 会跟着浮动 |

### 四条铁律

| 铁律 | 为什么 |
|---|---|
| **① 电容要够大（100nF）** | 太小电压会掉，MOS 半开 |
| **② 二极管要快** | 每周期开关一次，普通管发热 |
| **③ 占空比不能到 100%** ⭐ | 下管必须有机会给电容充电 |
| **④ 启动先"打水"** | 上电时电容是空的 |

### 一句话记忆

> **电容存的是"电压差"，不是"绝对电压"。地板抬多高，水面就跟着抬多高。**
> **而"地板"能不能回到 0V（打水），取决于下管有没有导通 —— 所以占空比永远不能到 100%。**

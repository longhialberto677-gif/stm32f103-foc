# 第 0 课（基础篇）：MOS 管与三极管补课

> 这节课不涉及你的板子，但不学它，第 1 课和第 4 课会完全看不懂。
> 建议顺序：先读本课 → 再读第 1 课 → 第 4 课时回来复习"高边驱动"那一段。

---

## 一、先建立最重要的一个认知：三极管是"电控开关"

先忘掉"放大""半导体""载流子"这些词。你只需要记住一句话：

> **三极管/MOS 管 = 一个用"电"控制的开关。**
>
> 给它一点电，它就导通（相当于开关合上）；不给电，它就断开（相当于开关断开）。

它和一个手动开关的区别：

| | 手动开关 | 三极管/MOS 管 |
|---|---|---|
| 谁来控制 | 你的手指 | **一个电信号** |
| 控制速度 | 一秒几次 | **一秒几万到几百万次** |
| 能不能自动化 | 不能 | **能（MCU 可以控制）** |

**这就是电机驱动的基础**：MCU 输出一个电信号 → MOS 管合上/断开 → 电机线圈得电/失电 → 通过每秒几万次的开关，控制流过电机的平均电流。

> 💡 **为什么不用"手动开关"或者"继电器"？** 因为 FOC 的 PWM 频率是 **10~20kHz**，也就是每秒要开关 1~2 万次。继电器一秒只能动作几次，机械开关更是完全做不到。**只有半导体开关能跟上这个速度。**

## 二、两种器件：三极管（BJT）vs MOS 管（FET）

这是新手最容易混的地方。它们的**功能一样**（都是电控开关），但**控制方式完全不同**。

### 2.1 三极管（BJT）：用"电流"控制

三个脚：

| 脚名 | 英文 | 作用 | 类比 |
|---|---|---|---|
| **基极** | Base（B） | **控制端**，给它一点电流 | 水龙头的**手柄** |
| **集电极** | Collector（C） | 电流**流入**端 | 水管**进水口** |
| **发射极** | Emitter（E） | 电流**流出**端 | 水管**出水口** |

**工作逻辑**：

```
基极给电流 → 集电极和发射极之间导通 → 大电流可以通过
基极不给电流 → 集电极和发射极之间断开 → 没有电流
```

**关键：它需要的是"电流"，不是"电压"。** 哪怕电压很高，只要没有电流流进基极，它就不导通。

### 2.2 MOS 管（MOSFET）：用"电压"控制

三个脚：

| 脚名 | 英文 | 作用 | 类比 |
|---|---|---|---|
| **栅极** | Gate（G） | **控制端**，给它电压 | 水龙头的**手柄** |
| **漏极** | Drain（D） | 电流**流入**端 | 水管**进水口** |
| **源极** | Source（S） | 电流**流出**端 | 水管**出水口** |

**工作逻辑**：

```
栅极和源极之间有足够电压（Vgs） → 漏极和源极之间导通
Vgs 不够 → 断开
```

**关键：它需要的是"电压差"，不是电流。**

### 2.3 为什么功率电路都用 MOS 管？

| | 三极管 BJT | MOS 管 MOSFET |
|---|---|---|
| 控制方式 | **需要持续电流**（基极电流） | **只需要电压**（栅极几乎不吃电流） |
| 控制功耗 | 一直有基极电流 → **持续耗电、发热** | 栅极只在开关瞬间吃电流 → **稳态几乎不耗电** |
| 导通电阻 | 有饱和压降（约 0.3V），大电流时发热大 | RDS(on) 可低到**几毫欧** → 发热小 |
| 开关速度 | 较快 | **更快** |
| 大电流能力 | 一般 | **强**（你的板用 6 颗） |

**结论：小电流、要简单的场合用三极管；大电流、要效率的场合用 MOS 管。**

> 你的板子两种都用了：
> - **三极管** → 驱动 LCD 背光（几十 mA，小电流）
> - **MOS 管** → 驱动电机（十几 A，大电流）

## 三、N 型 vs P 型：这是最容易搞混的地方

三极管和 MOS 管**各自都有两个类型**，先看 MOS 管（你的板子里 90% 是它）：

| | **N 沟道（N-MOS）** | **P 沟道（P-MOS）** |
|---|---|---|
| 导通条件 | **Vgs > 0**（栅极电压**高于**源极） | **Vgs < 0**（栅极电压**低于**源极） |
| 电流方向 | 漏极 → 源极 | 源极 → 漏极 |
| 最常用在哪 | **低边开关**（源极接地） | **高边开关**（源极接电源） |
| 同耐压下 RDS(on) | **小**（约 1/3） | 大 |
| 价格 | 便宜 | 贵 |

### ⭐ 核心规律（务必记住）

> **N-MOS：源极接地，栅极给正电压就导通 → 最适合做"低边开关"**
>
> **P-MOS：源极接电源，栅极拉到地就导通 → 最适合做"高边开关"**

**为什么？** 因为 MOS 管的导通条件是看 **"栅极相对源极"** 的电压差：

- **N-MOS 源极接地（0V）**：栅极给 10V → Vgs = 10V > 0 → **导通** ✅ 好办
- **N-MOS 源极接 12V 电源**：要让 Vgs > 0，栅极得给 **22V 以上**！你手上只有 12V → **做不到** ❌

所以**高边位置用 N-MOS 很麻烦**（这是第 4 课"自举电路"要解决的问题），而用 P-MOS 就很自然：

- **P-MOS 源极接 12V**：栅极拉到 0V → Vgs = -12V < 0 → **导通** ✅ 天然好办

### 高边 / 低边是什么？

先说清楚"边"是什么意思。假设你要用开关控制一个负载（电机、灯、加热丝）：

```
【高边开关】开关在负载上方
   +12V ──[开关]── 负载 ── GND
              ↑ 这里叫"高边"

【低边开关】开关在负载下方
   +12V ── 负载 ──[开关]── GND
                     ↑ 这里叫"低边"
```

**两种都能控制负载通断，但各有优劣**（后面详说）。

## 四、四种经典接法（每个都对应你板子上的真实电路）

### 4.1 低边 N-MOS（最常用、最好懂）

```
负载 (电机/灯)
   │
   ├───────── D (漏极)
   │
  [N-MOS]
   │
   ├───────── S (源极) ──── GND
   │
   └── G (栅极) ←── 控制信号 (0V 或 10V)
```

**工作过程**：
- 栅极给 10V → Vgs = 10V（因为源极接 GND = 0V）→ **导通** → 负载得电
- 栅极给 0V → Vgs = 0V → **断开** → 负载失电

**优点**：栅极只要相对"地"给电压就行，**MCU 操作简单**。
**缺点**：断开的只是"负载到地"这一段，**负载上端仍然带电**（比如电机一端还是接着 12V）。

> **你的板子上：三相桥的 3 个下管（Q2/Q4/Q6）就是低边 N-MOS。**

### 4.2 高边 P-MOS

```
   +12V
     │
     ├───────── S (源极)
     │
   [P-MOS]
     │
     ├───────── D (漏极) ──── 负载 ──── GND
     │
     └── G (栅极) ←── 控制信号 (12V 或 0V)
```

**工作过程**：
- 栅极拉到 **0V** → Vgs = 0V − 12V = **−12V** < 0 → **导通** ✅
- 栅极给 **12V** → Vgs = 12V − 12V = **0V** → **断开** ✅

**优点**：栅极给 0V 就导通，几乎不需要额外的电源。
**缺点**：P-MOS 的 RDS(on) 比同规格 N-MOS 大 3 倍左右 → **大电流时发热大**；而且贵。

> **你的板子上：「电源电路」里那两颗背靠背的 Q6/Q7（NCE30P12S）就是 P-MOS**，用它们做整板的总开关。
>
> **为什么这里能用 P-MOS？** 因为这是"总开关"，电流只有一路、而且板子对这点损耗不敏感（不像电机相电流那样十几安培高速开关）。**用 P-MOS 换来"控制简单"，这笔交易在这里划算。**

### 4.3 高边 N-MOS（需要自举）—— 第 4 课的主角

**问题来了**：三相桥的**上管**必须是 N-MOS（为了低的导通损耗），但它的源极接在电机相线上（电压在 0~12V 之间跳），栅极需要"比源极高 10V"的电压。

**这时候你有三个选择：**

| 方案 | 做法 | 评价 |
|---|---|---|
| ① 用 P-MOS | 换成 P-MOS，栅极拉到地就导通 | 简单，但 **RDS(on) 大 3 倍 → 发热严重** ❌ |
| ② 用隔离电源 | 给每路高边配一个独立的隔离 DC-DC | 效果好，但 **成本高、体积大** ❌ |
| ③ **自举电容** | 用一个电容"存"10V，让它的"地板"跟着源极一起浮动 | **成本几乎为零，效果够好** ✅ |

**自举的原理（第 4 课会细讲）**：

```
   +12V ──|>|──┬── VB (自举电容上端)
              │
            [C]  ← 这个电容存着"10.5V"
              │
   相线 ──────┴── VS (自举电容下端 = "地板")
                        ↑ 这个"地板"在 0~12V 之间跳
                        → 电容上端就自动浮到 10.5~22.5V
```

> **你的板子上：D1/D2/D3（FR107）+ C3/C4/C5（100nF）就是三路自举电路。**

### 4.4 低边 NPN 三极管（小信号开关）

```
   +3.3V (或 +5V)
     │
   [LED]  ← 负载
     │
     ├── C (集电极)
   [NPN]
     ├── E (发射极) ──── GND
     │
     └── B (基极) ←──[电阻]── 控制信号 (MCU 引脚)
```

**工作过程**：
- MCU 输出高电平 → 基极有电流流入 → **导通** → LED 亮
- MCU 输出低电平 → 基极无电流 → **断开** → LED 灭

**为什么中间要一个电阻？** ⚠️ **这个电阻非常重要，叫"基极限流电阻"**：

- 三极管的 **基极-发射极之间相当于一个二极管**，正向导通压降约 0.7V
- 如果直接把 3.3V 加到基极上**不加电阻**：`(3.3V − 0.7V) / 很小的内阻` → **电流会大到烧掉三极管或 MCU 引脚**
- 加上电阻（比如 1kΩ）：`(3.3V − 0.7V) / 1kΩ ≈ 2.6mA` → 安全 ✅

> **你的板子上：「外设电路」里驱动 LCD 背光的 Q3 就是这个接法**，R14 = 1kΩ 就是基极限流电阻。
>
> **为什么要用三极管？** 背光 LED 需要几十 mA，超过 STM32 单引脚的 20mA 上限。用三极管"以小控大"：MCU 只出 2.6mA 控制基极，三极管去承担几十 mA 的背光电流。

## 五、必须知道的 5 个参数（否则会烧管子）

### 5.1 Vgs(th) 阈值电压 —— 只是"开始导通"

数据手册上写的 `Vgs(th) = 2~4V`，很多人误以为是"给 4V 就能当开关用了"。**错！**

```
Vgs < 2V        → 完全截止（关）✅
2V < Vgs < 4V   → "开始导通"但电阻很大 ⚠️ 危险区
Vgs > 8~10V     → 完全导通，RDS(on) 最小 ✅
```

**危险区为什么危险？** 假设半开时 RDS(on) = 0.5Ω，流过 5A：
`P = I² × R = 25 × 0.5 = 12.5W` → **几毫米大的管子散 12.5W，几秒就冒烟。**

> **这就是为什么 MOS 管的栅极要驱动到 10V，而不是 3.3V。** MCU 直接驱动 MOS = 把 MOS 当电炉丝用。

### 5.2 RDS(on) 导通电阻 —— 决定导通损耗

MOS 完全导通后，漏极和源极之间还有一个很小的电阻（几毫欧到几十毫欧）。

**导通损耗 = I² × RDS(on)**

你的板子：假设 RDS(on) = 5mΩ，电机电流 10A：
`P = 100 × 0.005 = 0.5W` → 可以接受（加散热铜箔就行）

如果换成 RDS(on) = 50mΩ：`P = 100 × 0.05 = 5W` → **必须加散热片，否则烧**

> **这就是为什么第 4 课强调"上管也要用 N-MOS"**：同规格下 N-MOS 的 RDS(on) 只有 P-MOS 的 1/3。

### 5.3 Vgs 绝对最大值 —— 栅极不能给太高

一般 MOS 是 **±20V**。超过就击穿栅极氧化层（**永久损坏，不可恢复**）。

> 你的板子：FD6288T 用 +12V 驱动栅极，实际 Vgs 约 10.5V，**在 ±20V 内很安全** ✅

### 5.4 Ciss / Qg 栅极电容与栅极电荷 —— 为什么需要"驱动电流"

**栅极不是一个"电阻"，而是一个"电容"**（几 nF）。要把它的电压从 0V 拉到 10V，需要给它充入电荷。

```
充电电流 = 电荷量 / 充电时间

例：Qg = 20nC，想在 100ns 内充满
    I = 20nC / 100ns = 200mA  ← 峰值电流
```

**而 STM32 单引脚最大约 20mA** → **差 10 倍！**

**充不快会怎样？** 栅极电压上升慢 → MOS 在"危险区"停留时间长 → **开关损耗暴涨 → 发热**。

> **这就是为什么需要专门的"栅极驱动芯片"（第 4 课的 FD6288T）**：它能提供 1.8A 的峰值电流，把栅极"一脚踹开"。

### 5.5 体二极管（Body Diode）—— 既是朋友也是敌人

**MOS 管内部天然有一个二极管**，方向是"源极 → 漏极"（对 N-MOS）。

**朋友的一面**：
- 驱动**感性负载**（电机、继电器）时，它能当**续流二极管**用，给电感电流提供回路，防止电压尖峰

**敌人的一面**：
- 它**永远存在，无法关掉** → 所以单个 MOS **不能双向阻断电流**
- 这就是为什么「电源电路」里要用**两个 P-MOS 背靠背**：单个 MOS 反向时体二极管会导通，防不住反接

> 💡 **记住：MOS 管是"带一个甩不掉的二极管"的开关。**

## 六、三个必配的"周边电阻"（对应你板子上的真实元件）

### 6.1 栅极串联电阻（Rg）—— 控制开关速度

接在"驱动芯片输出"和"栅极"之间，典型 10Ω。

```
驱动输出 ──[Rg 10Ω]── 栅极
```

**作用**：
- 限制峰值电流（保护驱动芯片，它只有 1.8A 上限）
- 控制开关速度：

| Rg | 速度 | 后果 |
|---|---|---|
| 太大（100Ω） | 慢 | 在危险区停留久 → **开关损耗大、发热** |
| 太小（1Ω） | 快 | 电压/电流变化率太猛 → **EMI 超标、振铃、可能击穿** |
| **10Ω** | 适中 | 折中 ✅ |

> **你的板子：R8、R10 = 10Ω。**

### 6.2 栅源下拉电阻（Rgs）—— 保证"默认关断" ⭐

接在栅极和源极之间，典型 10kΩ。

```
栅极 ──[Rgs 10kΩ]── 源极
```

**为什么必须有？**

假设没有这个电阻，MCU 还没上电、驱动芯片还没初始化 → **栅极是浮空的**。

浮空的栅极像一个"小天线"，会被周围的电机噪声、PWM 干扰**耦合出随机电压** → MOS 随机导通 → **可能直接炸管**。

加上 10kΩ 后：栅极被强制拉到源极电位 → **Vgs = 0V → 可靠截止** ✅

> **这条是功率电路的安全底线：任何 MOS 的栅极都必须有电阻保证"没信号时是关的"。**
>
> **你的板子：R9（上管）、R13（下管）、R39（电源 P-MOS）都是这个作用。**

### 6.3 反并联二极管 —— 让"关"比"开"更快

```
驱动输出 ──┬──[Rg 10Ω]──┬── 栅极
           └──[二极管]───┘
       (阳极接栅极，阴极接驱动输出)
```

**这个二极管只在"关断"时导通**（因为关断时栅极电压 > 驱动输出）：

- **开通**：驱动输出变高 → 二极管反向截止 → 电流只能走 **Rg（慢）** → 开通慢一点，减小 EMI
- **关断**：驱动输出变低 → 栅极电压高于驱动输出 → **二极管正向导通** → 栅极电荷被**快速抽走** → **关断很快**

**为什么要"慢开快关"？**

因为**死区时间**是固定的（上下管之间的空白时间）。**关断太慢 → 上管还没关断、下管就导通了 → 直通（+12V 直接短路到地）→ 瞬间炸管。**

所以关断必须快。而开通慢一点没坏处，反而抑制振铃。

> **你的板子：D4、D5（1N4148W）就是这两个二极管。**

## 八、⚠️ 新手必踩的 6 个坑

| # | 坑 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | **用 MCU 直接驱动 MOS 栅极** | MOS 半开 → 发热烧毁 | 必须用栅极驱动芯片，栅极驱动到 10V |
| 2 | **忘记栅源下拉电阻** | 上电瞬间 MOS 随机导通 → 炸管 | 每颗功率 MOS 都配 10kΩ 下拉 |
| 3 | **三极管基极不加限流电阻** | BE 结当二极管被直接击穿 | 串 1kΩ 左右电阻 |
| 4 | **N-MOS 当高边用却不做自举** | 上管永远开不起来（Vgs 不够） | 要么用 P-MOS，要么加自举 |
| 5 | **搞错 N/P 型和电流方向** | 电路完全不工作或短路 | 记住："N 型源极接地，P 型源极接电源" |
| 6 | **只按 Vgs(th) 判断"能导通"** | 以为 3.3V 够用，实际在危险区 | 看 RDS(on) 对应的 Vgs（通常 4.5V 或 10V） |

---

## 九、本课小结（3 句话记住）

1. **三极管和 MOS 管都是"电控开关"**，区别是：三极管要**电流**控制，MOS 管要**电压**控制。
2. **N 型源极接地（低边），P 型源极接电源（高边）** —— 这是你能不能看懂功率电路的分水岭。
3. **MOS 管有三个必配电阻**：栅极串联电阻（控速度）、栅源下拉电阻（保安全）、反并联二极管（加速关断）。

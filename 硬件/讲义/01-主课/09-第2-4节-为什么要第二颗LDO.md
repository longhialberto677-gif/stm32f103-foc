# 第 2-4 节：为什么要第二颗 LDO —— 干净的 3.3V

> 难度 🔴 硬骨头，但**这是第 2 课最精彩的一节**。
> 这一节讲完，"模拟/数字分离"这个设计思想就彻底通了。

---

## 第 1 步：问题来了 —— 还剩三样东西要 3.3V

第 2-3 节结束，我们有了 **VCC（3.3V）**，能供 STM32 数字部分、LCD、按键、LED、CH340N、TJA1050T。

**但板子上还有三样东西要 3.3V，而且它们很"挑剔"：**

| 谁 | 要什么 | 为什么挑剔 |
|---|---|---|
| **STM32 的 VDDA** | 3.3V | **它是 ADC 的"尺子"** |
| **3 颗电流采样运放（OPA365）** | 3.3V | 它们的输出直接进 ADC |
| **1.65V 基准** | 3.3V | 它是"零电流"的参考点 |

**为什么这三样不能用现成的 VCC？因为 VCC 上有一个东西，对它们来说是毒药。**

---

## 第 2 步：毒药是什么？—— 先看 ADC 的原理

### 2.1 ADC 的本质：拿尺子量

```
ADC 内部有一把"尺子"，刻度是 0 ~ 4095
读数 = 4096 × (Vin / VDDA)
```

> **分母 VDDA 就是"尺子的长度"。**

### 2.2 尺子会抖，读数就全错

```
【理想情况：VDDA = 3.3000V 稳定】
   输入 1.6500V → 读数 = 4096 × 1.65/3.3 = 2048 ✅

【VDDA 抖动：从 3.3V 跳到 3.35V】
   同样是 1.65V 输入 → 读数 = 4096 × 1.65/3.35 = 2017
   → 读数差了 【31 个刻度】
   
   换算成电流（按 0.15V/A 灵敏度）：
   31 × 0.8mV = 24.8mV → 24.8mV / 0.15 = 【165mA 的假电流】
   → 实际没电流，读数却显示 165mA ❌
```

> **ADC 的精度完全取决于 VDDA 有多稳。尺子抖 1%，读数就错 1%。**
> **而 12 位 ADC 的 1 个刻度 = 0.8mV = 0.024%**
> **→ 要让 12 位 ADC 物尽其用，VDDA 必须稳到 0.024% 以内！**

### 2.3 VCC 上有什么噪声？

**回顾第 1-4 节的"数字电路的噪声"：**

```
MCU 内部 72MHz 时钟翻转、GPIO 切换、ADC 转换……
   → 每次逻辑翻转都要从 3.3V 瞬间抽一口电流（纳秒级脉冲）
   → 走线有电感
   → 突变电流 × 走线电感 = 【电压尖峰】
   → VCC 上出现高频纹波（典型 20~100mV）
```

```
VCC 上的噪声 50mV ÷ ADC 1 个刻度 0.8mV = 【62 个刻度】的噪声
→ 12 位 ADC 的精度被噪声吃掉了 62 个刻度（1.5%）
→ 等效位数只剩 10 位左右
→ 而且这个噪声是【随机的】，无法通过平均完全消除
```

> **所以决策一：VDDA 不能和数字部分共用 VCC，必须单独供电。**

## 第 3 步：三个层次的方案

### 方案 A：加个 RC 滤波（最省事）

```
   VCC ──[R 10Ω]──┬── VDDA
                  │
               [C 1µF]
                  │
                 GND
```

```
RC 低通，截止频率 f = 1/(2πRC) = 1/(2π×10×1e-6) ≈ 16kHz → 能滤高频 ✅
但 R 上有压降（取决于 VDDA 电流）
而且滤波不是"隔离"，只是"衰减" ⚠️
```

**评价**：便宜简单，但**只是改善，不是解决**。

### 方案 B：用磁珠代替电阻（常见做法）

```
直流时阻抗极小（几十毫欧）→ 几乎不降压 ✅
高频时阻抗很大（几十欧）   → 噪声被阻挡 ✅
```

**评价**：**这是最常见的做法**，很多开发板就这么干。

### 方案 C：用一颗独立的 LDO（本板选的）✅

```
   +5V ──[RT9013]── VCCA（独立的 3.3V）
```

**三个理由：**

| 理由 | 说明 |
|---|---|
| **① 真正的"隔离"** | VCCA 从 **+5V 重新稳出来**，**不是从 VCC 分出来的** |
| **② 借用了 LDO 的 PSRR** | LDO 有 20~60dB 的纹波抑制能力 |
| **③ 用"低噪声 LDO"还能更好** | RT9013 本身就是低噪声型号 |

```
【方案 A/B（滤波）】
   VCC 上的 50mV 噪声 → 经过滤波 → 还剩 5~10mV
【方案 C（独立 LDO）】
   +5V 上的噪声 → 经过 RT9013 的 PSRR（40dB = 衰减 100 倍）
   → VCCA 上只剩 零点几 mV ✅
   而且【数字部分在 VCC 上的噪声，根本传不到 VCCA】
```

> **方案 A/B 是"过滤"（filter）—— 噪声还在，只是被削弱。**
> **方案 C 是"隔离"（isolate）—— 噪声的传播路径被切断了。**
> **能"切断路径"，就不要只"削弱"。**

## 第 4 步：光分电源还不够 —— 地也必须分！

### 4.1 ADC 的两个"参考"

```
Vin 是相对【VSSA】（模拟地）测量的
```

| 参考 | 是什么 | 对应 |
|---|---|---|
| **VDDA** | **尺子**（量程上限） | 电源 |
| **VSSA** | **零点**（量程下限） | 地 |

> **ADC 的精度取决于"两个参考"：尺子（VDDA）和零点（VSSA）。这两个任何一个在抖，读数就全错。**

### 4.2 地会怎么抖？—— 回顾"地弹"

```
数字电路的大电流（几十~几百毫安）在地线上流动
   → 地线有电阻和电感
   → 地线上不同点出现电位差（"地弹"）
   → 典型值：几十 mV，而且是【高频抖动】
```

**具体到板子：**

```
如果 VDDA 和 VSSA 都接在"数字地"上：
   MCU 每翻转一次 → 地线上抖一下
   LCD 刷新时 → 地线抖
   LED 亮灭 → 地线抖
   → 这些抖动【直接】加在 ADC 的"零点"上
   → 零点抖 20mV → 相当于读数抖 25 个刻度
   → 加上电源的噪声，总共抖 80+ 个刻度 ❌
```

### 4.3 所以要做两件事

```
【第一件：把地分开】
   VCC 用【GND】（数字地）；VCCA 用【AGND】（模拟地）
【第二件：让两条地"单点汇合"】
   AGND ──[R44 = 0Ω]── GND
```

```
【不分开时】数字电流在"地"上流动 → 产生地弹
           → 地弹直接出现在 ADC 的零点上 ❌
【分开后】  数字电流只在 GND 上跑，在 R44 那一点才汇入 AGND
           → AGND 上的电流只有"模拟部分"（几 mA）
           → AGND 上的压降可以忽略 → ADC 的零点几乎不动 ✅
```

## 第 5 步：完整的设计逻辑链（第 2 课精髓）

```
        ┌─────────────────────────────────────────┐
        │  ADC 读数公式：读数 = 4096 × Vin / VDDA   │
        │  它有两个"隐含的参考"：                  │
        │     · VDDA = 尺子（决定量程）            │
        │     · VSSA = 零点（决定基准）            │
        └─────────────────────────────────────────┘
                          ↓
        ┌─────────────────────────────────────────┐
        │  要让读数准，这两个参考必须【极稳】       │
        │     · 数字电路的噪声会污染它们            │
        │     · 地弹也会污染它们                    │
        └─────────────────────────────────────────┘
                          ↓
        ┌─────────────────────────────────────────┐
        │  所以必须【双重隔离】：                   │
        │     ① 电源隔离：VDDA 单独用一颗 LDO       │
        │     ② 地隔离：VSSA 单独走 AGND            │
        │  并且两者只在一点和数字侧汇合（0Ω）        │
        └─────────────────────────────────────────┘
                          ↓
        ┌─────────────────────────────────────────┐
        │  于是有了：                              │
        │     AMS1117 → VCC + GND   （数字用）      │
        │     RT9013  → VCCA + AGND （模拟用）      │
        │     R44 = 0Ω 单点汇合                     │
        └─────────────────────────────────────────┘
```

> **一句话总结："ADC 的精度 = 它的两个参考有多稳。"**
> **所以：尺子（VDDA）要单独稳压，零点（VSSA）要单独走地。**

## 第 6 步：两颗 LDO 为什么型号不同？

| | **AMS1117-3.3**（供 VCC） | **RT9013-33GB**（供 VCCA） |
|---|---|---|
| 输出电流 | 约 **1A** | 约 **500mA** |
| 压差（Dropout） | **~1.1V** | **~250mV** ✅ |
| 静态电流 | 几 mA | 很小 |
| 噪声 | 较大 | **低噪声** ✅ |
| 封装 | SOT-223（大，好散热） | SOT-23-5（小） |
| **定位** | **"能扛"的数字电源** | **"干净"的模拟电源** |

**为什么数字那边要"能扛"？**

```
VCC 要供：MCU + LCD + 按键 + LED + CH340N + TJA1050T
   → 电流可能 200mA 以上，还会突跳
   → 需要"扛得住" → AMS1117（1A 能力），大封装散热好
   （数字部分不在乎噪声，只要能供得上电）
```

**为什么模拟那边要"干净"？**

```
VCCA 要供：VDDA + 3 颗运放 + 1.65V 基准
   → 总共才 20~30mA，但要求极其干净
   → RT9013（低噪声、低压差），小封装就够
```

### "低压差 250mV"的好处

```
RT9013 压差只有 250mV
→ 输入 5V 要输出 3.3V，还剩 1.45V 余量 ✅ 轻松

如果压差是 1.1V（AMS1117 那种）：
   输入 5V → 输出最多 3.9V → 勉强够 3.3V
   但万一 5V 掉到 4.2V（比如 USB 供电不稳）
   → 输出最多 3.1V → 【3.3V 稳不住了】
   → VDDA 掉电 → ADC 全乱 ❌
```

> **"Dropout（压差）"决定"输入电压最低能到多少，输出还不掉"。**
> **压差小 = 供电更可靠（输入稍微低一点也能稳住）。**

## 第 7 步：顺带解释两个"看不太懂"的设计

### 7.1 1.65V 基准为什么用 VCCA + AGND？

```
   VCCA (3.3V) ──[R1 10kΩ]──┬──[R4 10kΩ]── AGND
                             │
                             └──→ 运放跟随器 → VREF (1.65V)
```

```
如果分压用 VCCA 和 GND（跨了两套地）：
   → VCCA 以 AGND 为参考，GND 又是另一条地
   → 两者之间的电位差会混进分压结果
   → 1.65V 基准就跟着抖 ❌
用 VCCA + AGND（同一套）：
   → 分压的参考就是它自己的地 → 电位差自动抵消 ✅
```

> **规律：同一个模拟电路里的所有东西，都要挂在同一套电源/地上。**

### 7.2 运放也是这么接的

```
运放的 V+ 脚（5 脚）→ VCCA      ← 模拟电源
运放的 V− 脚（2 脚）→ AGND      ← 模拟地
```

**运放"看"的是采样电阻上的信号（那个信号在 PGND 附近），但供电和地是 VCCA/AGND。**
**这也是"跨系统"但允许的情况** —— 因为：

```
运放的输入端是高阻的（几乎不吃电流）
→ 它只是"读"那个信号，不会把 PGND 的噪声带进 AGND ✅
→ 而且运放做的是【差分放大】，会把共模的地弹减掉（第 5 课详讲）
```

> **这是"差分放大"的价值：它让"测量脏地上的信号"成为可能。**

## 第 8 步：三套地的完整架构（第 2 课收尾）

```
┌──────────────────────────────────────────────┐
│  PGND（功率地）                               │
│  · MOS 桥、采样电阻下端、FD6288T 的 COM        │
│  · TPS5430 功率部分                           │
│  · 电流大（几安培）、最"脏"                     │
└────────────────────┬─────────────────────────┘
                     │ [R43 = 0Ω]   ← 第 1 课
┌────────────────────┴─────────────────────────┐
│  GND（数字地 / 信号地）                        │
│  · STM32 数字部分、LCD、按键、LED              │
│  · CH340N、TJA1050T、AMS1117                  │
│  · 电流中等（几十~几百毫安）、中等噪声           │
└────────────────────┬─────────────────────────┘
                     │ [R44 = 0Ω]   ← 第 2 课
┌────────────────────┴─────────────────────────┐
│  AGND（模拟地）                               │
│  · STM32 的 VSSA、3 颗 OPA365、1.65V 基准      │
│  · 电流极小（几毫安）、要求最稳、最干净          │
└──────────────────────────────────────────────┘
```

**为什么 AGND 不直接接 PGND，而要经过 GND 中转？**

```
如果 AGND 直接接 PGND：PGND 上的地弹（几十 mV）【直接】加到 AGND 上 ❌
经过 GND 中转（两级隔离）：
   第一级：地弹在 R43 上被"稀释"
   第二级：GND 上的噪声再被 R44 隔离一次
   → AGND 相对安静得多 ✅
```

> **设计哲学：地的分级，是按"噪声等级"分的。**
> **最脏的（功率）放最外层，最干净的（模拟）放最内层，用 0Ω 逐级汇合。**

## 本节总结

### 三个决策、三个理由

| 决策 | 为什么 |
|---|---|
| **① 用第二颗 LDO（而不是从 VCC 滤波）** | 滤波只是"削弱"噪声；**独立 LDO 是"切断路径"** |
| **② 地也要分开（AGND）** | ADC 有两个参考：尺子（VDDA）和零点（VSSA），**两个都不能抖** |
| **③ 两颗 LDO 型号不同** | 数字要"能扛"（1A、大封装），模拟要"干净"（低噪声、低压差） |

### 核心公式（背下来）

```
ADC 读数 = 4096 × Vin / VDDA
→ 读数准不准，取决于 VDDA（尺子）稳不稳
→ 还取决于 VSSA（零点）稳不稳
→ 所以两者都要"单独、干净"
```

### 三条通用规律

**① 能"隔离"就不要只"过滤"**

```
滤波（RC/磁珠）：噪声还在，只是被削弱
隔离（独立 LDO）：切断了噪声传播的路径 ✅ 更彻底
```

**② 分"系统"要分得彻底：电源和地都要分**

```
只分电源不分地 → 地弹照样污染 ADC 零点 ❌
电源 + 地都分   → 才真正隔离 ✅
```

**③ 同一个模拟系统里的东西要"挂在同一套电源/地上"**

```
1.65V 基准分压要用 VCCA + AGND（同一套）
运放供电要用 VCCA + AGND（同一套）
→ 不要跨系统混搭
```

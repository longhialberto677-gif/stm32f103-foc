# 第 5 课：电流采样 —— FOC 的眼睛

> 本节包含两个小节：5-1 为什么要差分放大 / 5-2 为什么要有 1.65V 偏置

---

# 第 5-1 节：为什么要差分放大

> 难度 🔴。回答一个核心问题：**为什么不能"一根线直接接到 ADC"？**

---

## 第 1 步：现在的处境

**第 4 课结束，采样电阻上有了"电流的影子"：**

```
电流 1A → R19 上压降 = 1A × 10mΩ = 【10mV】
电流 5A → R19 上压降 = 【50mV】
```

**问题不只是"小"，还有更麻烦的事。**

---

## 第 2 步：麻烦在哪？（本节核心）

```
        [Q2 下管]
             │
             ├──── IA+  ← 上端
          [R19 10mΩ]
             │
             ├──── IA−  ← 下端
           PGND
```

**R19 下端的电压真的是 0V 吗？不是。**

```
【地弹】（第 1-4 节讲过）
   电机电流 5A 要从 R19 流回电池 → 走 PGND 铜箔
   铜箔有电阻（假设 10mΩ）→ 压降 = 5A × 10mΩ = 【50mV】
   → "R19 下端"其实是 【+50mV】，而且高频抖动

【把两个数字放一起】
   要测的信号（R19 压降）= 【10mV】
   地线上的噪声（地弹）  = 【50mV】
   → 噪声比信号大 5 倍！
```

> **如果直接单端测量（只测 IA+ 对地）：**
> `测到 = 10mV + 50mV = 60mV` → 换算成电流 = **6A**
> **而实际只有 1A！误差 6 倍，测量完全没有意义。**

---

## 第 3 步：怎么解决？—— 换个问法

**关键洞察：我们根本不需要知道"对地电压是多少"。**

```
我们想知道的只是：【R19 两端差多少伏】

   IA+ 对地 = 10mV + 50mV = 60mV
   IA− 对地 =  0mV + 50mV = 50mV
   
   → 50mV 是【两端都有】的 → 一相减就消失
   → 60 − 50 = 【10mV】 ✅
```

> **核心思想：只测量"两点之差"，两端共有的东西会被自动减掉。**

---

## 第 4 步：两个专业名词（面试常问）

| 名词 | 含义 | 在你这的例子 |
|---|---|---|
| **差模信号**（Differential） | **两端"不同"的部分** | R19 上的 10mV ← **要保留** ✅ |
| **共模信号**（Common-Mode） | **两端"共同"的部分** | 地弹 50mV ← **要减掉** ❌ |

> **差分放大器干的事：放大差模，抑制共模。**

---

## 第 5 步：用水压比喻

```
   水泵 ═══════[流量计]═══════ 回水池
              A点    B点
   A 表读数：1.50 巴    B 表读数：1.49 巴
   → 压差 = 0.01 巴 ← 这就是"流量大小"

【现在水泵出口压力剧烈波动（相当于地弹）】
   A 表读数：2.50 巴（涨了 1 巴）
   B 表读数：2.49 巴（也涨了 1 巴）

   只看 A 表 → 1.50 → 2.50，涨了 67%！以为流量变大了 ❌
   看两表之差 → 2.50 − 2.49 = 0.01，一点没变 ✅
```

> **单表会被"共同的压力波动"干扰；两表之差自动抵消了共同波动。**

---

## 第 6 步：差分放大器电路

```
                    R32 = 15kΩ
              ┌───────[====]───────┐
              │        ┌───────────┴──→ 输出（进 ADC）
    IA− ──[R34 1kΩ]────┤ 4 (IN−)
                         │  OPA365
    IA+ ──[R36 1kΩ]────┤ 3 (IN+)
              │          └── 2 脚 → AGND,  5 脚 → VCCA
   VREF ──[R38 15kΩ]────┘
```

| 电阻 | 接在哪 | 作用 |
|---|---|---|
| **R34 = 1kΩ** | IA− → 反相输入 | 输入电阻（增益的分母） |
| **R32 = 15kΩ** | 输出 → 反相输入 | **反馈电阻**（增益的分子） |
| **R36 = 1kΩ** | IA+ → 同相输入 | 让两个输入端"对称" |
| **R38 = 15kΩ** | VREF → 同相输入 | 提供偏置（5-2 节讲） |

### 增益怎么算？

```
⭐ 重要规则：R32/R34 必须等于 R38/R36
   R32/R34 = 15k/1k = 15，R38/R36 = 15k/1k = 15 ✅
   → 增益 = R32/R34 = 【15 倍】
```

> ⚠️ **为什么必须"成比例"？**
> **差分放大的关键是"两个输入端的路径要对称"。**
> **乱配（比如反馈 15k、同相端 10k）→ 两端对共模的衰减不一样 → 相减时【减不干净】→ 地弹又漏回来了。**

### 完整传递函数（写代码用这个）

```
V_ADC = 1.65V + (IA+ − IA−) × 15
```

---

## 第 7 步：怎么衡量"减得干净"？—— CMRR

```
CMRR = 共模抑制比 = 差模增益 / 共模增益

CMRR = 80dB 意味着：
   80dB = 10^(80/20) = 【10000 倍】
   共模信号 50mV → 输出里只剩 50mV / 10000 = 【5µV】✅
```

**CMRR 由什么决定？**

| 因素 | 影响 |
|---|---|
| 运放本身的 CMRR | OPA365 约 80~100dB |
| **⭐⭐ 四个电阻的匹配精度** | **这才是关键！** |

```
【电阻误差的影响】
   如果 R32/R34 = 15.0，但 R38/R36 = 14.8（误差 1.3%）
   → 共模抑制被限制在约 【40dB】（只能衰减 100 倍）
   → 比运放本身的 80dB 差很多 ❌
```

> **差分放大的精度，往往不取决于运放，"取决于四个电阻配得准不准"。**

---

## 第 8 步：为什么选 OPA365？

| 要求 | 为什么 | OPA365 |
|---|---|---|
| **低失调电压 Vos** | Vos 会变成**固定的电流读数偏移**（1mV → 6.7mA） | 典型 **40µV** ✅ |
| **高带宽 / 高转换速率** | 电流是 PWM 斩出来的，变化极快 | **50MHz** ✅ |
| **轨到轨输入输出** | 输出要能接近 0V 和 3.3V，不浪费 ADC 量程 | 支持 ✅ |

**额外好处：CMOS 输入 → 输入偏置电流极小（pA 级）。**

---

## 第 9 步：一个容易忽略的细节 —— 这是"低边"采样

```
【高边采样】
   采样电阻放在 +12V 和上管之间 → 两端都在 12V 附近
   → 共模电压 12V → 需要能承受高压的运放 ❌

【低边采样】（本板）
   采样电阻放在下管源极和 PGND 之间 → 两端都在 0V 附近
   → 【共模电压很小】（只有地弹几十 mV + 采样电阻压降）✅
   → OPA365（3.3V 供电）完全够用
```

> **这是"低边采样"的隐藏福利：省掉了"高压共模"的麻烦。**
> **代价：只有下管导通时才能测（第 4-3 节讲的）。**

---

## 5-1 小结

| 问题 | 答案 |
|---|---|
| **核心问题** | 信号 10mV，地弹 50mV → 单端测量完全没用 |
| **核心思想** | 不测"每点对地多少"，只测"两点之差" |
| **两个名词** | 差模（放大）、共模（抑制） |
| **四个电阻** | R32=R38=15k，R34=R36=1k；**必须成比例** |
| **增益** | R32/R34 = **15 倍** |
| **精度瓶颈** | 通常不是运放，**是四个电阻配得准不准** |

# 第 5-2 节：为什么要有 1.65V 偏置

> 难度 🔴。这一节讲完，"眼睛"就完整了。

---

## 第 1 步：先看上一步的成果

```
V_ADC = (IA+ − IA−) × 15
```

| 电流 | R19 压降 | × 15 后 |
|---|---|---|
| +1A | +10mV | **+150mV** |
| 0A | 0mV | **0V** |
| **−1A** | −10mV | **−150mV** ❌ |
| +5A | +50mV | **+750mV** |

**放大倍数够了，但出现了【负电压】。**

---

## 第 2 步：问题在哪？

```
STM32 的 ADC：
   输入范围 0V ~ 3.3V → 只能读"正"电压
   → 【负电压读不了】，超过 −0.3V 左右可能【损坏引脚】
```

**电机相电流为什么会有负的？**

```
相电流是【交流】的：
   U 相电流
     ↑   ╱‾‾╲
   0 ┼─╱──────╲──────→ 时间
     │          ╲    ╱
     │           ╲__╱
   → 正半周：电流从桥流进电机
   → 负半周：电流从电机流回桥
   
【FOC 里必须能测到负电流】—— 否则根本没法算 Id/Iq
```

---

## 第 3 步：怎么办？—— 把"零"抬到中间

```
【原来的信号】−150mV ~ +150mV
【加上 1.65V 后】
   −150mV + 1.65V = 1.5V
       0mV + 1.65V = 1.65V
   +150mV + 1.65V = 1.8V
   → 全部落在 0 ~ 3.3V 范围内 ✅
```

```
【不加偏置】❌
   −150mV   0   +150mV
   ────┬────┼────┬────→
     ↑ 负的部分读不到

【加 1.65V 偏置】✅
   1.5V      1.65V     1.8V
   ────┬───────┼───────┬────→
   0V ─┴───────┴───────┴─── 3.3V
       ↑       ↑       ↑
     负满量程  零电流  正满量程
```

> **"零电流"不再对应 0V，而是对应【量程正中间的 1.65V】。**

---

## 第 4 步：为什么必须是"正中间"？

```
【偏置在中间 1.65V】
   正电流可用 1.65V，负电流可用 1.65V → 【对称】✅

【偏置在 1V】
   正电流可用 2.3V，负电流可用 1V → 负电流容易削顶 ❌

【偏置在 3V】
   负电流可用 3V，正电流只剩 0.3V → 正电流稍大就饱和 ❌
```

**为什么对称重要？**

```
FOC 里相电流的正负是【同等重要】的
→ 三相对称（相位差 120°）
→ 如果某一相正负量程不一样 → 波形不对称 → FOC 算错
```

---

## 第 5 步：1.65V 怎么造出来？

```
   VCCA (3.3V) ──[R1 10kΩ]──┬──[R4 10kΩ]── AGND
                             │
                             └──→ 1.65V

分压比 = 10k / 20k = 1/2 → 电压 = 3.3 × 1/2 = 【1.65V】✅
```

**两个细节：**

| 细节 | 为什么 |
|---|---|
| **R1 = R4 = 10kΩ（等值）** | 分压比正好 1/2 |
| **接 VCCA + AGND**（不是 VCC + GND） | **同一套电源/地**，基准才稳（第 2-4 节讲的） |

---

## 第 6 步：⭐ 为什么分压之后还要加一颗运放？

**分压出来就是 1.65V 啊，直接接给 R38 不就行了？**

**不行 —— 因为分压点的"内阻"太大。**

```
【分压点的内阻】
   从分压点往两边看，R1 和 R4 是【并联】的
   内阻 = R1 ∥ R4 = 10k ∥ 10k = 【5kΩ】
```

**5kΩ 内阻会造成什么？**

```
【分压点接到了 R38（15kΩ）】
   → R38 和 5kΩ 形成【额外的一条分压支路】
   → 分压点电压被"拉偏"：
      实际 = 1.65V × 15k / (5k + 15k) = 【1.2375V】
   → 不是 1.65V 了！偏了 0.4V ❌
```

**更糟的是：**

```
【偏差会"随信号变化"】
   运放同相输入端的电压随 IA+ 变动
   → 通过 R38 反作用到分压点上
   → 分压点电压也跟着动
   → 【基准成了"会动的基准"】→ 完全失去意义 ❌❌
```

### 解法：加"电压跟随器"缓冲

```
   VCCA ──[R1 10k]──┬──[R4 10k]── AGND
                    │
                    └──→ 运放 3 脚 (IN+)
                    
                         运放 1 脚 (OUT) ──┬──→ VREF 网络（1.65V）
                         运放 4 脚 (IN−) ───┘  ← 输出接回反相输入
```

| 特性 | 说明 |
|---|---|
| **输入阻抗** | **极高** → 不从分压点取电流 → 不会拉偏 ✅ |
| **输出阻抗** | **接近 0Ω** → "硬"电压源，接多少负载都稳 ✅ |
| **电压增益** | **1**（不放大，只缓冲） |

> **分压器只能"指示"电压（内阻大），跟随器让它变成"能带负载"的电压（内阻小）。**

**为什么不能用别的办法省掉这颗运放？**

| 想法 | 为什么不行 |
|---|---|
| R1/R4 换小阻值（100Ω） | 内阻降到 50Ω，但**静态电流暴涨**：3.3/200 = 16.5mA 白烧 ❌ |
| 用大阻值（1MΩ） | 内阻更大（500kΩ），偏得更厉害 ❌ |
| 用基准电压芯片（REF3012） | 精度更高，但**贵、要单独买料** |

## 第 7 步：算一遍量程和分辨率 ⭐

### 已知参数

| 参数 | 值 |
|---|---|
| ADC 参考电压 | **3.3V**（VDDA） |
| ADC 位数 | **12 位** → 4096 刻度 |
| 偏置 | **1.65V** |
| 采样电阻 | **10mΩ** |
| 放大倍数 | **15 倍** |

### 算量程

```
【灵敏度】1A → 10mV → ×15 → 150mV
   → 【0.15 V/A】

【最大可测电流】= 1.65V / 0.15 V/A = 【±11 A】
```

### 算分辨率

```
【ADC 每刻度】3.3V / 4096 = 【0.806 mV】
【换算成电流】0.806mV / 0.15 V/A = 【5.4 mA】
```

### 汇总

| 项目 | 数值 |
|---|---|
| **量程** | **±11 A**（相电流峰值） |
| **理论分辨率** | **5.4 mA** |
| **实际分辨率** | 约 **50~100 mA**（受失调、电阻误差、噪声影响） |

**对 C2208 够不够？**

```
C2208 最大电流 4.5A（母线）→ 相电流峰值约 2A
→ 量程 ±11A → 【余量 5 倍以上】✅
```

---

## 第 8 步：⚠️ 量程和分辨率的"跷跷板"

```
量程 × 分辨率 ≈ 常数

想要更大量程 → 必须牺牲分辨率
想要更高分辨率 → 必须牺牲量程
```

**两个调整办法（效果一样）：**

| 办法 | 量程 | 分辨率 |
|---|---|---|
| **降低采样电阻**（10mΩ → 5mΩ） | ±22A | 10.8mA（差一半） |
| **降低运放增益**（15 → 7.5 倍） | ±22A | 10.8mA（差一半） |

**什么时候该改？**

```
【量程不够】读数卡在极值不动（饱和削顶）
   → 改小采样电阻或降低增益，代价是分辨率变差
【分辨率不够】读数噪声大、小电流测不准
   → 加大采样电阻或提高增益，代价是量程变小
```

---

## 第 9 步：⚠️ 三个必须知道的陷阱

### 陷阱 1：读数卡在 0 或 4095 = 饱和

```
→ 不是"电流真的这么大"，是【运放输出削顶了】
→ FOC 立刻失控（因为读到的电流是假的）

【排查顺序】① 量程不够 → ② 偏置不对 → ③ 最后才怀疑算法
```

### 陷阱 2：零点偏了，整个 FOC 都偏

```
如果 VREF 实际是 1.60V 而不是 1.65V：
   → 零电流时读数 = 1.60/0.806mV = 1985（而代码以为是 2048）
   → 每相都有 63 刻度偏差
   → 换算成电流：63 × 0.806mV / 0.15 = 【339mA 的假电流】
   → 电机静止时程序以为有 339mA 在流
   → Id 不为 0 → 电机发热、抖动、效率低
```

**所以代码里的 ADC_MID 必须用【实测值】：**

```
① 电机不转、PWM 关掉
② 读 1000 次 ADC，取平均
③ 把平均值写进代码的 ADC_MID（不要用理论值 2048）
```

### 陷阱 3：偏置必须用 VCCA，不能用 VCC

```
【用 VCC 分压】
   VCC 上有数字噪声 → 偏置跟着抖
   而 ADC 的参考是 VDDA（干净的）
   → 【偏置抖，但尺子不抖】→ 读数就抖 ❌

【用 VCCA 分压】（本板）
   VCCA 和 VDDA 是同一个"干净"电源
   → 偏置抖，尺子也抖 → 【相互抵消】✅
```

> **凡是影响测量的电压，都必须挂在同一套"干净"的参考上。**

---

## 5-2 小结

### 关键数字（背下来）

| 项目 | 数值 |
|---|---|
| 偏置 | **1.65V**（= VDDA/2） |
| 灵敏度 | **0.15 V/A**（= 10mΩ × 15） |
| **量程** | **±11 A** |
| **理论分辨率** | **5.4 mA** |
| ADC 刻度 | 0.806 mV |

### 两个关键设计

| 设计 | 为什么 |
|---|---|
| **用 VCCA + AGND 分压** | 和 VDDA/VSSA 同一套，噪声相互抵消 |
| **分压后必须加跟随器** | 分压点内阻 5kΩ，直接接负载会被拉偏 |

### 三个陷阱

| 陷阱 | 现象 | 解法 |
|---|---|---|
| **饱和削顶** | 读数卡在 0 或 4095 | 改小采样电阻或降低增益 |
| **零点偏了** | 静止时显示有电流 | **用实测平均值做 ADC_MID** |
| **偏置挂错电源** | 读数持续抖 | 偏置必须用 VCCA |

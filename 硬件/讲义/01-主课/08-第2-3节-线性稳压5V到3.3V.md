# 第 2-3 节：线性稳压 —— 5V 怎么变成 3.3V（AMS1117）

> 难度 🟡。核心概念在 2-1 节已经学过（线性稳压 = 烧掉多余电压）。
> 这一节要回答：**既然线性稳压会发热，为什么这里还要用它？**

---

## 第 1 步：问题来了

第 2-2 节结束，我们有了稳定的 **+5V**。现在需要：

| 谁 | 需要 | 电流 |
|---|---|---|
| STM32 数字部分 | 3.3V | 100~200mA |
| LCD / 按键 / LED | 3.3V | 几十 mA |
| CH340N / TJA1050T | 3.3V | 几十 mA |
| **STM32 的 VDDA** | **3.3V（要极干净）** | 几 mA |
| **3 颗运放** | **3.3V（要极干净）** | 几 mA |
| **1.65V 基准** | **3.3V（要极干净）** | 几 mA |

---

## 第 2 步：为什么不让 TPS5430 直接输出 3.3V？

**四个问题：**

### 问题 1：开关电源的输出有"高频纹波"

```
开关电源每秒开关 50 万次 → 输出必然带 500kHz 纹波
纹波幅度：典型 10~50mV

对数字电路（STM32 数字部分）：3.3V ± 50mV = ±1.5% → 完全没问题 ✅
对 ADC 的参考电压（VDDA）：
   12 位 ADC，1 LSB = 3.3V/4096 = 0.8mV
   纹波 50mV = 【62 个 LSB】的噪声 → ADC 的低 6 位全是噪声 ❌
```

> **开关电源的纹波，对数字电路无影响，对 ADC 是灾难。**
> **因为数字电路看的是"高低电平"，而 ADC 看的是"电压的精确值"。**

### 问题 2：TPS5430 是"大电流"器件，用在 200mA 上不合适

```
TPS5430 输出能力 3A，实际需要 200mA
→ 成本高、需要更大的电感电容、轻载时效率可能下降
```

### 问题 3：反馈基准不匹配

```
TPS5430 内部基准 1.221V
要输出 3.3V：R1/R2 = 1.7（不是整数，精度差一点）
```

### 问题 4：数字和模拟还是要分开

```
即使用一颗 TPS5430 供所有 3.3V
→ 数字部分的噪声还是会传到 VDDA
→ 还是需要分开！（第 2-4 节详讲）
```

> **所以决策是：让 TPS5430 只负责"高效地把 12V 降到 5V"；**
> **3.3V 这一级用线性稳压（小压差、电流小、要干净）。**

---

## 第 3 步：为什么这个场合"线性稳压"反而是对的？

```
【之前的错误方案：12V 直接线性降到 3.3V】
   压差 = 8.7V，效率 = 27.5%
   200mA 时发热 = 8.7V × 0.2A = 【1.74W】 ❌ 烧芯片

【现在的方案：5V 线性降到 3.3V】
   压差 = 1.7V，效率 = 3.3/5 = 【66%】
   200mA 时发热 = 1.7V × 0.2A = 【0.34W】 ✅ 可以接受
```

**再看 0.34W 会不会烧：**

```
AMS1117 是 SOT-223 封装，热阻约 60°C/W
温升 = 0.34W × 60 = 【20°C】
环境 25°C → 芯片温度 【45°C】 ✅ 完全没问题
```

| 方案 | 压差 | 效率 | 发热 | 芯片温度 | 结论 |
|---|---|---|---|---|---|
| 12V→3.3V | 8.7V | 27.5% | 1.74W | 129°C | ❌ 烧毁 |
| **5V→3.3V** | **1.7V** | **66%** | **0.34W** | **45°C** | ✅ **可用** |

> **"大压差用开关，小压差用线性"的完整含义：**
> **不是说"线性稳压不好"，而是"线性稳压只适合小压差"。**
> **压差 1.7V 时，它的缺点（发热）变得可以接受，而它的优点（干净）变得重要。**

---

## 第 4 步：线性稳压的"优点"到底是什么？

### 优点 1：输出干净（没有开关纹波）

```
线性稳压【内部没有开关动作】
   → 只是"持续调节一个可变电阻"
   → 输出上【没有开关频率的纹波】✅

对比：开关电源输出 3.3V + 50mV 纹波；线性稳压输出 3.3V + 几 mV 噪声
```

### 优点 2：有 PSRR（能"过滤"输入端的纹波）

```
PSRR = Power Supply Rejection Ratio（电源纹波抑制比）
     = "输入端有纹波时，输出端还剩多少"

典型 AMS1117：
   100Hz  → 约 60dB（输入纹波被衰减 1000 倍）
   10kHz  → 约 40dB（衰减 100 倍）
   100kHz → 约 20dB（衰减 10 倍）
```

**具体到板子：**

```
TPS5430 输出的 5V 上有 500kHz、50mV 的纹波
   ↓ 经过 AMS1117（PSRR 在这个频率可能 20~30dB）
   → 被衰减 10~30 倍
   → 输出 3.3V 上的纹波只剩 1.7~5mV ✅
```

> **"开关 + 线性"组合的经典套路：**
> ```
>   开关电源：高效地把大压差降下来（但输出有纹波）
>      ↓
>   线性稳压：把纹波"精修"掉（但效率略低）
>      ↓
>   最终：既高效、又干净 ✅
> ```

### 优点 3：外围元件极少

| | 元件数 | 面积 |
|---|---|---|
| TPS5430（12V→5V） | 约 8 个元件 | 大 |
| AMS1117（5V→3.3V） | **2 个电容** | 小 ✅ |

## 第 5 步：AMS1117 电路

```
                 ┌──────────────────┐
   +5V ──┬───────┤ VIN      VOUT    ├───────┬── VCC (3.3V)
         │       │   AMS1117-3.3    │       │
      [C32]      │      (U8)        │    [C31]
      10µF       │                  │    10µF
         │       │      GND         │       │
      [C33]      └────────┬─────────┘    [C34]
      100nF               │              100nF
         │               GND                │
        GND                                GND
```

| 位置 | 元件 | 值 | 作用 |
|---|---|---|---|
| **输入** | C32 | 10µF（有极性） | 输入储能 |
| **输入** | C33 | 100nF | 高频去耦 |
| **输出** | C31 | 10µF（有极性） | 输出稳定（防止振荡） |
| **输出** | C34 | 100nF | 高频去耦 |

### 为什么输出电容是"必须的"？

```
LDO 内部有一个"反馈环路"（和 TPS5430 一样）
→ 反馈环路需要一定的输出电容才能【保持稳定】
→ 如果输出电容太小或 ESR 不合适
→ 【LDO 会自激振荡】！输出变成几十 kHz 的振荡波形 ❌
```

> **重要提示：LDO 的输出电容不是"可选的"，是"必须的"。**
> **而且很多 LDO 对输出电容的"容量"和"ESR 范围"有明确要求（查数据手册）。**
>
> **历史上有个著名的坑**：某些老式 LDO 要求输出电容必须有 **0.1~2Ω 的 ESR**，如果用 ESR 极低的陶瓷电容，反而会振荡。

### 为什么"一大一小"配对？

| 电容 | 容量 | 擅长频率 |
|---|---|---|
| 10µF | 大 | 低频（几十 kHz 以下） |
| **100nF** | 小 | **高频（MHz 以上）** |

因为 ESL（等效串联电感）的关系，大电容高频时"变成电感"，所以需要小电容补上高频段。

> **这是全板反复出现的"标准配方"：大电容（10µF/470µF）+ 小电容（100nF）。**

### 有极性电容的注意点

C32/C31 带极性标记（可能是电解或钽电容）。

> **反接的电解电容 ≈ 一个短路 → 会发热、鼓包、甚至爆炸。**
> **这也是为什么第 1 课的"防接反"这么重要 —— 它保护的第一个对象就是这些电容。**

## 第 6 步：但还有个大问题 —— 为什么是"两颗" LDO？

**板子上还有第二颗 LDO：`RT9013`。**

```
   +5V ──┬──[AMS1117]── VCC  （数字 3.3V）
         │
         └──[RT9013] ── VCCA （模拟 3.3V）
```

**为什么不共用一颗？这是第 2-4 节的主题。先给一个预告：**

> **因为有一样东西，对"数字 3.3V"来说"能用就行"，但对"模拟 3.3V"来说是"致命的"。**
> **那样东西叫：噪声。**

## 本节总结

### 一个决策：为什么 3.3V 用线性稳压

| 考虑因素 | 12V→3.3V 线性 | **5V→3.3V 线性** | 5V→3.3V 开关 |
|---|---|---|---|
| 压差 | 8.7V | **1.7V** ✅ | 1.7V |
| 效率 | 27.5% | **66%** ✅ | 约 85% |
| 发热（200mA） | 1.74W ❌ | **0.34W** ✅ | 低 |
| 输出纹波 | 无 | **无** ✅ | **有（50mV）** ❌ |
| 外围元件 | 少 | **少（2 颗电容）** ✅ | 多 |

### 三条关键认知

**① 口诀的完整含义**

```
"大压差用开关，小压差用线性"
→ 不是说线性不好，而是"线性只在小压差时才划算"
```

**② "开关 + 线性"是经典组合**

```
开关电源：高效地降大压差（但输出有纹波）
→ 后面串一级线性：把纹波精修掉
→ 结果：既高效又干净 ✅
```

**③ LDO 的输出电容是"必须的"**

```
原因：LDO 内部有反馈环路，需要输出电容保持稳定
否则会【自激振荡】
→ 选 LDO 一定要看数据手册的"稳定性要求"
```

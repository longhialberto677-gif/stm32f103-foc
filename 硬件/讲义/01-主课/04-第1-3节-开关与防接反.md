# 第 1-3 节：怎么开关 + 怎么防接反（背靠背 P-MOS）

> 难度 🔴 硬骨头，但收益最大 —— **这一节是第 0 课的实战应用。**

---

## 第 1 步：两个真实场景

### 场景 A：我想关机

```
电机转完了，我想把板子关掉。
   ↓
方案一：拔插头
   → 太麻烦，XT30 插拔多了会磨损、接触变差，还可能打火
方案二：装个开关
   → 好，那开关要装在哪？
```

### 场景 B：我把电池接反了

```
XT30 插头是两芯的，正负极分得很清楚吧？
   → 其实很容易搞错：自己焊的转接线、标签掉了、光线不好
   ↓
一旦接反：12V 变成 −12V 加在板子上
   ↓
所有电解电容【瞬间炸开】（反接的电解电容等于短路）
TPS5430、AMS1117、驱动芯片……全部击穿
   ↓
板子报废，而且可能冒烟起火
```

> **所以这一节要解决两件事：① 想关机 ② 怕接反。**
> **而这块板子很聪明：用同一套电路，同时解决了这两个问题。**

## 第 2 步：防接反的三种做法

### 方案 1：串联一个二极管

```
电池 + ──|>|──┬── 板子
（正常时导通，接反时截止，挡住 ✅）
```

**✅ 优点**：简单、便宜、可靠
**❌ 致命缺点**：二极管有 **0.7V 压降**，而且是**一直存在**的

```
按板子输入 5A 算：
损耗 = 0.7V × 5A = 【3.5W】
→ 一颗二极管白烧 3.5W，还要加散热片
```

### 方案 2：用"整流桥"

四个二极管接成桥式，不管正接反接，输出都是正的。

| | 表现 |
|---|---|
| ✅ | 真正"自动纠正" |
| ❌ | **损耗更大**：电流要过两个二极管 → `1.4V × 5A = 7W` |

### 方案 3：用 MOS 管（本板选的）✅

**关键洞察：MOS 导通时不是"有固定压降的二极管"，而是"几毫欧的电阻"。**

```
MOS 导通压降 = I × RDS(on)
NCE30P12S 的 RDS(on) 约 10~20mΩ（取 15mΩ）

按 5A 算：压降 = 5A × 0.015Ω = 0.075V（只有 75 毫伏）
损耗 = 0.075V × 5A = 【0.375W】
```

**三方对比（按 5A 输入电流）：**

| 方案 | 压降 | 损耗 | 评价 |
|---|---|---|---|
| 串一个二极管 | 0.7V | **3.5W** | ❌ 太热 |
| 整流桥 | 1.4V | **7W** | ❌❌ 完全不行 |
| **P-MOS（本板）** | **0.075V** | **0.375W** | ✅ **好 10~20 倍** |

> **MOS 相对二极管的核心优势：导通时它是"电阻"（压降 = I×R），不是"固定压降的二极管"。电流越大，优势越夸张。**

## 第 3 步：关键难点 —— 为什么必须用"两个" P-MOS？

### 3.1 单个 P-MOS 为什么不行？

**回忆第 0 课：MOS 内部有一个体二极管，永远关不掉。**

| 类型 | 体二极管方向 |
|---|---|
| **N-MOS** | **源极 → 漏极** |
| **P-MOS** | **漏极 → 源极** |

**高边接法（单个 P-MOS，源极接电池正极）：**

| 情况 | 电流方向 | 体二极管 | 结果 |
|---|---|---|---|
| **正接** | 想从 S → D | 体二极管方向是 D→S，所以 **反偏截止** | ✅ 挡住 |
| **反接** | 想从 D → S | **正偏导通** | ❌ **电流从体二极管"绕"过去了** |

> **一句话：单个 MOS 只能"单向阻断"。反接时电流从体二极管绕过去了。**

### 3.2 两个背靠背（共源）→ 双向阻断

**把两个 P-MOS 的源极连在一起**（共源），两个漏极分别朝外 —— **两个体二极管方向相反**：

```
   Q6 体二极管：漏极(输入侧) → 源极(公共点)
   Q7 体二极管：漏极(输出侧) → 源极(公共点)

   → 两个二极管像两扇【朝里开的门】，谁都出不去 ✅
```

| 情况 | 结果 |
|---|---|
| **正接** | Q6 二极管想导通，但 Q7 二极管反向 → **挡住** |
| **反接** | Q6 二极管反向 → **挡住** |

### 3.3 那怎么"打开"？

**同时打开两个 MOS 的沟道**（不是绕过体二极管，而是另开一条低阻通路）：

```
两个沟道都导通（各几毫欧）
→ 电流走"沟道"这条路，电阻比二极管路径小得多
→ 电流畅通，损耗极小 ✅
```

## 第 4 步：完整电路与三种状态

### 4.1 电路图

```
   输入侧                                            输出侧
   (来自F2/D9)                                    (+12V 主轨)
      │                                                │
      ├── D ┌──────┐ S ──┬── S ┌──────┐ D ─────────────┤
      │     │  Q6  │     │     │  Q7  │                │
      │     └──────┘     │     └──────┘                │
      │        G         │        G                    │
      │        └────┬────┘                             │
      │             │  ← 【公共栅极】                    │
      │             ├──[R39 2.2kΩ]── 公共源极           │
      │             │                                  │
      │             └──[R40 1kΩ]──┬── U9 拨动开关 ── PGND
      │                           │
     PGND
```

### 4.2 三种状态逐个分析

**状态一：U9 断开（关机）**

```
U9 断开 → 栅极只能通过 R39 连到源极
        → 栅极电压 = 源极电压 → Vgs = 0V
        → P-MOS 不导通 ✅
        
（公共源极被 Q6 体二极管充到接近输入电压 12V，
  所以栅极也被 R39 拉到 12V → Vgs = 12−12 = 0V）
```

**状态二：U9 闭合 + 电池正接（开机）**

```
U9 闭合 → 栅极被拉到 PGND（0V）
        → 源极仍是 12V
        → Vgs = 0V − 12V = −12V < 0
        → P-MOS 导通 ✅  +12V 上线
```

**状态三：U9 闭合 + 电池接反（保护）⭐**

```
【第一步】公共源极电压？
   反接时 Q6 体二极管反偏不通
   但 Q7 体二极管（漏极→源极）正向导通
   → 公共源极被钳在"接近 0V"

【第二步】栅极电压？
   U9 闭合 → 栅极接到 PGND = 0V

【第三步】算 Vgs
   Vgs = 0V − 0V = 【0V】

【第四步】结论
   Vgs = 0V → P-MOS 不导通 ✅
   → 两个沟道都关着，只能走体二极管
   → 但两个体二极管方向相反，互相顶住
   → 【板子完全没电，保护成功】
```

### 4.3 三种状态汇总表

| 状态 | U9 | 电池 | 公共源极 | 公共栅极 | Vgs | MOS | 结果 |
|---|---|---|---|---|---|---|---|
| **关机** | 断开 | 正接 | ≈12V | ≈12V（经 R39） | **0V** | 关 | 输出没电 |
| **开机** | 闭合 | **正接** | ≈12V | **0V** | **−12V** | **开** | +12V 上线 |
| **保护** | 闭合 | **反接** | ≈0V | 0V | **0V** | 关 | 输出没电 |

> **这个电路的妙处：它是一个"自供电的逻辑"。**
> **栅极永远是 0V（因为 U9 接到地）；而源极电压取决于"接对了还是接反了"。**
> **不需要任何芯片判断，靠电路自身就实现了"自动识别极性"。**

## 第 5 步：两个电阻的分工（第 0 课的复习）

### R39 = 2.2kΩ —— 栅源下拉，保证默认关断

**接在"公共栅极"和"公共源极"之间。**

> **必须接在"栅极—源极"之间，不是"栅极—地"！**
>
> | 接法 | 关机时 Vgs | 结果 |
> |---|---|---|
> | 接"栅极—源极"（正确） | 12 − 12 = **0V** | 可靠关断 ✅ |
> | 错接成"栅极—地" | 0 − 12 = **−12V** | **一直导通，永远关不掉** ❌❌ |
>
> **因为 MOS 看的是 Vgs（相对源极）。**

### R40 = 1kΩ —— 栅极串联，保护开关触点

栅极是个电容。U9 闭合瞬间要给它充电：

```
没有 R40 → 开关触点承受巨大瞬时电流 → 打火、烧蚀、氧化 ❌
有 R40   → 限制充电峰值电流 → 保护触点 ✅
```

## 第 6 步：为什么这里用 P-MOS，电机桥却用 N-MOS？

| | 电源总开关（这里） | 三相桥 |
|---|---|---|
| 电流 | 一路总电流 | 三相，每相都大 |
| **开关频率** | **极低**（开机/关机各一次） | **每秒上万次** |
| 对损耗 | 不敏感 | **极其敏感** |
| **器件选择** | **P-MOS**（栅极拉低就通，控制简单） | **N-MOS + 自举**（RDS(on) 小 3 倍） |

> **同一个功能（当开关），在不同场合要选不同的器件：**
> - **"偶尔动一下"的地方** → 选**控制简单**的（P-MOS）
> - **"每秒动几万次"的地方** → 选**效率最高**的（N-MOS + 自举，忍受复杂度）
>
> **这就是"工程是取舍"的具体体现。**

## 本节总结

### 一个电路，三个功能

| 功能 | 怎么实现的 |
|---|---|
| **① 开关** | U9 断开 → 关；U9 闭合 → 开 |
| **② 防接反** | 接反时源极被钳到 0V，Vgs = 0V，MOS 不开；体二极管互相顶住 |
| **③ 超低压降** | 导通走沟道（几毫欧），压降 0.075V，比二极管方案省 10 倍损耗 |

### 三个"为什么"

| 问题 | 答案 |
|---|---|
| **为什么必须两个 P-MOS？** | 单个 MOS 的体二极管在反接时正向导通，电流会"绕"过去。两个共源串起来，体二极管方向相反，**互相顶住** |
| **为什么接反了 MOS 不导通？** | 接反时公共源极被钳到 0V，而栅极也是 0V → `Vgs = 0V` → 不满足 P-MOS 导通条件 |
| **为什么用 P-MOS 不用 N-MOS？** | 高边位置。P-MOS 栅极拉低就通；N-MOS 做高边需要自举。而这里开关频率极低，不需要为效率忍受复杂度 |

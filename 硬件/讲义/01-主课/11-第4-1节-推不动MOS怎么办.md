# 第 4-1 节：3.3V 信号怎么推动 12V 的 MOS

> 难度 🟡。这一节的内容在第 0 课和专题里学过大半 —— 重点是**把它们连到板子上**。

---

## 第 1 步：现在的处境

**第 3 课结束，大脑能输出 6 路 PWM 了：**

```
PA8 / PA9 / PA10      → 3 路上管 PWM   3.3V，最大 20mA
PB13 / PB14 / PB15    → 3 路下管 PWM   3.3V，最大 20mA
```

**电机那边需要什么？**

```
6 颗 MOS 的栅极，要 10V 以上才能完全导通
而且栅极是电容，充电瞬间要 200mA 峰值
```

**两边差得太远，中间必须有个"翻译官"。**

---

## 第 2 步：为什么不能直接接？（三个理由）

### 理由 1：电压不够 → MOS 会"半开"

```
MOS 的 Vgs(th) = 2~4V 只是"开始导通"，完全导通要 Vgs ≥ 10V

如果只给 3.3V：
   半开时 RDS(on) = 0.5Ω，流 5A
   发热 = 5² × 0.5 = 【12.5W】
   → 几毫米大的管子散 12.5W，几秒冒烟
```

### 理由 2：电流不够 → 开关太慢

```
栅极是电容（约 5nF），要充到 10V
想在 100ns 内充满 → 需要 【200mA 峰值】
而 STM32 单脚只有 20mA → 差 10 倍

充不快的后果：
   MOS 在"半开"区停留时间长 → 开关损耗暴涨
   而且【关断太慢会导致直通】（第 3-2 节讲的）
```

### 理由 3：上管源极在浮动 → 栅极电压根本给不出来 ⭐

```
下管：源极接 PGND（0V）→ 栅极给 10V，Vgs = 10V ✅

上管：源极接【电机相线 M_U】，在 0V ~ 12V 之间跳
   当 M_U = 12V 时，栅极需要 22V 才能让 Vgs = 10V
   → 而你手上只有 12V ❌
```

> **上管不光要"放大信号"，还要"造一个浮动的电压"。这个任务叫"自举"（下一节）。**

---

## 第 3 步：所以需要一颗专门的芯片

| 任务 | 说明 |
|---|---|
| **① 电平转换** | 3.3V 逻辑 → 12V 栅极电压 |
| **② 电流放大** | 20mA → 1.8A 峰值（把栅极"一脚踹开"） |
| **③ 高边自举** | 给上管造浮动栅压 |

**而且它是"三相"的（6 路输出），一颗芯片管三个半桥。**

---

## 第 4 步：于是有了 FD6288T

**峰岹（Fortior）的三相栅极驱动芯片，TSSOP-20 封装。**

| 参数 | 值 | 意义 |
|---|---|---|
| **输出电流** | **1.8A 峰值** | 比 IO 的 20mA 大 90 倍 |
| **耐压** | 250V | 只用 12V，余量巨大 |
| **VCC** | **接 +12V** | 栅极驱动到 10.5V 左右 |
| **封装** | TSSOP-20 | 20 个脚 |

### 引脚分组

```
【输入侧】（接 MCU）
   HIN1/HIN2/HIN3  ← 上管 PWM（TIM1_CH1/2/3）
   LIN1/LIN2/LIN3  ← 下管 PWM（TIM1_CH1N/2N/3N）
   VCC             ← +12V
   COM             ← 接 PGND

【输出侧】（接 MOS）
   HO1/HO2/HO3     → 上管栅极
   LO1/LO2/LO3     → 下管栅极
   VB1/VB2/VB3     ← 自举电容上端
   VS1/VS2/VS3     ← 自举电容下端（接电机相线）
```

**规律：一个"半桥"占 4 个脚（HO / LO / VB / VS），三路就是 12 个脚。**

---

## 第 5 步：它内部还送了三样保护

### 好处 1：硬件死区（双保险）

```
FD6288T 内部保证同一桥臂的 HO 和 LO 绝不会同时为高
→ 即使软件写错了，它也会自己插一段死区

⚠️ 但它内置的死区可能只有几十~一两百纳秒
   对功率较大的 MOS 可能不够！

正确做法：
   TIM1 的硬件死区设 500ns~1µs（第一道防线）
   FD6288T 的内置死区当第二道
   【双重保护，因为直通 = 炸管】
```

### 好处 2：欠压锁定（UVLO）

```
如果 +12V 掉到 8V 以下 → 驱动电压不够 → MOS 会半开 → 发热烧毁

FD6288T 内置保护：检测到欠压就【关掉所有输出】
→ 宁可不动，也不半开 ✅
```

### 好处 3：替 MCU 挡子弹

```
栅极回路里可能窜入尖峰和干扰
→ 先烧驱动芯片（几块钱，换一颗）
→ 而不是烧 MCU（几十块，整块板报废）
```

## 第 6 步：栅极上的三个元件

```
上管 Q1：
   HO1 ──┬──[R8 10Ω]──┬── 栅极
         │            │
         └──[D4 1N4148W]──┘   （阳极接栅极，阴极接 HO1）
                       └──[R9 10kΩ]── 源极（M_U）
```

| 元件 | 作用 | 为什么 |
|---|---|---|
| **R8 = 10Ω** | **栅极串联电阻** | 限制峰值电流（保护驱动芯片）；控制开关速度 |
| **D4 = 1N4148W** | **反并联二极管** | 让"关断"比"开通"快 —— 关断时它导通，把栅极电荷快速抽走 |
| **R9 = 10kΩ** | **栅源下拉电阻** | **保证默认关断** —— 防止浮空栅极被噪声误导通 |

**为什么要"慢开快关"？**

```
死区时间是固定的
关断太慢 → 上管还没关断、下管就导通了 → 直通炸管
→ 所以【关断必须快】
开通慢一点没坏处，反而抑制振铃
```

## 第 7 步：完整信号链

```
   MCU                FD6288T              功率级
   ────               ───────              ──────

   PA8 (3.3V) ──→ HIN1 ──┐
                          │  电平转换
   +12V ────────→ VCC ───┤  + 电流放大(1.8A)
                          │
   PB13 (3.3V) ─→ LIN1 ──┤
                          ├──→ HO1 ──[R8]─┬─→ Q1 栅极
                          │            [D4]│
                          │            [R9]│
                          │                └─→ Q1 源极
                          │
                          └──→ LO1 ──[R10]┬─→ Q2 栅极
                                      [D5] │
                                      [R13]│
                                           └─→ PGND
```

**3.3V 的小信号，经过这几步，变成了能开关 20 安培的"大动作"。**

## 本节总结

### 三个"推不动"的理由

| 理由 | 数字 |
|---|---|
| **电压不够** | 3.3V 让 MOS 半开 → 12.5W 发热烧管 |
| **电流不够** | 栅极要 200mA 峰值，IO 只有 20mA → 慢 10 倍 → 损耗爆炸 |
| **上管源极浮动** | 需要 22V，你只有 12V → 必须自举 |

### 驱动芯片干的三件事

| 任务 | FD6288T 的能力 |
|---|---|
| **电平转换** | 3.3V → 10.5V 栅极 |
| **电流放大** | 20mA → **1.8A 峰值** |
| **高边自举** | 用 VB/VS 脚 + 外接电容实现 |

### 白拿的三样保护

- **硬件死区**（双保险）
- **欠压锁定**（宁可不动，也不半开）
- **替 MCU 挡子弹**

### 栅极上的三个元件

| 元件 | 作用 |
|---|---|
| R8 = 10Ω | 限流 + 控制开关速度 |
| D4 = 1N4148W | 让关断更快（防直通） |
| R9 = 10kΩ | 保证默认关断 |

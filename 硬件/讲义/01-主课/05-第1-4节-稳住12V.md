# 第 1-4 节：把 12V 稳住（电容 + 地）

> 难度 🟡。第 1 课的最后一节。这节讲完，+12V 就真正可以用了。

---

## 第 1 步：问题一 —— 电机启动，母线会"塌"

```
电机静止 → 你让它启动 → 它要立刻抽 5A 电流
   ↓
这 5A 要经过：电池 → 插头 → 保险丝 → TVS → P-MOS → 走线 → 电机
   ↓
这条路上【每一段都有电阻和电感】：
   · 插头接触电阻：几毫欧
   · 保险丝：几十毫欧
   · P-MOS 导通电阻：30 毫欧
   · 走线：几十毫欧
   · 【电池自己的内阻】：几十到几百毫欧
   · 【导线的电感】：每米约 1µH
   ↓
更麻烦的是【电感】：电流想从 0 突变到 5A，电感会"反抗"
   → 反抗的结果：电压被拉下去
```

**结果：**

```
母线电压：12V → 瞬间掉到 9V 甚至更低（持续几毫秒）
   ↓
· MCU 的 3.3V 也跟着掉 → 可能【复位】
· FD6288T 可能【欠压保护】（自己关掉）
· 已导通的 MOS，栅极电压变低 → 【半开】→ 发热
```

> **需要：一个"蓄水池"。在母线旁边放大电容，电机突然抽电时先从电容里"借"。**

---

## 第 2 步：问题二 —— 设备一关机，电压会"冲"

**电感不光反抗"电流变大"，也反抗"电流变小"。**

```
电机正在转，电流 5A
   ↓
你拨动开关 U9 → 关掉总闸 → 电流被切断
   ↓
电感（电机绕组）不答应：「我要维持 5A！」
   ↓
它靠【把电压抬得极高】硬把电流"推"出去
   ↓
这个高压顺着线【回灌到母线】
   ↓
母线从 12V 冲到 30V、50V……
```

**这时候两样东西派上用场：**

| 元件 | 干什么 |
|---|---|
| **C28（470µF 电容）** | **吸收能量**：电压一升，它自动存更多电荷，把电压"顶住" |
| **D9（TVS）** | **最后的保险**：万一冲到 15V 以上，它导通把它按住 |

---

## 第 3 步：问题三 —— 高频噪声

| 噪声来源 | 频率 |
|---|---|
| MOSFET 每秒开关上万次 | 几十 kHz ~ 几 MHz |
| 开关瞬间的电流突变（di/dt） | 可到几十 MHz |
| 走线像天线，接收环境干扰 | 各种频率 |

**特点：能量很小，但频率极高。对付它需要"反应特别快"的电容。**

---

## 第 4 步：核心认知 —— 一个电容解决不了所有问题

### 4.1 真实的电容有"副作用"

```
   理想电容：      真实电容：
   ──||──          ──[ESR]──[ESL]──||──
                     ↑       ↑      ↑
                  等效串联  等效串联  理想电容
                   电阻      电感
```

| 参数 | 什么意思 |
|---|---|
| **C** | 容量（能存多少电荷） |
| **ESR** | 等效串联电阻（会发热） |
| **ESL** | **等效串联电感（关键！）** |

### 4.2 ESL 决定了"电容能应付多快的噪声"

```
电容阻抗 = 1/(2πfC) + ESR + 2πf×ESL
              ↑                ↑
        随频率【降低】      随频率【升高】

结果：
   频率很低时 → 容量主导，阻抗低，滤波好 ✅
   频率升高   → ESL 开始起作用，阻抗【反而上升】
   → 超过某个频率后，电容"不再是电容"，变成了"电感" ❌
```

### 4.3 不同电容的"有效频率范围"不同

| 电容类型 | 容量 | ESL | 有效频率范围 | 擅长什么 |
|---|---|---|---|---|
| **电解电容**（C28 470µF） | 大 | **大** | 几百 Hz ~ 几十 kHz | **大能量、低频** |
| **陶瓷电容**（C29/C30 10µF） | 中 | **小** | 几十 kHz ~ 几 MHz | **中频纹波** |
| **小陶瓷**（各处 100nF） | 小 | **极小** | **MHz ~ 几十 MHz** | **高频噪声** |

> **"用一个大电容解决所有问题"是做不到的 —— 不是容量不够，是"频率范围"覆盖不了。**

## 第 5 步：于是有了 C28 / C29 / C30

### 5.1 电路

```
   +12V ──┬──[C28  470µF 电解]──┐
           │                     │
           ├──[C29   10µF 陶瓷]──┼── PGND
           │                     │
           └──[C30   10µF 陶瓷]──┘
```

### 5.2 它们的分工

| 电容 | 主要对付 | 类比 |
|---|---|---|
| **C28 470µF 电解** | 电机启动/变速（低频大能量） | **水库**：存量大，放水慢 |
| **C29 / C30 10µF 陶瓷** | PWM 开关纹波（中高频） | **水塔**：水量中等，出水较快 |
| **各处的 100nF** | 开关瞬间尖峰（高频） | **随身水壶**：只一点，但立刻能喝 |

### 5.3 为什么 C29 和 C30 是两颗一样的？

**并联，降低 ESL：**

```
一颗 10µF：ESL = X
两颗 10µF 并联：ESL = X/2   （并联电感减半）
   电容量 = 20µF（翻倍）
   ESR   = X/2（减半）
   ESL   = X/2（减半）← 这才是重点
```

**为什么不直接用一个 20µF？**

```
两个 10µF 并联：
   · 容量一样，但 ESL 只有一半 ✅
   · 可以【一个靠近 MOS 桥、一个靠近 TPS5430】
     → 就近供电，减少走线电感 ✅
```

> **通用技巧："多个小电容并联"比"一个大电容"更好。**

### 5.4 布局规则（PCB 第一号规则）

```
【错】电容放得远：
   +12V ────[长走线, 有电感]──── 芯片
                  │
               [电容]   ← 离芯片 2cm
                        走线电感让高频滤波失效 ❌

【对】电容贴着引脚：
   +12V ──┬── 芯片
          │
       [电容]  ← 紧贴引脚，走线只有几毫米 ✅
```

**为什么？** 因为**走线本身有电感**（每毫米约 1nH）。电容放远了，走线的电感会抵消高频滤波效果。

## 第 6 步：问题四 —— 地线上也会"抖"

### 6.1 问题：大电流让"地"不再是 0V

```
   电机电流 5A 要从 MOS 桥流回电池
   ↓
   走的是"地线"（PGND）
   ↓
   假设 PGND 那段走线电阻 10mΩ
   ↓
   压降 = 5A × 0.01Ω = 【50mV】
   ↓
   "地线"两端：一端 0V，另一端 50mV
   → 【同一个"地"，两点电位差了 50mV！】
```

**而且这个电压是波动的：PWM 每秒开关 2 万次 → 地线电压以 20kHz 频率抖 → 这叫【地弹】（Ground Bounce）。**

### 6.2 为什么这对测量是致命的

```
采样电阻 10mΩ，电流 1A → 压降只有 【10mV】
而地弹 = 【50mV】

信噪比：信号 10mV vs 噪声 50mV
   → 噪声是信号的 5 倍
   → 测出来的东西毫无意义 ❌
```

### 6.3 解决方案：把"地"分成两级

```
【PGND 功率地】
   MOS 桥、采样电阻下端、驱动芯片 COM、TPS5430 功率部分
   电流大（几安培）、波动剧烈
        │
     [R43 = 0Ω]  ← 单点汇合
        │
【GND 信号地】
   MCU 数字部分、LCD、按键、LED、CH340N、TJA1050T、AMS1117
   电流小、相对平稳
```

**为什么这样分能解决问题？**

```
【不分的后果】
   电机大电流从"地"流回电池 → 地线上产生 50mV 压降
   → 而 MCU/ADC 的"零点"建立在这条地线上
   → 零点在抖 → 读数在抖 ❌

【分开之后】
   电机大电流只在 PGND 上跑，在 R43 那一点才汇入 GND
   → GND 上的电流只有"信号级"（几十毫安）
   → GND 上的压降可以忽略
   → ADC 的零点几乎不动 ✅
```

### 6.4 为什么是"单点"汇合？

```
【多点连接（错误）】
   PGND ══════════════════ GND
        ║                  ║
        ╚══[另一条地线]═════╝
   → 形成"地环路"（Ground Loop）
   → 大电流有两条路，形成环流 → 像天线一样辐射/接收干扰 ❌
   → "哪条路是参考地"变得不确定

【单点连接（正确）】
   PGND ─────── R43 ─────── GND
   → 电流【只能从这一个门进出】
   → 没有环流、没有天线效应 ✅
```

### 6.5 为什么用 0Ω 电阻而不是直接连？

| 原因 | 说明 |
|---|---|
| **① 强制单点** | 图上必须画一个明确位置，**不让 layout 时乱连** |
| **② 可改造** | 发现噪声问题时可把 0Ω 拆掉，换成**磁珠**（滤高频）或**小电感** |
| **③ 有测试价值** | 拆掉后串一个电流表，**单独测"到底有多少电流从 PGND 流向 GND"** |

> **关于磁珠**：它是一个"频率越高阻抗越大"的元件。低频（直流）时几乎不挡（几十毫欧），高频时阻抗很大（几十欧）。
> **把 0Ω 换成磁珠，相当于"允许直流通过，但阻挡高频噪声"。**

## 第 7 步：三套地的架构（第 1、2 课交接）

```
┌──────────────────────────────────────────────┐
│  PGND（功率地）                               │
│  · MOS 桥、采样电阻下端、FD6288T 的 COM        │
│  · TPS5430 功率部分                           │
│  · 电流大、波动剧烈、最"脏"                     │
└────────────────────┬─────────────────────────┘
                     │ [R43 = 0Ω]   ← 第 1 课
┌────────────────────┴─────────────────────────┐
│  GND（数字地 / 信号地）                        │
│  · STM32 数字部分、LCD、按键、LED              │
│  · CH340N、TJA1050T、AMS1117                  │
│  · 电流中等、中等噪声                          │
└────────────────────┬─────────────────────────┘
                     │ [R44 = 0Ω]   ← 第 2 课
┌────────────────────┴─────────────────────────┐
│  AGND（模拟地）                               │
│  · STM32 的 VSSA、3 颗 OPA365、1.65V 基准      │
│  · 电流极小、要求最稳、最干净                   │
└──────────────────────────────────────────────┘
```

**为什么 AGND 不直接接 PGND？**

```
如果直接接：PGND 上的地弹（几十 mV）【直接】加到 AGND 上 ❌
经过 GND 中转（两级隔离）：
   第一级：地弹在 R43 上被"稀释"
   第二级：GND 上的噪声再被 R44 隔离一次
   → AGND 相对安静得多 ✅
```

## 本节总结

### 四个问题、四个对策

| # | 问题 | 后果 | 对策 |
|---|---|---|---|
| 1 | 电机启动抽大电流 → **母线电压塌** | MCU 复位、驱动欠压、MOS 半开 | **C28 470µF**（蓄水池） |
| 2 | 电机停转电感回弹 → **母线电压冲** | 芯片击穿 | **C28 吸收 + D9 TVS 兜底** |
| 3 | PWM 开关产生**高频噪声** | 干扰、误动作 | **C29/C30 10µF + 各处 100nF** |
| 4 | 大电流造成**地弹** | 测量被淹没（50mV vs 10mV） | **PGND / GND 分开 + R43 单点汇合** |

### 三个通用规律

**① 电容要"多种并联"，不是"一个大的"**

```
容量大 ≠ 什么频率都能滤（每个电容都有 ESL）
→ 高频时电容会"变成电感"
→ 必须用"不同容量并联"覆盖不同频段
```

**② 电容离芯片越近越好**

```
走线本身有电感（每毫米约 1nH）
→ 电容放远了，走线电感会抵消滤波效果
→ 【去耦电容必须紧贴引脚】—— PCB 第一号规则
```

**③ 地要"按噪声分级 + 单点汇合"**

```
功率地（脏）→ 信号地（中）→ 模拟地（干净）
每级之间用 0Ω 连接
→ 避免地环路、避免噪声串扰
```

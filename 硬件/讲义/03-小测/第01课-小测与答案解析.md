# 答案

## 第一部分

**1.** `XT30 插头 → F2 保险丝 → D9 TVS → Q6+Q7 总开关 → 电容 → +12V`
（简化说"保险丝 → TVS → 总开关 → 电容"即可）

**2.** 因为 **接触电阻会发热**：`发热 = 电流² × 接触电阻`。
DC 圆头接触电阻约 0.1Ω，跑 10A → 10W，几分钟烫手熔化；
XT30 只有几毫欧 → 0.5W，只是温热。

**3.** **保险丝管"电流太大"（切断电路）；TVS 管"电压太高"（钳住电压，但不切断）。**

**4.** 靠**热**：过流 → 发热 → 内部高分子材料膨胀 → 撑开导电链 → 电阻暴涨 → 限流。
冷却后材料收缩 → 导电链恢复 → 所以"自恢复"。

**5.** 因为电感负载（电机）关断时产生的尖峰是**上下振荡**的（先冲高，再冲到 0V 以下）。单向 TVS 只能按一个方向，双向的上下都能按。

**6.**
- 选 **13V**：正常工作 12V 稍微波动就到 13V → TVS 经常导通 → **自己发热烧毁** ❌
- 选 **30V**：尖峰冲到 25V 它都不动 → 但 MOS 耐压只有 30V → **芯片先被打穿** ❌
- 选 **15V**：比 12V 高（不误动作）、比 30V 低很多（提前保护）✅
- **通用原则：夹在中间，两头留余量。**

## 第二部分

**7.**
- (a) 轴功率 60W ÷ 效率 0.8 = **75W**（电功率）
- (b) `I = P/U = 75W / 12V =` **6.25A**
- (c) 堵转时效率≈0，电流只受绕组电阻限制。假设绕组 0.5Ω：`I = 12/0.5 =` **24A**（是正常运行时的近 4 倍）

**8.**
- 3A 时：余量 = `3 − 0.3 =` **2.7A**（约 10 倍余量）✅
- 0.8A 时：余量 = `0.8 − 0.3 =` **0.5A**（只 2.7 倍）⚠️
- **结论：3A 更合理。**

**9.** `E = ½ × L × I² = 0.5 × 0.0005 × 64 =` **0.016 J = 16 mJ**

**10.**
- `20mJ = ½ × 470µF × (V₂² − 144)`
- `0.02 = 2.35e-4 × (V₂² − 144)`
- `V₂² − 144 = 85` → `V₂² = 229` → `V₂ ≈` **15.1V**
- **只升高约 3V！** 对 30V 耐压的 MOS **完全没有威胁** ✅
- 而且 15.1V 刚好在 TVS 的击穿电压附近 —— **也就是说，大部分情况下 TVS 都还没轮到出场。**

## 第三部分

**11.** 因为 PPTC 响应**慢**（几十 ms~几秒），而 MOS 耐受是**微秒级**。
堵转时电流瞬间冲到几十安培，**PPTC 还没反应过来，MOS 已经烧了**。
MOS 靠的是 **"检测到过流 → 立刻关 PWM"（硬件刹车，微秒级）** —— 第 4、8 课讲。
**保护是分层的：快的保护管快的事，慢的保护管慢的事。**

**12.** **母线电容（C28 470µF）**。
它容量大、离得近，几微秒内就能吸收大量电荷、把电压"顶住"。
**TVS 是第二道，负责"电容来不及处理的高频快尖峰"和"能量更大的异常浪涌"。**

**13.** 因为 TVS 的动作条件是"电压超过击穿值"——**它必须先被动等到电压升上来，才能开始导通**。
它不能预测、也不能阻止电压上升，**它只能把电压"削平"到不会损坏电路的高度**。
（而且它是纳秒级反应，快过大多数尖峰 —— **这不是"反应慢"，而是"只能被动应对"。**）

**14.** TVS 有**额定峰值脉冲功率**（例如 SMF 封装约 200~400W）。
如果尖峰能量超过额定值，TVS **会过热烧毁** —— 而且失效模式常常是**短路**，会把母线直接拉死。
所以：要么选更大封装（SMBJ 600W / SMCJ 1500W），要么靠前端的大电容先把能量吃掉。

**15.** 因为三相桥的下管/上管都有**体二极管**！
电机相线上出现的反向尖峰，会**先通过某个 MOS 的体二极管"泄"回 12V 母线**（或者被母线电压钳住）。
所以能到达母线的尖峰，能量已经被削弱过一轮了 —— **这是"体二极管"这个"甩不掉的二极管"的一个正面用途**（第 0 课讲过它既是朋友也是敌人）。

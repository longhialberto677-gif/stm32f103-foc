# 🔴 第 4 课：手把手 —— 给这块板摆件

> 难度 🔴。这一节把第 3 课的原则落到**你这块板的具体元件**上。

---

## 零、⭐ 最优先的一条：分区 + 定朝向

**在摆任何元件之前，先决定三件事：**

```
① 电池从哪边进？   → XT30 靠【左】
② 电机从哪边出？   → MR30 靠【右】
③ 信号往外从哪边？ → USB / CAN / LCD / 编码器 靠【下边或上边】
```

### 为什么电池和电机要在"两边"？⭐

```
【如果电池和电机在同一侧】

   ┌──────────────┐
   │ XT30    MR30 │  ← 都在上边
   ├──────────────┤
   │  [保护]       │
   │  [功率级]     │
   └──────────────┘
   
   → 电流从左上进，向下走，再绕回右上出去
   → 【路径折返】→ 回路面积大 → 噪声和压降都大 ❌

【电池在左、电机在右】

   ┌──────────────┐
   │ XT30     MR30│
   ├──┬────────┬──┤
   │  ↓        ↑  │
   │ [保护]→[功率级]│  ← 电流走一条直线
   └──────────────┘
   
   → 电流一路往右 → 【路径最短】✅
```

> ### 🎯 这是布局里最重要的一条"大纲"
> **先让大电流"走直线"，其它的都好办。**

### 六分区的空间分配

```
   ┌──────────────────────────────────────────────┐
   │  ← 功率区（PGND / +12V）→   ← 模拟区 →        │
   │ ┌──────────────────────┐  ┌──────────────┐  │
   │ │ 保护 / 开关 / 三相桥   │  │ 运放 / 基准   │  │
   │ │ 采样电阻 / FD6288T    │  │ VDDA          │  │
   │ └──────────────────────┘  └──────────────┘  │
   │                                              │
   │ ┌──────────────────────────────────────────┐│
   │ │  控制区（GND / VCC）                       ││
   │ │  STM32 / 电源变换 / 外设                    ││
   │ └──────────────────────────────────────────┘│
   └──────────────────────────────────────────────┘
```

**对应内层分区：**

| 内层 | 分区位置 | 谁在上面 |
|---|---|---|
| 内层 1（地） | PGND 左 / GND 中 / AGND 右 | 要和元件区对应 |
| 内层 2（电） | +12V 左 / VCC 中 / VCCA 右 | 同上 |

> ⚠️ **内层分区必须和顶层元件区"对齐"** ——
> **PGND 那片铜要正好在功率元件下面，AGND 那片要正好在模拟元件下面。**

## 一、电源区：从 XT30 到两颗 LDO

### 布局（按信号流排成一条线）

```
   ┌─────────────────────────────────────────────────────────┐
   │                                                          │
   │  [CN3]   [F2][D9]  [Q6][Q7]   [C28]   [U10]  [L1]  [D12] │
   │  XT30    保险丝    背靠背    470µF   TPS5430       续流  │
   │            TVS     P-MOS     电解                        │
   │    │        │        │         │       │                │
   │  +12V ──────┴────────┴─────────┴───────┤                │
   │                                         │                │
   │                                    [C44][C45]  去耦       │
   │                                                          │
   │                        [U8]      [U11]                   │
   │                       AMS1117   RT9013                   │
   │                      → VCC      → VCCA                   │
   └─────────────────────────────────────────────────────────┘
        ↑ 入口                                            出口 ↓
```

### 逐个讲为什么

| 元件 | 放哪 | 为什么 |
|---|---|---|
| **CN3（XT30）** | **最左边、板边** | 接口靠边；电流从这里起 |
| **F2（保险丝）** | 紧跟 CN3 | 电流必经，越短越好 |
| **D9（TVS）** | 紧跟 F2 | TVS 要"第一时间"把尖峰接住，**离入口越近越好** |
| **Q6/Q7（背靠背 P-MOS）** | 紧跟其后 | 大电流路径，走直线 |
| **C28（470µF）** | 紧靠开关之后 | 它是"蓄水池"，要离负载入口最近 |
| **U10（TPS5430）+ L1 + D12** | 一起，成一组 | ⭐ **这三个是"开关回路"，面积必须最小** |
| **C44/C45** | 紧贴 U10 的 VIN 脚 | 去耦电容必须贴脚（差 2cm 差 4 倍） |
| **U8 / U11（两颗 LDO）** | 放在 5V 出来之后 | 它们吃 5V，输出 3.3V |

### ⭐ 特别强调：TPS5430 的"开关回路"

**这是电源区最需要注意的地方。**

```
【开关回路（电流每秒在里面转 50 万圈）】

    +12V ──→ [U10 内部开关] ──→ PH ──→ [L1] ──→ +5V
                                  │
                              [D12]  ← 续流二极管
                                  │
                                 PGND
```

**这个回路的"形状"决定了噪声大小：**

```
【回路面积大】❌
   ┌──────────────────────┐
   │  开关      电感        │
   │   ↑         ↓         │
   │   └── D12 ──┘         │  ← 回路绕了一大圈
   └──────────────────────┘
   → 大回路 = 大天线 → 辐射噪声 ❌

【回路面积小】✅
   ┌──┐
   │  │  开关/电感/二极管紧挨在一起
   └──┘
   → 小回路 → 辐射小 ✅
```

> ### 🎯 做法
> **把 U10 的 PH 脚、D12、L1 的输入端"挤在一起"**，让回路的面积尽可能小。
> **同时 C44/C45 紧贴 VIN 脚**（输入端的电流也是脉冲的）。

## 二、功率区：三相桥

### 布局

```
                    +12V（从左边来）
                        │
        ┌───────────────┼───────────────┐
        │               │               │
     [Q1]            [Q3]            [Q5]      ← 三上管（排成一排）
        │               │               │
        ├── M_U ────────┼── M_V ────────┼── M_W ──→ 电机端子（右边）
        │               │               │
     [Q2]            [Q4]            [Q6]      ← 三下管
        │               │               │
     [R19]           [R35]           [R49]     ← 三采样电阻
        │               │               │
        └───────────────┼───────────────┘
                        │
                      PGND（打大量过孔下去）
```

### 三个关键决策

#### 决策 1：三相桥的输出朝电机端子

```
【为什么？】
   三个半桥的中点（M_U / M_V / M_W）要接电机
   这是【大电流路径】
   → 朝向电机端子，走线最短 ✅
   
【如果朝向反了】
   → 三条大电流线要横穿整个板子
   → 又长又占地方，还可能穿过模拟区 ❌
```

#### 决策 2：三组半桥"平行排列"

```
   [Q1][Q3][Q5]     ← 三个上管，间距均匀
   [Q2][Q4][Q6]     ← 三个下管
   [R19][R35][R49]  ← 三个采样电阻
   
   → 每一列是一个"半桥"
   → 三列一样 → 走线对称 → 三相电流均衡 ✅
   → 而且 FD6288T 的三路输出（HO1/2/3, LO1/2/3）也是顺序排列的
     → 连线不用交叉 ✅
```

#### 决策 3：⭐ MOS 的散热焊盘直接连到 PGND 平面

```
【MOS 的漏极/源极焊盘要和铜皮大面积连接】
   · 下管的源极 → 接采样电阻 → 接 PGND → 【打很多过孔下去】
   · 上管的漏极 → 接 +12V → 【打很多过孔到 12V 平面】
   
【为什么？两个理由】
   ① 【散热】：MOS 的损耗变成热，要靠铜皮散出去
   ② 【电气】：大电流要有低阻抗通路
```

> ⚠️ **过孔数量**：大电流路径上，**一个过孔约 1A**。
> **母线峰值 4.5A → 至少 5~8 个过孔，而且要扎堆打。**

## 三、驱动区：FD6288T 的"夹心"位置

### 布局

```
   ┌─────────────────────────────────────────────┐
   │                                             │
   │   [STM32]                                   │
   │      │  ← 6 根线（HIN/LIN），信号线，可以走远  │
   │      ↓                                      │
   │   [FD6288T]   ← 夹在中间                    │
   │      │  ← 6 根栅极线，必须短                 │
   │      ↓                                      │
   │   [Q1][Q3][Q5]                              │
   │   [Q2][Q4][Q6]                              │
   │                                             │
   └─────────────────────────────────────────────┘
```

### ⭐ 为什么 FD6288T 要靠近 MOS，而不是靠近 MCU？

**这是本节最重要的推理。**

```
【两种摆法的代价对比】

【摆法 A：FD6288T 靠近 MCU（离 MOS 远）】
   · HIN/LIN 线短（信号，轻）  ✅
   · 栅极线长（驱动，重）      ❌
   
   → 栅极线要 1.8A 的峰值电流给栅极电容充电
   → 线长 → 走线电感大 → 充电变慢 → 开关损耗大
   → 而且栅极线是"噪声源"，长了会辐射出去，影响采样
   → 还可能振铃 ❌❌

【摆法 B：FD6288T 靠近 MOS（离 MCU 远）】← 推荐
   · HIN/LIN 线长（信号，轻）  ⚠️ 可以接受
   · 栅极线短（驱动，重）      ✅
   
   → 栅极线短 → 充电快 → 开关损耗小
   → 噪声辐射少
   → HIN/LIN 只是 3.3V 的逻辑信号，频率不高，走远一点没事
```

> ### 🎯 判断原则
> **"重"的信号（大电流、快速变化）要短；"轻"的信号（小电流、慢速）可以长。**
>
> **栅极线是"重"的（1.8A 脉冲充放电），HIN/LIN 是"轻"的 → 让栅极线短。**

### 自举电容也要贴

```
【C3/C4/C5（100nF）要紧贴 FD6288T 的 VB / VS 脚】
   · 它们每个 PWM 周期都要充放电
   · 走线长了 → 走线电感大 → 自举电压不稳
   → 【可能导致上管驱动不足】
```

## 四、采样区：既靠近又隔离

### 布局

```
   ┌─────────────────────────────────────────────┐
   │                                             │
   │  【功率区】                                  │
   │   [R19][R35][R49]  ← 采样电阻紧贴下管        │
   │      │   │   │                              │
   │      │   │   │  ← IA+/IA− 差分对，短且贴近   │
   │      ↓   ↓   ↓                              │
   │   ┌─────────────────────┐                   │
   │   │ 【模拟区】            │                  │
   │   │  [运放 U7][U12]      │  ← 运放紧贴采样电阻 │
   │   │  [1.65V 基准 U13]    │                   │
   │   │  [R1][R4]            │                   │
   │   │  ░░░░░░░░░░░░ ← 铺一小片地（AGND）        │
   │   └─────────────────────┘                   │
   │                                             │
   └─────────────────────────────────────────────┘
        ↑ 注意：模拟区要"离开"功率区的噪声
```

### 三个要求

| 要求 | 为什么 |
|---|---|
| **① 运放紧贴采样电阻** | 信号只有 10mV，走线长了会拾取噪声 |
| **② IA+/IA− 要走"差分对"** | 两根线并排、贴近、等长 → 减小回路面积 + 共模干扰互相抵消 |
| **③ 模拟区周围铺一小片地** | 屏蔽 |

### ⭐ 一个矛盾：既要"近"又要"远"

```
【矛盾】
   · 运放要靠近采样电阻（信号弱，怕走长线）
   · 但采样电阻在功率区（噪声大，运放要远离噪声）
   
【怎么解决？】
   把运放放在【功率区的边缘、紧靠着采样电阻，但在模拟区那一侧】
   
   ┌──────────────┬──────────────┐
   │   功率区      │   模拟区      │
   │  [R19]━━━━━━━┿━━[运放]       │
   │  [R35]       │  [U7]        │
   │  [R49]       │              │
   └──────────────┴──────────────┘
        ↑ 采样电阻靠近边界    ↑ 运放紧贴边界另一侧
   
   → 走线很短 ✅
   → 但运放"在"模拟区里，下方是 AGND ✅
```

> ### 🎯 这是"分区布局"的精髓
> **靠"边界"来同时满足"近"和"隔离"两个矛盾的要求。**

### 增益电阻要贴运放脚

```
【R32/R34/R36/R38 必须紧贴运放的 3/4 脚】
   → 那里是高阻抗节点（第 3 课第 4 步讲的）
   → 走线长了就成天线
```

## 五、控制区：STM32 放中间

### 布局

```
   ┌─────────────────────────────────────────────┐
   │              【功率区】                      │
   │         [三相桥]  [FD6288T]                 │
   │              ↑                              │
   │         6 根 PWM 线（可以走远）               │
   │              ↓                              │
   │         ┌─────────────┐                     │
   │         │  [STM32]    │  ← 板子中部          │
   │         └─────────────┘                     │
   │          ↑    ↑    ↑                        │
   │       去模拟区 去外设 去电源                  │
   └─────────────────────────────────────────────┘
```

### ⭐ 为什么 STM32 放中间？

```
【因为它是"枢纽"，要连四个方向】
   · 上：6 根 PWM 线 → FD6288T
   · 右：3 根 ADC 线（其实很近）→ 运放
   · 下：I2C / 按键 / LED / 屏
   · 各方向：SWD / 串口 / CAN
   
   → 放中间，总连线长度最短 ✅
   → 放边上，就要往四个方向拉长线
```

### ⚠️ 但有一条"不能省"

```
【STM32 的去耦电容（C9~C12，4 颗 100nF）必须紧贴 VDD 脚】
   VDD_1 / VDD_2 / VDD_3 每个脚旁边一颗
   → 距离超过 2cm 就基本失效（第 3 课算过：11MHz → 2.5MHz）
```

### 还要注意：晶振要贴 MCU

```
【8MHz 晶振（X1）和它的两个 20pF 电容】
   → 必须紧贴 PD0/PD1 脚
   → 晶振是"敏感模拟信号"（微弱正弦波）
   → 走线长了可能不起振或频率不稳
   → 而且晶振下方【不要走线】（避免干扰）
```

## 六、外设区：接口按板边分配

```
   ┌──────────────────────────────────────────────┐
   │ CN3(XT30)                          MR30(电机) │  ← 左边 / 右边
   │                                              │
   │  [电源区]              [功率区]               │
   │                                              │
   │         [STM32]  [FD6288T]                   │
   │                                              │
   │  [USB-C]  [SWD]   [CN1编码器]  [LCD FPC]  [CAN]│  ← 下边一排
   └──────────────────────────────────────────────┘
```

| 接口 | 放哪 | 特别注意 |
|---|---|---|
| **CN3（XT30 电源）** | 板边（左） | 方便插电池 |
| **MR30（电机）** | 板边（右） | 大电流，靠功率区 |
| **USB Type-C** | 板边 | 调试时反复插拔 |
| **SWD 排针** | 板边 | 调试时反复插拔 ⭐ |
| **CN1（编码器 I2C）** | **远离功率区** | ⚠️ I2C 最怕噪声 |
| **LCD FPC** | 板边 | 屏幕要能装到面板上 |
| **CAN 端子** | 板边 | 接总线 |
| **按键 / LED** | 面板侧 | 要能按到、看到 |

### ⚠️ 编码器接口（CN1）要特别注意

```
【I2C 是最怕干扰的总线】
   · 高阻抗（开漏 + 上拉）
   · 线长（要接到电机上）
   · 就在电机旁边（噪声源）

【布局要求】
   ① CN1 放在【远离功率区】的位置
   ② I2C 的走线尽量短，远离电机相线
   ③ 最好和电机线"垂直交叉"而不是"平行"
   ④ 可以考虑加 100nF 到地（可选）
```

## 八、⚠️ 五个新手最常犯的布局错误

| # | 错误 | 后果 | 正确做法 |
|---|---|---|---|
| **1** | **去耦电容离芯片 1cm 以上** | 高频滤波失效 | **紧贴引脚（越近越好）** |
| **2** | **TPS5430 的开关回路面积大** | 辐射噪声大 | U10/D12/L1 挤在一起 |
| **3** | **运放和采样电阻之间走长线** | 采样噪声大 | 靠"分区边界"做到又近又隔离 |
| **4** | **编码器接口放在功率区旁边** | I2C 被干扰、读数跳变 | 远离功率区 |
| **5** | **大电流路径绕远路** | 压降大、发热、噪声 | 先定"直线路径"，再摆别的 |

---

## 第 4 课小结

### 布局的"骨架"

```
   ① 电池在左、电机在右     → 大电流走直线
   ② 三个分区：功率 / 控制 / 模拟
   ③ 内层分区和顶层元件区对齐
```

### 每个区的要点

| 区 | 要点 |
|---|---|
| **电源区** | 按信号流排成一条线；**开关回路面积最小**；去耦贴脚 |
| **功率区** | 输出朝电机端子；三组平行排列；**散热焊盘打大量过孔** |
| **驱动区** | **FD6288T 靠近 MOS**（栅极线要短）；自举电容贴 VB/VS 脚 |
| **采样区** | 运放靠"分区边界"做到**又近又隔离**；增益电阻贴运放脚 |
| **控制区** | STM32 放中间（枢纽）；去耦贴脚；晶振贴 MCU |
| **外设区** | 接口按板边；**编码器接口远离功率区** |

### 一句最重要的判断原则

> **"重"的信号（大电流、快速变化）要短；**
> **"轻"的信号（小电流、慢速）可以长。**
>
> **栅极线是"重"的，HIN/LIN 是"轻"的 → 让 FD6288T 靠近 MOS。**

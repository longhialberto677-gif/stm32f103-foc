# 🟢 第 3 课（补充）：你的板子是"六分区 4 层板"

> 你说：**两个内层，每层分三个区域**
> ```
> 内层 1（地）：PGND ／ GND ／ AGND
> 内层 2（电）：+12V ／ VCC ／ VCCA
> ```
> 这个设计很讲究，先把它的原理和坑讲透。

---

## 一、先画出你的叠层

```
   ┌───────────────────────────────────────────────────────────┐
   │  顶层（Top）    元件 + 信号走线 + 局部铺铜                  │
   ├═══════════════════════════════════════════════════════════┤
   │  内层 1（地平面）                                          │
   │     ┌──────────┬──────────┬──────────┐                    │
   │     │  PGND    │   GND    │  AGND    │                    │
   │     │ (功率地) │ (数字地) │ (模拟地) │                    │
   │     └──────────┴──────────┴──────────┘                    │
   ├═══════════════════════════════════════════════════════════┤
   │  内层 2（电源平面）                                        │
   │     ┌──────────┬──────────┬──────────┐                    │
   │     │  +12V    │   VCC    │  VCCA    │                    │
   │     │ (12V)    │ (数字3.3)│ (模拟3.3)│                    │
   │     └──────────┴──────────┴──────────┘                    │
   ├═══════════════════════════════════════════════════════════┤
   │  底层（Bottom）  信号走线 + 局部铺铜                        │
   └───────────────────────────────────────────────────────────┘
```

**这是一个非常"专业"的设计思路 —— 行业里叫「分区平面」（Split Plane）。**

---

## 二、⭐ 它解决了什么问题？（回顾我们之前遇到的矛盾）

**在第 2 课（电源变换）里，我们讲过三套地必须分开：**

```
PGND（脏）→ GND（中）→ AGND（干净）
单点汇合（0Ω 电阻）
```

**但后来发现一个问题：**

```
【在"整片铺铜"的板子上，"单点汇合"很难做到】
   因为平面面积太大
   → 两个大铜块之间的寄生电容会让它们在高频下耦合
   → 隔离失效
```

**你的"分区平面"正好绕过了这个问题：**

```
【不是"两个完整的平面叠在一起"】
   而是"在同一层内，把铜分成互不相连的三个区域"

   → 三个区域之间【有物理间隙】（不连铜）
   → 没有大面积的面对面 → 寄生电容小 ✅
   → 真正实现了"分地" ✅
```

> ### 🎯 一句话
> **"分区"比"分层"更好 —— 因为它能做出物理隔离，而不只是"名字不同"。**

---

## 三、这个设计好在哪（3 条）

### 好处 1：真正实现了三套地的隔离 ⭐

```
【AGND 那片铜】
   · 只服务模拟部分（VDDA、4 颗运放、1.65V 基准）
   · 和 PGND 之间【不连铜】
   · 只在【一个点】用 0Ω 电阻（R44/R43）汇合
   
→ 功率地的噪声不会直接灌进模拟地 ✅
→ 这是 10mV 级采样能测准的前提
```

**对比一下"不分区的整片地平面"：**

```
【整片地平面】
   MOS 桥的 5A 回流 → 从整片铜里流回电池
   → 电流路径上的任何一点都有压降
   → 运放的"地"如果恰好在路径上 → 地弹灌进运放 ❌

【分区平面】
   功率回流只在 PGND 那片里跑
   AGND 那片完全不在路径上 ✅
```

### 好处 2：电源也分开了（VCC / VCCA）

```
【VCC（数字 3.3V）】
   · 供 MCU 数字部分、LCD、按键、USB、CAN
   · 电流大（200mA+）、噪声重

【VCCA（模拟 3.3V）】
   · 供 VDDA、运放、1.65V 基准
   · 电流小（30mA）、要求极干净

→ 分成两片 → 数字电源的噪声不会串到模拟电源 ✅
→ 【和第 2-4 课讲的"两颗 LDO"是同一个思想】
```

### 好处 3：+12V 有专属大电流平面

```
【12V 要过大电流（母线 2A，峰值 4.5A）】
   用平面走 → 阻抗极低、压降小、不发热 ✅
```

## 四、⚠️ 分区平面必须注意的 6 个坑

**分区听起来很美，但"分不好"比"不分"更糟。**

### 坑 1：⭐⭐ 信号线不能"跨区"走

**这是最重要的一条。**

```
【反例：一条信号线从 AGND 区上方跨到 PGND 区上方】

   顶层走线 ────────────────────────→
   ══════════════════════════════════
   内层地:  │ AGND 区 │ 间隙 │ PGND 区 │
            ↑                 ↑
         回流在这边        回流要跨到那边
         
   → 信号的回流电流【被迫跨越两个地平面】
   → 回流路径被切断 → 形成大回路 → 辐射噪声 ❌
   → 这叫"跨分割"（Split Crossing），是 EMC 大忌
```

**正确做法：**

```
① 每一条信号线，下方必须是【连续的地】
   · 模拟信号 → 下方是 AGND
   · 数字信号 → 下方是 GND
   · 功率信号 → 下方是 PGND

② 如果必须"跨区"，就在跨区的地方
   【放一颗 0Ω 或者几个过孔】把两片地连起来
   → 给回流一条"桥"
```

### 坑 2：分区之间的"间隙"要够宽

```
【间隙太窄（比如 0.2mm）】
   · 生产时可能因为蚀刻误差"粘"在一起 → 短路
   · 高压差时可能爬电/击穿

【建议间隙】
   · 普通信号区之间：0.5mm 以上
   · 12V 和其他区之间：0.5~1mm
   · 大电流区和敏感区之间：1mm 以上（越宽越好）
```

### 坑 3：每一片区域的"过孔数量"要够

```
【地平面靠过孔"接收"顶层元件的地】
   一个标准过孔约能过 1A

【AGND 区】
   电流小（几十 mA）→ 1~2 个过孔够
   但【每个模拟元件都要有就近的过孔】⚠️
   → 运放的 GND 脚旁边就要有个孔

【PGND 区】
   电流大（几安培）→ 【要打很多孔】
   → 采样电阻、MOS 源极、驱动芯片 COM，每个都要多打几个
   → 而且要"扎堆打"，不是分散
```

### 坑 4：⭐ 三种"分区方式"要选对

**分区可以按"整条带"分，也可以按"块"分：**

| 方式 | 长什么样 | 适合 |
|---|---|---|
| **条带式** | 左边一片、中间一片、右边一片 | 布局是"一条线"的板子 |
| **块式** | 中间一块、周围一圈 | 布局是"围绕中心"的板子 |

```
【你这块板适合哪种？】

   条带式（推荐）：
   ┌─────────┬──────────┬─────────┐
   │  功率   │   数字   │  模拟   │
   │  PGND   │   GND    │  AGND   │
   │  +12V   │   VCC    │  VCCA   │
   └─────────┴──────────┴─────────┘
   ↑ 左边        ↑ 中间      ↑ 右边
   
   因为你的板子天然是"功率→控制→模拟"的流向 ✅
```

### 坑 5：⭐ 大电流不能"经过"敏感区

```
【PGND 那片铜里，电流不是"均匀分布"的】
   它走【电阻最小的路径】= 两点之间的直线附近

【如果 AGND 区恰好"卡"在大电流的必经之路上】
   → 就算不连铜，也会有【电场耦合】和【磁场耦合】
   → 噪声照样进去 ❌

【正确做法】
   把 AGND 区放在【远离大电流路径】的位置
   → 通常是板子的"角落"或"边缘"
```

### 坑 6：分区的"形状"要避免"细长条"

```
【反例：AGND 做成一条细长的带子】
   ┌───┐
   │AGND│ ← 又细又长
   └───┘
   → 细长条 = 大电感
   → 地平面自己的阻抗就高了 ❌
   → 失去了"平面"的意义

【正确】AGND 那片要"尽量方、尽量大"
```

## 五、⭐ 六分区叠层的"标准检查清单"

**画完板子后，逐条检查：**

| # | 检查什么 | 怎么查 |
|---|---|---|
| **1** | 三片地是否真的互相独立（没连铜） | 在软件里看内层 1 的铜，确认三块分开了 |
| **2** | 三片电源是否互相独立 | 看内层 2 |
| **3** | **每一条信号线的下方是否是"对应的地"** | 逐条看关键信号（采样线、编码器线） |
| **4** | 有没有"跨分割"的信号线 | 找出跨越区边界的线，补 0Ω 或过孔桥 |
| **5** | 分区间隙是否够宽 | 用"间距检查"（Clearance Check） |
| **6** | 每片地的过孔数量是否够 | PGND 要最多，AGND 要"每个元件都有" |
| **7** | AGND 是否远离大电流路径 | 目视看布局 |
| **8** | 三个 0Ω（R43/R44 等）是否是"唯一连接点" | 确认没有别的路径把两片地连起来 |

> ⚠️ **第 8 条特别容易出错：**
> **如果某个元件的 GND 脚恰好跨在两片地上，或者某个接插件同时接了两种地，**
> **那"单点汇合"就失效了 —— 要专门检查。**

## 六、这张叠层的一个小提醒

**内层 2 上的 +12V / VCC / VCCA，三片的面积要差很多：**

```
【+12V】要大 —— 因为电流大（2~4.5A）
   建议占内层 2 的 40~50%

【VCC】中等 —— 200mA
   建议占 25~30%

【VCCA】小 —— 30mA
   建议占 10~15%（够用就行，但要"方"）
```

**另外：+12V 的平面还要注意"从哪里进、从哪里出"：**

```
【电流入口】XT30 → 保护 → 开关 → 这里打孔进 12V 平面
【电流出口】12V 平面 → 打孔出 → 三相桥上管漏极
          12V 平面 → 打孔出 → TPS5430 的 VIN
          
→ 入口和出口都要"多个过孔扎堆"
→ 而且【入口和出口之间的路径要顺】（别让电流在平面里绕圈）
```

# 🟡 第 3 课：先摆件，后连线 ⭐ 本课程最重要的一节

> 难度 🟡。**这一节讲"布局"，它决定 80% 的成败。**
>
> 一句话：**布局定生死，布线定质量。**

---

## 第 1 步：先看一个"乱摆"的例子（有具体数字）

**同样一颗电容、同样的原理图，只因为"摆的位置"不同，效果差 4 倍多。**

### 两种摆法

```
【方案 A：电容贴着芯片脚】
   VCC ──┬── 芯片 VDD 脚
         │
      [100nF]   ← 距离 1mm
         │
        GND

【方案 B：电容放在旁边，离芯片 2cm】
   VCC ──┬────────────────────── 芯片 VDD 脚
         │
      [100nF]   ← 距离 20mm
         │
        GND
```

### 算一下差多少

```
【关键数字】走线的电感 ≈ 1nH / mm

方案 A：走线电感 ≈ 1mm × 1nH/mm × 2（去和回）= 【2nH】
方案 B：走线电感 ≈ 20mm × 1nH/mm × 2      = 【40nH】

【电容加走线电感后，会有个"自谐振频率"】
   超过这个频率，电容就不再像电容，反而像电感 → 失去滤波作用

   f = 1 / (2π√(L × C))

方案 A：f = 1/(2π√(2nH × 100nF))  ≈ 【11 MHz】
方案 B：f = 1/(2π√(40nH × 100nF)) ≈ 【2.5 MHz】
```

### 结论

```
方案 A 能有效滤到 11 MHz
方案 B 只能有效滤到 2.5 MHz

→ 【差 4 倍多】
→ 而 MOS 开关产生的高频噪声正好在几 MHz ~ 几十 MHz
→ 【方案 B 的电容对最主要的噪声基本无效】
```

> ### 🎯 这是"布局定生死"的第一个例证
> **2cm 在 PCB 上是很近的距离 —— 新手很容易就摆成这样。**
> **而代价是"这颗电容白装了"。**

## 第 2 步：布局的四条核心原则

### 原则 1：按"信号流"摆 ⭐

**把原理图想象成一条从左到右的流水线，PCB 上也照着这条线摆。**

```
【你的电源部分，信号流是这样的】

   电池输入 ──→ 保护 ──→ 开关 ──→ 12V ──→ 降压 ──→ 5V ──→ 3.3V
      │           │        │        │        │       │
   [XT30座]   [F2][D9]  [Q6/Q7]  [电容]  [TPS5430][LDO]

【PCB 上也按这个顺序从左到右排】

   ┌──────────────────────────────────────────────────┐
   │ [XT30] [F2][D9] [Q6/Q7] [C28] [U10][L1] [U8][U11]│
   └──────────────────────────────────────────────────┘
      入口                                       出口

   → 电流走一条直线，不绕弯 ✅
   → 每个元件都"顺路" ✅
```

**反过来（乱摆）会怎样？**

```
   ┌──────────────────────────────────────────────┐
   │ [L1] [XT30] [U8] [Q6/Q7] [U11] [C28] [F2]   │
   └──────────────────────────────────────────────┘

   → 电流进入后要左右横跳
   → 走线长、回路大、噪声大 ❌
   → 大电流绕来绕去，压降也大
```

### 原则 2：相关的靠近，无关的远离

**必须"靠近"的五组：**

| 相关的元件 | 为什么必须靠近 |
|---|---|
| **芯片 + 它的去耦电容** | 走线电感（见上面那个例子） |
| **驱动芯片 + 它驱动的 MOS** | 栅极走线要短（噪声、振铃） |
| **运放 + 它的增益电阻** | 高阻抗节点，走线长了像天线 |
| **TPS5430 + 电感 + 续流二极管** | **这是开关回路，面积越小噪声越小** ⭐ |
| **采样电阻 + 运放** | 信号只有 10mV |

**必须"拉开"的三组：**

| 要拉开的 | 为什么 |
|---|---|
| **功率区 ↔ 模拟区** | 别让噪声串过去 |
| **MOS 桥 ↔ 编码器接口** | I2C 最怕干扰 |
| **高频开关节点 ↔ 采样线** | 采样信号太弱 |

> ### 🎯 实用的分组方法
> **先按"功能块"分组，每块占一小片区域，块内紧凑、块间留空。**
> ```
> ┌────────┐ ┌────────┐ ┌────────┐
> │ 电源区  │ │ 功率区  │ │ 控制区  │
> │12V→3.3V│ │ 三相桥  │ │  MCU   │
> └────────┘ └────────┘ └────────┘
> ```
> **不要把所有元件"均匀撒"在板子上。**

### 原则 3：⭐ 大电流路径优先安排

```
【先决定大电流怎么走，再安排别的】

   大电流路径：电池 → 保护 → 开关 → 12V → 三相桥 → 电机
   → 【这条路径要尽量短、尽量直、尽量宽】
   → 先把这几个元件的位置定下来
   → 剩下的元件绕着它们摆
```

**为什么优先？**

```
【因为大电流路径"改不动"】
   一旦摆好，改一个元件就要动一片
   → 所以先摆它，再摆灵活的小元件

【小信号路径改起来容易】
   采样线、控制线都是小电流，多绕几毫米无所谓 ✅
```

### 原则 4：接口靠板边

```
【所有对外接口都靠边放】
   · XT30 电源座    → 靠一边（方便插电池）
   · 电机输出端子    → 靠另一边（方便接电机）
   · USB Type-C     → 靠边（调试时反复插）
   · CAN 端子       → 靠边
   · LCD FPC 座     → 靠边
   · SWD 调试排针    → 靠边（调试时反复插）
```

**为什么？**

```
【如果接口在板子中间】
   → 插头伸出来挡住别的元件
   → 外壳装不进去
   → 插线时手伸不进去
```

> ### 🎯 特别是"经常插拔的接口"
> **USB、SWD、电源座 —— 你调试时会反复插拔，一定要方便够到。**

## 第 3 步：⭐ 布局的"优先级顺序"（照这个走）

```
【第 ① 步：定接口位置】
   · 插头必须在板边，而且位置一旦定了基本不改

【第 ② 步：定大电流路径】
   · 从接口一路到功率级，把这条线上的元件排好

【第 ③ 步：定功能区块】
   · 每个区块占一片区域（电源区 / 功率区 / 控制区 / 模拟区）

【第 ④ 步：区块内微调】
   · 去耦电容贴芯片脚
   · 电阻电容靠近它服务的芯片
```

> **核心逻辑：先定"不能动的"，再定"要短的"，最后摆"灵活的"。**

---

## 第 4 步：一个容易忽略的坑 —— 高阻抗节点

**这条对运放电路特别重要。**

```
【运放的反相输入端（4 脚）是一个"高阻抗节点"】

   IA− ──[R34 1kΩ]──┬── 4 脚
                    │
                 [R32 15kΩ]
                    │
                  输出

   → 这个节点阻抗高、信号弱（毫伏级）
   → 【它像一根天线】，容易拾取周围的噪声
```

**所以布局要求：**

| 要求 | 为什么 |
|---|---|
| **R32、R34 紧贴运放的 3/4 脚** | 走线越短，天线效应越弱 |
| **这个节点周围不要走功率线** | 别主动送噪声过去 |
| **可以在它周围铺一小片"地"** | 屏蔽 |

> ⚠️ **常见错误：**
> ```
> 把运放放在"模拟区"，但把增益电阻放在很远的地方
> → 那两条"通往高阻抗节点"的走线就成了天线
> → 采样噪声大、读数乱跳
> ```

## 第 5 步：布局时的"3 秒检查法"

**每摆一个元件，问自己三个问题：**

```
① 它和"必须靠近"的元件，距离够近吗？
   （去耦电容贴芯片脚了吗？驱动芯片离 MOS 近吗？）

② 它会不会挡住"大电流路径"？
   （大电流要绕它走吗？）

③ 它周围有没有"怕干扰"的东西？
   （它旁边有没有采样线、编码器线？）
```

**三个问题都过了，再摆下一个。**

## 第 6 步：这块板的布局顺序（具体到你板子上）

```
【第 1 步：接口定位】
   · XT30 电源座      → 靠左边
   · 电机端子（MR30）  → 靠右边
   · USB Type-C       → 靠下边
   · CAN 端子 / LCD 座 / SWD → 靠边

【第 2 步：功率链】
   · F2 / D9 / Q6 / Q7    → 紧跟 XT30
   · C28（470µF）          → 紧跟开关之后
   · TPS5430 + L1 + D12    → 从 12V 分出去
   · 三相桥（Q1~Q6）        → 靠近电机端子一侧
   · 采样电阻 R19/R35/R49   → 紧贴三个下管

【第 3 步：驱动】
   · FD6288T               → 夹在 MCU 和三相桥中间
   · 自举电容 C3/C4/C5      → 紧贴 FD6288T 的 VB/VS 脚
   · 栅极电阻 R8~R13        → 紧贴 MOS 栅极

【第 4 步：控制】
   · STM32                 → 放在板子中部（它要连很多地方）
   · 去耦电容 C9~C12        → 紧贴 VDD 脚

【第 5 步：模拟】
   · 4 颗运放               → 靠近采样电阻，但【和功率区隔开】
   · 1.65V 基准 + R1/R4     → 紧贴运放

【第 6 步：电源细部】
   · AMS1117 / RT9013       → 靠近它们的负载
   · 各种 100nF             → 全部紧贴对应芯片脚

【第 7 步：外设】
   · LCD 座 / 按键 / LED / 编码器座 → 按接口位置就近摆
```

## 第 3 课小结

### 四条原则

| 原则 | 内容 |
|---|---|
| **① 按信号流摆** | 从输入到输出一条线顺下来 |
| **② 相关的靠近** | 芯片+去耦、驱动+MOS、运放+增益电阻、采样电阻+运放 |
| **③ 大电流优先** | 先安排功率通路，小元件绕着摆 |
| **④ 接口靠边** | 特别是经常插拔的（USB、SWD、电源座） |

### 布局优先级

```
接口位置 → 大电流路径 → 功能区块 → 区块内微调
```

### 三个量化认知

| 认知 | 数字 |
|---|---|
| 走线电感 | 约 **1nH/mm** |
| 去耦电容离芯片 2cm | 有效滤波从 11MHz 掉到 **2.5MHz**（差 4 倍） |
| 高阻抗节点 | 运放输入端，**走线越长越像天线** |

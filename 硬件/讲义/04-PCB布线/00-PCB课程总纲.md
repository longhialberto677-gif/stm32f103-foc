# PCB 布线课程 · 总纲

> 讲课原则：**一节只讲一件事**，讲透再走。
> 每一节都按 **为什么要这么做 → 怎么做 → 这块板上的实际例子** 这条线。
>
> ⚠️ 本课程以 **你手上这块 STM32 FOC 驱动板** 为实际案例。

---

## 为什么 PCB 布线值得单独学

```
原理图 = "谁和谁连"        → 逻辑正确就行
PCB   = "怎么连、连多宽、放哪里" → 决定"能不能用、会不会烧、噪声大不大"
```

**同一张原理图，画成不同的 PCB，结果可能差 10 倍：**
- 好的布线 → 电流干净、采样准确、不发热、一次成功
- 差的布线 → 采样全是噪声、MOS 炸掉、EMC 过不了、反复改板

> **所以行业里有句话："原理图决定能不能工作，PCB 决定工作得好不好。"**

## 课程结构

| 课 | 标题 | 核心问题 | 难度 |
|---|---|---|---|
| **1** | 搞懂 PCB 是什么 | 从"图纸"到"实物"中间发生了什么 | 🟢 |
| **2** | PCB 的结构：层和铜 | 板子是"千层饼"，每层干什么 | 🟢 |
| **3** | 先摆件，后连线 ⭐ | 布局比布线重要得多 | 🟡 |
| **4** | 手把手：给这块板摆件 | 元件一个个摆在哪、为什么 | 🔴 |
| **5** | 走线规则 | 线多宽、怎么走、能否直角 | 🟡 |
| **6** | 大电流怎么处理 ⭐ | 十几安培怎么走才不烧 | 🔴 |
| **7** | 地平面怎么设计 ⭐ | PGND / GND / AGND 在铜上怎么分 | 🔴 |
| **8** | 散热怎么设计 | MOS 和采样电阻的热往哪跑 | 🟡 |
| **9** | 抗干扰布局 | 编码器线、采样线怎么不被打扰 | 🔴 |
| **10** | 检查与打板前确认 | 提交工厂前必须过的清单 | 🟡 |
| **11** | 打板、焊接、上电 | 从下单到第一次通电 | 🟢 |

**难度：🟢 轻松 / 🟡 需要动脑 / 🔴 硬骨头**

---

## 讲课顺序的逻辑

```
第 1-2 课：搞懂游戏规则（是什么、有什么工具）
     ↓
第 3-4 课：摆件（最重要的一步，占 80% 的成败）
     ↓
第 5-9 课：连线（走线、电流、地、散热、抗干扰）
     ↓
第 10-11 课：检查 + 打板（收尾）
```

> **记住一句话：布局定生死，布线定质量。**
> **新手最容易犯的错是"急着拉线"—— 摆件没摆好，线怎么拉都是错的。**

## 这块板要特别注意的 5 件事（先剧透）

| # | 关键点 | 为什么 |
|---|---|---|
| 1 | **大电流路径要短、要粗** | 母线十几安培，细线会烧 |
| 2 | **三套地要分开走** | PGND / GND / AGND，单点汇合 |
| 3 | **去耦电容必须贴芯片脚** | 离远了等于没装 |
| 4 | **采样线要短、要对称、远离功率线** | 信号只有 10mV，噪声一进来就废 |
| 5 | **MOS 要留散热铜皮** | 导通损耗变成热，得有地方跑 |

**这五条是这块板的"命门"，后面会逐条展开。**

# 🟢 第 2 课：PCB 的结构 —— 层和铜

> 只讲一件事：**一块 PCB 到底是由什么组成的。**

---

## 一、先建立一个画面：PCB 是"千层饼"

**把一块 PCB 从侧面切开，放大看：**

```
        ┌──────────────────────────────┐  ← 丝印层（白色字，比如 R19、+12V）
        ├──────────────────────────────┤  ← 阻焊层（绿色油墨，盖住不该露铜的地方）
        ├══════════════════════════════┤  ← 顶层铜（信号走线、焊盘）
        ├──────────────────────────────┤
        │      基材（玻璃纤维+树脂）      │  ← 绝缘的"骨架"，不导电
        ├──────────────────────────────┤
        ├══════════════════════════════┤  ← 底层铜
        ├──────────────────────────────┤  ← 阻焊层（底面）
        └──────────────────────────────┘  ← 丝印层（底面）
```

| 层 | 是什么 | 作用 |
|---|---|---|
| **基材**（FR-4） | 玻璃纤维 + 环氧树脂 | **绝缘骨架**，机械支撑 |
| **铜层** | 压在上面的铜箔 | **导电**，走线和焊盘都在这里 |
| **阻焊层**（Solder Mask） | 绿色（也有红/蓝/黑）油墨 | **盖住不该沾锡的地方**，防短路、防氧化 |
| **丝印层**（Silkscreen） | 白色印刷字 | **给人看的标注**：位号、极性、版本号 |

> 💡 **为什么板子是绿色的？** 绿色阻焊最便宜、对比度好（看铜线清楚）。**颜色和性能无关。**

## 二、铜层：板子的"血管"

### 关键参数：铜厚

```
1oz（盎司）= 1 盎司铜铺在 1 平方英尺上的厚度 ≈ 35 微米

【常见规格】
   0.5oz ≈ 17.5µm  → 便宜，只能过小电流
   1oz   ≈ 35µm    → 【最常用】
   2oz   ≈ 70µm    → 大电流板用（贵一些）

【为什么重要？】
   同样宽度的线，铜越厚 → 截面积越大 → 能过的电流越大
   → 母线要跑 10A，1oz 可能要 3mm 宽；换 2oz，1.5mm 就够
```

### 双面板 vs 四层板

| | 单面板 | **双面板** ⭐ | 四层板 |
|---|---|---|---|
| 铜层数 | 1 | **2** | 4 |
| 元件 | 只在顶层 | **顶层 + 底层** | 顶层 + 底层 |
| 价格 | 最便宜 | **便宜（主流）** | 贵 1.5~2 倍 |
| 走线难度 | 难（不能交叉） | **中等** | 容易 |
| 地平面 | 没有 | **可以铺（但不连续）** | **完整地平面** ✅ |

**你的板子大概率是双面板：**

```
   顶层：元件 + 信号走线 + 部分铺铜
   底层：主要用来铺地平面 + 走一些线
```

> 💡 **四层板的好处**（了解即可）：
> ```
> 【第二层做成完整地平面】
>    → 每个元件的地都能就近打过孔到地平面
>    → 回流路径短、噪声小
>    → 【对采样精度和大电流都有好处】
> 【第三层做成电源平面】
>    → +12V / +3.3V 各占一片铜 → 阻抗极低
> ```
> **但对你这块板，双面板用心画也能做好；四层板是"更省心"，不是"必须"。**

## 三、六个专业名词（必须认识）

### 1. 焊盘（Pad）

```
   作用是【焊接元件引脚的地方】

   ┌────┐
   │▓▓▓▓│  ← 这块裸露的铜就是焊盘
   └────┘     元件引脚放上去，用锡焊住
```

| 元件类型 | 焊盘形式 |
|---|---|
| 直插元件（如排针） | **通孔焊盘**（铜环 + 中间一个洞） |
| 贴片元件（如 0603 电阻） | **表面焊盘**（一小块铜，不穿孔） |
| BGA / QFN 芯片 | 底部一堆小焊盘 |

### 2. 过孔（Via）

```
   作用是【把顶层和底层连通】

   顶层 ────●────      ← 这个小圆点就是过孔
            │
   底层 ────●────         孔内壁镀铜，上下导通
```

**什么时候需要它？**

```
【走线过不去】
   顶层被挡住 → 打过孔下到底层 → 绕过去 → 再打孔回顶层
【地平面回流】
   顶层元件的地 → 打过孔 → 到底层地平面（最短路径）
```

### 3. 走线（Trace）

```
   ──────────────────  ← 就是铜做的"导线"

   三个参数：
   · 宽度（Width）  ← 决定能过多少电流
   · 层（Layer）    ← 顶层还是底层
   · 长度（Length） ← 越短越好
```

### 4. 铺铜（Copper Pour）

```
   作用是【把一大片区域填满铜】

   ┌─────────────────┐
   │░░░░░░░░░░░░░░░░░│  ← 这一大片都是铜（通常接地）
   │░░░┌───┐░░░┌───┐░│
   │░░░│元件│░░░│元件│░│  ← 元件和走线处会被"挖空"（避让）
   │░░░└───┘░░░└───┘░│
   └─────────────────┘
```

| 好处 | 说明 |
|---|---|
| **① 提供"地平面"** | 每个元件就近接地，回流路径短 |
| **② 帮助散热** | 大片铜是散热片 |
| **③ 屏蔽干扰** | 铜像"墙"一样挡住噪声 |

### 5. 阻焊层（Solder Mask）

```
   ┌──────────────┐
   │▓▓▓▓▓▓▓▓▓▓▓▓▓▓│  ← 绿色阻焊（盖住铜）
   │▓▓▓┌────┐▓▓▓▓▓│
   │▓▓▓│焊盘│▓▓▓▓▓│  ← 焊盘处【不盖】，露出来好焊接
   │▓▓▓└────┘▓▓▓▓▓│
   └──────────────┘
```

```
① 防止焊接时锡"乱跑"造成短路
② 防止铜氧化（铜暴露在空气中会氧化变黑）
```

### 6. 丝印（Silkscreen）

```
   ┌──────────────┐
   │   R19        │  ← 这个"R19"就是丝印
   │  ┌────┐      │
   │  │焊盘│      │
   │  └────┘      │
   │  +12V  GND   │  ← 网络名也是丝印
   └──────────────┘
```

| 作用 | 例子 |
|---|---|
| **标位号** | R19、C28、U10 |
| **标极性** | 电解电容的"+"、二极管的阴极 |
| **标网络** | +12V、GND、M_U |
| **标版本/日期** | V1.0 / 2026-09 |

> ⚠️ **丝印很容易被忽略，但对调试极其重要** —— **找测试点全靠丝印。**

## 四、一块板子的"正反面"

```
【顶层（Top）】
   · 大部分元件放这里
   · 主要的信号走线在这里
【底层（Bottom）】
   · 少放元件
   · 【主要用来铺地平面】
   · 走一些"顶层过不去"的线
```

**为什么这么分？**

```
因为【底层空出来铺地】最有价值：
   · 地平面完整 → 回流路径短、噪声小
   · 顶层元件接地时，打个过孔就到地平面 ✅
```

## 五、回到你的板子

```
【顶层】
   ┌─────────────────────────────────┐
   │  [U10]      [Q1][Q3][Q5]        │  ← 电源芯片 + 三相桥上管
   │  [L1]                            │
   │  [U1 主控]  [R19][R35][R49]     │  ← MCU + 三个采样电阻
   │  [U2 FD6288]                     │
   │  [U4 USB]  [U6 CAN]  [LCD 座]   │
   └─────────────────────────────────┘

【底层】
   ┌─────────────────────────────────┐
   │░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│  ← 大片地平面
   └─────────────────────────────────┘
      ↑ 但要注意：这块板有"三套地"，
        不能简单铺一整个地平面（第 7 课细讲）
```

> **这块板的特殊之处：**
> ```
> 大电流路径（+12V → 三相桥 → 电机）要特别粗
> 微弱信号（采样 10mV）要特别保护
> → 【两个"极端"在同一块板子上】← 这就是它的难处
> ```

## 第 2 课小结

| 概念 | 一句话 |
|---|---|
| **PCB 结构** | 千层饼：基材 + 铜层 + 阻焊层 + 丝印层 |
| **铜层** | 唯一导电的部分，1oz = 35µm |
| **单/双/四层板** | 双面板是主流；四层板有完整地平面，更省心 |
| **焊盘 Pad** | 焊接元件的地方 |
| **过孔 Via** | 连通顶层和底层 |
| **走线 Trace** | 铜做的导线，宽度决定电流能力 |
| **铺铜 Pour** | 大面积填铜：地平面 + 散热 + 屏蔽 |
| **阻焊层** | 绿油，防短路和氧化 |
| **丝印** | 白字，标位号/极性/网络名 |

# 2.1 保险丝和 PTC（已算完，见 04 号文件）

## 核心结论
```
最坏稳态输入电流 = 5.9A（12V 输入、三路满载）
→ 保险丝/PTC 额定要按 6A 选，再留温度降额
→ PTC 温度降额：25°C→100% ｜ 50°C→80% ｜ 60°C→70%
```

## 三个方案
| 方案 | 规格 | 优点 | 缺点 |
|---|---|---|---|
| A【推荐】 | 自恢复 PTC 保持 6A / ≥30V | 短路后自动恢复 | 压降 240mV、热天降额 |
| B | 7.5A 慢断保险丝 + 座 | 压降小(90mV) | 短路后要换 |
| C | 不装，靠电源限流 | 最省事 | 依赖外部电源 |

## 两个绝对不要
```
❌ 快断保险丝（上电浪涌 78A/150µs 必然误跳）
❌ 按"输出 3A"选 3A 保险丝（12V 输入时输入电流 5.9A）
```

# 2.2 TVS 二极管 —— 它到底防什么？

## （一）先分清三种"坏事"，各有各的对策

| 故障类型 | 时间尺度 | 典型来源 | 谁负责 |
|---|---|---|---|
| **反接** | 持续（直到断电） | 线接错了 | **背靠背 P-MOS** |
| **浪涌 / 尖峰** | 微秒 ~ 毫秒 | 插拔打火、感性负载断电、静电 | **TVS** |
| **持续过流 / 短路** | 毫秒 ~ 秒 | 后级坏了、负载短路 | **保险丝 / PTC** |

> ⭐ **关键认知：三层防护各管一种故障，不能互相替代。**
> ```
> 反接 → P-MOS 挡（TVS 挡不住持续反接，会烧掉自己）
> 浪涌 → TVS 挡（P-MOS 挡不住 100V 尖峰，会击穿）
> 过流 → 保险丝挡（TVS 挡不住持续电流）
> ```

## （二）TVS 是怎么工作的

TVS = 一颗"电压到了一定值就变成导线"的二极管，**专门用来把尖峰"吃掉"**。

```
      正常时（比如 12V）：
         TVS 像【断路】→ 不耗电、不影响电路

      尖峰来时（比如 60V 冲过来）：
         TVS 瞬间导通 → 把电压"钳"在钳位电压上
         → 多出来的能量变成热量散发掉
         → 后级只看到被钳住的电压 ✅

      尖峰过后：
         TVS 自动恢复成断路
```

**三个关键参数（这是选型的全部）：**

| 参数 | 符号 | 含义 | 选型规则 |
|---|---|---|---|
| **反向截止电压** | V_RWM | 正常工作时能长期承受、不漏电的电压 | **必须 > 最大输入电压**，一般取 1.2~1.3 倍 |
| **击穿电压** | V_BR | 开始导通的电压 | 略高于 V_RWM |
| **钳位电压** | V_C | 大电流下被钳住的最高电压 | **必须低于后级器件的耐压** ⭐ |

## （三）算一遍：我们的模块该选什么 TVS

```
输入上限 = 24V
→ V_RWM 必须 > 24V，取 1.25~1.3 倍 → 30~33V 档

候选：
  SMBJ30A  → V_RWM=30V，V_BR=33.3~36.8V，V_C=48.4V
  SMBJ33A  → V_RWM=33V，V_BR=36.7~40.6V，V_C=53.3V  ⭐
  SMBJ36A  → V_RWM=36V，钳位更高

⚠️ 关键约束：钳位电压必须 < P-MOS 的 Vds 耐压（AO4407A 是 30V）
   但 SMBJ33A 钳位 53.3V >> 30V  ❌ 看起来不匹配！
```

## （四）⭐ 这个"不匹配"怎么解释？—— 一个必须想清楚的工程判断

```
【看起来矛盾】
   AO4407A Vds = 30V
   SMBJ33A 钳位 = 53.3V
   → TVS 钳住的电压比 MOS 耐压还高，那 TVS 不就没用了吗？
```

**答案是：TVS 用的不是"钳位电压"这一条，而是"截断能量"这件事。**

```
【完整逻辑链】
① TVS 把尖峰从"无限高"降到"有限高度"
   → 没有 TVS：尖峰可能 100~200V（插拔打火）→ MOS 必死
   → 有 TVS  ：尖峰被压到 40~50V 以下

② 那 40~50V 超过 MOS 的 30V 怎么办？
   → MOS 的 Vds 30V 是【直流耐压】，而雪崩击穿是【能量型】的
   → 几十微秒的 40V 脉冲，MOS 能扛（大多数 MOS 有雪崩能量能力）
   → 而且 TVS 的钳位是【大电流下】的电压，
     实际小能量尖峰时 TVS 工作在比 V_C 低得多的电压（约 V_BR 附近）

③ 真正的保护是"把能量吃掉"：
   → 尖峰的总能量 = 很小（毫焦耳级）
   → TVS 一颗 600W 的管子，能吃掉几十毫焦耳 ✅
   → MOS 只需承受"残留的那个电压"
```

**所以工程上的常规做法是：**
```
V_RWM > 最大工作电压（24V）  ← 保证不误动作
V_C 尽量低                    ← 越低越好
不苛求 V_C < MOS 耐压         ← 因为能量已经被 TVS 吃掉了
```

> ⚠️ **但如果你要"绝对保守"**：把 MOS 换成 40V 的（如 SI4459BDY / DMP4015SK3），
> 就能做到"钳位 53V > 40V"仍然不匹配，但余量大得多。
> **这是个真实的工程取舍 —— 老师傅也各有各的做法。**

## （六）⚠️ AO4407A 的 30V 耐压：一个要你自己拍板的余量问题

```
输入上限 24V，AO4407A 耐压 30V → 余量只有 1.25 倍
```

**两种做法，各有道理：**

| 做法 | 理由 | 代价 |
|---|---|---|
| **A. 就用 AO4407A（30V）** | 浪涌能量由 TVS 吃掉，MOS 只需扛残余电压；很多成熟模块这么做 | 余量小，靠 TVS 兜底 |
| **B. 换 40V 的 P-MOS** | 余量 1.67 倍，更抗造 | 贵一点，Rds(on) 稍大 |

**40V 档的候选（自己按渠道选）：**

| 型号 | Vds | Id | Rds(on) | 封装 |
|---|---|---|---|---|
| SI4459BDY | −40V | −14A | 20mΩ | SO-8 |
| DMP4015SK3 | −40V | −12A | 25mΩ | SO-8 |
| IRF9310 | −30V | −20A | 8mΩ | SO-8（这条仍是 30V） |

> **我的建议：第一版用 AO4407A（便宜好买），但 TVS 一定要装好、走线要短。**
> 如果你以后打算把这个模块长期挂在设备上用，再换 40V。

## （七）TVS 的另外两个坑

| 坑 | 说明 |
|---|---|
| **装成单向的，却用在可能有反压的地方** | 单向 TVS 只能挡一个方向。反接时它会被正向导通 → 大电流 → 烧掉。**反接由 P-MOS 挡，TVS 只挡正向浪涌，所以单向可以**（要放在 P-MOS 之后更安全） |
| **V_RWM 选得太低** | 比如用 24V 的 TVS 挡 24V 输入 → 正常工作时就轻微导通 → **持续发热烧毁** ⚠️ 必须留 25% 余量 |

## （八）TVS 该放在哪？

```
【位置 A】放在 P-MOS 之前（紧贴输入接口）
   ✅ 浪涌在进入 MOS 之前就被削掉 → MOS 最安全
   ⚠️ 但反接时 TVS 会被正向导通 → 可能烧掉

【位置 B】放在 P-MOS 之后（VIN_RAW 上）
   ✅ 反接时 P-MOS 挡住，TVS 不会被反压
   ⚠️ 浪涌要先经过 MOS 才被削

⭐ 推荐：放【P-MOS 之后】（VIN_RAW 上）
   理由：反接保护优先（反接是人为高频故障，浪涌是偶发），
        而且 MOS 的体二极管能提前削掉一部分负向尖峰
```

# 2.3 保护链的顺序

## 正确顺序

```
输入接口 → [PTC/保险丝] → [P-MOS 背靠背] → [TVS] → VIN_RAW → 三路降压
              ↑                ↑             ↑
           限制能量        挡反接        削尖峰
```

**为什么必须是这个顺序？逐个替换试一下：**

| 顺序 | 会发生什么 | 判定 |
|---|---|---|
| **保险丝 → P-MOS → TVS** ⭐ | 过流先被限 → 反接被挡 → 尖峰被削 | ✅ 正确 |
| TVS → 保险丝 → P-MOS | 反接时 TVS 正向导通（被反压）→ **烧 TVS** | ⚠️ 次优 |
| P-MOS → 保险丝 → TVS | 浪涌先砸到 P-MOS 才被限流 → MOS 承受全部冲击 | ⚠️ 次优 |
| 保险丝 → TVS → P-MOS | 反接时 TVS 被烧（同第 2 行） | ⚠️ 次优 |

**一句话原则：**
```
① 保险丝在最前 —— 保护"上游"（电源、导线）
② 反接保护在保险丝后 —— 反接时它截止，电流≈0，保险丝不会跳 ✅
③ TVS 在反接保护后 —— 避免被反压烧掉
```

> **⭐ 注意一个顺带的好处**：因为反接时 P-MOS 挡得死（电流≈0），
> **保险丝不会因为反接而跳闸** —— 接反了只要改过来就行，不用换保险丝。

# 2.5 ⚠️ 一处必须在数据手册里确认的参数（第 4 步会用到）

**TPS5430 的"最小可控导通时间"（minimum controllable on-time）—— 我不能凭空给数字。**

它决定了两件很要命的事：

```
① 最大占空比上限  → 输入 6V 时能不能做出 5V 输出？
② 最小导通时间下限 → 输入 24V 做 3.3V 时，Ton 会不会太短导致"跳周期"、纹波变大？
```

**先看我们的需求算出来是多少：**

| 输出轨 | 最坏工况 | 占空比 D | 导通时间 Ton = D / 500kHz |
|---|---|---|---|
| 5V | Vin=6V | 83.3% | **1667ns** |
| 5V | Vin=24V | 20.8% | **417ns** |
| 3.3V | Vin=24V | 13.7% | **275ns** ← 最短 |
| 12V（可调） | Vin=24V | 50.0% | 1000ns |

```
最短的 Ton = 275ns（3.3V 轨，24V 输入）
```

**所以关键就是一句话：TPS5430 的最小导通时间必须明显小于 275ns。**

> ⭐ **请在第 4 步之前，打开 [TI TPS5430 数据手册（SLVS632）](https://www.ti.com/document-viewer/lit/html/SLVS632K)，
> 在"电气特性"表里找 `Minimum controllable on-time` 或 `t_on(min)` 这一行，把数字记下来。**
>
> - 如果 < 150ns → ✅ 275ns 完全够用，**三路设计不用改**
> - 如果在 200~275ns 之间 → ⚠️ 3.3V 轨在 24V 输入时会"跳周期"，需要提高电感量
> - 如果 > 275ns → ❌ 3.3V 轨不能在 24V 输入下正常工作，**必须换方案**

**为什么要较这个真？** 因为这正是"自己画模块"和"抄别人的图"的分水岭：
抄图的人不知道自己的设计在什么条件下会失效；自己算过的人知道边界在哪。

数据手册入口：[TI TPS5430/TPS543x 数据手册 SLVS632（Rev. I）](https://www.manualzz.com/doc/27862824/)、
[TPS5430-Q1 中文数据手册](https://www.ti.com.cn/cn/lit/ds/symlink/tps5430-q1.pdf)

```

选型：
  F1  PTC 自恢复保险丝  保持 6A / 耐压 ≥30V  （或 7.5A 慢断保险丝 + 座）

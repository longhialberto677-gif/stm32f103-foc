# 通用可调降压模块 —— 设计手册（TPS5430 三路输出）

> 项目：`D:\PCB_project` 的延伸练手项目
> 定位：**通用桌面降压模块**，不是给某块特定板子供电
> 参考图：网上那张"TPS5450 双路模块"（已分析，见本文第 9 节：它有哪些坑）
> 目标参数：**输入 6~24V ｜ 输出 5V/3A、3.3V/3A、可调 5~12V/3A**

---

## 0. 先记住三句话

```
① 每路 3A 是"甜点"——覆盖一个标准舵机、一个大触摸屏、一堆传感器。
   要冲 5A 不是改电阻，是改散热和二极管，难度跳一个台阶。第一版就做 3A。

② 电感选型看"饱和电流"，输出电容选型看"耐压 + 纹波电流"，不是只看数值。

③ 反馈分压决定输出电压，公式和讲义第 2-2 节那条一模一样：
   Vout = 1.221V × (1 + R_top / R_bot)
```

                                        │                     │

```

**三颗芯片完全一样，只是反馈分压不同** —— 这是这个设计最省心的地方：BOM 里同一种料买三份。

> ⚠️ **为什么 3.3V 也用降压，而不是从 5V 接一颗 AMS1117？**
> ```
> 5V → 3.3V 用 LDO，输出 3A 时：损耗 = (5 − 3.3) × 3A = 5.1W ❌
>   5.1W 全靠一颗 SOT-223 烧掉 → 烫到能煎蛋，且 LDO 会热保护降流
> 用第二颗 TPS5430 做 3.3V：损耗 ≈ 1.35W ✅
> ```
> 你 FOC 板上用 AMS1117 是对的（那里只要 200mA，损耗 0.34W）。
> **但"通用大电流模块"必须用开关方式。这是个特别值得你亲手验证的对比实验。**

## 2. 关键公式（全部来自 TPS5430/TPS5450 手册）

### 2.1 输出电压（反馈分压）

```
Vout = 1.221V × (1 + R_top / R_bot)

R_top = 接在 Vout 与 VSENSE 之间的电阻
R_bot = 接在 VSENSE 与 GND 之间的电阻
```

**注意：TPS5430 手册的写法是**
```
R_top = R_bot × (Vout − 1.221) / 1.221
```

### 2.2 电感纹波电流

```
ΔI_L = (Vin − Vout) × Vout / (Vin × fsw × L)

fsw = 500kHz（TPS5430/5450 固定频率）
经验：让 ΔI_L ≈ 输出电流的 30%~40%
```

### 2.3 电感峰值电流（选饱和电流用）

```
I_peak = Iout + ΔI_L / 2      ← 电感的"饱和电流"必须 > 这个值，建议留 30% 余量
```

### 2.4 输出电容纹波

```
ΔVout ≈ ΔI_L / (8 × fsw × C_out)          ← 容性分量
ΔVout ≈ ΔI_L × ESR                         ← 阻性分量（陶瓷电容时代通常更小）
```

### 2.5 输入电容的 RMS 纹波电流（决定要几颗电容）

```
I_cin(rms) = Iout × √(D × (1 − D))      D = Vout / Vin
最坏情况 D = 0.5 → I_cin(rms) = Iout / 2
```

## 3. 反馈分压电阻表（已用标准阻值算过实际误差）

**基准 = 1.221V，R_top 从 E24 系列选（1k~47k），R_bot 从 E24/E96 选。**

| 目标输出 | R_top | R_bot | 实际输出 | 误差 | 说明 |
|---|---|---|---|---|---|
| **5.00V** | **10kΩ** | **3.24kΩ** | 4.99V | −0.2% | 和你 FOC 板完全一致，直接抄 |
| **5.00V**（更准） | 9.1kΩ | 2.94kΩ (E96) | 5.000V | 0.01% | 追精度时用这组 |
| **3.30V** | **5.1kΩ** | **3.0kΩ** | 3.297V | −0.1% | 3A 轨用它 |
| **12.00V** | 43kΩ | 4.87kΩ (E96) | 12.002V | 0.02% | 可调轨最高档 |
| **9.00V** | 9.1kΩ | 1.43kΩ (E96) | 8.991V | −0.1% | 可调轨中档 |
| **7.50V** | 2kΩ | 390Ω | 7.483V | −0.2% | 可调轨低档 |
| 15.00V | 9.1kΩ | 806Ω (E96) | 15.006V | +0.04% | 需要 Vin ≥ 18V |
| 6.80V | 36kΩ | 7.87kΩ (E96) | 6.806V | +0.09% | 参考图那一路 |
| 8.00V | 24kΩ | 4.32kΩ (E96) | 8.004V | +0.05% | 参考图那一路 |

> **电阻一定要用 1% 精度**（E96 系列本身就是 1% 规格的）。5% 碳膜电阻会让输出电压偏出 ±1.5%。
> **R_top 不要超过 100kΩ** —— VSENSE 引脚有微小漏电流，阻值太大误差会放大；也不要低于 1kΩ（白费电流）。

### 3.1 可调轨：用"跳线切电阻"，不要用电位器

**为什么不用电位器？** 电位器有机械触点，会随振动漂移、会氧化、时间长了输出会自己变。**做模块要稳。**

推荐结构：**R_top = 10kΩ 固定，R_bot = 2kΩ 固定 ∥（跳线选择的并联支路）**

```
        VADJ 输出
           │
        [10kΩ]  R_top
           │
           ├──────── VSENSE
           │
        [2kΩ]   R_bot (常焊)
           │
           ├───[2.61kΩ]──[JP1]──┐
           ├───[7.32kΩ]──[JP2]──┤  这几个电阻并联在 2kΩ 两端
           │                    │
          GND ──────────────────┘
```

| 跳线 | 并联支路阻值 | 等效 R_bot | 实际输出 |
|---|---|---|---|
| 全不接 | — | 2.00kΩ | 7.33V |
| JP1 | 2.61kΩ | 1.13kΩ | **12.00V** ✅ |
| JP2 | 7.32kΩ | 1.57kΩ | **8.99V** ✅ |
| —— | 直接用 1.2kΩ 当 R_bot | 1.20kΩ | **4.94V** ✅ |

> **如果你就是想要"连续可调"的手感**：装一颗 **3296W 多圈精密电位器**（22kΩ），
> 但**调好之后一定要用万用表量出实际阻值，换成同值固定电阻**，再焊死。或者点一点硅胶固定。

## 4. 电感选型（已算好纹波）

**选型三要素：① 电感量 ② 饱和电流 Isat ③ 直流电阻 DCR（决定发热）**

| 轨 | 电感量 | 最大输入时的纹波 ΔI_L | 峰值电流 | 饱和电流要求 | 推荐规格 |
|---|---|---|---|---|---|
| 5V/3A | **15µH** | 0.53A (p-p) | 3.26A | **≥ 4.5A** | 6×6mm 屏蔽型，DCR < 40mΩ |
| 5V/3A | 10µH | 0.79A | 3.40A | ≥ 4.5A | 体积更小，纹波稍大 |
| 5V/3A | 6.8µH | 1.16A | 3.58A | ≥ 5A | 最省地方，纹波明显 |
| 3.3V/3A | **10µH** | 0.57A | 3.28A | **≥ 4.5A** | 同上 |
| 3.3V/3A | 6.8µH | 0.84A | 3.42A | ≥ 4.5A | 可选 |
| 可调轨/3A | **15µH** | 0.71A (@12V) | 3.4A | **≥ 5A** | 输出电压越高纹波越大 |

**计算公式（自己动手算一遍）：**
```
ΔI_L = (Vin − Vout) × Vout / (Vin × fsw × L)

以 5V/3A、Vin=24V、L=15µH 为例：
ΔI_L = (24 − 5) × 5 / (24 × 500000 × 15e-6)
     = 95 / 180 = 0.528A  ✅ 约为输出电流的 18%，很稳
```

> ⚠️ **电感最容易犯的错：只看电感量，不看饱和电流。**
> 饱和电流不够 → 电感在峰值时"失效变成一根导线" → 电流暴涨 → 芯片内部电流限制反复打嗝，或者直接烧。
> **必须买"屏蔽型"（Shielded）**，否则它会变成一个天线，把你的电流采样和编码器信号全污染掉。

## 5. 电容选型

### 5.1 输入端

| 位置 | 元件 | 参数 | 作用 |
|---|---|---|---|
| 总输入 | **C1 电解** | 470µF / **35V**（24V 输入必须 35V 档） | 储能、吸收输入线电感 |
| 每颗芯片 VIN 旁边 | **C2/C3 陶瓷** | 10µF / 50V X7R ×2（每颗芯片一对） | ⭐ **"当场供货"**，必须紧贴 VIN 引脚 |
| 每颗芯片 VIN 旁边 | C4 陶瓷 | 100nF / 50V X7R | 高频去耦 |

**耐压怎么选？** 电解电容耐压 ≥ **1.5 × 最大输入电压**：
```
24V × 1.5 = 36V → 取 35V 或 50V 档
24V 输入用 25V 电容 = 直接炸（电解电容超压会爆浆）❌
陶瓷电容耐压 ≥ 2 × Vin → 24V 输入用 50V 档
```

**要几颗？算一下 RMS 电流就知道：**
```
I_cin(rms) = Iout × √(D × (1 − D))
3A、D=0.42（5V out / 12V in）→ I_cin(rms) = 1.48A
→ 单颗 10µF/50V X7R（0805）约能扛 1~2A rms，所以用两颗并联才稳
```

### 5.2 输出端

| 轨 | 输出电容 | 说明 |
|---|---|---|
| 5V | **47µF/10V X7R ×2** + 100nF | 低 ESR，纹波小 |
| 3.3V | **47µF/10V X7R ×2** + 100nF | 同上 |
| 可调 | **100µF/25V 电解 + 22µF/25V X7R + 100nF** | 可调轨电压范围宽，耐压按 25V 选 |

```
以 5V 轨、ΔI_L = 0.53A、47µF×2 = 94µF 计算：
ΔVout = 0.53 / (8 × 500000 × 94e-6) = 1.4mV   ✅ 非常干净
```

> ⚠️ **X5R/X7R 才是"陶瓷电容"，不要买 Y5V** —— Y5V 的容量随电压和温度能掉 80%。
> ⚠️ **电解电容的寿命看温度**：105°C 规格比 85°C 贵一点点，但寿命长好几倍，值得。

### 5.3 自举电容（容易忽略的一个细节）

```
PH ──[C_boot]── BOOT        （10nF ~ 100nF / 50V X7R）
```

- **TPS5430**：手册典型值 **10nF**
- **TPS5450**：手册典型值 **0.1µF**
- 参考图给的也是 10nF，但如果你照抄到 5450 上，**建议按手册改成 0.1µF**

> **为什么需要它？** 讲义第 4-2 节讲过：芯片内部高边开关是 N-MOS，
> 它的栅极需要比源极（PH 节点）高约 10V。PH=24V 时栅极要 34V，芯片只有 24V。
> 自举电容就是那个"把地板一起抬上去"的小电池。

## 7. PCB 布局（这是成败关键，不是走线好不好看的问题）

### 7.1 每路必须满足的三个"最小"

```
① 【开关回路面积最小】⭐ 最重要
   Cin(+) → U 的 VIN → 内部开关 → PH → D → GND → Cin(−)
   这个圈里的电流是"方波"，面积越大 → 辐射噪声越大 → 干扰你的 MCU/编码器/ADC
   → 把 Cin、芯片、D 三者挤在一起，圈越小越好

② 【PH 节点铜皮最小】
   PH 是全场最"脏"的节点（24V 方波，边缘极陡）
   → 铜皮只要够过电流就行，不要为了好看铺一大块
   → PH 的走线要短而宽，不要伸出任何多余分支

③ 【反馈线远离 PH】
   VSENSE 是毫伏级的高阻节点
   → R_top/R_bot 的分压点必须【直接接在输出电容的焊盘上】，不要从别处引
   → 反馈走线要从远离 PH 的一侧绕，最好被 GND 包着
```

### 7.2 散热（3A 能跑住的关键）

```
TPS5430 的底部散热焊盘（EPAD）是【唯一】的散热通道
   ↓
焊盘下打 9~16 个过孔（0.3mm 钻孔 / 0.6mm 焊盘）
   ↓
过孔连到【背面的大块铜皮】（GND 或 PH 都行，接到大面积铜上）
   ↓
背面铜皮面积建议 ≥ 20cm²（大约 4.5cm × 4.5cm 一整片）
```

**温度估算（5V/3A 为例）：**
```
损耗 ≈ 续流二极管 0.45V×3A×0.58 + 芯片内部导通/开关损耗 ≈ 1.8W
若 θJA ≈ 55°C/W（两面板 + 大铜皮）→ 温升 ≈ 99°C  → 环境 25°C 时结温约 124°C ⚠️
若把铜皮做大 + 打过孔 → θJA 可降到 35°C/W → 温升 63°C → 结温 88°C ✅
```
> **所以"同样 3A，有人做出来温温的，有人做出来烫手"——差别全在铜皮和过孔。**

**三颗芯片不要挤在一起**：三个热源隔着放，中间留铜皮散热。板子要是够大，每颗芯片分到 20cm² 铜皮。

### 7.3 分层建议

- **第一版就用 2 层板**（练手够用，便宜，能验证布局）
- 顶层：元件 + 功率走线（宽 ≥ 2mm / 3A）；底层：**完整地平面** + 散热铜皮
- 3A 走线宽度参考：外层 1oz 铜，**1mm ≈ 1A**，温升 10°C 大概要 1.5~2mm 宽
- **不要在地平面上开长槽**，尤其不能让功率回路的地电流"绕路"到芯片的地脚

## 8. 辅助电路（参考图有，但都有问题）

### 8.1 输入保护（参考图完全没有 → 必须加）

```
输入 → [F1 保险丝] → [D1 TVS] → [Q1 背靠背 P-MOS] → 主输入轨
```

| 元件 | 作用 | 选型要点 |
|---|---|---|
| **F1 保险丝** | 短路时切断 | 4A 慢断（或 3A 自恢复 PTC）。**PTC 会随温度降低保持电流**，夏天可能误跳 |
| **D1 TVS** | 吸收浪涌/静电 | SMBJ33A（24V 系统）；**接入电压要选在最大输入电压之上**，否则正常工作时就漏电 |
| **Q1 P-MOS** | 防反接 | 讲义第 1-3 节的方案。**供电端正接时压降只有 I×Rds(on) = 3A×10mΩ = 30mV ✅** |

> **对比：参考图用一颗肖特基串联防反接 → 5A 时白烧 2W。**
> 这就是"背靠背 P-MOS"值钱的地方，你讲义里已经学过了。

### 8.2 使能脚（EN / ENA）

```
TPS5430 的 ENA(5脚)：悬空 = 内部上拉 = 使能（可以不管）
TPS5450 的 ENA(5脚)：同样悬空即使能
```

**但建议加上"上电错峰"**（三颗芯片同时启动会一起拉扯输入电容）：
```
VIN ──[100kΩ]──┬── ENA
               │
             [100nF]
               │
              GND
→ 上电后 ENA 电压缓慢上升，芯片延后启动
```
或者更讲究一点：**用前一路的输出把后一路的 ENA 拉高**，做"级联上电"（5V 稳了才开 3.3V）。

### 8.3 指示灯

```
输出轨 ──[1kΩ]──[LED]── GND        → 3.3V 时约 1.7mA，5V 时约 3mA
```
> ⚠️ **参考图用的是 5kΩ，5V 下只有 0.6mA —— LED 会暗到几乎看不见。别抄这个值。**
> 3.3V 轨用 1kΩ 就够亮；12V 轨要用 **3.3kΩ**（否则 LED 过流）。

## 9. 参考图（那张 TPS5450 双路图）的 5 个坑 —— 别照抄

| # | 参考图的问题 | 为什么是问题 | 你的方案怎么做 |

| 2 | **U7 用一颗肖特基串联防反接** | 5A × 0.45V = 2W 白烧，还降低输出电压 | 用 Q1 背靠背 P-MOS，压降 30mV |
| 3 | **下路输入端只有一颗 100nF** | 5A 级芯片手册要求输入 ≥10µF，这一路明显单薄 | 每颗芯片都配 10µF×2 + 100nF |
| 4 | **使能脚全部悬空** | 三路同时上电，互相拖拽输入电容 | 加 RC 延时或级联上电（8.2 节） |
| 5 | **指示灯限流 5kΩ** | LED 只有 0.6mA，看不见 | 按电压算：3.3V→1kΩ，12V→3.3kΩ |

**参考图值得学的 3 个点：**
1. ✅ **可调那路用"固定电阻 + 跳线切档"而不是电位器** —— 这个思路很好
2. ✅ 每路输出挂一个 LED 做"这路活了"的指示 —— 调试神器
3. ✅ 两路共用一颗输入二极管（省一个元件的思路）

## 10. 焊接与上电测试流程（照着做，别跳步）

### 阶段 0：焊前目检
```
[ ] 三颗芯片的 1 脚方向对不对（看丝印的圆点/缺口）
[ ] 电解电容正负极对不对（长脚是正，壳体有白条的是负）
[ ] 肖特基二极管方向对不对（有银灰色色环的一端 = 阴极 = 接输出侧）
[ ] 电感没有装反（多数无方向，但有标记的按丝印）
```

### 阶段 1：不装芯片先量（⭐ 关键，能救你三颗芯片）
```
[ ] 输入端子两端测电阻：应该是【高阻/开路】，不能是 0Ω
    → 如果是 0Ω = 输入短路，先找出来再上电
[ ] 三路输出对地测电阻：应该都是几百 Ω 以上
    → 接近 0Ω = 输出短路
[ ] 确认 TVS 和电解电容极性
```

### 阶段 2：空载上电（限流电源！）
```
[ ] 电源设 12V，【限流设 200mA】
[ ] 上电，看电流：正常空载应该 < 30mA（三颗芯片静态电流合计）
    → 电流直接顶到限流值 = 有短路，立刻断电
[ ] 量三路输出：
      5V 轨：4.95 ~ 5.05V ✅
      3.3V 轨：3.26 ~ 3.34V ✅
      可调轨：跳线各档位分别量
```

### 阶段 3：逐步加载（用水泥电阻或电子负载，别用电机）
```
[ ] 0.5A → 量输出，压降应 < 20mV
[ ] 1A   → 量输出 + 用手背碰芯片（烫到不能碰 = 超过 60°C，正常）
[ ] 3A   → 量输出 + 量温度（最好有红外测温枪）
      目标：芯片表面 < 90°C，电感 < 80°C，二极管 < 90°C
[ ] 记录：输入功率 / 输出功率 → 算效率（3A 时应 ≥ 85%）
```

### 阶段 4：示波器（有的话一定要看）
```
[ ] 看 PH 节点波形：应该是干净的方波
    → 有严重振铃（尖峰超过 Vin 的 1.5 倍）= 布局有问题，加 RC 吸收或改布局
[ ] 看输出纹波：应该 < 50mV
    → 纹波过大 = 输出电容不够或 ESR 太大
[ ] 【最容易炸的场景】输入电压从 24V 直接拉满 → 看 PH 有没有异常
```

### 阶段 5：加载测试（积累经验）
```
[ ] 输入 24V / 输出 5V / 3A（最坏工况：压差最大 → 芯片内部损耗最大）
[ ] 输入 6V  / 输出 5V / 3A（最坏工况：占空比接近上限 → 看会不会掉压）
[ ] 输入 24V / 可调轨 12V / 3A
```

## 11. 常见坑清单（收藏起来，翻车时对照）

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | 输出电压偏高/偏低 | 反馈电阻用 5% 或算错 | 用 1% 电阻，按第 3 节表 |
| 2 | 输出纹波巨大（几百 mV） | 输出电容太小 / ESR 太大 / 用了 Y5V | 加 47µF X7R，改 X7R/X5R |
| 3 | 芯片发烫到烫手 | 散热过孔没打 / 铜皮太小 | 打过孔 + 加大背面铜皮 |
| 4 | 带载就掉压 | 电感饱和 / 输入线太细 / 保险丝内阻大 | 换 Isat 更大的电感 |
| 5 | 上电就烧芯片 | 输入电压超 36V / 电解电容反接 / VIN 和 GND 接反 | 检查极性和耐压 |
| 6 | 输出振荡（电压来回跳） | 反馈走线穿过了 PH 区域 / 输出电容 ESR 太低 | 重走反馈线，加前馈电容 |
| 7 | 效率只有 70% | 续流二极管用成了普通硅管 | **必须肖特基** |
| 8 | 空载正常，一接电机就重启 | 电机启动电流把输入拉低 | 加大输入电容，或让电机走独立电源 |
| 9 | 输出电压调不上去 | 占空比限制（Vout 不能超过 Vin × 0.85） | 提高输入电压 |
| 10 | 三路一起开就出问题 | 同时上电拖垮输入 | 加 RC 使能延时 / 级联上电 |

## 12. 下一步（建议的开发顺序）

```
第 1 步：先做【一路】5V/3A（最小系统：芯片 + 电感 + 二极管 + 电容 + 反馈）
        → 验证你的布局、散热、上电流程。成功后再复制。
第 2 步：复制成三路，只改反馈分压 → 一次打样搞定
第 3 步：加输入保护（保险丝 / TVS / P-MOS）+ 使能错峰
第 4 步：实测三路在 3A 下的温升，决定要不要冲 5A
第 5 步：（进阶）把 SS34 换成同步整流的芯片（如 TPS54560 / MP2315 系列）
        → 效率从 85% 提到 92%，二极管那个最烫的元件消失了
```

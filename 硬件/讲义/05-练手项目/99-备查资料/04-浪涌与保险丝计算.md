一、上电浪涌：电容充电的冲击电流有多大？
==============================================================================
输入总容量 = 470µF 电解 + 30µF 陶瓷 = 500µF
路线上还有：背靠背 P-MOS（Vgs 从 0 慢慢建立）+ 保险丝内阻 + 电源内阻

模型：I(t) = (Vin − VD0)/R · exp(−t/RC)，冲击能量 E = ½CV²
      （P-MOS 的栅极经 100k 到地，Vgs 建立需要时间 → 天然软化冲击）

| 输入 | 电源+线阻(Ω) | 峰值电流 | 时间常数 | 冲击能量 | 2×RC 内 I²t |
|---|---|---|---|---|---|
| 12V | 0.10 | **113A** | 50µs | 0.04J | 0.32 A²s |
| 12V | 0.30 | **38A** | 150µs | 0.04J | 0.11 A²s |
| 12V | 0.60 | **19A** | 300µs | 0.04J | 0.05 A²s |
| 24V | 0.10 | **233A** | 50µs | 0.14J | 1.36 A²s |
| 24V | 0.30 | **78A** | 150µs | 0.14J | 0.45 A²s |
| 24V | 0.60 | **39A** | 300µs | 0.14J | 0.23 A²s |

解读：
  · 峰值电流能达到几十安 —— 但只持续约 0.1 毫秒（RC 时间常数级别）
  · 保险丝【不是】按峰值电流选的，而是按"稳态电流 + 能不能扛住这个短暂的 I²t"
  · 好消息：背靠背 P-MOS 的栅极经 100kΩ 到地，
    Vgs 建立需要时间 → 管子是"慢慢导通"的 → 天然软化了浪涌 ✅

二、稳态电流：保险丝/PTC 的额定值该选多大？
==============================================================================
| 场景 | 输出总功率 | 输入电压 | 输入稳态电流 | 备注 |
|---|---|---|---|---|
| 三路满载（5V/3.3V/12V 各 3A） | 60.9W | 24V | **2.95A** | ✅ 正常工况 |
| 三路满载 | 60.9W | 12V | **5.90A** | ✅ 正常工况 |
| 只跑 5V+3.3V 两路满载（12V/3A 不用） | 24.9W | 12V | **2.41A** | ✅ 正常工况 |
| 只跑 5V/3A | 15.0W | 12V | **1.45A** | ✅ 正常工况 |
| 三路满载 | 60.9W | 6V | **11.80A** | ❌ 6V 输入跑不了三路满载（占空比不够） |

⭐ 关键：**最坏稳态输入电流 = 5.90A**（12V 输入、三路满载）

   → 这时候输入电流是 24V 工况的【两倍】（因为功率守恒：P = V×I）
   → 所以"保险丝选 4A"是【错的】！12V 满载就把它跳了 ❌

选型规则：
   额定值 > 最大稳态电流，且要预留【温度降额】

   PTC 的保持电流有温度降额（典型曲线）：
       25°C → 100% ｜ 40°C → 约 90% ｜ 50°C → 约 80% ｜ 60°C → 约 70%
   → 要保证 5.9A 在 50°C 下也不跳，需要的保持电流
     = 5.9 / 0.8 = **7.4A** → 选 **8A 档 PTC**

   ⚠️ 但 8A 的 PTC 体积大、压降也大。所以对"练手模块"，更现实的做法是：

     方案 A【推荐】：PTC 保持电流 6A / 耐压 ≥30V
        → 24V 满载（2.95A）绰绰有余 ✅
        → 12V 三路满载（5.9A）在常温下勉强，热天可能跳 ⚠️
        → 折中，体积可接受

     方案 B：7.5A 慢断保险丝 + 可换保险丝座
        → 电流能力足，但短路后要换保险丝

     方案 C【最省事】：不装保险丝，靠电源自己的限流
        → 调试期用带限流的台式电源，本身就是最好的保护 ✅
        → 模块自己的 TPS5430 还有逐周期限流 + 过温保护

三、两种器件的取舍：慢断保险丝 vs 自恢复 PTC
==============================================================================

┌──────────────┬────────────────────────┬────────────────────────┐
│              │ 慢断保险丝 (玻璃/陶瓷管) │ 自恢复 PTC             │
├──────────────┼────────────────────────┼────────────────────────┤
│ 跳了怎么办    │ 必须换新的 ❌           │ 断电冷却几分钟自动恢复 ✅│
│ 内阻/压降     │ 约 0.015Ω → 90mV ✅     │ 约 0.04Ω → 240mV 🟡    │
│ 额定值温度漂移│ 基本不漂 ✅             │ 高温下保持电流下降 🟡   │
│ 对浪涌的耐受  │ 慢断型能扛 ✅           │ 靠热容，也能扛 ✅       │
│ 调试友好度    │ 短一次换一颗 ❌         │ 短一次等一会儿 ✅       │
│ 成本          │ 0.2 元 + 座 0.5 元      │ 0.8 元                 │
└──────────────┴────────────────────────┴────────────────────────┘

（压降按 6A 最坏工况算：0.015×6 = 90mV ｜ 0.04×6 = 240mV）

四、⚠️ 一个容易被忽略的坑：热插拔的第二次冲击
==============================================================================

情景：模块正在跑（470µF 已充满 24V），你把 DC 头拔下来又立刻插回去

  拔出：电容慢慢放电（靠芯片静态电流，能维持好几秒）
  插回：电容还剩约 20V，插头接触瞬间 → 20V 直接加到已经充到 20V 的电容上
        → 冲击电流 = (24 − 20)/R，比冷启动小得多 ✅

但如果【拔出后到插回之间电容放完了】（比如你换了个电源）→ 相当于冷启动。

真正的风险是【插头接触抖动】：插头插入时弹片会"蹭"几下，
每次蹭都是"通-断-通"，可能产生多次小冲击。
→ 这就是为什么【输入端大电容 + DC 座】的组合，
  比"裸接线"更容易让保险丝疲劳老化。
→ 对策：TVS 吸收尖峰 + 保险丝/PTC 选对档位。

五、最终选型
==============================================================================

最坏稳态输入电流 = 5.90A（12V 输入、三路满载）；典型工况约 1~3A

【方案 A · 推荐】自恢复 PTC
   保持电流 6A、跳闸电流 12A、耐压 ≥30V 直插 PTC
   立创搜索："PTC 自恢复保险丝 6A 30V"
   代价：6A 时压降约 240mV（可接受）
   实测确认：跑 3A 时量 PTC 两端压降应 <150mV

【方案 B】7.5A 慢断保险丝 + 5×20mm 保险丝座（可换）
   ⚠️ 必须【慢断(T)】，不能用【快断(F)】，否则每次开机都可能误烧
   好处：内阻小（压降仅 90mV）、电流能力强
   代价：短路后要换保险丝

【方案 C · 最省事】先不装，靠台式电源的限流保护
   调试期用带限流设定的电源，本身就是最好的保护
   而且 TPS5430 自带逐周期限流 + 过温关断，也能保护自己
   → 等模块跑通了，再决定要不要补 PTC

❌ 【绝对不要】快断保险丝 —— 上电浪涌必然误跳
❌ 【绝对不要】按"输出电流 3A"去选 3A 保险丝 —— 输入电流可能到 6A

🛡️ 记住三层防护的分工：
   ① 背靠背 P-MOS → 挡反接（人为接错线）
   ② TVS          → 挡浪涌尖峰（毫秒级）
   ③ 保险丝/PTC   → 挡持续过流、后级短路
   三层各管一种故障，缺一不可。

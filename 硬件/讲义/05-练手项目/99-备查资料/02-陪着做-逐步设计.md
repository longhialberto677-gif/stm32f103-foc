# ⚠️ 第 1 步 · 1.3 【重大修正】单颗 P-MOS 挡不住反接，必须改背靠背

> **这一节是"复核"出来的**，不是新内容。我回头验算第 1.1 节的电路时发现：
> 我原来写的那个接法**能挡倒灌，但挡不住输入反接**，而且后果很严重。
> 已经写成脚本复算过（`工具\验证_PMOS_OR电路.py`），结论可复现。

## （一）反接时会发生什么

**先说一个容易想错的地方：反接不等于"输入短路"。**

```
   电源+ ──── 板 GND ────┬──────────────┐
                          │              │
                     [ 470µF 电容 ]      │  ← 后级（电容 + 三颗芯片）
                     [ 三颗芯片   ]      │
                          │              │
   电源− ──── DC座中心针 ──┴──[Q1 体二极管]──┘
```

**电流路径：** `电源+ → 板GND → 后级 → Q1体二极管 → 输入− → 电源−`

**这条路径不经过电源内部，它不是短路，而是"整个后级被反向充电"。**

**脚本算出来的结果（反接 12V）：**

| 反接电压 | 输出节点被拉到 | 后级承受电压 | 体二极管 |
|---|---|---|---|
| −12V | **−11.30V** | **−11.30V** | **导通 ❌** |
| −24V | **−23.30V** | **−23.30V** | **导通 ❌** |

**后果：**
```
① 470µF 电解电容被反向充电 → 鼓包 / 爆浆 ⚠️
② 三颗 TPS5430 的 VIN 被加 −11.3V
   → 芯片内部 ESD 二极管大电流 → 烧芯片 ⚠️
```

> **为什么单颗挡不住？** 因为 P-MOS 内部那个**体二极管**（寄生二极管）方向是固定的：
> 它天生允许"输出侧 → 输入侧"的电流。你想用它挡反接，方向刚好挡反了。

## （二）✅ 正确接法：背靠背（每路两颗，共用漏极）

```
   输入正极 ── S[Q1a]D ──┬── D[Q1b]S ── 输出节点
                         │
   （两颗栅极都经 100kΩ 到 GND；两颗的体二极管方向【面对面】）
```

| 工况 | 结果 |
|---|---|
| **正接 +12V** | Q1a：Vgs = 0−12 = −12V → 导通；Q1b 同理导通。**总压降 = 2 × 3A × 13mΩ = 78mV** ✅ |
| **反接 −12V** | Q1a：Vgs = +12V > 阈值 → 沟道关断。两颗体二极管方向相反、互相顶住 → **双向都不通，反接电流 ≈ 0** ✅ |

> ⭐ **一句话记忆：背靠背 = 让两个体二极管面对面互相堵死。**

## （三）代价（很小）

| 项目 | 原方案（2 颗） | 修正方案（4 颗） |
|---|---|---|
| 零件数 | 2 颗 P-MOS | 4 颗 P-MOS |
| 压降（3A） | 39mV | **78mV** |
| 损耗（3A） | 0.117W | **0.234W** |
| 挡住倒灌 | ✅ | ✅ |
| **挡住反接** | ❌ | ✅ |

**多花两颗 MOS（几毛钱），换整块板子免于"一次接反全废"。值得。**

## （四）修正后的第 1 步结论

```
接口：   DC-005-2.0 母座（丝印"中心正极 ≤2A"）+ KF2EDGK-5.08-2P 端子（≤3A）
输入级： 【每路两颗 AO4407A 背靠背】
          DC 座路 = Q1a + Q1b
          端子路  = Q2a + Q2b
          4 颗栅极均经 100kΩ 到 GND
作用：   ① 两路 OR（高电压自动胜出）
         ② 挡住反接（真正的保护）
         ③ 防止倒灌回电源
压降：   3A 时每路 78mV
```

> **🛡️ 顺便把三层防护的分工记在脑子里（第 2 步会继续补全）：**
> ```
> ① P-MOS 背靠背 → 挡【反接】（人为接错线的持续性故障）
> ② TVS          → 挡【浪涌】（毫秒级的电压尖峰）
> ③ 保险丝       → 挡【持续过流 / 后级短路】
> 三层各管一种故障类型，缺一不可，也不能互相替代。
> ```

# 第 1 步 · 1.2 【本节】DC 座规格 + 端子选型 + PCB 封装 + 丝印

## （一）DC 母座：先把"规格"讲清楚

**DC 座只有两个参数真正重要：中心针直径、额定电流。**

### 中心针直径：2.0mm vs 2.5mm

```
   外径 5.5mm（这个是行业通用的，基本都一样）
   ┌─────────────┐
   │   ○ ← 中心针  │   内径 2.0mm 或 2.5mm
   └─────────────┘

插头常见的三种（买错的根源就在这）：
   5.5 × 2.1mm  → 用【2.0mm】母座 ✅（最常见，路由器/摄像头那类）
   5.5 × 2.5mm  → 用【2.5mm】母座 ✅
   3.5 × 1.35mm → 小圆孔（音叉插头/部分开发板），槽位不通用 ❌
```

> **⚠️ "2.0mm 母座"其实配的是 2.1mm 插头** —— 这是行业惯例：母座标 2.0，公头标 2.1，实际是**同一对**。
> 这与"2.5mm 母座配 2.5mm 插头"是两套规格，**互不通用**。

### 额定电流

| 版本 | 触点 | 额定电流 | 说明 |
|---|---|---|---|
| DC-005-2.0 | 全铜/铜合金，中心针较细 | **2A** | [常见规格书写 2A](http://www.cn-bbj.com/page/cn/p_view?id=13470) |
| DC-022 / DC-005-2.5 | 中心针粗、弹片面积大 | **3~5A** | 大电流适配器多用 |

> ⚠️ **不要相信"DC-005 5A"这种标法。** 你参考图上那颗写的是 `DC-005-5A-2.0`，
> 这里的 **"5A" 是厂家型号后缀，不是电流额定值**。2.0mm 中心针接触面积有限，
> 长期跑 3A 会发热 → 弹片退火变松 → 接触电阻变大 → 更热（**正反馈，最后烧座子**）。

## （二）我的推荐（这就是第 1 步的最后一个决定）

```
⭐ 第一版就用 2.0mm 版本，但在丝印上写清楚 "DC ≤ 2A"

理由：
  ① 你手边的适配器 90% 是 5.5×2.1（配 2.0mm 母座）→ 立刻能用，不用额外买插头
  ② 3A 满载这条路由【端子】承担，DC 座只当"轻载/临时"输入
  ③ 便宜好买：立创商城搜 "DC-005-2.0"，几毛钱一个
  ④ 和参考图的封装一致，你可以直接抄它的 PCB 封装（省一步画封装）

如果你想跑满 3A 也想用 DC 座：选 2.5mm 版本，但【必须自己买 5.5×2.5 的插头】，
否则会插不进/接触不良。
```

## （三）接线端子：推荐用"插拔式"而不是"螺钉式"

```
【螺钉式 KF301-5.08-2P】          【插拔式 KF2EDGK-5.08-2P（推荐）⭐】
   ┌─────────┐                       ┌─────────┐   ┌─────────┐
   │ ⊕     ⊖ │  ← 拧螺丝压线         │ ⊕     ⊖ │ + │ ⊕     ⊖ │ ← 公头拧线
   └─────────┘                       └─────────┘   └─────────┘
     焊在板上，线直接插                  母座焊在板上    公头可拔插
```

| | 螺钉式 | **插拔式（推荐）** |
|---|---|---|
| 换线速度 | 要螺丝刀 | **一拔一插** ✅ |
| 可靠性 | 一样可靠 | 一样可靠 ✅ |
| 成本 | 便宜（约 0.5 元） | 贵一点（约 1.5 元） |
| 调试友好度 | 一般 | **非常好 —— 调试时反复插拔不伤板子** ✅ |

**间距必须是 5.08mm**（不是 3.81、不是 2.54）—— 这是大电流端子的通用间距。

## （五）⭐ 摆放与机械强度（这里最容易翻车）

**DC 座的通病：插拔力全部集中在 3 个焊盘上，用久了翘焊盘。**

```
        板边
   ┌──────────────────────────
   │  ┌────────┐
   │  │ DC-005 │ ← 插座主体悬在板外
   │  └┬──┬──┬─┘
   │   │  │  │     ← 3 个焊盘
   │   ●  ●  ●
   │  1  2  3
   │
```

**三个必须做的加固措施：**

```
① 中心针那个焊盘（走 3A 的那个）→ 焊盘上的走线要【宽 ≥ 1.5mm】，最好铺铜连出去
② 两个接地脚 → 直接连到【背面地平面】，做多个过孔
③ ⭐ 在插座主体下方/两侧留【直插孔或半孔】，可以穿一根扎带或短铜线压住插座本体
   → 这才是真正防翘焊盘的办法（很多成熟模块都有这个设计）
```

**摆放位置规则：**

| 规则 | 为什么 |
|---|---|
| **DC 座和端子都放在板边** | 不然插头插不进去 / 线拧不上 |
| **DC 座的中心孔朝板外** | 方向反了插不进去 |
| 两个接口**分开放在不同边** | 避免同时插两个大插头时互相打架 |
| **P-MOS 紧贴接口放** | 缩短大电流路径，减少压降和噪声 |
| 从接口到 P-MOS 再到保护链的走线 **≥ 1.5mm 宽（3A）** | 3A 走 1mm 会温升 30°C+ |

## （六）丝印怎么写（这一条比你想的重要 10 倍）

丝印是这块板子**唯一的"使用说明书"**。装完壳子以后，上面这几行字就是全部信息。

```
【输入端子旁边】
   ╔══════════════════╗
   ║  +   −           ║   ← 用大号丝印，+ 用粗体
   ║  6~24V  ≤3A      ║   ← 电压范围 + 电流上限
   ╚══════════════════╝

【DC 座旁边】
   ┌─────────────────┐
   │ DC 5.5×2.1 中心正极 │
   │      ≤ 2A        │   ← ⭐ 这个电流限制必须写，否则以后自己都会忘
   └─────────────────┘

【每路输出端子旁边】
   5V / 3A          ← 建议用不同颜色区分：5V 红字、3.3V 绿字、ADJ 黄字
   3.3V / 3A
   ADJ 5~12V / 3A

【板子背面或空白处】
   通用降压模块 v1.0  输入6~24V  输出5V/3.3V/ADJ  每路3A
   设计：________  日期：____
```

> **为什么 "≤2A" 必须写在 DC 座旁边？**
> 因为三个月后你会完全忘记"DC 座承载不了 3A"这件事，
> 然后插上一个 3A 负载 → 座子发热 → 弹片退火 → 接触不良 → 电压跌落 → 莫名其妙的问题。
> **丝印就是写给未来的自己看的。**

### 第 2 步 · 保险丝：已经算出来的关键数字 ⭐

**最坏稳态输入电流 = 5.90A（12V 输入、三路满载）**

| 场景 | 输出功率 | 输入电压 | 输入稳态电流 |
|---|---|---|---|
| 三路满载 | 60.9W | 24V | 2.95A |
| **三路满载** | **60.9W** | **12V** | **5.90A** ⚠️ |
| 只跑 5V+3.3V 两路满载 | 24.9W | 12V | 2.41A |
| 只跑 5V/3A | 15.0W | 12V | 1.45A |

```
⭐ 功率守恒的必然结果：输入电压减半 → 输入电流翻倍
   → 所以"按输出 3A 选 3A 保险丝"是【错的】，12V 满载就跳闸 ❌
   → 额定值要按【6A】这个最坏值来选，还要留温度降额
```

**浪涌也要算（不然保险丝会误跳）：**

| 输入 | 电源+线阻 | 峰值冲击电流 | 时间常数 | 冲击能量 |
|---|---|---|---|---|
| 12V | 0.3Ω | 38A | 150µs | 0.04J |
| 24V | 0.3Ω | 78A | 150µs | 0.14J |

> ✅ **一个意外的好消息**：背靠背 P-MOS 的栅极经 100kΩ 到地，
> Vgs 建立需要时间 → 管子是"慢慢导通"的 → **天然软化了上电浪涌**。

**结论（第 2 步会展开讲）：**
```
✅ 方案 A【推荐】自恢复 PTC：保持电流 6A、耐压 ≥30V
✅ 方案 B      7.5A 慢断保险丝 + 可换座
✅ 方案 C【最省事】先不装，靠台式电源的限流
❌ 绝对不要：快断保险丝（浪涌必跳）
❌ 绝对不要：按"输出 3A"选 3A 保险丝
```

### 里面两个"早点知道能省一次打样"的结论 ⭐

**结论 1：5V 轨要满 3A，输入至少 6.2V**

```
路径上固定压降（3A 满载）：
   OR 级 P-MOS 40mV + 电感 DCR 90mV + 芯片内部高边 MOS 300mV = 430mV
最低 Vin = (5V + 0.43V) / 0.87（最大占空比）= 6.24V
→ 所以标称"输入 6V"其实满载跑不动 5V/3A，实际底线是 6.5V 左右
```

**结论 2：可调轨的输出上限 = 输入电压 × 0.85**

```
12V 输出跑 3A → 需要输入 ≥ 14.3V
6V 输入时，可调轨最多只能输出 5V 左右
→ 这是"通用可调"模块的铁律：想输出高压，必须给足输入
→ 模块丝印上要写清楚：ADJ 12V 档需输入 ≥15V
```

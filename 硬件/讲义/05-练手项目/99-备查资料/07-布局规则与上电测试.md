# 第一部分：PCB 布局规则

## 0. 一句话总纲

```
整个设计里最脏、最热、最要命的地方只有一个：每一路的【开关回路】。
布局的唯一目标就是：把这个圈做小，并且让热量出得去。
```

## 1. ⭐ 每路的"开关回路"必须最小

```
   ┌─────────── 这个圈里的电流是【方波】 ───────────┐
   │                                                │
  C_in(+) ──→ U 的 VIN ──→ 内部开关 ──→ PH ──→ D ──→ GND ──→ C_in(−)
                                                  ↑
                                          续流时电流走这里
```

**为什么？** 圈里的电流每次开关都从 0 跳到 3A（每秒 50 万次），
圈的面积越大 → 辐射的电磁噪声越强 → 干扰你的 MCU、ADC、编码器。

**具体怎么做：**
```
[ ] C_in（10µF）紧贴芯片的 VIN 引脚，距离 < 5mm
[ ] 续流二极管 D 紧贴芯片的 PH 引脚和 GND
[ ] 电感 L 紧贴 PH 引脚
[ ] 这三个元件（芯片 / D / C_in）**挤在一起**，不要为了"整齐"拉开
[ ] GND 侧用铺铜连接，不要用细走线（细线有电感，等于把圈变大）
```

## 2. PH 节点：铜皮要够用就行，不要大

```
PH 是全场最脏的节点（最高 24V 方波，边沿极陡）→ 它就是个天线
[ ] 铜皮只按电流需要（3A → 宽 ≥1.5mm）
[ ] 不要为了"好看"把 PH 铺一大片
[ ] PH 不要伸出任何多余的分支
[ ] PH 铜皮【不要】放在反馈走线旁边
```

## 3. 反馈走线：这一条最容易毁掉整个设计

```
[ ] 分压电阻（R_top/R_bot）的【上端】直接接在【输出电容的焊盘上】
    → 不要从别处引线过来（否则取样点带着噪声）
[ ] VSENSE 走线尽量短，并且用 GND 包着（或走到地平面的另一侧）
[ ] VSENSE 走线【绝对不能】穿过 PH 区域或电感下方
[ ] 两个分压电阻靠在一起放，中间节点就是 VSENSE
```

## 4. 散热（决定 3A 能不能跑住）

```
[ ] 芯片底部散热焊盘（EPAD）下打 9~16 个过孔（0.3mm 钻孔 / 0.6mm 焊盘）
[ ] 过孔连到【背面的大面积铜皮】
[ ] 背面铜皮面积 ≥20cm²（约 4.5cm×4.5cm）
[ ] 三颗芯片不要挤在一起，中间留铜皮散开热量
```

**为什么这么较真？** 同样的电路、同样的 3A：

| 散热条件 | 温升 | 结温（环境 25°C） | 判定 |
|---|---|---|---|
| 小铜皮、无过孔 | 126°C | 151°C | ❌ 过温保护 |
| 一般铺铜 | 99°C | 124°C | ⚠️ 偏高 |
| **大铜皮 + 过孔阵列** | **72°C** | **97°C** | ✅ 安全 |

## 5. 走线宽度（外层 1oz 铜，温升约 10°C 的口径）

| 电流 | 建议宽度 |
|---|---|
| 3A | ≥1.5mm |
| 6A（12V 满载输入） | ≥3mm 或铺铜 |
| 信号线（反馈、ENA、LED） | 0.25mm 足够 |

## 6. 分层

```
[ ] 第一版就用 2 层板（练手够用，便宜，能验证布局）
[ ] 顶层：元件 + 功率走线
[ ] 底层：完整地平面 + 散热铜皮
[ ] 地平面不要开长槽；功率回路的地电流不要绕远路回到芯片地脚
```

## 7. 摆件顺序（对着参考）

```
1. 先摆机械件：DC 座、端子（都靠板边，DC 座中心孔朝外）
2. 摆输入保护链：PTC → 4 颗 P-MOS（紧贴接口）→ TVS
3. 摆输入电容：470µF 电解 + 每路 2 颗 10µF（靠近各自芯片）
4. 摆三路：芯片 + D + L + 输出电容 → 一组一组来，**三组互相隔开**
5. 最后摆：反馈分压、LED、使能 RC
6. 丝印：+ / − 、电压、电流上限、"DC 中心正极"
```

# 第二部分：上电测试流程

## ✅ 关键心态：**分五步，每步都能停下来**

```
新手最容易犯的错：焊完 → 直接接 24V 满载 → 冒烟 → 不知道哪里坏了
正确做法：每一阶段只增加一个"新变量"，出问题能立刻定位
```

## 阶段 0：焊后目检（不上电）

```
[ ] 三颗芯片 1 脚方向（看丝印圆点/缺口）
[ ] 电解电容极性（壳体白条 = 负极）
[ ] 肖特基 D2/D3/D4 方向（色环端 = 阴极 = 接输出侧）
[ ] 4 颗 P-MOS 方向（S 朝电源侧，D 朝输出侧）⭐ 这条最容易错
[ ] TVS 方向（单向 TVS 有极性）
[ ] 反馈电阻阻值（用万用表逐个量，1% 电阻容易和旁边的混）
```

## 阶段 1：不上电，先量电阻（⭐ 能救你三颗芯片）

```
[ ] 输入端子两端：应高阻/开路，不能是 0Ω（0Ω = 输入短路）
[ ] 三路输出对地：应几百 Ω 以上（接近 0Ω = 输出短路）
[ ] 三路输出对 GND：反向测一次（确认没有二极管直通）
[ ] 检查 P-MOS 的 S/D 之间：应有体二极管压降（0.4~0.6V）—— 确认方向对
```

## 阶段 2：空载上电（**必须用限流电源**）

```
[ ] 电源设 12V，限流设【200mA】
[ ] 上电，看电流：正常空载 < 30mA（三颗芯片静态电流合计）
     → 电流顶到限流 = 有短路，立刻断电
[ ] 量输入（P-MOS 之后）：应比电源低 80~150mV（PTC + P-MOS 压降）
[ ] 量三路输出：
      5V  轨：4.95 ~ 5.05V ✅
      3.3V 轨：3.26 ~ 3.34V ✅
      可调轨：跳线各档位分别量
[ ] 三颗 LED 应都亮（可调轨在高档位时注意限流电阻）
```

## 阶段 3：逐步加载（用水泥电阻或电子负载，**别用电机**）

```
[ ] 0.5A → 量输出，压降应 < 20mV
[ ] 1A   → 摸芯片（能碰住 = <60°C 正常；烫到不能碰 = 危险）
[ ] 3A   → 量温度（红外测温枪最好）
       目标：芯片 < 90°C ｜ 电感 < 80°C ｜ 二极管 < 90°C
[ ] 记录：输入功率 / 输出功率 → 算效率（3A 时应 ≥85%）
```

## 阶段 4：示波器（有就一定看）

```
[ ] PH 节点波形：应是干净方波
     → 振铃尖峰超过 Vin 的 1.5 倍 = 布局有问题
[ ] 输出纹波：应 < 50mV（我们算出容性纹波只有 1.5mV，实际取决于 ESR/布局）
[ ] 上电瞬间看输入：浪涌被 P-MOS 软化了多少
```

## 阶段 5：极限与故障测试

```
[ ] 输入 24V / 5V 轨 3A（压差最大 → 芯片内部损耗最大）
[ ] 输入 6.5V / 5V 轨 3A（占空比最大 → 看会不会掉压）
[ ] 输入 24V / 可调轨 12V / 3A
[ ] ⭐ 故意短路输出（PTC 应跳，断开后自动恢复）
[ ] ⭐ 故意反接输入（应完全无电流 —— 验证背靠背 P-MOS）
[ ] 两个输入接口同时接不同电压（验证 OR：高电压胜出）
```

## 阶段 6（可选）：长期跑

```
[ ] 24V 输入 + 5V/3A 连续跑 1 小时，每 10 分钟记一次温度
[ ] 看温度是否稳定（如果持续爬升 = 热设计有问题）
```

# 第三部分：故障排查表

| 现象 | 最可能的原因 | 怎么查 |
|---|---|---|
| 输出偏高/偏低 | 反馈电阻错/用了 5% | 量分压电阻实际阻值 |
| 纹波巨大 | 输出电容太小 / 用了 Y5V | 换 X7R |
| 芯片发烫 | 散热过孔没打 / 铜皮太小 | 对照第一部分第 4 节 |
| 带载掉压 | 电感饱和 / PTC 压降大 / 线太细 | 量各段压降 |
| 上电就烧 | 输入超 36V / 电解反接 / VIN-GND 接反 | 对照阶段 0 |
| 输出振荡 | 反馈线穿过 PH / 输出电容 ESR 太低 | 重走反馈线 |
| 效率只有 70% | 续流二极管用成普通硅管 | 必须肖特基 |
| 一接电机就重启 | 电机启动电流拉低输入 | 加输入电容，或电机独立供电 |
| 可调轨高压档掉压 | 占空比限制（Vout ≤ Vin×0.85） | 提高输入电压 |
| 三路一起开就出问题 | 同时上电拖垮输入 | 检查使能 RC 延时 |
| **反接后板子坏了** | P-MOS 没做背靠背（只装了 1 颗） | 对照第 1 步 1.3 节 |

# 第 2 课：两个接口为什么不能直接拧在一起

> 第 1 课的结论：DC 母座 + 接线端子，两个都装。
> 这节课解决一个自然冒出来的问题：**那把它们直接连起来不就行了？**
> **不行。这课就讲为什么。**

---

## 一、先看"直接并联"是什么样

```
   12V 适配器 ──[DC 母座]──┬──────── 后面的电路
                           │
   15V 电池  ──[接线端子]──┘
```

两个电源的正极都接在同一条线上，负极也接在一起（地）。

**看起来没问题，实际上会出大事。**

---

## 二、会发生什么

两个电源电压不一样（一个 12V、一个 15V），接在一起时：

```
   12V ──────┬────── 15V
             │
        这条线是多少伏？
```

**答案：15V。** 因为电压高的那一边说了算。

**然后呢？关键在这里 ——**

```
   15V 电源 ──→ 顺着导线 ──→ 反向灌进 12V 适配器
```

**电流从 15V 那边流出来，倒着灌进了 12V 适配器。**

| 谁 | 发生什么 |
|---|---|
| **12V 适配器** | 被**反向加电** → 内部电路承受反压 → 轻则保护不工作，**重则烧掉** ⚠️ |
| **15V 电池** | 白白往外放电（给适配器"充电"） |
| **整条线** | 电压由高的一边决定，低的那边完全不干活 |

> **记住这句话：电源不会"只出不进"。你不给它装阀门，它就会被别人灌。**

---

## 三、还有更常见的第二种情况

就算两个电源电压**一样**（比如两个 12V），直接并联也有问题：

```
   12V 适配器 A ──┬── 12V 适配器 B
                  │
   两个都是 12V，谁说了算？→ 电压高的那个（哪怕只高 0.1V）
```

结果：
```
· 电压略高的那个 → 承担全部负载
· 电压略低的那个 → 一点都不出力（甚至被倒灌一点点）
```

**后果：一个电源过热，另一个闲着。** 这不是"并联分担"，是"一个打两份工"。

---

## 四、解决办法：装一个"单向阀"

**单向阀 = 只让电往一个方向走的东西。**

```
   12V 适配器 ──[单向阀]──┐
                          ├── 后面的电路
   15V 电池  ──[单向阀]──┘
```

装上之后：

| 情况 | 结果 |
|---|---|
| 只有一个电源接 | 电顺着单向阀流进去 ✅ |
| 两个都接、电压不同 | **高电压那个供电，低电压那个被单向阀挡住** ✅ 不会被倒灌 |
| 拔掉一个 | 另一个立刻接管，输出不断电 ✅ |

> ⭐ **这就是"OR 电路"：谁有电就用谁。不用开关，不用判断逻辑，自动的。**

---

## 五、单向阀用什么做？

**用二极管就行**（二极管天生只让电流单向通过）。

```
   12V ──▶|──┐
              ├──→ 输出
   15V ──▶|──┘
```

**但二极管有个缺点：它会"吃掉"一点电压。**

```
每颗二极管吃掉约 0.45V
→ 输入 24V 变成 23.55V
→ 3A 电流下，每颗发热 0.45V × 3A = 1.35W  ⚠️ 比芯片自己还烫
```

**所以有更好的做法，第 3 课讲**（用 MOS 管当单向阀，压降只有 60mV）。

## 六、今天的小任务（1 分钟）

**验证一下你的 12V 适配器到底能不能"被灌"** —— 这个不用做，只是让你想清楚一件事：

> 你手边的 12V 适配器，如果被反向加 15V，你猜会怎样？
> （答案：大概率烧掉 —— 因为它是"只出不进"设计的。）

**真正给你的任务是这个：**

用万用表量一下你适配器的输出插头，**确认中心针是正极**：

```
[ ] 万用表拨到直流电压档
[ ] 黑表笔碰插头【外壳】，红表笔碰插头【中心孔】
[ ] 读数应该是 +12V 左右
    → 是 +12V  ✅ 中心针确实是正极
    → 是 −12V  ❌ 这是"中心负极"的电源！这很少见但存在，
                  那我们的电路要改（告诉我一声）
```

---

## 本课小结（三行）

```
① 两个电源不能直接并联：高电压的会把电流倒灌进低电压的
② 也不能"同电压并联"：会变成一个干活、一个闲着
③ 解决办法是每路加一个"单向阀"，做成 OR 电路
```

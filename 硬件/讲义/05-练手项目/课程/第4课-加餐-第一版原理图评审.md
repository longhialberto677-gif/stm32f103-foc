## ⚠️ 问题 1（最严重）：DPSS84 根本扛不住这个电流

**DPSS84（= BSS84 系列）是"小信号 MOS"，不是功率 MOS。**

| 参数 | DPSS84 / BSS84 的实际值 | 我们需要什么 |
|---|---|---|
| 连续漏极电流 I_D | **约 −130mA ~ −200mA** | **6A（输入最坏工况）** |
| 导通电阻 Rds(on) | **约 1.2Ω ~ 10Ω** | **< 50mΩ** |
| 封装 | SOT-23（很小，散热差） | SOP-8 或更大 |
| 耗散功率 | 约 0.2~0.3W | 需要 > 0.5W 余量 |

**算一下会怎样（假设 Rds(on) = 1.2Ω，走 3A）：**

```
压降   = 3A × 1.2Ω = 3.6V        ← 输入 12V 只剩 8.4V ❌
损耗   = 3A² × 1.2Ω = 10.8W      ← SOT-23 封装会瞬间冒烟 ⚠️
两颗串联 → 压降 7.2V、损耗 21.6W  ← 直接烧毁
```

**参照对比（这才是我们要的量级）：**

| 型号 | Vds | I_D | Rds(on) | 3A 时压降 |
|---|---|---|---|---|
| DPSS84 / BSS84 | −60V | −0.13A | ~1.2Ω | **3.6V** ❌ |
| **AO4407A** | −30V | −12A | 13mΩ | **39mV** ✅ |
| SI4459BDY | −40V | −14A | 20mΩ | 60mV ✅ |

> ⭐ **选 P-MOS 的三条硬指标：**
> ```
> ① I_D（连续漏极电流）≥ 电路最大电流 × 2   → 我们要 ≥12A
> ② Rds(on) ≤ 50mΩ                        → 保证压降小、不发热
> ③ Vds 耐压 > 输入最高电压 × 1.3          → 24V×1.3=31V，所以 30V 偏紧、40V 更好
> ```
> **BSS84 这类"小信号 MOS"只适合做信号开关（几毫安），绝对不能用在大电流通路上。**

## ✅ 问题 2：背靠背接法核对 —— 这个你做对了

图上是：**输入 → Q1 的 S，Q1 的 D ↔ Q2 的 D，Q2 的 S → 输出**

```
   输入 ── S[Q1]D ──┬── D[Q2]S ── 输出
                    │
        （共用【漏极】= drain-to-drain）
```

**这正是第 4 课讲的"两个体二极管面对面"。** 判定：✅ 正确。

> ⚠️ 但要提醒一句：**共的是"漏极"（D），不是"源极"（S）。**
> 如果哪天改成 S–S 相接，两颗体二极管方向就一致了 → 反接又有后门了。
> **检查方法：两颗的 D 必须相连。**

## ⚠️ 问题 3：栅极的分压 R39(2.2k)/R40(1k) 会让 MOS 关不断

**先算一下这个分压点电压：**

```
栅极电压 = 12V × R40 / (R39 + R40) = 12V × 1k / (2.2k + 1k) = 12V × 0.3125 = 3.75V
Vgs = 3.75V − 12V = −8.25V  → 管子【完全导通】
```

**问题在于：这个分压让 MOS 一直导通，开关 U9 就失去了"关断"的作用。**

```
U9 是 SPDT 开关，通常是：
  位置 A → 把栅极接到 GND      → Vgs = −12V → 导通 ✅
  位置 B → 把栅极接到 +12V     → Vgs = 0V   → 关断 ✅
```

**但图上 R39(2.2k) 从栅极接到 +12V，R40(1k) 从栅极接到 GND：**

| 开关位置 | 栅极电压 | Vgs | 状态 |
|---|---|---|---|
| 接 GND | 0V（被硬拉低） | −12V | 导通 ✅ |
| 悬空（NC） | 3.75V（分压） | −8.25V | **还是导通** ❌ |

**结果：开关关不掉输出。**

**怎么改（两种，选一种）：**

**方案 A（推荐，最简单）：栅极经 100kΩ 到 GND，不要分压。**
```
   栅极 ──[100kΩ]── GND
   → 一直导通，永远不关（如果你不需要开关功能，就这样）
   → 缺点：不能关断
```

**方案 B（要开关功能）：让开关直接切换栅极，不要用分压。**
```
   U9 公共脚 ── 两颗的栅极
   U9 位置 A ── GND          → 导通
   U9 位置 B ── +12V         → 关断
   + 栅极加一颗 100kΩ 到 GND（做默认状态，防止悬空）
```

> ⭐ **原则：栅极要么被"硬拉到 GND"（导通），要么被"硬拉到源极电位"（关断）。
> 不要用分压器给栅极一个中间电压** —— 那会让 MOS 停在半导通区（既发热又关不掉）。

# 第 4 课 · 加餐 2：用户第二版评审（NCE30P12S 版）

> 用户第二版：Q6/Q7 = **NCE30P12S**，栅极经 **R39 = 2.2kΩ** 接到源极、**R40 = 1kΩ** 经开关 U9 到 GND
> 用户问：**"电阻怎么定呀？"**

## ✅ 器件换对了

| 参数 | DPSS84（第一版） | **NCE30P12S（第二版）** | 需要 |
|---|---|---|---|
| 电流 | 0.13A | **12A** | ≥6A ✅ |
| Rds(on) | ~1.2Ω | **约 8~16mΩ** | ≤50mΩ ✅ |
| Vds | 60V | **30V** | >31V ⚠️ 偏紧 |
| 封装 | SOT-23 | **SOP-8（散热好）** | ✅ |

**两管串联压降 ≈ 3A × 2 × 8mΩ ≈ 48mV** —— 合格。
⚠️ 唯一小遗憾：30V 耐压对 24V 输入余量只有 1.25 倍（靠 TVS 兜底）。

## ⚠️ 问题：R39 接错了位置，导致 MOS 关不掉

**现在是：R39(2.2k) 从【栅极】接到【源极】，R40(1k) 从【栅极】经开关到 GND。**

| 开关状态 | 栅极电压 | Vgs | MOS 状态 |
|---|---|---|---|
| 接通（到 GND） | ≈0V | −12V | 导通 ✅ |
| **断开** | 12V×1k/(2.2k+1k) = **3.75V** | **−8.25V** | **还是导通** ❌ |

**问题所在：开关断开时，栅极被 R39/R40 分压成一个中间电压，
源极在 12V，所以 Vgs 仍然是 −8.25V —— MOS 不会关。**

## ✅ 正确做法：R39 的作用是"关断时把栅极拉到源极电位"

```
      源极节点（S 公共端 = 输入正极）
              │
          [R39 100kΩ]        ← 栅极与源极之间（不是与地之间）
              │
   ───────────┴──────── 栅极 G（两颗共用）
              │
          [R40 10kΩ]
              │
         U9 开关 ──→ GND

   开关闭合 → 栅极下拉到 0V → Vgs = −12V → 导通 ✅
   开关断开 → 栅极被 R39 拉到源极电位 → Vgs ≈ 0V → 关断 ✅
```

**关键点：R39 必须跨接在【栅极】和【源极】之间，而不是栅极和地之间。**
因为 P-MOS 的源极是那颗管子的"参考点"，**栅极跟着源极走，才是真的关断**。
（那个"会不会被分压顶开"的顾虑就没有了 —— 源极抬高，栅极跟着抬高。）

## 📐 电阻怎么定：三步

**第 1 步：R40（栅极到开关到 GND）—— 定"导通有多彻底"**

```
要求：Vgs 足够负，让 MOS 完全导通（不能停在半开区）
取 R39 : R40 ≥ 10 : 1

用 R39 = 100kΩ、R40 = 10kΩ：
  栅极电压 = 12V × 10k/(100k+10k) = 1.09V
  Vgs = 1.09 − 12 = −10.9V  → 完全导通 ✅
  即使输入降到 6V：Vgs = −5.45V → 仍然够导通 ✅
```

**第 2 步：R39 —— 定"关断有多彻底 + 静态电流"**

```
R39 越大：静态电流越小，但抗干扰差
R39 越小：静态电流大

取 100kΩ 的理由：
  静态电流 = 12V / 110k ≈ 0.11mA（几乎不耗电）
  开关断开时栅极被拉到源极电位，Vgs ≈ 0V → 可靠关断 ✅
  栅极漏电流只有 nA 级，100kΩ 上的压降可忽略 → 不会误导通
```

**第 3 步：检查有没有超过规格**

```
[ ] 分压电流 0.11mA 远小于开关 U9 的额定电流 ✅
[ ] 电阻功耗 = 12V² / 110k ≈ 1.3mW，0603 封装足够 ✅
[ ] 不需要考虑开关速度（这是直流通断，不高速开关）✅
```

## 📋 最终电阻表

| 位号 | 阻值 | 接在哪 | 作用 |
|---|---|---|---|
| **R39** | **100kΩ** | 栅极 ↔ **源极** | 关断时把栅极拉到源极电位 |
| **R40** | **10kΩ** | 栅极 ↔ 开关 ↔ GND | 导通时把栅极拉到地 |

> ⭐ **记忆法：**
> ```
> R39（100k）→ 负责"关"，接在栅极和源极之间
> R40（10k） → 负责"开"，接在栅极和地之间，中间串开关
> 比例 10:1 → 保证导通时 Vgs 足够负；1:10 → 保证关断时接近 0V
> ```

## ⚠️ 还有一个必须你自己确认的点：S–S 还是 D–D

**你的图上两颗 P-MOS 的源极（S）相连（共源极）。**
第 4 课我讲的是共漏极（D–D）。这两者**都能工作**，但要注意：

```
两颗体二极管方向【必须相反】（一颗朝左、一颗朝右）
→ 这样才能互相堵死
```

**如果两颗体二极管的箭头都朝同一个方向 → 反接挡不住。**

**怎么确认：**
```
[ ] 看符号里的体二极管箭头：一颗指向中心节点、另一颗背离中心节点 → ✅ 正确
[ ] 如果两颗箭头同向 → ❌ 反接时有一条路是通的
```

**或者更省事的做法：直接照参考图那样，用「一颗源极在左 + 一颗源极在右」的镜像画法**
（这样即使都是共源极，体二极管方向也必然相反）。

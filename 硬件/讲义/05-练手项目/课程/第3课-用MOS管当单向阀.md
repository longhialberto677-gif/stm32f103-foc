# 第 3 课：用 MOS 管当单向阀

> 第 2 课的结论：每路要加一个"单向阀"，防止倒灌。
> 二极管能用，但白烧 1.35W。这节课讲**怎么换成 MOS 管**。

---

## 一、MOS 管是什么

**MOS 管 = 一个电控开关。**

```
   栅极(G) ──┤      ├── 源极(S)
             │ MOS  │
   漏极(D) ──┤      │
```

- **栅极 (G)** = 控制端（决定开关通断）
- **源极 (S) / 漏极 (D)** = 电流进出的两个脚

**它和二极管最大的不同：**

| | 二极管 | MOS 管 |
|---|---|---|
| 怎么导通 | 自动（电压方向对就通） | **靠栅极电压控制** |
| 导通后压降 | 0.45V（固定） | **I × Rds(on)** = 3A × 13mΩ = **39mV** |
| 3A 时发热 | 1.35W ❌ | **0.117W** ✅ |

**差了 11 倍。这就是要用它的原因。**

---

## 二、⭐ 关键：MOS 管里天生带一个二极管

**这是全课最重要的一点。**

```
   实际 MOS 管内部长这样（符号里那个箭头就是它）：

        S
        │
        ├──▶|──┐        ← 体二极管（寄生二极管）
        │      │           方向：从 D 指向 S
        │    ┌─┴─┐
   G ───┤    │ │
        │    └─┬─┘
        ├──|◀──┘
        │
        D
```

**这个"体二极管"是制造工艺带来的，去不掉。它有两个后果：**

| 后果 | 说明 |
|---|---|
| ✅ 好处 | 它天生就是个单向阀 → 反方向自动不通 |
| ⚠️ 代价 | **它的方向是固定的，你想改也改不了**（第 4 课会用到这条） |

**一句话：MOS 管 = 一个开关 + 一个方向固定的二极管，两者并联。**

---

## 三、怎么接成"单向阀"（P 沟道）

我们用 **P 沟道 MOS**（型号 AO4407A：

```
   输入正极 ──── S [P-MOS] D ──── 输出
                 │
                 G
                 │
              [100kΩ]
                 │
                GND
```

**逐脚说明：**

| 脚 | 接到哪 | 为什么 |
|---|---|---|
| **S（源极）** | **输入正极** | 源极要"朝着电源" |
| **D（漏极）** | **输出** | 漏极要"朝着负载" |
| **G（栅极）** | 经 **100kΩ** 到 **GND** | 拉到 0V，让 Vgs 变成负的 → 导通 |

**它为什么自动工作、不用控制芯片？**

```
栅极永远接 0V
→ Vgs = 0 − Vs = −Vs
→ 只要输入电压 > 2V 左右，Vgs 就足够负 → 管子自动导通 ✅
```

**那"单向"体现在哪？**

```
· 正向（输入 → 输出）：管子导通，电流走沟道，压降只有 39mV ✅
· 反向（输出 → 输入）：输出侧电压比输入侧高
   → 沟道想导通的电流方向正好相反 → 不通
   → 体二极管也反偏 → 不通 ✅
   → 两重保险，挡住倒灌
```

---

## 四、⚠️ 最容易接错的地方：S 和 D 别搞反

**这是本课唯一需要背下来的东西：**

```
   ✅ 正确：供电侧 ── S [MOS] D ── 负载侧
   ❌ 错误：供电侧 ── D [MOS] S ── 负载侧
```

**接反了会怎样？**

```
体二极管方向本来就固定：从 D 指向 S 导通
如果你把 S 接到输出侧：

   输入 ── D [MOS] S ── 输出
   体二极管：从 D 指向 S → 正好是"输入 → 输出"方向
   → 体二极管【永远导通】→ 单向阀失效！
   → 两个接口直接并联 → 倒灌又回来了 ❌
```

> ⭐ **口诀：源极朝着电源，漏极朝着负载。**

---

## 五、不用背符号，用万用表就能判断 S/D

**MOS 管的体二极管会告诉你怎么接：**

```
[ ] 万用表拨到【二极管档】
[ ] 红表笔碰一个脚，黑表笔碰另一个脚，看读数
[ ] 读数约 0.5V 的那一次 → 红表笔碰的是【S】，黑表笔碰的是【D】
    （因为二极管档是"红笔出电流"，电流从 S 流向 D 就是正向）
```

**验证方法：**
```
[ ] 找到 0.5V 读数的那两个脚 → S 和 D
[ ] 剩下那个脚就是 G（栅极）
[ ] 把 S 接电源、D 接输出
```

## 七、今天的小任务（1 分钟）

**如果你手边有 MOS 管**（任意型号都行）：

```
[ ] 用万用表二极管档找出它的体二极管（0.5V 左右的那一对脚）
[ ] 确认哪边是 S、哪边是 D
[ ] 想一想：如果这是 P 沟道管，接到电路里该哪边朝电源？
```

## 本课小结（四行）

```
① MOS 管 = 电控开关，导通后压降只有 39mV（二极管是 450mV）
② 它内部天生带一个"体二极管"，方向固定：D → S
③ 接法口诀：源极朝电源，漏极朝负载
④ 栅极经 100kΩ 接 GND，它就能自动工作，不需要控制芯片
```

# 第 4 课：1 颗不够，为什么必须背靠背

> 第 3 课做出来的电路：每路 1 颗 MOS 当单向阀。
> 这节课要告诉你：**它挡得住"倒灌"，但挡不住"接反"。**

---

## 一、先分清两件不同的事

**这是本课的地基，一定要分清：**

| 名称 | 什么意思 | 例子 |
|---|---|---|
| **倒灌** | 电流从**另一个电源**流回来 | 15V 那边灌进 12V 适配器 |
| **反接** | 人**把线接反了** | 电源正极接到了板子的 GND 上 |

**第 3 课那颗 MOS 解决的是"倒灌"。这节课解决的是"反接"。**

---

## 二、反接时会发生什么

**先想清楚一件事：反接不是"输入短路"。**

```
   电源+ ──── 板 GND ────┬──────────────┐
                          │              │
                     [ 470µF 电容 ]      │  ← 后级（电容 + 三颗芯片）
                     [ 三颗芯片   ]      │
                          │              │
   电源− ──── DC座中心针 ──┴──[MOS 体二极管]──┘
```

**电流路径：**

```
电源+ → 板GND → 后级 → MOS体二极管 → 输入− → 电源−
```

**这条路径不经过电源内部** —— 所以不是"输入短路烧电源"，
而是 **"整个后级被反向加电"**：

| 后果 | 说明 |
|---|---|
| 470µF 电解电容 | **被反向充电** → 鼓包 / 爆浆 ⚠️ |
| 三颗 TPS5430 | VIN 被加负电压 → 内部保护二极管大电流 → **烧芯片** ⚠️ |

**算出来的数字（反接 12V 时）：**

```
后级承受的电压 = −11.3V
```

---

## 三、为什么 1 颗挡不住？—— 回到第 3 课那句话

第 3 课说过：

> **MOS 管 = 一个开关 + 一个方向固定的二极管。**

反接时：
```
开关部分：栅极 0V，源极 −12V → Vgs = +12V > 阈值 → 沟道【关断】✅
体二极管：方向固定（D→S）→ 反接时正好是正向 → 【导通】❌
```

**开关关了，二极管却开了 → 电流照样过去。**

> ⭐ **一句话：只要你用 1 颗 MOS，它的体二极管就是一个"永远关不掉的后门"。**

---

## 四、✅ 解决办法：用 2 颗，让两个体二极管"面对面"

```
   输入正极 ── S[Q1a]D ──┬── D[Q1b]S ── 输出
                         │
   （两颗栅极都经 100kΩ 到 GND）
```

**注意中间那条线：两颗的 D 接在一起（这叫"共用漏极"）。**

**这样做的效果是：两个体二极管的方向正好相反。**

```
正接时：
  Q1a 的体二极管：D → S （朝右，和电流同向）✅ 能通
  Q1b 的体二极管：S → D （朝左，和电流反向）❌ 挡住
  → 但没关系！两颗的【沟道】都导通了（Vgs 都是负的）
  → 电流走沟道，压降 = 2 × 3A × 13mΩ = 78mV ✅

反接时：
  Q1a 沟道关断，体二极管挡不住（朝右，正好和反接电流同向）
  → 但反接电流要往左走（输出 → 输入）
  → Q1a 体二极管：朝右 → 反向 → 挡住 ✅
  → 而且 Q1b 的体二极管朝左，它倒是想让电流往左走...
     但 Q1b 需要"中间节点"有电压才能导通，而中间节点被 Q1a 挡住了
  → 结果：两颗互相堵死，电流 ≈ 0 ✅
```

> ⭐ **口诀：背靠背 = 让两个体二极管面对面，互相堵死。**

---

## 五、代价（很小）

| 项目 | 1 颗 | **2 颗（背靠背）** |
|---|---|---|
| 零件数 | 1 | 2 |
| 压降（3A） | 39mV | **78mV** |
| 损耗（3A） | 0.117W | **0.234W** |
| 挡住倒灌 | ✅ | ✅ |
| **挡住反接** | ❌ | ✅ |

**多花一颗 MOS（几毛钱），换整块板子免于"一次接反全废"。**

## 六、电路更新（第 2 次更新）

```
   DC母座(+) ── S[Q1a]D ──┬── D[Q1b]S ──┐
                           │              │
   端子(+)  ── S[Q2a]D ──┬── D[Q2b]S ──┤── VIN_RAW → 后面的电路
                          │              │
   4 颗栅极各经 100kΩ 到 GND            │
   DC座(−) 和 端子(−) 都接 GND ─────────┘
```

| 位号 | 元件 | 数量 |
|---|---|---|
| Q1a / Q1b | AO4407A（DC 座那一路，背靠背） | 2 |
| Q2a / Q2b | AO4407A（端子那一路，背靠背） | 2 |
| R1~R4 | 100kΩ | 4 |

**注意：每路的"输入正极"接** `S`**，"输出"接** `D`**，中间是两颗的** `D` **连在一起。**

## 七、一个白送的好处 ⭐

```
反接时，P-MOS 挡得死死的（电流 ≈ 0）
→ 保险丝/PTC 不会因为反接而跳闸
→ 接反了只要改过来就行，不用换保险丝 ✅
```

## 本课小结（四行）

```
① "倒灌"和"反接"是两件不同的事，1 颗 MOS 只能解决前者
② 反接的电流路径：电源+ → 板GND → 后级 → 体二极管 → 输入− → 电源−
③ 背靠背（2 颗共用漏极）= 两个体二极管面对面 → 反接电流 ≈ 0
④ 代价：压降 39mV → 78mV，多花一颗 MOS
```

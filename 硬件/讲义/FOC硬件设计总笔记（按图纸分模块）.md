## 第 0 讲：整体地图 —— 硬件怎么套进 FOC

FOC（磁场定向控制）一句话：**让三相电流按照你想要的方向和大小流进电机，而不是让电压瞎给。**

控制环：

```
目标转速/转矩
   ↓
① 电流环：算这一瞬间三相各应该流多少电流
   ↓
② 反 Park/Clarke 变换：电流 → 三相电压占空比
   ↓
③ SVPWM：占空比 → 6 路 PWM（3 个半桥的上下管）
   ↓
④ 驱动芯片：PWM 电平太小推不动 MOS → FD6288T 放大
   ↓
⑤ 三相逆变桥：6 个 MOS 把直流"斩"成三相
   ↓
⑥ 电机转起来 → 电流真的按你算的流了吗？
   ↓
⑦ 电流采样：量出来 → 采样电阻 → 运放放大 → ADC
   ↓
⑧ ADC 结果送进 MCU，与①的"应该流多少"对比 → 修正 → 回到①
```

**图纸对应关系：**

| 原理图 | 在 FOC 环里的位置 |
|---|---|
| 电源电路 | 供能；提供母线电压采样 |
| 主控电路 | STM32F103C8T6 = 跑①②③⑧的大脑 |
| 驱动电路 | FD6288T = ④，并负责自举让上管能被驱动 |
| 电流采样电路 | ⑦，最容易被忽略但最影响手感 |
| 外设电路 | 人机交互：LCD / 按键 / LED |
| 通讯电路 | USB 调参 + CAN 组网 |
| 电源稳压 | VCC / VCCA 的物理来源（数字/模拟分离） |

> **核心认知：FOC = 软件算法 × 硬件采样精度。算法再漂亮，采样抄错一点，电机就叫、就抖。**

## 第 1 讲：电源电路

> 图：`eae43bc7c83d356b13b3b1f6405f5b68.png`（960×651）

### 能量链

```
电池/适配器 → 保护 → 开关 → +12V 主轨 → TPS5430 降压 → +5V
```

### 1. 输入端（CN3 = XT30PW-M）

**为什么用 XT30 而不是 DC 圆头？** 因为这是**动力电池接口**。XT30 接触电阻小、能过十几安培；DC 圆头几分钟就发烫。

> **电流等级决定接口形态**：信号线用杜邦线，功率线必须用大接触面积 + 带锁扣的插头。

### 2. 保护三件套

| 位号 | 型号 | 作用 |
|---|---|---|
| F2 | BSMD1812-800-12V | 自恢复保险丝（PPTC），过流自己变阻限流，故障排除后自动恢复 |
| D9 | SMF15CA | 双向 TVS，吸收插拔打火 / 电机反电动势回灌的电压尖峰 |
| Q6+Q7 | NCE30P12S ×2 | 背靠背 P-MOS 总开关 + 防反接 |
| R39 | 2.2kΩ | 栅源上拉 → **默认关断** |
| R40 | 1kΩ | 栅极限流 |
| U9 | SS-12D06-G050 | 手动滑动开关（拉低栅极 → P-MOS 导通） |

**背靠背 P-MOS 为什么用两个？** 单个 P-MOS 的体二极管反向天生导通，只能单向阻断。两个共源反串后，任意方向的电压都被其中一个体二极管挡住 → 既能当开关，又顺手实现防反接。

> **安全底线：所有功率开关，栅极必须有上拉/下拉保证"没信号时是关的"。** 否则上电瞬间 MCU 还没初始化，MOS 乱导通就可能炸管。

### 3. +12V 滤波：C28 470µF 电解 + C29/C30 10µF

| 电容 | 对付什么 |
|---|---|
| 470µF 电解 | 低频大能量：电机变速时母线电流猛变，当"蓄水池"防母线被拉塌 |
| 10µF 陶瓷 | 中频纹波 |
| 100nF | 高频开关噪声，必须**贴着芯片引脚放** |

> **贯穿全板的规律：大电容在入口，小电容贴芯片。**

### 4. TPS5430 降压（+12V → +5V）

| 元件 | 值 | 作用 |
|---|---|---|
| L1 | 15µH | 储能电感 |
| D12 | SS34 肖特基 | 续流。**必须肖特基**：压降仅 0.3V，反向恢复极短（500kHz 下每 2µs 切换一次） |
| C40 | 10nF | **自举电容**（BOOT↔PH），给内部高边 N-MOS 提供浮动栅压 |
| R48 / R53 | 10kΩ / 3.24kΩ | 反馈分压，`Vout = 1.221 × (1 + 10/3.24) ≈ 5V` |
| C44 / C45 | 100nF / 10µF | VIN 就近去耦 |
| C39 / C38 | 220µF / 100nF | 输出滤波 |

> **"5V"不是芯片固定的，是这两个电阻的分压比决定的。** 所有开关/线性电源都是这个套路。

> 💡 C40 自举的套路，在第 3 讲的 FD6288T 上会**一模一样再出现一次**（只是功率大得多）。

### 5. 地：PGND 与 GND 用 R43 = 0Ω 单点连接

功率地上有十几安培的开关电流，会让地线各点产生毫伏级电位差。若运放/ADC 的参考地也跟着晃，测量全是噪声。

**做法：功率电流只走 PGND，信号电流只走 GND，最后用一个 0Ω 电阻在唯一一点汇合。**

### 6. 隐藏联系：母线电压必须被采样

`实际加在电机上的电压 = 占空比 × 母线电压`。电池从 12.6V 掉到 10V 时，若程序还按 12V 算，输出的电压、电流环全部偏。**所以必须有一路 ADC 测母线电压做前馈补偿。**

## 第 2 讲：主控电路

> 图：`c35e27a6aa78ea748034155119681f92.png`（1642×504）

### 1. 两个晶振

| 晶振 | 接脚 | 配电容 | 作用 |
|---|---|---|---|
| X1 = 8MHz | PD0-OSC_IN(5) / PD1-OSC_OUT(6) | C1、C2 = 20pF | 主时钟：8MHz × PLL 9 = **72MHz 系统主频** |
| X2 = 32.768kHz | PC14(3) / PC15(4) | C8、C14 = 10pF | RTC 走时（32768 = 2¹⁵，15 级二分频得 1Hz） |

**72MHz 决定 FOC 电流环的更新率上限**（整套 Clarke/Park/PI/SVPWM 约几微秒 → 电流环可做到 10~20kHz）。

那两颗小电容是**负载电容**，容值必须按晶振规格书来，配错会不起振或频偏。

### 2. 复位电路

```
VCC ──[R3 10kΩ]──┬── NRST(7)
                 ├──[C6 100nF]── GND     ← 滤除电机噪声导致的随机复位
                 └──[按键 TS-1088]── GND ← 救命键
```

### 3. BOOT0 / BOOT1

| 引脚 | 处理 | 含义 |
|---|---|---|
| BOOT0（44 脚） | R2 = 10kΩ 下拉 | 0 |
| BOOT1（复用 **PB2**，20 脚） | R5 = 10kΩ 下拉 | 0 |

两者都拉低 → 从**主 Flash** 启动（正常运行程序）。

> ⚠️ BOOT1 复用 PB2，那颗 10kΩ 下拉会一直挂着。以后想用 PB2 输出高电平时要记得有这个拉扯。

### 4. SWD 调试接口 H1（4 针）

| H1 | 接 |
|---|---|
| 1 | SWCLK → PA14(37) |
| 2 | SWDIO → PA13(34) |
| 3 | GND |
| 4 | VCC |

**为什么用 SWD 而不是 JTAG？** 2 根线 vs 5 根线。**调 FOC 时把 `Ia/Ib/Ic`、`theta`、`Id/Iq` 拖进 Live Watch，一边转电机一边看波形——这是学 FOC 最有效的方式。**

> ⚠️ 如果程序把 PA13/PA14 配成普通 IO 或关了 SWD，**下次就连不上调试器了**，只能靠 BOOT0 拉高进 Bootloader 擦除。这两个脚别乱用。

### 5. 去耦电容：数字 4 颗 + 模拟 1 颗，分开的

| 网络 | 去耦 | 接哪 |
|---|---|---|
| **VCC**（数字） | C9/C10/C11/C12 = 4×100nF | VDD_1/2/3（24/36/48 脚）→ GND |
| **VCCA**（模拟） | C13 = 100nF | VDDA(9) → AGND |
| VSS / VSSA | — | VSS→GND，VSSA(8)→AGND |

**为什么分开？** ADC 的"尺子"就是 VDDA/VSSA：`读数 ≈ 4096 × Vin / VDDA`。VDDA 上有纹波，读数就全错，且错得毫无规律 → **三相电流采样废掉**。

### 6. ⭐ 引脚规划表

| 引脚 | 网络名 | 功能 |
|---|---|---|
| PA8 / PA9 / PA10 | TIM1_CH1 / CH2 / CH3 | 三相上管 PWM |
| PB13 / PB14 / PB15 | TIM1_CH1N / CH2N / CH3N | 三相下管 PWM（互补） |
| PA1 / PA2 / PA3 | 三路电流采样输出 | ADC 采三相电流 |
| PA0 | 分压采样 | NTC 温度 / 母线电压 🔍 |
| PA13 / PA14 | SWDIO / SWCLK | 调试 |
| PA4 / PA5 / PA7 | LCD_CS / LCD_SCLK / LCD_MOSI | LCD SPI |
| PB0 / PB1 / PB10 | LCD_DC / LCD_RES / LCD_BL | LCD 控制 + 背光 |
| PA15 / PB3 / PB4 / PB5 | KEY1~KEY4 | 按键 |
| PB8 / PB9 | I2C_SCL / I2C_SDA | I2C（⚠️ 缺上拉） |
| PB11 / PB12 | LED2(绿) / LED1(红) | 状态指示 |
| PB6 / PB7 | USART1_TX / RX | CH340 串口 |
| PA11 / PA12 | CAN1_RX / CAN1_TX | CAN |

### 7. 四个"为什么"

**① 为什么必须用 TIM1？** STM32 上只有高级定时器具备 FOC 的三件套：

- **互补输出**：一通道自动生成一对反相波形
- **硬件死区**：上下管绝不能同时导通（直通 = +12V 短地 = 炸管）。死区由寄存器设定，**软件写错也不会直通**
- **刹车输入 BKIN**：外部过流信号一拉，**一个时钟周期内**强制 6 路 PWM 进安全状态

**② 为什么是 PA8/9/10 + PB13/14/15？** 这是 F103 的**复用功能固定映射**，不是自由挑的。设计顺序是"先定用 TIM1 互补输出 → 查手册挑脚 → 剩下的分给外设"。

**③ 为什么 PA1/PA2/PA3 采电流？** 同属 ADC1 规则/注入通道（可定时器触发自动采样），且**靠近 VDDA/VSSA（8、9 脚）**，走线短，抗数字噪声。

**④ 37 个 IO 只用一半说明什么？** **FOC 只用 6 路 PWM + 3~4 路 ADC，不到 10 个脚。** 硬件成本主要在功率级和采样精度，不在 MCU 引脚数。

## 第 3 讲：驱动电路 + 三相功率级

> 图：`e1af9a8c19cd4dcd61c89c55b2f3f83b.png`（900×862）

### 1. MCU 为什么不能直接推 MOS？

| 理由 | 说明 |
|---|---|
| **① 电压不够** | Vgs(th) 只是"开始导通"。3.3V 驱动时 MOS 处于半开区，就是个电炉丝（RDS(on)=0.5Ω、5A → 12.5W 发热） |
| **② 电流不够** | 栅极等效电容要给 20nC 电荷，100ns 内充满需 **200mA 峰值**；STM32 单 IO 上限约 ±20mA |
| **③ 上管源极浮动** | 上管源极接 M_U（在 0~12V 间猛跳）。源极 12V 时栅极需 22V，而手上只有 12V → **栅压必须"跟着源极浮起来"** |

### 2. FD6288T 干三件事

[FD6288](https://www.fortiortech.com/en/product/hvic/hvic/fd6288)（峰岹/Fortior，1.8A / 250V / TSSOP-20）：

1. **电平转换 + 电流放大**：VCC 接 **+12V**（驱动电压越高，MOS 导通越充分，RDS(on) 越小；同时 10.5V 在 Vgs 绝对最大额定 ±20V 内）
2. **硬件死区**：保证同桥臂 HO/LO 不同时为高
3. **自举高边驱动**

> ⚠️ 芯片内置死区可能只有几十~一两百 ns，对大功率 MOS 可能不够。**真正的第一道防线是用 TIM1 的硬件死区设 500ns~1µs**，芯片内置死区当第二道。**双重保护，因为直通 = 炸管。**

### 3. ⭐ 自举电路（全讲精髓）

图中：**D1/D2/D3 = FR107**（阳极接 +12V，阴极接 VB1/2/3）；**C3/C4/C5 = 100nF**（跨在 VBx 与 VSx 之间）。

**"水桶垫高"比喻**：要给二楼送水，就在二楼放个水桶，趁没人时从一楼打上去。

```
        +12V ────|>|──── VB1  ← 水桶的水面
                 D1      │
                         ├── C3 (100nF)  ← "水桶"
                         │
   电机相线 M_U ──────── VS1  ← "地板"，在 0~12V 间跳
```

**工作时序：**

```
【阶段一】下管导通 → M_U ≈ 0V → VS1 ≈ 0V
          +12V 经 D1 给 C3 充电到约 10.5V    ← "打水"，必须靠下管导通创造时机

【阶段二】下管关断、上管导通 → M_U ≈ 12V → VS1 ≈ 12V
          C3 电荷不变，"地板"抬高 → VB1 自动变成约 22.5V
          上管栅极 22.5V、源极 12V → Vgs = 10.5V ✅ 完美导通

【阶段三】上管关断 → 回到阶段一充电
```

**由此推出 4 条铁律：**

| 规则 | 原因 |
|---|---|
| ① 自举电容要够大（100nF 典型） | 上管导通期间全靠它供电，电压掉到 8V 以下 MOS 就开始半开 |
| ② 自举二极管要快 | 每周期开关一次。**FR107 够用；进阶可换 SS14 肖特基**（压降更低、自举电压多 0.7V） |
| ③ **占空比绝不能到 100%** | 上管一直导通 → 下管永不导通 → **水桶没机会打水** → 自举电压漏光 → 上管掉电 → 炸。**SVPWM 占空比要限制在 95~97% 以内** |
| ④ 启动要先"打水" | 上电时 C3 是空的，必须先让下管导通几周期充电 |

> 💡 **第 ③ 条是新手最常踩的坑**：为了"全力输出"把占空比设到 100%，电机转一下就停。**这是硬件限制，不是 bug。**

### 4. 栅极驱动网络：慢开快关

```
上管：HO1 ──┬──[R8 10Ω]──┬── Q1 栅极 ──[R9 10kΩ]── Q1 源极(M_U)
            └──[D4 1N4148W]──┘   (阳极接栅极，阴极接 HO1)

下管：LO1 ──┬──[R10 10Ω]──┬── Q2 栅极 ──[R13 10kΩ]── Q2 源极(R19 上端)
            └──[D5 1N4148W]──┘  (阳极接栅极，阴极接 LO1)
```

- **开通**：HO1 变高 → 电流走 **R8 (10Ω)** → 慢一点充上去 → **减小 EMI / 振铃**
- **关断**：HO1 变低 → 栅极电压高于 HO1 → **D4 正向导通** → 电荷被快速抽走 → **关断很快**

**为什么"慢开快关"？** 死区时间是固定的。**关断太慢 → 上管还没关断下管就导通 → 直通炸管**，所以关断必须快。开通慢一点无害，反而抑制 `dv/dt` 振铃。

- **R9/R13 = 10kΩ 栅源下拉**：MCU/驱动还没初始化时栅极不能浮空（浮空栅极会被电机噪声耦合出电压导致误导通）。**还是"默认关断"。**

> 🔍 **细节**：图中 R13 下拉端接的是"Q2 源极 / R19 上端"而不是直接 PGND。大电流时 R19 上的压降会让 Vgs 略微变负 → 关断更彻底（有利），但也略微降低实际驱动电压。电流几安培时压降仅几十 mV，**可忽略**；追求极致时 R13 直接接 PGND 更标准。

### 5. 三相全桥 + 采样电阻

```
     +12V ──┬──────┬──────┬
            Q1     Q3     Q5      ← 上管 ×3 (SL30N02D)
      M_U ──┼──────┼──────┼──→ U3 端子 → 电机 U/V/W
            Q2     Q4     Q6      ← 下管 ×3
         [R19]  [R35]  [R49]     ← 三颗 10mΩ 采样电阻
         10mΩ   10mΩ   10mΩ
          PGND ───┴──────┘
```

**为什么 12V 母线用 30V 的管子？** 电机是感性负载，PWM 开关瞬间寄生电感产生尖峰：`12V + 几伏振铃 ≈ 15~20V`，留 1.5 倍余量是标准做法。**若以后母线升到 24V，必须换 40V/60V 管子**——改板第一件事。

**为什么上管用 N-MOS 不用 P-MOS？** 同耐压下 **N-MOS 的 RDS(on) 只有 P-MOS 的约 1/3**，导通损耗小得多。代价是需要自举——**用电路复杂度换效率，功率电路里永远划算。**

### 6. 三电阻 vs 单电阻 vs 双电阻

| 方案 | 采样电阻 | 优点 | 缺点 |
|---|---|---|---|
| **三电阻（本板）** | 3 | **每相随时可测，波形最干净**，可做完整 FOC + 过流保护，三相同步采样 | 成本高、运放多、需 3 路 ADC |
| 双电阻 | 2 | 省一点运放 | 有一相要"算"，低速误差大 |
| 单电阻（母线） | 1 | 最便宜 | **采样时刻极难控制**，占空比特殊区测不准，低速性能差 |

> **本板选"三电阻 + 三运放"，说明设计者是想认真做 FOC 的。在采样上省钱 = 在 FOC 性能上省钱。**

### 7. 调试四看（示波器）

| 顺序 | 测什么 | 应该看到 |
|---|---|---|
| ① 6 路 PWM | FD6288T 的 6 个输入脚（**不接电机**） | 干净方波，上下管之间有明显空隙 |
| ② 死区 | HO1 和 LO1 同时测 | 两路之间有**几百 ns 的空白**（都不为高）← 保命符 |
| ③ 栅极波形 | Q1/Q2 栅极对源极 | **10~10.5V 方波**。只有 3.3V → 驱动没工作；振铃大 → 调栅极电阻 |
| ④ 自举电压 | VB1 对 VS1 | **稳定 10~11V**。在掉 → 自举电容/二极管有问题，或占空比太满 |

> **上电纪律：先不接电机、用低压（5V 母线）测波形，确认无误再上 12V，最后才接电机。任何一次上电都要假设下一秒会炸。**

## 第 4 讲：电流采样

> 图：`e21a35e8880599ce2be51403b14e0b2d.png`（W 相 U12）、`aa0b5c53c0d9f452b2ae87d95a9ee7c1.png`（V 相 U7/U13）

### 1. 为什么 FOC 必须测电流

只有油门没有速度表，就无法"稳定保持 60km/h"。电机参数随温度变、母线电压会波动、负载会突变——**没有反馈就是开环瞎猜。**

### 2. 四次变换

```
电机电流 I (A)
  → ① 穿过 10mΩ 采样电阻 → V = I × 10mΩ  (毫伏级，ADC 看不上)
  → ② 差分放大 ×15        → 0.15 V/A
  → ③ 叠加 1.65V 偏置     → 0~3.3V 单极性
  → ④ 12 位 ADC 量化      → 0~4095
```

### 3. 为什么必须差分

R19 下端名义上是 PGND，但它是"脏地"——上面有十几安培的开关电流，地线上不同点电位差可达几十~上百 mV 且高频抖动。

- **单端测量**：`真实信号(10mV) + 地线噪声(可能 50mV)` → **噪声比信号大 5 倍，毫无意义**
- **差分测量**：只输出 `IN+ − IN−`，**共模干扰（两个输入端共有的东西）被减掉**

> 💡 **功率电路里测微小信号，永远用差分，永远不要单端对地。**

### 4. 电路拓扑与增益计算

```
                    R32 = 15kΩ
              ┌───────[====]───────┐
              │        ┌───────────┴──────→ PA2 (→ ADC)
    IB- ──[R34 1kΩ]────┤ 4 (IN−)
                         │  U7 (OPA365)
    IB+ ──[R36 1kΩ]────┤ 3 (IN+)
              │          └── 2 脚 → AGND,  5 脚 → VCCA
              │
   VREF ──[R38 15kΩ]────┘
```

**增益**：当 `R32/R34 = R38/R36` 时，`增益 = R32/R34 = 15k/1k = 15 倍`。

**完整传递函数（写代码用这个）**：

```
V_ADC = 1.65V + (IB+ − IB−) × 15
其中 (IB+ − IB−) = I × 10mΩ
```

> ⚠️ **必须保持电阻比例对称**（15:1 = 15:1）。乱配会让共模抑制变差——这是自己改电路最容易犯的错。

### 5. ⭐ 1.65V 偏置：本讲最重要的设计思想

电机相电流是**交流**（有正有负），而 ADC 只能读 0~3.3V。若直接送信号：正半周能测，**负半周完全测不到还可能损坏引脚**。

**解决：把"零电流"抬到量程正中间。**

```
0V ─────────────── 1.65V ─────────────── 3.3V
负电流满量程        零电流              正电流满量程
```

**做法（U13）**：

```
VCCA (3.3V) ──[R1 10kΩ]──┬──[R4 10kΩ]── AGND
                          └──→ U13 的 3 脚 (IN+)
                                U13 的 1 脚(输出) ──┬──→ VREF (1.65V)
                                U13 的 4 脚(IN−) ───┘   ← 输出直接接回反相输入 = 电压跟随器
```

**R1 = R4 = 10kΩ** → 分压比 1/2 → **VCCA/2 = 1.65V**

**为什么分压后还要加运放（跟随器）？**

| 不加 | 加了 |
|---|---|
| 分压点内阻 5kΩ（R1∥R4）。R38(15k) 和它并联会**把 1.65V 拉偏**，且偏差随信号变化 → **基准在动，全错** | 运放输出阻抗≈0Ω，是"硬"电压源，接多少负载都稳 ✅ |

> 💡 **设计口诀：凡是"基准电压"，最后一定要经过缓冲器（跟随器）。看到"分压 + 运放跟随"，就知道在做基准源。**

### 6. 量程与精度（算一遍）

| 项目 | 数值 |
|---|---|
| ADC 参考 | VCCA = 3.3V，12 位 → 4096 刻度 |
| 每刻度电压 | 3.3V / 4096 = **0.806 mV** |
| 零电流码值 | 约 **2048**（量程中点） |
| 采样电阻 | **10 mΩ** |
| 放大倍数 | **15** |
| **总灵敏度** | 0.01Ω × 15 = **0.15 V/A** |
| **可测最大电流** | 1.65V ÷ 0.15 = **±11 A** |
| **理论电流分辨率** | 0.806mV ÷ 0.15 ≈ **5.4 mA** |
| **实际分辨率** | 受运放失调/电阻误差/ADC 噪声影响，约 **50~100 mA**（仍够用） |

> ⚠️ **量程陷阱**：若读数卡在 0 或 4095 不动，说明运放输出**饱和削顶**了。先怀疑量程不够，而不是算法错。**电机峰值电流不能超过 ±11A。**

### 7. 为什么选 OPA365

[OPA365](https://www.ti.com/product/OPA365)：单通道、轨到轨、CMOS 输入、SOT-23-5。

| 要求 | 原因 | OPA365 |
|---|---|---|
| **低失调 Vos** | Vos 会变成固定电流偏移（1mV → 6.7mA 误差） | 典型 40µV 级 ✅ |
| **高带宽/压摆率** | 电流是 PWM 斩出来的，变化极快，跟不上的运放会"平滑掉"真实波形 | **50MHz** ✅ |
| **轨到轨输出** | 输出要接近 0V 和 3.3V，才不浪费 ADC 量程 | 支持 ✅ |
| CMOS 输入 | 输入偏置电流极小（pA），不会在 kΩ 级电阻上产生额外压降 | ✅ |

> 🔍 运放供电是 **VCCA + AGND**（不是 PGND）——正是"模拟地/功率地分开"的又一次落地。

### 8. ⭐ 什么时候采样：时机比精度更重要

Q2 开通/关断瞬间 `di/dt` 极大（几 A/ns），寄生电感产生巨大尖峰，叠加在 10mV 有用信号上 → **信噪比变负**。

**做法：**

1. **TIM1 配成中心对齐模式**：计数器先上数到峰值再下数到 0，峰值/谷值时刻波形对称、三相下管状态可预测
2. **ADC 由定时器硬件触发**（TIM1 TRGO → ADC 外部触发），在峰值/谷值时刻**自动**转换，不需 CPU 干预
3. **三相电流同时采样**（ADC 注入组），保证 `Ia + Ib + Ic = 0` 的约束成立

> 💡 **三电阻方案的额外好处**：三相同步采样，不需要"错开时间采、再推算第三相"，低速性能更好。这就是"认真做 FOC"的具体兑现。

### 9. 软件换算（记住这三个常量）

```c
#define ADC_MID    2048.0f   // 1.65V 偏置对应的码值（零点）
#define GAIN       15.0f     // 运放增益：R32/R34 = 15k/1k
#define R_SHUNT    0.01f     // 采样电阻 10mΩ

float to_amps(uint16_t adc) {
    float volts = (adc - ADC_MID) * 0.000806f;  // 3.3V/4096
    return volts / GAIN / R_SHUNT;
}
```

**`2048` 来自偏置，`15` 来自电阻比，`0.01` 来自 R19。硬件参数一变，代码必须同步改。**

## 第 5 讲：外设 + 通讯 + 稳压

### A. 电源稳压

> 图：`6fde4a3d7922f28e4e465c85429b46e6.png`（975×859）

```
   +5V ──┬──[AMS1117-3.3 (U8)]──┬── VCC  (数字 3.3V) → GND
         │   C32 10µF / C33 100nF │   C31 10µF / C34 100nF
         │
         └──[RT9013-33GB (U11)]──┬── VCCA (模拟 3.3V) → AGND
             C42 1µF / C43 100nF │   C47 1µF / C46 100nF
                                  
   AGND ──────────[R44  0Ω]────────── GND     ← 单点汇合
```

**为什么要两颗 LDO？** 若一颗同时供数字和模拟：MCU 每次逻辑翻转都在 VCC 上产生电流脉冲 → 走线电感 → 高频纹波 → 顺供电线传到 VDDA → **ADC 参考在抖 → 低几位全是噪声 → 采样精度崩掉**。

分成两颗后，**VCCA 是从 +5V 重新稳出来的，不是从 VCC 分出来的**，数字噪声被隔离在另一侧。

**为什么型号不同？**

| | AMS1117-3.3 | RT9013-33GB |
|---|---|---|
| 定位 | 老牌通用，输出约 1A | 低压差、低噪声，约 500mA |
| 压差 | ~1.1V | **~250mV**（效率高、发热少） |
| 适合 | **数字部分**（电流大、不在乎噪声） | **模拟部分**（电流小、要干净） |

> 💡 **原则：敏感的模拟电源要"并联独立取电"，不要"串联在数字电源后面"。**
> ⚠️ **但注意**：两颗 LDO 都是 3.3V、输入同一个 +5V，这还只是"分离"而非"隔离"（+5V 的噪声仍会同时传到两边）。
> **进阶做法**：VCCA 的 LDO 输入串磁珠/小电感做 π 型滤波；或用低噪声 LDO（TPS7A 系列）；最彻底是给 VDDA 用独立基准（REF3033）。**对教学板来说，两颗 LDO 已经很到位。**

**⭐ R44 = 0Ω：三套地的收口**

| 图 | 地的处理 |
|---|---|
| 电源电路 | PGND 用 **R43 = 0Ω** → GND |
| 主控电路 | VSSA 接 AGND；AGND 用 **R44 = 0Ω** → GND |
| 采样电路 | 运放 V− 接 AGND；采样电阻下端接 PGND |

```
PGND (功率地) ← 大电流、强噪声：MOS 桥、采样电阻、驱动 COM
   │ R43 = 0Ω
GND  (数字地) ← 中等噪声：MCU 数字、LCD、按键、USB、CAN
   │ R44 = 0Ω
AGND (模拟地) ← 最干净：VDDA、运放、1.65V 基准
```

**为什么用 0Ω 而不是直接连？**
1. **强制单点**：图上必须画一个明确位置，禁止第二条地回路
2. **可调试**：噪声有问题时可换成**磁珠**（滤高频）或**反并联二极管**（限制地电位差 ±0.7V）
3. **约束 layout**：0Ω 焊盘位置就是汇合点，画板不会乱连

> 💡 **全板接地哲学：功率电流只走 PGND，数字电流只走 GND，测量相关只走 AGND，三者各走各的，最后用 0Ω 拧在一个点上。**

### B. 外设电路

> 图：`e7456c365a64f61ac7c5df97c0b1317d.png`（1198×885）

**LCD（SPI，10 针 FPC）**

| 信号 | 网络名 | MCU 引脚 |
|---|---|---|
| 片选 | LCD_CS | PA4 |
| 时钟 | LCD_SCLK | PA5 |
| 数据 | LCD_MOSI | PA7 |
| 数据/命令 | LCD_DC | PB0 |
| 复位 | LCD_RES | PB1 |
| 背光 | LCD_BL | PB10 → 三极管 Q3（R14 1k、R16 1k） |

**为什么 FOC 一定要屏幕？** 串口太慢：115200 波特率打印一行要几十 µs，而电流环每 50~100µs 跑一次——**打印一行就把控制周期撑爆了**。屏幕能高频刷新人眼可读的信息（转速、三相电流、电角度、母线电压、温度、故障码）。**调 PI 参数时盯屏幕看电流是否振荡，比看串口滚屏直观 10 倍。**

**为什么 SPI 不用 I2C/并口？** 比 I2C 快得多（几十 MHz vs 400kHz）且不需上拉；比并口省引脚（6 根 vs 十几根）。代价是只写不读，且多一根 DC 线。

**为什么背光要三极管？** 背光 LED 电流几十 mA，**超过 STM32 单 IO 的 20mA 上限**。用 PB10 控制基极（微安级），三极管开关大电流——**"用小的控制大的"，和 MOS 驱动电机同一个思路。**

**按键（4 个，上拉 + 低电平触发）**

| 按键 | MCU 引脚 | 上拉 |
|---|---|---|
| KEY1 | PA15 | R17 = 4.7kΩ |
| KEY2 | PB3 | R22 = 4.7kΩ |
| KEY3 | PB4 | R24 = 4.7kΩ |
| KEY4 | PB5 | R28 = 4.7kΩ |

**为什么必须上拉？** 机械开关只有"通/断"两个状态，断开时引脚**浮空**（电压不确定，会被噪声干扰）。上拉把引脚默认拉到高电平，**按下才是低电平**。

**为什么 4.7kΩ？** 太小（100Ω）按下时灌电流 33mA 浪费电；太大（1MΩ）抗干扰弱。

**为什么没有 RC 消抖电容？** 机械按键按下瞬间金属片弹跳 5~20ms，一次按下会被读成好几次。**软件消抖更常见**：

```c
if (read_key() == 0) {      // 第一次读到低
    delay_ms(20);           // 等弹跳结束
    if (read_key() == 0) return KEY_PRESSED;  // 确认 ✅
}
```

> 💡 **进阶**：把按键扫描放进 1ms 定时器中断，用状态机消抖——既不阻塞也不占元件，是实际产品的标准做法。

**LED**

| LED | 颜色 | 限流电阻 | MCU 引脚 |
|---|---|---|---|
| LED1 | 红 | R26 = **1kΩ** | PB12 |
| LED2 | 绿 | R30 = **470Ω** | PB11 |

**为什么阻值不同？** 红灯正向压降约 1.8V、绿灯约 2.2V，且人眼对亮度感受不同。要让两颗看起来一样亮，需要不同限流电阻。

电流估算：绿灯 `(3.3−2.2)/470 ≈ 2.3mA`；红灯 `(3.3−1.8)/1k = 1.5mA`，都远低于 20mA 上限。

**推荐的用法**：绿灯常亮 = 就绪、PWM 未使能；绿灯闪 = 运行中；**红灯亮 = 故障锁存**。

> 💡 **最有用的一招：让红灯在硬件保护（TIM1 刹车）触发时点亮并锁存。** 电机突然停了、不知道原因时，**红灯告诉你是保护动作而不是程序跑飞**——这一颗灯能省你几个小时。

> ⚠️ **隐患 1：I2C 没有上拉电阻**
>
> CN1（HC-1.25-4PWT，4 针）：1=VCC，2=I2C_SCL→**PB8**，3=I2C_SDA→**PB9**，4=GND。**图上找不到任何上拉。**
>
> I2C 是**开漏输出**，器件只能拉低不能拉高。**没有上拉 → 总线永远无法产生高电平 → 完全无法通讯。**
>
> 三种可能：① 上拉在外接模块上（能用，但只能挂一个模块）；② PCB 上有但原理图漏画；③ 真的没有（**接口现在是死的**）。
>
> **STM32 内部上拉约 40kΩ 太弱**：上升沿变慢，400kHz Fast Mode 下波形变"圆角"导致误码。**I2C 标准上拉是 2.2k~4.7kΩ，必须外置。**

### C. 通讯电路

> 图：`e54ff0daa6bd0e9b3de3a17f9ec3bbb6.png`（1279×886）

**USB Type-C + CH340N**

| 元件 | 型号/值 | 作用 |
|---|---|---|
| USB1 | HC-TYPE-C-16P-01E | 16 针 Type-C 母座 |
| R15 / R12 | **5.1kΩ** | **CC1 / CC2 下拉** |
| F1 | SMD0603-075-6 | VBUS → +5V 自恢复保险丝 |
| U4 | CH340N | USB 转串口 |
| C18 / C20 | 100nF | V3 脚 / VCC 脚退耦 |

**⭐ R12/R15 = 5.1kΩ 是 Type-C 的"身份证"**：充电器/电脑通过测 CC 上的下拉电阻判断"对面插的是什么"。**5.1kΩ 下拉 = "我是需要供电的设备（Sink）" → 输出 5V**。不接下拉，很多充电器理都不理你。

**CC1 和 CC2 都要接**——Type-C 线正反插会交换 CC1/CC2，你永远不知道插的是哪一面。

> Type-C 规范里不同阻值代表不同电流能力：5.1kΩ → 默认 USB 电流；想申请 3A 要用专用协议芯片通信。

**CH340N 的 V3 脚为什么接 VCC？**（经典易错点）

- **CH340G（5V 版）**：V3 接 **100nF 电容到地**，**不能接电源**（内部自产 3.3V 给 USB 收发器）
- **CH340N（3.3V 版，本板）**：V3 接 **VCC（3.3V）** + 100nF 去耦

**接错轻则通讯不稳，重则烧芯片。换型号务必查这一脚。**

**串口接法**：CH340N TXD(6) → 网络 CH340 TX → **PB7**（USART1_RX）；CH340N RXD(7) → CH340 RX → **PB6**（USART1_TX）。**是正确交叉** ✅

> 💡 **记法：永远看"信号往哪流"，发送方的 TX 必须接到接收方的 RX。** 图上网络名是站在 CH340 角度命名的，很容易看反。

> ⚠️ 数据线上**没有串联 22Ω 电阻**（通常用于阻抗匹配/限流）。没有也能工作，但 **USB 频繁掉线时，加两颗 22Ω 串联电阻是第一个可以试的办法**。同时 D+/D− 在 PCB 上必须走差分对、等长、90Ω 阻抗。

| RXD(4) | CAN RX | **PA11** | CAN1_RX ✅ |
| S(8) | GND | — | **接 GND = 高速模式**（250k~1Mbps） |

**⭐ 为什么 CAN 两端必须各有一个 120Ω？** CAN 用差分信号，物理上是**特征阻抗 120Ω 的双绞线**。若末端阻抗不匹配，能量会反射回来与原信号叠加 → 波形振铃 → 接收端把振铃当成多个位 → **数据错乱**。并联 120Ω 让末端阻抗"看起来"和线一样，**能量被完全吸收**。

> ⚠️ **隐患 2：板载 120Ω 固定不可断开**
>
> CAN 规范是**最远两端各一个 120Ω，中间节点不接**。
> - 双节点实验（本板 + USB-CAN 分析仪）→ 正好两个，匹配 ✅
> - **挂 3 个以上节点** → 板载 120Ω 与其他并联，总线阻抗被拉低（3×120Ω = 40Ω），可能通讯不稳 ⚠️
>
> **建议改成跳线/拨码选择**（或两个 60Ω 串联中间引出跳线），兼容两种场景。

**为什么电机驱动板要 CAN？**

| | UART | CAN |
|---|---|---|
| 拓扑 | 点对点 | **总线（一条线挂十几个节点）** |
| 抗干扰 | 弱（单端） | **强（差分 + CRC + 自动重发）** |
| 距离 | 几米 | **几十米（低速上百米）** |
| 多主 | 不支持 | **支持（硬件优先级仲裁）** |

**实际场景**：机器人/机械臂一条 CAN 挂 6 个关节电机同步运动；电动滑板通过 CAN 上报转速/电流/温度/故障码；四足/无人机用 CAN 的**硬件仲裁**保证急停指令第一时间抢占总线。

> 💡 **CAN 的核心优势是"硬件级可靠性和实时性"**：每帧有 CRC，出错自动重发；冲突靠 ID 优先级仲裁（ID 越小优先级越高），不需软件处理。**比自己在 UART 上写协议可靠得多。**

**D7 = PESD2CAN**：CAN 可能引到板外走几十米线，静电/浪涌/雷击感应会耦合进来，PESD2CAN 是专为 CAN 设计的双路 TVS。**只要接口引到板外，就必须有保护。**

**没有共模电感**：严格设计会在 CANH/CANL 串共模电感抑制共模噪声。本板没装 → 定位是"板内/短距离通讯"。**要拉到电磁环境恶劣的场合（如电机旁走长线），加共模电感是第一步改进。**

**信号全景（FOC 闭环）：**

```

② TIM1 输出 6 路带死区互补 PWM      ← 第2讲
③ FD6288T 电平转换 + 1.8A 放大 + 自举 ← 第3讲
④ 三相全桥开关，电机线圈过流        ← 第3讲
⑤ 电流穿过 10mΩ → 10mV 级压降       ← 第3讲
⑥ 差分放大 ×15 + 1.65V 偏置         ← 第4讲
⑦ TIM1 在 PWM 峰值硬件触发 ADC      ← 第4讲
⑧ Ia/Ib/Ic 数字量（PA1/PA2/PA3）
⑨ Clarke：Ia/Ib/Ic → Iα/Iβ
⑩ Park（需电角度 θ）：Iα/Iβ → Id/Iq
⑪ PI 调节：Id/Iq vs 目标 → Vd/Vq 修正
⑫ 反 Park + SVPWM → 回到 ①（闭环完成）
```

### 二、⭐ 从 0 到电机转起来：8 步路线图

> **每一关都必须"看到预期现象"才能进下一关。跳步 = 炸管。**

#### 第 0 关：焊接与静态检查（不接电！）

| 检查项 | 方法 | 通过标准 |
|---|---|---|
| 电源短路 | 万用表测 +12V↔PGND、+5V↔GND、VCC↔GND、VCCA↔AGND | **电阻不能接近 0Ω**（应为几百 Ω 以上或电容充电曲线） |
| 元件方向 | 目视 | 电解电容极性、IC 一脚方向、二极管方向 |
| 虚焊/连锡 | 目视 + 放大镜 | 特别是 TSSOP-20（FD6288T）和 SOT-23 的引脚 |
| MOS 桥直通 | 万用表二极管档测 M_U↔+12V、M_U↔PGND | 应能看到体二极管的单向压降，**不能双向都通** |

#### 第 1 关：上电，只看电源（不接电机、不下载程序）

| 测什么 | 在哪测 | 预期 |
|---|---|---|
| +12V | C28 两端 | 输入电压（开关拨到 ON） |
| +5V | C39 两端 | **4.95~5.05V**（TPS5430 由 R48/R53 定） |
| VCC | C31 两端 | **3.3V ± 2%** |
| VCCA | C47 两端 | **3.3V ± 2%** |
| VREF | U13 输出 | **1.65V ± 1%** ← 这是电流采样的零点，必须准 |

> ⚠️ **如果 VREF 不是 1.65V（比如 0V 或 3.3V），先别往下走**——说明基准跟随器有问题，后面所有电流读数都会错。

#### 第 2 关：下载与 SWD 连接

| 步骤 | 预期 |
|---|---|
| 接 SWD（SWCLK/SWDIO/GND/VCC 四线） | 调试器能识别芯片（读 ID） |
| 下载一个最简程序（比如点灯） | LED 按预期闪烁 |
| 确认 PA13/PA14 没被占用 | **能连续两次连接成功**（第一次就把自己锁死的教训很常见） |

#### 第 3 关：只跑 PWM，不接电机（示波器必备）

| 测什么 | 在哪测 | 预期 |
|---|---|---|
| 6 路 PWM 输入 | FD6288T 的 6 个输入脚 | 干净方波，频率 = PWM 频率，占空比可控 |
| **死区** | HO1 与 LO1 同时测 | 两路之间有**几百 ns 的空白**（都不为高）← 保命符 |
| 栅极波形 | Q1/Q2 栅极对各自源极 | **10~10.5V 方波**（不是 3.3V！） |
| 自举电压 | VB1 对 VS1 | **稳定 10~11V** |
| 占空比上限 | 让程序输出 100% | **自举电压会掉** → 证明必须限制占空比（可把上限设到 95%） |

> 💡 **这关可以顺便验证第 3 讲的疑点 4（TIM1 通道与相序交叉）**：只让 CH1 输出 50% 占空比，用示波器看 M_U/M_V/M_W 哪个端子在动。**记录下来，写代码时对应。**

#### 第 4 关：电流采样标定（不接电机）

| 步骤 | 预期 |
|---|---|
| 电机不接（或三相短路但不通电），PWM 关掉 | 运放输出应停在 **1.65V** |
| 读 ADC：`to_amps()` 结果 | **≈ 0A ± 50mA** |
| 检查零点漂移 | 长时间观察，读数不应缓慢漂移（漂移大 → 运放失调或基准不稳） |

> ⚠️ **如果零点不是 0A**：先查 VREF 是否 1.65V，再查 ADC_MID 常量是否为 2048，最后查运放本身。

#### 第 5 关：开环强拖（第一次让电机转）

**这一步最关键的心态：不要做闭环，先开环。**

| 步骤 | 预期 |
|---|---|
| 母线用**低压**（5V 或更低） | 限制故障时的电流 |
| 输出固定频率、固定幅度的旋转电压矢量（开环 V/F） | 电机**平稳旋转**，电流波形接近正弦 |
| 缓慢升频 | 转速跟随，电流不过大 |
| 观察三相电流 | **三相对称、相位差 120°、接近正弦** ← 说明相序和采样都对 |

> ⚠️ **电机抖动/不转/异响** → 立刻停！检查：① 相序（第 3 关记录的结果）；② 电流采样通道对应；③ 死区时间是否过小。

#### 第 6 关：电流环闭环（电压模式 → 电流模式）

| 步骤 | 预期 |
|---|---|
| 目标 `Id = 0`、`Iq = 小值` | 电机出力，`Iq` 实际值跟随目标 |
| 观察 `Id`、`Iq` | **`Id` 应接近 0**（这是"磁场定向"是否正确的判据！） |
| 增大 `Iq` 目标 | 转矩增大 |
| 检查相电流波形 | 仍是正弦，无尖刺 |

> ⚠️ **`Id` 明显不为 0** → 通常是**电角度没对齐**：需要做"电角度标定"（强制一个已知电压矢量、看转子停在哪，据此建立 d 轴与转子的对应关系）。

#### 第 7 关：速度环 / 位置环

| 步骤 | 预期 |
|---|---|
| 加上速度环（电流环是内环） | 转速跟随目标，无持续振荡 |
| 整定 PI：先 P，再加 I | 响应快、超调小、稳态无静差 |
| 突加负载 | 转速能恢复，电流自动增大 |

#### 第 8 关：保护与故障处理

| 保护 | 实现 |
|---|---|
| 过流 | 比较器输出 → **TIM1 刹车输入（BKIN）** → 硬件一个周期内封锁 6 路 PWM |
| 过温 | NTC → ADC → 降额或停机 |
| 欠压/过压 | 母线电压采样 → 停机 |
| 故障锁存 | **红灯常亮 + 故障码显示在 LCD** ← 排查全靠这个 |

### 三、调试工具清单（按必需程度排）

| 工具 | 必需性 | 为什么 |
|---|---|---|
| **示波器（≥2 通道）** | 🔴 必需 | 看 PWM、死区、栅极波形、自举电压、电流波形。**没有它调试 FOC 就是盲人摸象** |
| **STM32 调试器（ST-Link 等）** | 🔴 必需 | 下载 + **Live Watch 实时看变量**（`Ia/Ib/Ic`、`theta`、`Id/Iq`） |
| **万用表** | 🔴 必需 | 电源、短路检查 |
| **可调直流电源（带限流）** | 🟠 强烈建议 | **限流功能是你的安全网**：一开始把限流设到 0.5A，故障时不会炸板 |
| **USB-CAN 分析仪** | 🟠 建议 | 调 CAN 通讯（PCAN / 便宜的 CANable 都可以） |
| **电流钳/电流探头** | 🟡 加分 | 直接看真实相电流，验证采样链路 |
| **热成像仪或测温枪** | 🟡 加分 | 长时间跑，找异常发热（MOS、LDO、采样电阻） |

> 💡 **最省钱且最有效的组合：一块 ST-Link + 一个二手 2 通道示波器 + 一个带限流的可调电源。** 有这三样，FOC 就能调出来。

### 四、⭐ 新手必踩的 10 个坑

| # | 坑 | 现象 | 原因 / 解法 |
|---|---|---|---|
| 1 | **上下管直通** | 上电就炸管 | 死区太小或没配；**用 TIM1 硬件死区设 500ns~1µs，并先不接电机验证** |
| 2 | **自举掉电** | 电机转一下就停、上管发热 | 占空比到 100% → 下管永不导通 → 自举电容补不上电。**限制占空比 ≤95%** |
| 3 | **采样饱和削顶** | 电流读数卡在极值不动 | 电机峰值电流超过 ±11A（本板量程）。**限流、加大量程或用更小采样电阻** |
| 4 | **偏置搞错** | 电流读数恒定偏移、Id 不为 0 | VREF 不是 1.65V，或代码里 ADC_MID 不是 2048。**先测 VREF 再写代码** |
| 5 | **相序反了** | 电机抖动、堵转、反转 | TIM1 通道与电机相序不对应（**本板有交叉，见疑点 4**）。**做"只开 CH1，看哪个端子动"的实验** |
| 6 | **电角度没对齐** | `Id` 明显不为 0、效率低、异响 | d 轴与转子位置没有对应关系。**做电角度标定** |
| 7 | **母线电压没测/没前馈** | 电池掉电后转速、电流都偏 | 必须有一路 ADC 测母线电压并做前馈补偿 |
| 8 | **PI 参数振荡** | 电流/转速啸叫、来回振 | 先只上 P（从小到大），再加 I；**带宽不能超过采样率/10** |
| 9 | **地环路噪声** | 采样噪声大、读数乱跳 | 地没按 PGND/GND/AGND 分开走；或 0Ω 单点被画成了多点连接 |
| 10 | **ADC 采样时刻错** | 电流波形有尖刺、读数周期性跳变 | 没有在 PWM 峰值/谷值由定时器硬件触发，而是软件随便采。**用 TIM1 TRGO 触发 ADC** |

| 3 | **PA0 是 NTC 测温还是母线电压** — 驱动图读作 `VCCA→R6(NTC)→PA0→R7→AGND`（测温），采样图读作电压采样 | 决定保护策略与是否需要母线前馈 | 搜 `PA0`，看 R6 是不是热敏电阻 | 🟠 中 |
| 4 | **TIM1 通道与相序交叉** — 读图显示 `TIM1_CH1/CH1N → HIN/LIN`，而 `HO1/VS1 → M_U`；即 CH1 可能实际驱动 W 相 | 电机抖动/反转/堵转 | 只开 CH1 输出 PWM，看 M_U/M_V/M_W 哪个端子在动 | 🔴 高 |
| 5 | **图纸位号跳跃** — 运放位号 U3/U5/U7/U12/U13，电阻 R1~R54 散落，同一采样链电阻编号不连续 | 说明有多个图纸版本；对位号时须用最终版 | 以最终版图纸为准核对位号与网络名 | 🟡 低 |
| 6 | **I2C 缺上拉**（隐患） | I2C 无法通讯 | 搜 PB8/PB9 或查 PCB | 🔴 高 |

## 一句话总结全板设计哲学

1. **能量从粗到细**：12V → 5V → 3.3V（数字/模拟分开）
2. **地按噪声分级**：PGND / GND / AGND，0Ω 单点汇合
3. **功率开关默认关断**：所有栅极都有上拉/下拉
4. **大电容在入口，小电容贴引脚**
5. **上管必须自举**：所以占空比永远不能到 100%
6. **电流必须差分放大 + 偏置到量程中点**：所以有 10mΩ、15 倍、1.65V
7. **采样时机由硬件定时器决定**：不在干净的瞬间采，再高的精度也没用
8. **FOC 只用 6 路 PWM + 3 路 ADC**，剩下全是保障可靠性和可调试性

## 一、这个项目是什么

**硬件设计已全部学完并整理成讲义；下一步是写软件（FOC 代码）。**

## 四、⭐ 开工前必须先核实的三件事

**这三件事会影响软件能不能跑对，务必先查：**

| # | 查什么 | 在哪查 | 为什么重要 |
|---|---|---|---|
| **1** | **F2 保险丝的实际型号**（3A 还是 8A？） | EasyEDA 打开「电源电路」→ 点 F2 → 看属性"值" | 若是 3A，带 C2208 会误跳闸（正常跑就断电） |
| **2** | **I2C 上拉电阻有没有** | ① 看电机尾部 AS5600 小板有没有两颗电阻<br>② 或在 EasyEDA 搜 `PB8`/`PB9` | **没有上拉 → 编码器完全读不到 → 只能用无感 FOC** |
| **3** | **TIM1 通道与电机相序的对应** | 焊好板子后实测：只让 CH1 输出 PWM，看 M_U/M_V/M_W 哪个端子动 | 对应错了 → 电机抖动/反转/堵转 |

**另有一批"待核实的网络名疑点"（PA0/PA1/VREF/VREF1 的归属），列在：**
`讲义\FOC硬件设计总笔记（按图纸分模块）.md` 的 **附录 B**

## 五、关键设计参数（写代码要用）

### 整块板

| 项目 | 值 |
|---|---|
| MCU | STM32F103C8T6（Cortex-M3，**无硬件浮点**） |
| 主频 | 8MHz 晶振 × PLL 9 = **72MHz** |
| PWM 定时器 | **TIM1**（互补输出 + 硬件死区 + 刹车输入） |
| 6 路 PWM 引脚 | PA8/PA9/PA10（上管）、PB13/PB14/PB15（下管） |
| 三相电流采样 | **PA1 / PA2 / PA3**（ADC1 注入组） |
| 编码器接口 | **CN1**（4 针：VCC / PB9-SDA / PB8-SCL / GND） |
| 串口 | PB6/PB7（USART1，接 CH340N） |
| CAN | PA11/PA12（CAN1，接 TJA1050T） |

### 电源网络

| 网络 | 电压 | 用途 |
|---|---|---|
| +12V | 12V | 三相桥、FD6288T |
| +5V | 5V | 两颗 LDO 的输入 |
| VCC | 3.3V | 数字部分（AMS1117） |
| VCCA | 3.3V | 模拟部分（RT9013）：VDDA、运放、基准 |
| VREF | **1.65V** | 电流采样偏置（= VCCA/2） |

### 地

```
PGND ──[R43 0Ω]── GND ──[R44 0Ω]── AGND
```

### 电流采样链路的关键数字 ⭐

| 项目 | 值 |
|---|---|
| 采样电阻 | **10mΩ**（2512 封装，3W） |
| 运放增益 | **15 倍**（R32/R34 = 15k/1k） |
| 灵敏度 | **0.15 V/A** |
| 偏置 | **1.65V**（零电流对应 ADC 约 2048） |
| **量程** | **±11 A**（相电流峰值） |
| **理论分辨率** | **5.4 mA** |
| ADC 每刻度 | 0.806 mV（3.3V / 4096） |

### 电机（东兴威 C2208）

| 参数 | 值 |
|---|---|
| **极对数** | **7** ← 程序里必须填对 |
| KV 值 | 120 |
| Ke | 0.0796 V/(rad/s) |
| 额定电压 | 12V（最大 24V） |
| 额定电流 | 0.8A |
| **最大电流** | **4.5A** |
| 线电阻 | 21.2Ω |
| 相电感 | 5.3mH |
| 额定转速 | 1800 RPM |
| 编码器 | **AS5600**（I2C，地址 0x36，12 位绝对角度） |

**结论：这块板的量程（±11A）对 C2208（峰值约 2A 相电流）余量 5 倍以上 —— 硬件完全够用。**

## 六、下一步：写软件

**软件部分的路线（第 8 课有详细清单）：**

```
① 只跑 PWM，示波器看死区和 6 路波形
② 打开 ADC，看三个电流值稳定在 0A 附近（电机不转）
③ 电流采样标定（零点 + 增益，用实测值，不要用理论 2048）
④ 读编码器（先做 I2C 扫描，看能不能扫到 0x36）
⑤ 电角度对齐（强制电压矢量 → 记偏移量）
⑥ 开环强拖 → 看三相电流是否正弦对称
⑦ 电流环闭环 → 盯 Id 是否接近 0
⑧ 速度环 / 位置环
⑨ 保护与故障处理
```

**第一版参数建议（求稳）：**

```
PWM 10kHz ｜ 死区 1µs ｜ 占空比限幅 10%~90%
ADC 注入组 + T1_TRGO 触发 ｜ RCR = 1
电流环 10kHz ｜ 速度环 1kHz ｜ 极对数 7 ｜ 电流上限先设 3A
```

## 八、已知的"图纸不一致"汇总（软件前必须确认）

| # | 疑点 | 影响 | 优先级 |
|---|---|---|---|
| 1 | `VREF` 与 `VREF1` 是否是同一个网络 | 三相偏置不一致 → FOC 跑偏 | 🔴 高 |
| 2 | **PA1 被两个电路占用**（过流比较器 vs U 相运放） | ADC 通道映射错 → 电流全错 | 🔴 高 |
| 3 | PA0 是 NTC 测温还是母线电压 | 保护/前馈策略不同 | 🟠 中 |
| 4 | **TIM1 通道与相序是否交叉** | 抖动/反转/堵转 | 🔴 高 |
| 5 | 图纸位号跳跃（U3/U5/U7/U12/U13、R1~R54） | 说明有多版本图纸 | 🟡 低 |
| 6 | I2C 缺上拉（隐患） | 编码器用不了 | 🔴 高 |
| 7 | CAN 终端电阻焊死（隐患） | 多节点组网阻抗失配 | 🟠 中 |
| 8 | F2 型号待确认（3A / 8A） | 带 C2208 可能误跳 | 🟠 中 |

**排查方法：在 EasyEDA 里用"网络名搜索"逐个确认，或焊好板子后实测。**

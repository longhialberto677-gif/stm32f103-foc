## 一、这个仓库是什么

这是一个**学习型仓库**，不是成熟产品代码。它的作用是把我学 FOC 的全过程留下来：

- 每一节课的**讲义**（用"遇到什么问题 → 所以要干什么 → 于是有了什么算法"的方式写）
- 实际写的**驱动代码**（Clarke/Park/SVPWM/电流环…）
- **CubeMX 工程配置** + **Simulink 仿真模型**
- 学习进度、踩过的坑、还没搞懂的疑点

主要资料是中文笔记，放在 `硬件\讲义\` 和 `软件\讲义\` 下。

## 二、硬件平台

| 项目 | 参数 |
|---|---|
| MCU | STM32F103C8T6（Cortex-M3，72MHz，**无硬件浮点**） |
| 电机 | 东兴威 C2208 表贴式永磁（SPM）无刷电机，**极对数 7** |
| 编码器 | AS5600 磁编码器（I2C，地址 0x36，12 位绝对角度） |
| 功率级 | FD6288T 三相栅极驱动 + 6 路 N-MOS 三相桥 |
| 母线电压 | 12V（最大可到 24V） |
| PWM | TIM1 互补输出 + 硬件死区（1µs）+ 刹车输入，目标 10kHz |
| 电流采样 | 10mΩ 采样电阻 → 差分放大 15 倍 → 1.65V 偏置 → **±11A 量程** |
| 电源架构 | 12V →(TPS5430 开关降压)→ 5V →(AMS1117 / RT9013)→ 3.3V 数字 + 模拟双路 |

### 引脚分配

| 功能 | 引脚 |
|---|---|
| 6 路 PWM（上管） | PA8 / PA9 / PA10 |
| 6 路 PWM（下管） | PB13 / PB14 / PB15 |
| 三相电流采样（ADC1 注入组） | PA1 / PA2 / PA3 |
| 编码器（CN1） | PB8-SCL / PB9-SDA |
| 串口（USART1 → CH340N） | PB6 / PB7 |
| CAN（CAN1 → TJA1050T） | PA11 / PA12 |

## 四、怎么用这个仓库

### 只想看笔记
按顺序读：

1. **硬件**：`硬件\项目总览.md` → `硬件\讲义\01-主课\00-课程进度与文件索引.md` → 17 篇主课
2. **软件**：`软件\讲义\01-主课\00-课程进度与文件索引.md` → 按课号顺序

### 想编译代码
1. 用 **STM32CubeMX** 打开 `myself_foc.ioc`（改完外设点生成）
2. 用 **Keil MDK-ARM** 打开 `MDK-ARM\myself_foc.uvprojx` 编译下载
3. 编译产物（`.o/.crf/.axf/.hex` 等）已在 `.gitignore` 排除，clone 后需自己重新编译

> ⚠️ Keil 的用户配置文件（`*.uvoptx` / `*.uvguix.*`）含**本机路径和调试器序列号**，也被排除，所以 clone 后 Keil 的窗口布局和调试器设置要重新配一次。

### 想跑仿真
用 **MATLAB/Simulink** 打开 `仿真\SVPWM.slx`，观察 SVPWM 的扇区切换与三相占空比波形。

### 重新生成正弦表
```bash
python tools/gen_sin_tab.py        # 默认 1024 点表（4KB Flash）
python tools/gen_sin_tab.py 256    # 256 点表（1KB Flash）
```

## 五、FOC 的整体数据流（整门课就是要讲清这一个环）

```
                 ┌──────────────────────── 代码里要写的部分 ────────────────────────┐
                 │                                                                  │
 速度给定 ω* ──►[速度 PI]──► iq* ──┐                                               │
                                  ├─►[电流 PI]──► Ud,Uq ──►[反 Park]──► Uα,Uβ ──►[SVPWM]──► 6 路占空比
 磁场给定 id*=0 ───────────────────┘        ▲                                     │
                                            │                                     │
                                       id, iq ◄──[Park]◄── iα,iβ ◄──[Clarke]◄── ia,ib,ic
                                                                          ▲
                                                              ADC（TIM1 触发，谷底采样）
```

**关键设计数字**（写代码时反复用）：

```
PWM 10kHz  ｜  死区 1µs  ｜  占空比限幅 10%~90%
ADC 注入组 + T1_TRGO 触发  ｜  RCR = 1
电流环 10kHz  ｜  速度环 1kHz  ｜  极对数 7  ｜  电流上限先设 3A
采样灵敏度 0.15 V/A  ｜  零电流对应 ADC ≈ 2048（理论值，实测为准）
```

## 七、已知疑点 / 待核实清单

> 这些是**图纸与实物可能不一致**的地方，会直接影响软件能不能跑对。详见 `硬件\项目总览.md` 第八节。

| # | 疑点 | 影响 | 优先级 |
|---|---|---|---|
| 1 | `VREF` 与 `VREF1` 是否同一网络 | 三相偏置不一致 → FOC 跑偏 | 🔴 |
| 2 | **PA1 被两个电路占用**（过流比较器 vs U 相运放） | ADC 通道映射错 → 电流全错 | 🔴 |
| 3 | PA0 是 NTC 测温还是母线电压 | 保护 / 前馈策略不同 | 🟠 |
| 4 | **TIM1 通道与电机相序是否交叉** | 抖动 / 反转 / 堵转 | 🔴 |
| 5 | **I2C 缺上拉电阻** | 编码器读不到 → 只能无感 FOC | 🔴 |
| 6 | CAN 终端电阻焊死 | 多节点组网阻抗失配 | 🟠 |
| 7 | F2 保险丝型号（3A / 8A？） | 带 C2208 可能误跳闸 | 🟠 |

**开工前的调试顺序**（详见硬件第 8 课）：

```
① 只跑 PWM，示波器看死区和 6 路波形
② 打开 ADC，看三个电流值稳定在 0A 附近（电机不转）
③ 电流采样标定（零点 + 增益，用实测值）
④ 读编码器（先 I2C 扫描，看能否扫到 0x36）
⑤ 电角度对齐（强制电压矢量 → 记偏移量）
⑥ 开环强拖 → 看三相电流是否正弦对称
⑦ 电流环闭环 → 盯 Id 是否接近 0
⑧ 速度环 / 位置环
⑨ 保护与故障处理
```

## 目录约定

每个变更一个文件夹，编号递增、不复用，文件夹内含三样：

- `NN-<名称>.md` —— Markdown 版，便于 `git diff` 与在 GitHub 网页上直接阅读
- `NN-<名称>.docx` —— Word 版，**图片已内嵌**，便于阅读、打印、单独发送
- `img/` —— 原始截图，上面两个版本都引用这里的图

## 怎么加一条新记录

1. 新建 `NN-<名称>/`，编号取现有最大值 +1
2. 截图放进 `img/`，正文按"**现象 → 数据/证据 → 根因 → 待确认 → 下一步**"写；配图用 `![图注](img/xxx.png)` 引用（这样 GitHub 网页上也能直接看到图）
3. 生成 Word 版（图片会自动内嵌，不依赖外部文件）：

   ```powershell
   pwsh tools/md2docx.ps1 -Md "变更记录/NN-<名称>/NN-<名称>.md"
   ```

   脚本直接驱动 Word COM 建文档，不需要 pandoc 等外部工具，输出同名 `.docx` 并自动校验图片确实进了 `word/media`。
4. 在本文件顶部表格里加一行

> 注意：`.docx` 里的图片是内嵌的，所以两份文档内容重复是**故意的**——`.md` 服务于 git 版本管理，`.docx` 服务于阅读和分享。改了 `.md` 记得重跑一次第 3 步。
